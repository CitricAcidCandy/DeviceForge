# 调试器持久日志分页

独立于原百条日志搜索，输入为明确插件和可选代次／日志编号／任务／会话／关键词，输出为安全记录、下一游标与覆盖范围。`LogMetrics` 克隆共用原保留目录、两工作槽和有界游标缓存，不另建日志存储或执行器。

| 文件 | 职责 |
| --- | --- |
| 上级 `debugger.rs` | 公开请求／响应、筛选规范化、两秒绝对期限、受限阻塞工作和游标容量 |
| `scan.rs` | 首次文件窗口、实际时间排序、关联筛选、键集分页与缺口记录 |
| `scan/identity.rs` | 已打开文件的系统身份，Windows 卷号／文件索引及 Unix 设备／inode |
| `tests.rs` | 真实 JSONL 跨 200 条分页、游标绑定、同时间消歧、轮转／追加与共享槽回归 |

游标在宿主内存保存筛选、排序、文件身份和长度、窗口及最后条目的字节偏移。最多 128 项，每个游标有效五分钟，不输出路径。翻页重新扫描固定的有界持久窗口，最多保留本页加一条匹配记录；不会缓存完整日志内容，也不会复用旧接口已截断的百条结果。

固定窗口限制、未完成扫描、缺失关联、坏行及轮转缺口分别返回。日志按追加模式使用；首尾锚点和系统身份用于发现正常轮转／截短／替换，不承诺防止外部程序恶意改写并保留全部元数据。保留范围内未命中不能证明从未发生，完整取完当前页集也不是全量审计或生产验收。
