# 服务器保留日志查询

`../query.rs` 只读部署日志目录中的宿主 JSONL 文件，支持按结构化上下文中的完整 UUID 精确匹配，或按公开消息、日志等级、日志／任务编号、操作、错误码、方法与路由进行关键词匹配。关键词忽略大小写，最多 128 字节；不搜索底层私有字段。返回公开诊断字段及最多 20 个关联任务 ID，不返回文件路径、请求体、令牌或任意附加字段。

默认时间倒序，也可选择升序。时间按 RFC 3339 解析，兼容小数秒和时区偏移；在整个扫描预算范围内保持最多一百条排序靠前的匹配记录，不能先取得旧百条再倒序。关联任务只来自本次实际返回的记录。关键词搜索的结果级 `log_id` 为 `null`，每条记录独立保留自己的日志编号；完整编号查询保持原编号语义。

读取最多两项并行，不排队；阻塞扫描预算两秒，宿主等待上限 2.5 秒。枚举最多 1024 个目录成员、64 份日志、64 MiB 总量，每份最多末尾 8 MiB，单行最多 8192 字节，返回最多 100 条。截断、截止或文件轮转导致遗漏时明确 `limited`，不能把未命中解释为“从未发生”。不修改日志、不强制刷新写入队列、不承担业务操作或任务状态管理。

测试覆盖精确关联、超过前端 200 项后的关键词匹配、截取前排序、升降序、小数秒与时区、私有字段不匹配、无关文本、半行、单行与结果上限、无效查询、容量及截止退出。
