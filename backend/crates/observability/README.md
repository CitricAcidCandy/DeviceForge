# 宿主可观测性

独立跨层支撑库，提供可信日志上下文、配置和结构化日志写入，不依赖领域、用例、基础设施或插件 SDK。日志设计和公开响应见后端 `docs/日志与关联契约.md`。

默认有界 8192 条队列，单条格式化记录最多 8192 字节；超限整条丢弃，不生成半行 JSON。独立写入线程按日轮转，保留最多 14 个本模块命名空间日志文件。统计分别显示队列丢弃、超大事件丢弃、写入字节和 I/O 错误。

仅输出 `apk_`、`deviceforge_` 日志目标，外部 SDK 载荷日志被过滤。正常退出需要保持运行句柄直到业务收敛；强制终止不能保证刷新。本模块不是不可丢失的审计账本。
