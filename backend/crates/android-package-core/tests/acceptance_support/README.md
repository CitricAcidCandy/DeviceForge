# 包核心独立验收夹具

本写集独立于库内单元测试，只使用公开 API。不生成宿主产物、不启动工具/服务，不修改 src/Cargo 或旧 tests。当前第一组已冻结，未编译/格式化/运行；主代理统一执行，未运行的测试不能记为通过。

`acceptance_control.rs` 直接验证过期优先、无截止点取消、动态借用取消状态及原 std::time::Instant 保留，不使用 Tokio 虚拟时间。300 秒未来点用于避免短期限调度抖动，不是真实长任务证据。

`stored_zip.rs` 自行按 ZIP 固定字段构造 Stored local header、中央目录和 EOCD，不调用被测核心或 zip writer。CRC32 的外部固定检查向量为 ASCII `123456789`→`0xcbf43926`、空串→`0`。成员偏移用于只改 payload 制造 CRC 错误，保留两套 header 的 CRC、长度、名称及目录结构；重复成员直接在两个 header 中编码同名，不受生成库去重影响。

`manifest.xml`/`signature.txt` 固定旧成功样本的业务值，文件使用 LF。后续解析必须保留本文件原文；它们不是旧 CRLF 样本的字节身份声明。期望字段由独立测试固定，不能从被测解析结果回算。

基础 control/error/profiles/models 已核对冻结摘要；两组 archive/android 公开签名确认后接调用。实际共 48 个测试函数：Control 6，归档入口 14 加 tree_cases 7，Android/APKS/SDK/XML 回归 21；其中 2 个是夹具校准，46 个调用公开核心 API。参数化坏包变体不冒称额外独立测试数量。

归档覆盖目录保留重名、精确缺/多匹配先于目标创建、CRC 坏选中拒绝与坏未选中正对照、精确限额等值/多一字节、UTF8 名字字节上限、二进制原字节、长度不一致、结构坏尾/分卷/ZIP64/路径/链接。目标长度门闩验证中途取消；只读 File 验证 Io::Write 的原系统错误。APKS 另证全外层读取及内层 CRC 不在保证范围。

树测试分开监测期与最终规则：Reverse 在缺必需成员时可扫描，补齐后才打包；完成 ZIP 按独立中央目录/local header/CRC 读取器比对，不假定 descriptor 的 writer 策略。Splits 的空/非 APK 后缀精确失败与损坏结构失败分别核对；任意合法 ZIP.apk 是结构正对照，不代表可安装 APK。1000 目录与新增一个文件证明目录计数及 profile 差异；长度变更为 SourceChanged，同长度替换不在本组保证范围。

解析固定完整业务值/None/排序/原文、输入文本等值/多一字节、精确错误，以及 SDK 多 DEX/前缀/最多十条且保留检测点。PKG-XML-001 三个独立函数保持修复前期望：namespace 未定义实体拒绝、等价转义 URI 识别、两等价 URI 同本地属性重复拒绝。主代理先保存原生产版本的真实失败，再复验修复版；不会为了旧实现改成宽松期望。

缺少独立 I/O hook 的公开 File API 不足以证明物理零 I/O、sync 失败或严格返回前门闩。本组不增加 hook、不以回调序号假定阶段；大体积/深度/全部 10000 边界和其它完整矩阵条目仍属后续。库测试不代表包工具、协议资源清理、真机或分发通过。
