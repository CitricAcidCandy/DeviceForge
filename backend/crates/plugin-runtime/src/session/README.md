# 协议 5 双向会话运行库

本模块为一个插件进程承载一个持续交互会话。公开入口为 `serve_session(options, handler)` 和可注入管道的 `serve_session_io(reader, writer, options, handler)`，返回 `Result<(), String>`。旧协议 3、4 的运行入口和处理器签名保持不变。

处理器依次接收 SDK 的 `SessionOpen`、已有 `InvocationContext`、`SessionInput` 和可克隆 `SessionOutput`，返回已有 `Execution`。处理器无额外 `Send` 或 `'static` 要求。输出成功入队不等于宿主已经读取；清理 complete 只能来自处理器的真实声明。

## 握手与限额

- 首次读取前校验 `SessionOptions`；默认通道容量 8、累计输入 1 MiB、双路合计输出 16 MiB、握手传输 5 秒、终态传输宽限 2 秒。容量允许 1 至 64，累计输入/输出各最多 64 MiB；传输时间分别必须大于零且最多 30 秒、5 秒。累计限额允许零，零输入限额仍接受空输入块和 EOF，零输出限额仍接受空输出块。
- 公开帧使用 SDK 的版本 5 严格模型。Open 最大 512 KiB，Ready/Start 最大 4 KiB，控制和普通输出最大 65536 字节，终态最大 1 MiB，均包含换行。输入/输出单块最多 8192 字节，保留零字节和非法 UTF-8。
- C0 在 Ready 写出前固定，截止点为 C0 加 Start 原剩余预算。等待 Start 的耗时不会重计，已经到期或先收到取消时不调用业务处理器。握手整体有独立的有界传输等待。

## 输入与输出

`SessionInput::recv(&mut self)` 返回 `Result<Option<Vec<u8>>, SessionIoError>`；空数组返回空块，公开 EOF 关闭输入。EOF 后仍监听取消，重复 EOF 和后续输入会取消会话。输入总量在入队前校验；`try_send` 遇满队列记录失败、撤销业务并继续观察控制，不让排队阻塞取消。

`SessionOutput::send(&self, stream, bytes)` 仅确认有界入队。所有克隆共享异步锁、累计限额和准入顺序；先校验单块和累计总量，获得槽位后才复制。排队、输出传输和管道 I/O 都受同一取消信号及固定业务截止点约束。

正常结束关闭输出准入并排空已准入块，再发送 Finished。所有已发送的两路输出共享从 1 开始的连续序号，Finished 使用下一个序号。取消后丢弃未发送的输出。输出帧尚未写出任何字节时可以取消丢弃；若 JSON 或换行已经部分写出后中断，则等待真实处理器结束后返回传输失败，不将 Finished 拼接到半帧后，也不声称宿主已收到清理确认。

`SessionIoError` 为 `Closed`、`Cancelled`、`Timeout`、`ChunkTooLarge { limit }`、`InputTooLarge { limit }`、`OutputTooLarge { limit }` 或 `InputQueueFull`，不包含输入内容或工具诊断。输入侧协议、限额和队列错误作为会话终态错误公开，业务 recv 收到取消；输出超限同时通知取消，即使处理器忽略 send 错误也不能发布晚成功。

## 取消、清理与终态

主动取消、原业务到期、宿主断流、坏帧、输入队列溢出和传输失败均撤销新的 I/O。首次失败在通知取消之前固定，清理等待超过原截止点不改写此前原因。监督同时驱动控制、处理器和输出；不丢弃已启动处理器来伪造清理完成。处理器不合作时，本运行入口仍等待真实 Execution；后续宿主监督必须保留未确认风险。

真实 Execution 的 cleanup 字段原样进入终态；失败不发布产物。空业务错误归一化为固定失败，超长错误按 UTF-8 边界限制为 4096 字节；超大终态转为有界错误并保留 cleanup，显式 null 结果保持合法。

终态写入、刷新和关闭共享独立 `transport_grace`，不延长业务期限。发送失败仍是传输失败，不证明宿主收到确认。调用方丢弃整个运行入口 Future 会通知取消并撤销 I/O，但无法在被丢弃的 Future 内等待处理器；此时没有成功清理终态，宿主必须保留未确认风险。

本模块不实现宿主 owner/generation、热卸载、容量、HTTP/MCP、终端插件命令、PTY、进程树或远端设备事务。完整交互终端还需要后续实际接线和独立服务、浏览器及真机证据。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `../session.rs` | 加法公开入口、选项预检、握手与终态装配 |
| `options.rs` | 公开默认值、纯配置验证 |
| `io.rs` | 业务输入句柄、输出共享准入与字节限额 |
| `state.rs` | 首次失败、取消和输出准入撤销 |
| `control.rs` | 有界控制读取、共享 EOF、非阻塞输入投递 |
| `pump.rs` | 输出排空或丢弃、连续序号和传输失败回流 |
| `transport.rs` | 固定 C0 握手、有界序列化、半帧处理及终态宽限 |
| `lifecycle.rs` | 并发监督、真实处理器等待与 Drop 未确认语义 |

独立 session 测试由测试角色提供，编译与门禁由主代理统一运行。本说明记录实现合同，不将尚未执行的门禁或内存管道测试计为真实终端迁移完成。
