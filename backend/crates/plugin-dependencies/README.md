# 公开插件依赖契约

本库仅提供版本化声明、验证与版本匹配，不读取环境、文件或网络，不依赖宿主和具体插件。服务器、浏览器及完整功能插件共用同一契约。

独立组件在包根携带 `dependencies.json`，格式为 `{"format_version":1,"dependencies":[]}`；完整发布第二版的 `dependencies` 字段使用相同对象。每项声明稳定工具标识、兼容范围、入口、发现规则、探测、固定下载来源和配置绑定。缺少声明表示没有可推断的工具依赖，不按插件名称猜测。

发现规则的 `environment` 使用环境变量内容作为根；变量直接指向文件时，单入口映射可为 `.`。`path` 使用查找到的程序父目录作为根，入口仍需明确映射。`user_directory` 相对于宿主用户根。相对入口不得越界。真实本机版本必须通过探测获得；仓库候选也可使用经校验的安装元数据。

兼容范围使用 SemVer 语法；四段版本仅支持精确匹配或通配范围。下载来源必须固定实际版本、平台、摘要、大小及全部入口。市场与官方来源独立校验，官方来源只接受 HTTPS。业务参数不允许替换下载地址或本机目标路径。
