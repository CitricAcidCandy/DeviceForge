# 统一发布领域

本模块定义 release.json、安装计划、持久发布视图、资源绑定以及可替换安装存储端口。validation 只处理纯规则：身份、版本、平台、大小、摘要、相对路径和 JSON Pointer；不进行网络、磁盘或进程操作。requirements 表示用户必要输入，tools.bindings 表示宿主工具默认路径，二者不写入配置原值。

每个必要输入可用 `any_of` 声明最多 16 个额外候选配置指针：主 `config_pointer` 或任一候选原值已填写即可满足该输入，多个必填输入仍须分别满足。候选必须是合法 JSON Pointer，不能与主指针或其他候选重复。空候选列表省略序列化，旧声明的字节结构保持不变；敏感字段的满足性由存储端按原值判断，遮蔽视图不能作为填写证据。

恢复受阻状态保留持久启用意图，以有界失败阶段和原因供客户端展示；受阻时拒绝普通生命周期修改。资源回收端口只接受应用取得的运行组件集合与是否预览，不接受客户端指定文件路径，返回相对资源标识和字节统计。

完整跨层接线见后端 docs/contracts/统一插件安装v1.md。新增公开字段后由主程序生成器同步客户端类型。
