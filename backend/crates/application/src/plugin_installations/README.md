# 整套发布操作

`actions.rs` 接收发布标识、预览修订、取消令牌和原执行上下文，输出原 `InstalledRelease`。重载和成功包恢复复用 `PluginService.serialized`、原贡献注册和安装文件事务，不建立调试专用安装器。

一次操作使用 `min(原截止点, 用例进入时刻 + 30 秒)`；排队等待可取消或到期，取得门禁后排空当前事务。工作阶段从同一预算预留末尾五秒供补偿，不能在 HTTP 停止等待或补偿时重启预算。底层开始提交后需排空至稳定视图，物理磁盘阻塞不代表能保证硬实时返回。

重载按整套服务器组件撤销、加载，失败时恢复操作前已加载组件；活动任务冲突沿用原拒绝规则。完整发布的浏览器贡献仍由原共同加载层消费目录并确认，后端宿主激活成功不代表浏览器执行成功。该串行事务不提供跨组件注册表的单指令原子发布。

成功包恢复只使用安装存储独立登记的 `host_activation` 证据，普通事务前版不能作为成功证据。恢复保留操作前启停意图；缺依赖或必填配置时保留启用意图并返回待激活状态。配置、数据库、设备和其他业务数据不属于代码恢复事务。

直接测试位于 `../plugin_installations_tests/actions.rs`，由共享 Cargo 协调方按模块精确执行。
