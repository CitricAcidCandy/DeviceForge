# 插件旧资源后台回收

`plugin_recovery.rs` 负责当前插件代际校验、双并发预算、监督和结果发布；恢复任务同时登记宿主与插件的真实凭据，客户端离开不丢弃任务，卸载和服务停止会取消并等待收口。

`background.rs` 只在旧会话监督结束后续办清理，最多三次、退避零/250/1000毫秒；不重放打开、触摸或其他设备业务。普通调用不等待后台恢复，不因历史告警或正在恢复返回冲突。适配器及插件须逐资源跳过仍在用的资源，不能全插件排他。

告警、恢复报告和本次调用成功资格分别保存。晚到恢复只能清除开始时的风险修订；新故障不能被旧成功清零。真实活动凭据仍影响卸载排空与容量，不以清零状态伪造已释放。
