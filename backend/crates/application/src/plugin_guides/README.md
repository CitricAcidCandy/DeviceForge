# 宿主指南快照服务

输入为完整指南快照和下载缓存端口，输出为实际采用的版本、正文、来源和有界错误类别。正文仍在公开SDK仓库唯一维护；服务不加载插件、不修改调用权限、不提交Job。

首次读取只加载本地缓存，预算2秒，不联网；坏缓存保留现场并回退内置正文。显式更新预算20秒，校验完整的两端八主题、单篇128KiB／整包2MiB、正文SHA-256和内置兼容基线，确认保存后一次性切换。并发更新快速冲突，正常读继续取得旧可用快照；不存在周期轮询或自动写入重试。

网络、解析或保存准备失败不切换内存正文。原子文件提交恰逢取消或到期时，磁盘结果可能未确认；服务明确报告当前正文未切换，不声称已回滚，不自动重试。重启后重新完整校验缓存。`reset`显式采用内置快照且不联网，仍须确认保存。

JSON编码和解析使用两格受限阻塞工作；所有异步端口等待继承同一绝对期限和退出信号。只保留最近16条阶段／错误类别，不回传底层URL、部署路径或凭据。测试使用内存端口，不涉及真实网络、设备或用户缓存。
