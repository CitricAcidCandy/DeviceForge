# 依赖用例

本模块只编排领域端口，不读取文件、环境变量或网络。`DependencyService` 统一查询、检测、安装和卸载后释放引用；`DependencyOperations` 复用任务进度、取消和执行总期限，供 HTTP/MCP/CLI 使用。

- 正常插件安装调用 `ensure`：先检测，兼容工具零下载，只有缺失且可安装的必需项才准备，不递归启用。
- `scan` 供已持有生命周期门禁的调用使用，仅检测与绑定，不下载；管理操作使用 `scan_and_apply`，就绪后按原启用意图恢复待依赖的发布。
- `install` 是缺失/可选补装入口，就绪后仅恢复原本待依赖且保留启用意图的发布，不反复加载活动组件。
- 完整发布组件归属和候选选择由端口实现，不能在此添加平台或插件名单；原生和脚本运行时、浏览器的身份统一为 release/server/browser。
- 工具下载阶段不持有全局插件生命周期锁。组件已提交而依赖失败时保留部署和真实缺项，不伪造成功、不删除原有工具。

`plugin_dependencies_tests.rs` 验证先检测后下载、共享复用零下载、可选项不自动下载、重新检测不下载和取消边界。真实仓库、进程探测、HTTP 与页面另行验收。
