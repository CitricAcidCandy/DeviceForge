# 调试器应用核心

本目录负责有界实例目录、显式目标会话、一次投递桥接和生命周期事件；不引用 HTTP/MCP。服务器操作只捕获已有注册贡献并转交原 Job，不提供第二执行器、浏览器脚本或投屏实现。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `mod.rs` | 服务构造、可替换时钟装配、短临界区和状态通知 |
| `types.rs` | serde 与 schemars 公开 DTO、有限工具和错误代码 |
| `config.rs` | 默认容量、预算和单调时钟；测试可缩小预算 |
| `commands.rs` | 数据输入模式、32步白名单与前向绑定拒绝；不执行业务或编排浏览器 |
| `sessions.rs` | 实例登记、心跳、目录和会话目标选择 |
| `state.rs` | 原子终态、到期扫描、槽位晋升和有界历史 |
| `bridge.rs` | 入队、异步等待、两秒长轮询和回执校验 |
| `events.rs` | 双限额事件环、会话过滤和缺口分页 |
| `validation.rs` | 身份、结构、凭据字段和流式编码字节限额 |
| `server_operations.rs` | 精确代次的原贡献目录与原 Job 提交，复用原业务准入 |
| `tests.rs`、`tests/long_poll.rs`、`tests/generations.rs` | 专项失败路径、可控时钟、通知、跨代选择与重载回归 |

公开类型通过 `apk_application::debugger::*` 导出。装配层创建唯一 `Arc<DebuggerService>`，HTTP/MCP 共用同一实例。服务器目标存在性由装配层在打开或切换目标前检查；核心只作结构验证，不能单凭核心接受就声称服务器目标真实存在。

详细行为与当前证据边界见后端实施文档《插件调试器底座》。本目录不启动后台任务或进程；最后一次访问后的过期记录保持有界，并在下一次访问时回收。长轮询只在本次 Future 内等待通知和计时器。

读取默认 5 秒，普通动作 10 秒，重载传输默认 30 秒；排队与等待共用入队截止点。仅已派发的本次重载可以跨卸载／加载目录间隙，其他旧代命令撤销；回执后必须真实目录确认才可显式选择或跟随新代次，且不重放命令。

数据写入沿10秒动作预算；自动调试作为单条命令使用独立30秒预算，由浏览器在原目标内执行步骤。单个业务投影256KiB、整段参数1MiB，普通旧输入仍为64KiB；协议及绑定规则见后端《插件调试器v1》。
