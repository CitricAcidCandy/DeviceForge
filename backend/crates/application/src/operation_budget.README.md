# 普通操作执行预算与提交资格

`operation_budget.rs` 负责注册预算的纯规则、准入绝对截止点和到期/取消诊断，不读取业务参数或平台名称。实际目标快照决定声明和缺省预算，旧别名复用目标；设备专用预算沿原契约。

`completion.rs` 负责每任务成功资格与显式取消的短时排序。取得存储槽后复核截止点和注册代际，释放注册读锁与任务资格锁后才启动成功事务。资格已被成功取得时，取消只在阻塞工作池或同步兼容边界等待实际结果；失败事务释放资格并唤醒等待者。

`terminal.rs` 单独承担成功、取消与失败终态的存储编排；所有旁路共用资格判断。内部Failure保留类型化清理失败，在尚未取得资格时优先于到期/取消，事务失败复位和重试也保留该原因；已有资格与终态仍不可覆盖。completion仅管理短锁、原因及排空通知，不执行数据库副作用，也不清除owner资源风险。

提交存储、执行和副作用适配分别保留在 blocking、submission、runner 和基础设施中。本模块不修改公开 JobStore 端口，不包含工具调用、平台规则或产品界面。不可中断存储事务、工作池许可与 owner/application tracker 一起排空；Future 丢弃不等于工作停止。

单元测试覆盖纯截止点、父预算收紧、资格/取消竞争和失败复位。独立应用测试、真实进程、HTTP/MCP、浏览器及新分发证据仍须主代理执行；暂停 Tokio 时间不能作为真实长进程或性能证据。
