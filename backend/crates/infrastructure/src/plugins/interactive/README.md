# 独立插件进程会话适配

本目录实现领域 `SessionProvider`，以公开第五版帧和公共双向进程流承载一个会话。普通任务协议 1–4、设备发现及性能采样仍走各自端口；不把逐条输入变成普通 Job，不提供伪终端、进程树或远端资源自动回收。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `definition.rs` | 清单组合校验、领域声明校验、预编译打开参数模式和查表验证 |
| `mod.rs` | 共享清单、模式校验器及粘性未确认状态，纯构造会话与监督 Future |
| `handles.rs` | 有界输入准入、EOF、同步取消、取消安全接收及缓存 ready/wait |
| `transport.rs` | 有界换行帧、跨分片读取和整帧写入准入 |
| `supervision.rs` | 输入副本、握手、原期限、产物发布与监督 Drop 守卫 |
| `supervision/pump.rs` | 同时推进输入、输出、取消、终态校验及真实退出确认 |

插件构造时通过 `SessionDefinition::validate(plugin_id)` 复用命名空间、对象模式、文档内引用和预算规则，再编译 JSON 模式。`ProcessPlugin` 持有按完整会话操作 ID 索引的共享校验器；`open` 只查表和验证打开参数，不编译模式、不启动进程、不准备文件。应用应在原子资格判断中登记 supervisor，随后锁外运行；会话归属及 generation 由应用固定。

## 输入与等待

输入队列容量为 8，原字节累计上限 1 MiB，单块最多 8192 字节。send 与 eof 共享互斥准入顺序，先预留容量再复制；空块不是 EOF，EOF 后输入和重复 EOF 拒绝。等待 ready、互斥锁或队列容量时均观察取消、撤销与原截止点。

取消不等待输入队列；监督撤销新的数据准入，独立发送 Cancel 并继续读取终态。普通控制帧整帧不超过 65536 字节，与底层单块大小一致；被丢弃的待发送 Future 未准入的帧不会残留半帧。已准入的帧按底层顺序完整写入，取消帧不插入其内部；底层写入失败或宽限到期无法证明可靠传输时保留未确认。Open 可以跨多个底层块；握手中断后强制收口，不在不可靠字节流后拼 Cancel。

ready 缓存握手结果。监督先发布真实 ready/exit，再撤销输入；已挂起的 ready 等待同时被结果和撤销唤醒时，再读已发布结果，避免把真实失败误写成普通输入关闭。recv 不取走未完成接收的输出，None 仅表示输出结束。wait 排空并丢弃未读输出，避免无消费者卡住终态；完成后重复返回同一共享记录，丢弃等待 Future 可以重新等待。

## 期限与资源确认

原业务截止点 D 覆盖准备、握手和业务。业务取消通过第五版 Cancel 传递，底层 `spawn_stream_with_lease` 使用独立强制取消 token，硬期限为 D 加清理和退出宽限；当前合作清理最多 5 秒，终态后等待直接进程退出最多 2 秒，不重启或延长业务预算。输出原字节双路合计最多 16 MiB，传输编码另有限额，诊断 stderr 不进入业务输出或日志。

匹配会话 ID、连续共享序号、唯一有效 Finished、明确 complete 及真实进程成功退出全部成立后才记 Complete。有效终态明确 failed 时记 Failed；缺失或坏终态、强制终止、非零退出、监督 Drop 记 Unconfirmed。真实 Finished 的 sequence 单独保存，取消丢弃输出后不猜序号。process_exited 只证明直接进程退出，不能证明派生进程或远端资源已释放。

业务尚未启动时单独确认：准备阶段拒绝且未创建进程，或取消/到期发生在从未尝试写入 Start、直接插件进程已确认回收的阶段，可以记 Complete，并保留原失败原因及空业务结果。协议5提供者在 Start 前不得调用业务处理器。只要尝试过 Start 写入，即使写入结果不明确，也继续按可能已启动处理，不能凭直接进程退出降低清理要求。

客户端句柄 Drop 仅请求合作取消，不 abort 监督。监督继续持有输入副本租约；公共进程层在直接进程退出确认前持有同一租约。已启动进程的清理未确认须粘性标记 unresolved，后续成功不能清除，provider 拒绝新的 open，宿主应阻止卸载完成和同 ID 重载。未轮询监督被丢弃时，通道 Drop 发布缓存 Unconfirmed 并撤销句柄，不虚构进程退出。

测试由独立 `infrastructure/tests/interactive_sessions*` 覆盖真实插件进程。适配器通过不表示宿主注册卸载、HTTP/MCP、终端界面、真机或外部资源验收全部完成；集成构建与服务门禁由主代理执行。
