# 插件装载关联规则

`execution` 只校验普通预算并映射贡献，设备与采样不能重复声明普通预算。`performance` 校验性能 API 与协议的组合、同提供者精确能力及严格采样封套，再映射领域来源；不持有设备观测、会话或执行器。

API 1 仍只接受协议 2 且禁止整个插件产物授权。API 2 只接受协议 4 与设备 API 3 的同贡献 device/read 能力，允许其他贡献使用产物；选择器不得触达采样封套。实际调用仍由 `ProcessPlugin` 按精确采样贡献清空有效产物权限，并在成功或失败响应发布前拒绝非空输出。

协议资格和纯规则的测试不能替代真实进程对空产物上下文及零发布的验证，也不能代表会话热卸载或真机指标通过。
