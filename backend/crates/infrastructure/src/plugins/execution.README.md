# 普通操作预算映射

`execution.rs` 只校验清单的显式普通预算并映射领域贡献。`execution` 缺省或为 null 时保留 `None`；显式声明映射为 `OperationExecutionSource::Declared`。普通操作的默认 60000 毫秒预算由应用注册层固化，安装和进程映射不代填默认值。

发现、设备能力和性能采样按清单中的实际 operation 关联判断，不按平台名判断。这些操作已有专属预算，不能在同一贡献上重复声明普通预算。同插件其它普通贡献可以独立声明 1 至 3600000 毫秒的预算。

native 和 Node 的 ZIP/TGZ 安装保留原 `Contribution.execution`，生成运行清单后仍走 `ProcessPlugin` 校验。浏览器清单不加入服务器预算字段。

`ExecutionContext.deadline = Some(D)` 时，输入副本、进程运行、响应校验和全部输出发布共用同一绝对截止点，不重新申请 60 秒或 120 秒阶段窗口。`None` 保持兼容阶段期限。已经到期且收到外层取消时报告 `Timeout`；到期前观测到的显式取消保持 `Cancelled`，清理未确认始终保留 `CleanupFailed`。

期限不等于阻塞工作已经停止：输出内容验证闭包继续持有临时目录，进程调用继续等待原有有界清理，Future 丢弃的资源标记沿用原守卫。多个产物发布不是事务，期限前已提交的产物不会因后续超时自动回滚。

本批新增纯映射、便携包和期限分类回归源码。按协作约束未运行格式化、编译或测试，运行证据由主代理统一提供。
