# 工具租约恢复债务

本模块只负责宿主工具仓库读锁、直接进程退出凭据与调用债务，不核对设备资源，不解释插件恢复报告，不清除清理风险标记。

## 身份与接线

- `acquire(path, cancel, deadline, &unresolved)` 将一次调用登记到同一 `Arc<AtomicBool>` 对象身份下。标记的布尔值不是身份；新建相同布尔值不能解锁旧组。
- `recovery_ready(&Arc<AtomicBool>) -> bool` 只表示该组是否已全量排空：没有活动调用，且全部保留调用已确认真实直接进程退出；空组返回真。它不是后台逐旧资源核对的准入门禁。
- `confirmation.rs` 独立负责确认范围。`ToolLease::recovery_snapshot(&unresolved)` 只记录核对开始时已退出且 inactive 的历史调用编号和 Weak 身份，不持有工具读锁或插件强引用。
- `confirm_recovery(&snapshot)` 只确认该快照内的历史，不撤销任何活动登记或工具锁。同 owner 的新活动调用不阻止旧历史确认；在途未退出及核对期间晚到的失败债务仍保留并返回具体 busy，不以另一条资源未结束阻止已经核对的历史前进。重复旧确认也不能覆盖新债务。
- 核对报告、匹配协议响应、清理 Complete 与真实零退出全部成立后才可确认。只有同一台账临界区内确实没有当前调用或新增债务，也没有核对期间发生的历史折叠，快照确认才清除 `unresolved`；仍有新活动调用时保留诊断，不为清标记强制结束新调用。主调用者继续负责 owner、代际、恢复编号及风险修订。
- `confirm_recovery(&Arc<AtomicBool>)` 保留全量排空调用者的保守语义，不直接清理 `unresolved`；后台恢复不再用该形式。单纯改布尔值或只看到业务 tracker 为空不会释放仍被资源持有者使用的工具锁。

## 退出凭据

合作进程的 `Owner::wait` 只在系统 wait 成功时记录退出；已知退出在返回前同步释放 Owner 与清理守卫，恢复调用本身不会遗留异步活跃登记。未完成等待才由 Drop 移交后台，后台 reap 成功继续更新同一调用。等待失败、丢失运行时或后台被丢弃都不伪造退出。

会话监督在真实退出结论已知时记录凭据，另把专用 `ProcessLease` 交给公共工具进程所有者。公共库仅在未启动或确认真实 wait/reap 后正常释放该对象；回收失败时保守保留。因此外层会话监督丢失后，晚到的后台成功仍能补上凭据。这个对象不能交给任意普通业务 Future 当作退出探针。

`ToolLease::retain` 保留外部债务，不把仓库读锁永久绑定到外部恢复。真实直接进程退出已确认，且最后一个调用持有者结束后，释放不再需要的仓库读锁；如果业务持有者先结束、后台系统退出凭据后到，先保留读锁，再由同一调用的退出凭据释放。其他活动调用的锁保持不变。直接进程已退出不代表外部资源已释放，历史记录和 `unresolved` 不因新调用成功而清零。

## 有界与可见性

每个 owner 最多 64 个活动或退出未确认的调用，单宿主最多 256 个此类组、4096 个此类调用；达到真实资源占用上限时启动前明确返回冲突，不释放未知退出进程的锁。已退出且调用持有者已结束的旧债务移出这组额度，不会因历史失败累计而永久拒绝新登记。

已退出调用的外部债务明细独立保留最近 4096 条，包含原 owner 的 Weak 身份与调用编号，不持有仓库读锁。超限只将最旧明细折叠到饱和未确认计数，并产生结构化警告，不宣告这些外部资源已清理。活动表只持有必要读锁和 Weak，不持有 ToolLease/owner 的强引用，没有 Arc 环；未知退出的孤立资源仍受实际占用保护。

台账互斥异常保留 `uncertain` 诊断，登记新调用仅告警，继续检查具体资源占用；正常新调用不因此生成伪债务。显式确认仍须拒绝在台账不可信时宣告风险清除。日志只记录数量和本机调用编号，不记录原始插件输出或敏感配置。

## 验证边界

`recovery_tests.rs` 覆盖旧进程仍持有、旧失败后新调用、已退出历史不占活动额度、真实仓库写锁释放、晚到退出不释放新调用锁、身份区别和协议4恢复返回后同步排空，另补同 owner 活动新调用下的重复确认、晚到失败及晚到 reap 不被旧快照冲销。`recovery.rs` 的隔离测试覆盖历史明细上限、台账诊断不阻断新登记及部分确认不覆盖其他 owner；插件恢复测试验证存在新 active 时真实运行核对、未退出债务保留 busy。本补丁只做定点格式及差异检查，测试交主代理统一 Cargo 执行；不代表真机、浏览器投屏或完整恢复产品流程已验收。
