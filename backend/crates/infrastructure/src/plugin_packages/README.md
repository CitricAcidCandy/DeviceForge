# 有界插件包文件适配器

构造 `FilePluginPackages::open(server_root: &Path, browser_root: &Path, node_binary: Option<PathBuf>) -> Result<Self>`。服务器根目录必须与 FilePluginCatalog 的部署根相同；浏览器使用独立根目录。旧 Node 入口来自管理员参数或 PATH；新脚本入口通过公开 dependency 引用解析共享运行时，包不能选择机器程序路径。

上传最多 64 MiB，解包总量最多 256 MiB，单文件最多 64 MiB，条目最多 4096，清单最多 64 KiB，归档准备期限 120 秒，后续依赖准备沿用有界执行期限。准备工作最多 2 个，文件工作池最多 2 个，静态读取最多 8 路；已安装列表最多 256 项。每个根目录持有独占部署锁，暂存与发布在同一卷。

`archive` 负责 ZIP/TGZ 有界展开，`paths` 负责相对路径/链接/边界，`manifest` 负责便携声明与 ProcessPlugin 映射，`storage` 负责发布和读取。拒绝绝对路径、越界、反斜杠、设备名、链接、重复文件及不完整归档。暂存结果由资源守卫拥有，错误与取消均清理本次目录。

普通点文件与点目录属于合法包资源，包括单清单打包器生成的 `.deviceforge-entry.js`；不能用“以点开头”作为拒绝整个插件的条件。归档展开、便携入口验证和旧包静态读取共用同一规则，`.deviceforge-package.json`、`.deviceforge-runtime.json` 仍为宿主元数据保留名。完整发布的组件解包使用发布路径规则，随后同样通过便携入口验证；回归同时覆盖 ZIP/TGZ 安装、格式 2 更新和入口原字节读取。

安装发布只采用目录原子重命名，普通安装不覆盖同 ID。独立更新在完整验证后持有部署锁，将旧目录移入本次暂存，再同卷发布新目录；发布失败恢复旧目录，回滚失败保留旧副本。列表和资源读取共用该锁，不观察中间状态；不承诺突然断电下的事务恢复。不会执行安装脚本或访问 npm registry，脚本业务模块须随组件携带，工具与解释器通过统一依赖声明准备。本模块只管理可信代码部署，不宣称进程隔离或常驻会话。
