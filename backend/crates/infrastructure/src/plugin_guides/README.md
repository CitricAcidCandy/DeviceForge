# 指南下载与缓存适配

`HttpGuideStore`实现领域层`GuideStore`。输入为装配时明确的缓存目录、指南来源以及每次调用的绝对截止点和取消信号；输出为不超过2 MiB的完整字节，不解析正文、不判断兼容性、不切换应用层当前版本。

来源只允许HTTPS；为本机测试保留回环HTTP。来源和每次重定向均拒绝凭据与片段，最多三次重定向，HTTPS不得降级为HTTP。下载客户端独立创建，不携带业务API令牌、Cookie或来源认证头；读取与下载只在调用时发生，无后台轮询、定时更新或自动重试。HTTP状态失败、内容长度或分块累计超限均明确失败。

缓存固定为给定目录内的`current.json`，读取不存在时返回空，超大、非普通文件和符号链接拒绝。文件操作放入最多两个持有许可的阻塞工作，保存另限制一个写入者；等待许可、排队、逐块操作和网络等待共用同一截止点。取消或期限到达会阻止尚未开始的提交；迟到工作不会自行获得新的提交资格。

保存先以唯一名称和`create_new`创建本次暂存，分块写入并执行`flush/sync_all`，最后在同一目录原子替换。准备、下载及实际替换失败保留旧快照，不先删旧文件，不扫描目录或删除他人的暂存。自有暂存在所属阻塞工作退出时清理。

操作系统已经开始原子替换但结果尚未返回时，取消或到期不能被描述成已经回滚；此时返回固定的“指南缓存提交结果未确认”错误，不自动再执行。应用层只能在保存确认成功后切换内存版本；下一次读取或重启发现磁盘有效内容不同，必须重新执行完整的结构、摘要和兼容性校验。底层文件系统若永久阻塞，最多占用已有两个工作许可，宿主等待按原期限结束，不再累积无界文件工作。

定向单元仅测试本模块：`cargo test -p apk-infrastructure plugin_guides::tests --lib -j 1`。测试临时文件在工程所在G盘的独立`artifacts`目录；本机HTTP仅使用随机回环端口，所有处理任务在测试退出前收齐，不访问用户服务、设备或真实指南来源。
