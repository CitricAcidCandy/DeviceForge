# 用户目录统一安装适配器

mod 负责装配、有限工作池和目录排他锁；fetch 负责流式获取与摘要缓存；prepare 负责便携组件映射、工具选择和计划；content 负责普通文件清单；paths 负责路径边界与原子写入；transaction 负责活动视图、CAS 提交和中断恢复；storage 负责持久查询、启停记录和不可变浏览器资源。

所有安装写入均位于构造器传入的用户根。配置目录不在安装写集内，程序升级和删除保留旧版本、共享工具及配置。事务恢复不能确认完整性时初始化明确失败；不以空记录掩盖损坏。当前缓存与历史程序没有自动回收策略。

测试覆盖真实离线 ZIP、摘要拒绝、版本身份不可变、CAS、旧程序与配置保留、字节资源及日志恢复。完整验证命令由主流程统一运行。
