# 设备提供者进程映射

声明从公开 SDK 映射成领域定义，引用必须属于插件实际贡献，能力版本、范围、读写和输入形状有界校验。发现结果先反序列化公开消息并校验最多 128 台、重复本地 ID、声明能力与描述长度；无效结果返回 dependency_failed，不进入宿主目录。

发现贡献必须接受空对象。能力贡献验证标准 device_id/input 封套结构、显式字段类型与模式编译，不要求业务 input={} 或任意固定设备 ID 合法；业务必填字段、pattern、enum 在实际任务提交时验证。复杂模式的可满足性不做静态推断。

ProcessPlugin 沿原协议 1/2/3 执行离散任务；该模块不缓存设备、不调度第二套任务、不添加平台分支。便携安装保留 devices 声明，安装不执行代码；此阶段不是常驻连接或全平台迁移。

协议 1 保留发现数组，协议 2/3 保留宿主产物包装；应用只识别完整 result/artifacts 包装，不把任意业务 result 字段拆开。坏清单的安装校验使用 invalid_input，已有数量/体积上限保留 TooLarge。协议 2/3 可输出产物，严格设备封套的嵌套输入产物选择仍待协议加法设计。
