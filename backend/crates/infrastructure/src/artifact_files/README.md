# 受控临时产物文件

作用：把 ArtifactStore 数据流复制为部署工具可读取的独占临时文件，统一安装和分析模块的 SHA-256 校验与临时目录生命周期。适用于必须接收文件路径的本地工具。

快速开始：基础设施模块调用 materialize(store, id, extensions, cancel)，在工具执行完成前保留返回的 Materialized。

API：materialize 接受领域存储端口、产物 ID、允许的扩展名和取消令牌；返回元数据、受控路径及目录所有权。单文件最大 64 MiB，复制期限 120 秒，按块核对大小和 SHA-256。文件后缀由允许列表选出，工具不能从用户输入选择服务器路径。

Temporary 是内部资源守卫；正常退出删除本次创建的独占目录，Windows 文件占用时后台最多重试 10 秒。Materialized.directory 使用 Arc，以便阻塞解压线程与异步发布共同持有目录，避免任务 Future 被取消后删除仍在处理的输入。异常终止可能留下系统临时目录，当前不执行全局扫描。
