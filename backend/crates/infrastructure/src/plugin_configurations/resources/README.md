# 托管工具配置模式补齐

`schema.rs` 是有效配置快照的纯变换规则，输入公开配置模式、用户值、绑定指针与托管入口，输出补齐后的值或明确错误。它不读取文件、不保存配置、不修改修订，也不识别官方插件 ID。

仅沿绑定经过的对象、已有数组项、本地引用及组合模式展开，补齐缺失的必需 `const` 字段；已有常量冲突时排除该分支。相同输出合并，不同输出保留歧义错误。普通开放对象、字典和模式键延续路径绑定；展开数量和递归深度有界。最终完整模式校验由 `resources.rs` 在全部绑定完成后执行。

相邻测试使用 Android 两插件的真实公开模式，并覆盖第三方普通路径、分支冲突、歧义、本地引用、组合模式和数组指针；资源集成测试另核对状态与不可变修订原字节不变。
