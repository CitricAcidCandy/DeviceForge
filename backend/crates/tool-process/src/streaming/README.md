# 有界双向工具流

本模块公开同一直接进程的持续 stdin/stdout/stderr，不解释文本、平台命令、插件帧或 PTY。调用方用独立 argv 准备 `ToolCommand`，不得设置 `input`；运行时输入通过可克隆的 `StreamingInput` 发送。

## 接口与限额

- `spawn_stream(command, options, cancel)` 返回会话；租约版本在末尾追加 `Arc<T: Send + Sync + 'static>`。
- `StreamOptions::new(execution)` 沿用 `ExecutionOptions` 的绝对截止点、两路累计输出限额及清理期限。默认分片 8192 字节、通道容量 8、累计输入 1 MiB；分片允许 1 至 65536 字节，容量允许 1 至 64。输入累计限额可为零，此时仍可发送空块和 EOF。
- `input().send(bytes)` 成功只确认入队，不保证工具已读取。共享异步锁排序所有克隆的输入和 EOF；获得队列槽位后才复制，取消的排队不计入累计限额。`chunk_size` 同时限制输入单块。
- `input().close()` 将 EOF 排在此前准入的块之后；所有克隆随即拒绝后续输入及重复关闭。空字节不是 EOF。输入错误独立为 `Closed`、`ChunkTooLarge` 或 `InputTooLarge`。
- `recv()` 返回带 stdout/stderr 标识的原始字节，单路保序，不保证跨管道的全局顺序。所有输出块仍计入原累计输出限额；返回 `None` 只表示输出通道关闭，直接进程及清理结果须通过 `wait` 获取。
- `wait()` 排空并丢弃未读输出以解除背压，返回真实退出状态和两路累计字节。非零退出是正常 `StreamExit` 数据；输出、超限、取消、期限或清理失败仍使用原执行错误。成功取得终态后再次等待返回配置错误。

## 生命周期

stdin 写入、两路输出和直接进程等待并发驱动。工具退出立即撤销输入，用户无须先关闭输入。工具主动关闭 stdin 时不将 BrokenPipe 当作退出状态；仍继续读取输出并等待真实状态。其他 I/O 失败触发有界清理。

输出背压、输入准入和管道 I/O 均受同一绝对期限与会话取消约束。会话使用调用者令牌的子令牌，主动取消或 Drop 不取消调用者父令牌。被丢弃的 `wait` Future 保留监督句柄，下一次等待继续排空和收取同一终态。

Drop 会话撤销输入并取消后台业务，不 abort 监督任务；监督使用既有 `Owner` 与 `finish` 继续确认直接进程退出。租约在确认之前保留；超过清理预算时沿用现有后台回收与保守保留规则。监督任务异常返回 `CleanupFailed`，运行时关闭或任务丢弃也不能声明清理已确认。调用方适配器负责自己的未确认风险状态。

直接进程退出不证明派生进程树、远端会话、设备事务、共享 daemon 或租约自身的目录删除成功。后续交互终端还需要插件协议、宿主代际/卸载、HTTP/MCP 和前端消费接线。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `../streaming.rs` | 公开导出、启动前资格、通道及后台装配 |
| `options.rs` | 公开流选项与纯配置验证 |
| `input.rs` | 共享准入顺序、输入限额、EOF 和管道写入 |
| `output.rs` | 原字节分片、两路独立累计和输出背压 |
| `lifecycle.rs` | 并发驱动、原期限、撤销、直接退出及租约确认 |
| `session.rs` | 会话句柄、输出消费、可重试等待及 Drop 撤销 |

独立真实进程行为测试由 `tests/` 提供；执行与报告由主代理统一完成。源码实现及模拟工具测试不能代替真机或完整终端迁移验收。
