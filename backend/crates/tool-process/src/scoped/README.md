# 完整工具范围

本目录实现 `ScopePolicy::OwnedTree` 的完整工具进程入口。Windows 启动时先以挂起方式创建直接进程，建立本次 Job、关联完成端口并核对初始线程归属，再恢复执行；Job 的活动进程计数和完成通知共同作为范围收口条件。

`ScopedStreamExit` 将直接进程结果与完整范围结果分开返回。只有直接进程、所有 Job 后代、双向管道和监督工作都完成确认时，`scope` 才是 `Complete`，租约也在该时点释放。取消、超时、输出失败和丢弃会话只触发一次清理截止点，无法确认时保留 `Failed` 和租约。

非 Windows 目标目前返回未取得完整范围运行资格的错误；Linux 独立 subreaper 及 macOS 受控档案仍需单独实现和验收。
