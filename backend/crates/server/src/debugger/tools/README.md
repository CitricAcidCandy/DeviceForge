# 调试工具证据与端口适配

| 文件 | 输入与输出 | 职责与副作用 |
| --- | --- | --- |
| `diagnostics.rs` | 日志筛选、排序和游标到有界日志页 | 转发持久日志端口，不读取文件；保留旧内存事件接口 |
| `diagnostics_adapter.rs` | 原 `LogMetrics` 到 `DebuggerDiagnostics` | 真实持久日志分页，克隆复用原两槽、目录及游标缓存；错误不暴露服务器路径 |
| `reload.rs` | 所选会话及确认到重载结果 | 浏览器桥单次投递；服务器只转发原 PluginService，等待与后台执行分开 |
| `report.rs` | 所选会话、可选日志与导出格式到证据和产物 | 等待真实回执、递归脱敏、保留覆盖范围；显式导出使用原 ArtifactStore |

生命周期回调必须使用调用者传入的原服务实例，并在其串行管理队列内进行代次校验、排空和加载。日志适配器必须先在持久范围内按全部条件筛选排序，再分页；不能把已截断的百条记录重新过滤伪装完整查询。

所有响应保留真实范围和未确认状态，变更不自动重放。完整输入合同及尚需主代理接线的部分见后端实施文档《插件调试器交付-20261028》。
