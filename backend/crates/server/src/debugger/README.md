# 本机调试边界适配

HTTP 与 MCP 使用同一 `DebuggerService`，各自不保存另一份会话状态。
`access` 独立核对真实回环连接和浏览器来源；缺少连接证据按不可核实拒绝，不以 Host 或转发头猜测。
`tools` 只映射公开用例，浏览器命令交给精确选定的实例，服务端目标的未接入动作明确拒绝。
`openapi` 从 Rust DTO 导出桥接契约，供主代理同步前端生成类型。

这是分批实施的宿主底座。能力响应明确保留生产验收未完成状态，不能将工具出现在目录中当作所有目标支持该工具。
调试插件 UI、共同导入更新与恢复、持久报告和第三方实际闭环必须分别验收。

2026-10-28 增量：`tools/` 接收持久日志、产物及原生命周期适配器；`server_target` 支持精确所选插件的 service／operation 原 Job。旧 `invoke` 保持兼容，完整功能须由主代理为 HTTP/MCP 同时接入 `invoke_with_ports`。未注入能力明确拒绝，不在异步线程读日志文件，不另建安装或重载体系。
