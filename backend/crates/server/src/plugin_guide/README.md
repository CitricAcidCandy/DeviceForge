# 插件开发知识入口

本模块由宿主统一管理指南查询和显式在线更新，不依赖业务插件，不运行插件、不创建任务。MCP协议服务及工具目录继续留在宿主，资料更新不改变操作的调用权限。

- `schema.rs` 负责严格参数、主题枚举，以及分开的只读查询和显式更新工具声明。
- `catalog.rs` 负责固定来源与编译期嵌入的前后端文档。
- `query.rs` 负责目标选择、实际采用版本元数据和配套通信指引，不实现下载或缓存。
- `plugin_guide.rs` 装配应用指南服务、基础设施端口和初始化说明。普通读取只访问首次校验的本地缓存，不联网。

新增主题须同时补齐前后端文档、枚举和固定目录。参数拒绝未知字段、空值和错误类型；`topic` 只在省略时使用 `overview`。单端返回一份主题，`fullstack` 返回前后端各一份。

对外知识覆盖开发流程、公开能力与接口、约束、生命周期、调试和发布要求，必须支持无宿主源码的独立插件工程。文档响应只含 `target/topic/content`，不返回源码位置或文档物理地址；客户端使用正文，跨主题继续调用工具。公开 SDK 作为可选独立开发包处理，未提供发行渠道时不能假设可下载；示例需区分完整可运行包与有额外依赖的 API 示意。

知识版本 4 保持八主题和请求参数，删除公开文档项的 `source` 字段，补齐公开调试流程。保留第三版的完整发布 v2、独立组件 dependencies.json、环境与全用户根发现、跨插件共享、一次安装仅下载缺项、手动覆盖与任务接口；发布 v1 仍可读取。query 返回支持的发布格式和宿主 API 版本，不读取资源服务器能力或执行发布。

当前内置基线为5，正文唯一来源是公开SDK的指南库。新工具`deviceforge.update_plugin_development_guide`必须传`{"action":"update"}`或`{"action":"reset"}`；前者有界下载完整快照，后者不联网回到内置正文。调用者不传下载地址或本机路径。响应仅在根增加实际来源、正文摘要、兼容版本和有界诊断；文档项仍只有三个字段。

完整校验及采用事务见应用层`plugin_guides`，下载与原子缓存见基础设施同名模块。产品运行装配启用固定官方来源；无运行配置的独立MCP装配仍可读内置正文，更新返回未配置，绝不偷偷写用户目录。新快照尚未发布、或新宿主尚未部署时，不能声称运行服务已支持在线更新。
