# 插件开发知识入口

本模块只把随构建发布的中文文档提供给 MCP 客户端，不依赖插件管理服务，不运行插件、不读运行时文件、不访问网络、不创建任务。

- `schema.rs` 负责严格参数、主题枚举和只读幂等的工具声明。
- `catalog.rs` 负责固定来源与编译期嵌入的前后端文档。
- `query.rs` 负责目标选择、版本元数据和配套通信指引。
- `plugin_guide.rs` 提供 MCP 边界使用的最小入口和初始化说明。

新增主题须同时补齐前后端文档、枚举和固定目录。参数拒绝未知字段、空值和错误类型；`topic` 只在省略时使用 `overview`。单端返回一份主题，`fullstack` 返回前后端各一份。
