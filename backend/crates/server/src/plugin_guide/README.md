# 插件开发知识入口

本模块只把随构建发布的中文文档提供给 MCP 客户端，不依赖插件管理服务，不运行插件、不读运行时文件、不访问网络、不创建任务。

- `schema.rs` 负责严格参数、主题枚举和只读幂等的工具声明。
- `catalog.rs` 负责固定来源与编译期嵌入的前后端文档。
- `query.rs` 负责目标选择、版本元数据和配套通信指引。
- `plugin_guide.rs` 提供 MCP 边界使用的最小入口和初始化说明。

新增主题须同时补齐前后端文档、枚举和固定目录。参数拒绝未知字段、空值和错误类型；`topic` 只在省略时使用 `overview`。单端返回一份主题，`fullstack` 返回前后端各一份。

对外知识覆盖开发流程、公开能力与接口、约束、生命周期、调试和发布要求，必须支持无宿主源码的独立插件工程。文档响应只含 `target/topic/content`，不返回源码位置或文档物理地址；客户端使用正文，跨主题继续调用工具。公开 SDK 作为可选独立开发包处理，未提供发行渠道时不能假设可下载；示例需区分完整可运行包与有额外依赖的 API 示意。

知识版本 4 保持八主题和请求参数，删除公开文档项的 `source` 字段，补齐公开调试流程。保留第三版的完整发布 v2、独立组件 dependencies.json、环境与全用户根发现、跨插件共享、一次安装仅下载缺项、手动覆盖与任务接口；发布 v1 仍可读取。query 返回支持的发布格式和宿主 API 版本，不读取资源服务器能力或执行发布。
