# 宿主实时传输

本目录只负责 WebSocket 准入、命名空间分发、有界发送和连接回收。调试状态仍由 `DebuggerService` 持有，任务状态仍经 `Application` 的原任务存储读写。本模块不执行插件动作、不复制任务状态，也不启动数据库扫描。

## 连接与职责

- `/api/v2/realtime/socket.io` 仅允许 WebSocket 升级。升级前检查真实连接身份、来源格式和独立物理连接额度。
- 每个升级请求创建一个 `SocketIo` 实例，该物理连接上的 `/debugger`、`/tasks` 共享它。关闭句柄因而只影响当前物理连接，不会关闭其他浏览器。
- 命名空间分别验证可选令牌；调试命名空间额外复用现行本机连接和网页来源检查。任务订阅不依赖调试插件安装或启用。
- `access` 负责准入及普通 HTTP 许可交接，`lifecycle` 持有物理关闭归属，`outbox` 负责容量和公平发送，`debugger/tasks` 只适配原业务服务，`wire` 统一消息封套及关闭入口。

## 容量与交付

物理连接最多 32 条。升级成功立即释放普通 HTTP 在途许可，实时连接继续持有独立许可；普通响应仍将许可保留到响应释放。

| 资源 | 边界 |
| --- | --- |
| 库发送缓冲 | 每条物理连接 8 包 |
| 应用消息数量 | 调试 6 包，任务 2 包，包含发送中和已预留消息 |
| 应用正文额度 | 调试 7 MiB，任务 1 MiB，合计最多 8 MiB |
| 消息及帧 | 1 MiB＋16 KiB，另在入队时预留 128 字节帧头 |
| 任务通知 | 固定 100 毫秒窗口；待发送通知仅保留最新修订，`reset` 要求不会被合并丢失 |
| 调试业务并发 | 当前实例已交付且未终态最多 4 条，客户端空槽声明仅作为额外上限 |

两类消息各有保留额度，调试积压不能耗尽任务的准入位置。两条队列都有消息时轮流出队；只有一类消息时保持该类先进先出。所有额度均计算发送中的消息，避免出队后出现额外容量。

调试泵先预留发送资格，再调用服务领取命令；没有资格时只等待容量或真实状态变化。用例层按完整批次的字节预算分包，未装入本批的命令保持原参数、顺序和期限。

单条命令加上当前目录就超过预算时，准入返回容量错误，不创建命令。目录在准入后增长造成超限时，原命令以明确容量失败结束，动作未交付，连接和后续独立工作继续可用。

## 恢复与竞争

已交付动作不重放。登记恢复先校验全部在途命令的归属，之后更新插件目录，最后读取最新精简终态；完整结果仍保存在原服务历史，由原命令标识查询。恢复不续期命令或调试会话。

`bridge:ready` 的空槽是绝对值且可能晚到。服务在同一状态锁内按已交付未终态数量限制领取数，即使旧的 `limit=4` 与批次、回执交错，也不能突破 4 条总并发。

控制锁或服务锁的 `Busy` 仅引起 5～40 毫秒的短退避，总窗口最多 250 毫秒并受已知原业务期限限制。短退避耗尽后保持连接，等待锁释放、真实状态变化或取消，不无限定时重试，也不把普通锁竞争升级为断线。锁释放信号独立于业务修订：只读请求结束也能唤醒竞争方，健康泵不会消费自己的锁释放通知形成空转。

## 关闭与服务退出

命名空间统一经 `wire` 请求关闭；发送队列停止接收该类新消息，关闭任务按 lane 合并登记。库的 `disconnect()` 在缓冲满时会失败，不能忽略返回值：先在 5 秒内重试，只在真实物理发送阻塞仍无法收敛时关闭当前物理连接。

另一命名空间仍在使用时，正常关闭仅撤销当前消费者。最后一个消费者离开时，在库移除其命名空间记录前关闭底层传输，保留物理关闭归属。未完成命名空间登记的连接仍受库的 5 秒连接期限约束，物理许可不会仅因空命名空间的 `close()` 返回就提前释放。

`Lifecycle` 的退出任务登记在应用原任务跟踪器内，应用停止会等待这项收尾。退出时停止新准入，关闭其登记的物理连接，再通过模块任务跟踪器有界等待发送泵、订阅和回收任务。物理关闭与本模块任务排空各有 5 秒等待上限，应用为宿主资源收尾提供最多 12 秒的总等待；未确认的关闭记录诊断，不能伪装为成功或提前释放已绑定传输的许可。普通命名空间循环不抢先删除退出协调器需要的物理关闭记录。

尚未登记命名空间时，库的 `close()` 返回不足以证明 Engine.IO 已关闭。升级请求的资源凭证与库保存的请求部分共享归属；只有最后一份释放，才归还这种连接的物理许可。退出可以有界等待该释放信号，不用额外扫描或推测网络关闭时间。

ACK 发送器是库提供的一次性对象，发送失败不能伪造重试成功。业务结果在入队 ACK 前已写入原调试状态；发送失败通过有界关闭及后续命令状态核对收敛。关闭时未发送的消息明确记录为未确认，不静默重放动作或清除历史结果。

## 验证边界

本目录单元测试使用真实内存准入和状态机、受控时钟及无监听的库关闭句柄，不依赖新的库测试特性，也不启动端口、服务或浏览器。真实 WebSocket 联通、网络背压与浏览器最终表现仍需要独立证据。
