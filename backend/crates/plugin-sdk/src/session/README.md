# 交互会话公开契约

本模块定义独立协议 5 的打开、Ready/Start、持续输入/双路输出、EOF、取消与清理终态。旧协议 1–4 和普通任务 Request/Response 保持原语义。

`handshake.rs` 定义打开与固定预算握手；`frames.rs` 定义输入控制和递增输出/终态；`validation.rs` 提供同样用于直接构造与反序列化的纯限额规则。字节数组解析在超过 8192 个字节时拒绝，不按不可信长度预分配；传输方仍须先限制整行帧大小。

`SessionOpen.client` 可选，包含 `id` 与 `is_local`。插件必须在清单 `sessions.client_context` 显式声明 `true` 才会收到该字段；省略声明保持 `false`，宿主省略字段以兼容拒绝未知字段的旧插件。身份由宿主传输边界确认，不从业务 `input` 取值；无上下文不得推断为本机主控。SDK 只校验字段和长度，不实施业务控制权。

空字节数组是数据，只有 EOF 关闭输入；输出共享递增序号，跨 stdout/stderr 的顺序表示运行库发送顺序。终态必须显式给出 result 或 error，合法 null result 保持存在；cleanup 由处理器真实报告，不从终态、传输关闭或直接进程退出推导。

模块不依赖宿主、Tokio 或工具进程，不执行协议状态机。会话身份匹配、前后帧顺序、累计限额、截止点和输出消费由运行库/宿主分别落实。完整边界见 [第五版裁定](../../../../docs/contracts/交互会话协议第五版裁定.md)。
