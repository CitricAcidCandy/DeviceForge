# 普通操作总预算声明

`execution::ExecutionBudget`（根导出同名类型）是普通服务器操作的可选显式声明。输入和输出均为严格对象 `{"api_version":1,"total_timeout_ms":120000}`；版本只允许 1，总预算为 1 至 3600000 毫秒整数。JSON 解码和 `validate()` 均拒绝非法版本、越界值；对象拒绝未知字段。模块仅依赖 serde，不引用宿主，不执行 I/O。

`Contribution.execution` 省略或 null 均表示未声明，序列化时省略。默认有效预算 60000 毫秒由宿主注册层决定，SDK 不自动补值。设备发现、设备能力和性能专用采样不得在同一个实际操作上重复声明普通预算；该关联校验属于宿主注册/清单边界，不能按平台名猜测。

预算声明不是进程截止点：Request/Response 和业务 input 不增加预算字段。普通宿主 Job 的总期限从准入计时，旧分阶段窗口不再表示其总预算；底层 context None 保留兼容。旧宿主可能拒绝新清单字段，不承诺向旧宿主加载兼容。Rust 字面量须增加 `execution: None` 或显式声明。

所属纯回归覆盖旧贡献省略/null、边界值、非法 JSON 和 Rust 构造校验；本批测试已编写，尚未运行，由主代理统一验证。
