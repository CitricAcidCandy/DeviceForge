# 交互会话协议第五版裁定

日期：2026-10-10。模式：architecture-first；本批落实公开 SDK、运行库和独立行为验证，随后接领域端口、宿主 owner/generation、HTTP/MCP、前端消费和终端插件。各批证据独立，公共协议不表示完整业务迁移完成。

## 架构门禁与选择

目标是一个独立插件进程持续承载一个交互会话：打开、启动、多次原字节输入、双路原字节输出、输入 EOF、取消和明确清理终态。旧协议 1–4 的请求、响应及处理器签名保持不变；新协议 5 不装入旧普通任务调用路径，也不宣称多会话复用、PTY、进程树或远端资源自动回收。

受影响的当前层为公开契约、公共运行库和独立测试；下一批领域端口与宿主集成通过同一契约适配。比较两条路径：扩充旧 Request/Response 会把单次任务和双向生命周期混合；独立 session 模块可显式限定状态与资源所有权。因此采用独立模块，不给既有 serve_io 或任务 terminal.rs 追加交互分支。

## 冻结的公开协议

- 所有帧为一行 JSON，以换行结束；关联字段统一为 protocol_version=5 与 session_id（1–128 字节）。Open/Ready/Start 分别使用 command=open/ready/start；operation 为 1–128 字节。
- Open 包含 operation、input 与可选 artifacts；上限 512 KiB。Ready/Start 上限 4 KiB。C0 在 Ready 写出前固定；Start.remaining_timeout_ns 上限 3600000000000，截止点为 C0 加原预算，等待 Start 不重启时钟。握手本身另有有界传输等待。
- SessionControl 使用 command=input/eof/cancel；input.bytes 为 JSON 字节数组，保留非法 UTF-8 和零字节，单块最多 8192 字节、控制/数据整帧最多 65536 字节。空数组是空输入，只有 eof 关闭输入。eof 后拒绝重复 EOF 和后续 input，但继续读取 cancel。
- SessionEvent 使用 event=output/finished；output 包含 stream=stdout/stderr、bytes 和从 1 开始的共享递增 sequence。finished 使用下一个 sequence，携带 SessionOutcome：result 或非空 error 二选一、outputs、cleanup=complete/failed；显式 null 是合法 result。普通输出帧上限 65536 字节，终态上限 1 MiB。
- 通道默认容量 8，允许 1–64；默认累计输入 1 MiB、累计双路输出 16 MiB，配置上限各 64 MiB。输入队列满以可观察错误取消会话，避免满队列阻塞后续取消读取；输出使用有界背压，等待受同一取消与截止点约束。超限在复制/入队前拒绝。
- 主动取消、到期、输入 EOF 以外的宿主断流、坏帧、输入队列溢出或传输失败均撤销新的 I/O，并等待已启动处理器返回 Execution；不能丢弃处理器 Future 后报告清理完成。处理器不合作时由未来宿主监督收口并保留未确认资源，本运行库不伪造确认。
- 正常结束先关闭输出准入并排空已入队输出；取消后丢弃尚未写出的输出，避免慢消费者阻塞清理。终态发送使用独立有界传输宽限，不延长业务截止点；写出终态失败仍是传输失败，不证明宿主收到清理确认。
- 在途 JSON 帧若尚未写出任何字节，可以取消丢弃；若已写出部分字节再被取消、到期或写入失败，则会话传输返回失败，等待处理器清理后关闭传输，不向半帧后拼接 finished。错误终态的文案必须非空且不超过 4096 字节，失败终态不发布产物。

## 冻结的运行入口与协作写权

公开 API 为 serve_session(options, handler) 与 serve_session_io(reader, writer, options, handler)；处理器参数依次为 SessionOpen、InvocationContext、SessionInput、SessionOutput，返回已有 Execution。输入 recv 返回 Result<Option<Vec<u8>>, SessionIoError>；输出 send(stream, bytes) 返回 Result<(), SessionIoError>，仅确认有界队列准入，不证明宿主消费。SessionOutput 可克隆，所有克隆共享累计限额和顺序。

SessionOptions 包含 channel_capacity、input_limit、output_limit、handshake_timeout、transport_grace。两个传输时间分别默认 5 秒与 2 秒，允许大于零且最多 30 秒和 5 秒。选项在首次读取前校验。

- 主代理独占 plugin-sdk/session、SDK lib.rs/README、本文、Cargo 调度及根交付记录。
- 后端代理独占 plugin-runtime/session、运行库 lib.rs/README、context.rs 的 pub(crate) 构造器调整，不修改 SDK 或测试。
- 测试助理独占 plugin-runtime/tests/session* 与 SDK 新增 session 测试文件，不修改生产代码，不运行 Cargo。
- 前端代理独占 frontend/docs/交互终端公开接口消费边界.md，只记录本批协议到未来公开宿主的适配边界；不手写 HTTP 类型、改 UI 或运行生成器。

本批可立即实施，没有等待用户答复的阻断项。具体 UI、正式分发、宿主卸载、真机与完整终端仍由后续实际接线及独立证据确认。
