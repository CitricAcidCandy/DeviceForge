# 宿主交互会话接入裁定

日期：2026-10-10。模式：architecture-first。完整目标为会话贡献发现、真实插件进程、宿主所有权/代际、HTTP/MCP 共用用例、严格 TS 消费及终端业务；按依赖增量实现，不能以端口或进程适配代替完整业务。

## 门禁与路径选择

公开协议第五版已冻结并通过本批 1101 项工作区及必要服务门禁。当前新增会话声明与独立端口，随后接宿主注册及网络。旧普通协议 1–4、Job 与设备/性能贡献保持；每次打开独立插件进程，平台命令留在插件内，产品 UI 等设计稿。

选择独立会话贡献、可分离的输入和接收句柄、持续监督。将会话输入改成重复普通 Job 会丢失同一进程和所有权；把协议 5 直接塞进旧普通执行分支会混淆终态，因此不采用。领域只表达端口和结果，进程 I/O 由基础设施负责。

## 接线不变量

- 普通 Manifest.protocol_version 仍为 1–4；可选 sessions 显式声明 protocol_version=5 和独立 operations。允许普通 operations 为空且会话贡献非空；设备/性能只能引用原普通贡献。两种贡献不得同名，避免公开发现歧义。
- provider 纯构造 Launch（独立输入句柄、接收/结束句柄和监督 Future），不先启动进程。未来应用在原子准入中固定 owner/generation 并登记监督，随后锁外执行；打开请求或读取请求被丢弃不丢弃资源监督。
- 业务 D 在副本准备/启动前固定。握手及 Start 仅传剩余预算，不更新 D。发送 EOF 只发协议控制，不关闭物理 stdin；之后仍可取消。
- 业务取消和 D 不直接送给公共进程硬监督。使用独立强制取消 token 和覆盖合作清理、终态传输/真实退出的硬期限；取消优先撤销输入，再发协议 Cancel，并有限等待真实终态和退出。
- 半帧、非法身份/序号、重复/缺失终态、传输故障、failed 清理或非零退出均不确认外部资源。合法 Finished、cleanup complete、真实零退出全部成立才确认；后续成功不清除既有 unresolved。
- 输出原字节、共享递增序号和有界背压；输入准入与 EOF 共享排序，控制取消独立于数据队列。等待终态须持续排空未读输出，等待 Future 丢弃不丢后台所有权；再次等待得到相同缓存结果。
- 客户端接收句柄 Drop 请求取消，监督仍保留输入副本及产物租约至真实进程确认。监督 Future 自身丢弃不能返回清理确认，保留未确认风险；未来应用必须持续登记真实监督。

## 当前协作与证据范围

后端代理独占 SDK 声明/domain 端口；主代理独占基础设施适配与清单安装接缝、架构裁定和 Cargo；测试助理独占新增 infrastructure 会话测试及独立夹具；前端代理维护独立消费边界，不手改生成类型或产品 UI。具体签名经主代理冻结后实施。

本批没有需要用户答复的阻断项。最低真实进程证据包括提前输出、多次原字节输入、EOF 后取消、慢消费者取消、固定期限、真实清理/零退出资格、未确认粘性、Drop 后监督和可重等终态。应用注册/卸载、HTTP/MCP、终端插件和真机仍按后续实际接线验收。
