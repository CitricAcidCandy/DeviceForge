# 产物接口

## 上传与下载
POST `/api/v1/artifacts?filename=<URL编码文件名>` 接收 application/octet-stream 原始流。默认上限 64 MiB，其中 JSON/MessagePack 最多 16 MiB，返回 201 与产物元数据。上传端点独立于 JSON 的 256 KiB 限制；仍使用同一个访问令牌及限流。超过类型体积或结构上限返回 413，媒体类型错误返回 415，上传并发满返回 409。

GET `/api/v1/artifacts/{id}` 获取元数据；GET `/api/v1/artifacts/{id}/content` 流式下载。下载强制 attachment，文件名按 UTF-8 编码，附带 nosniff 和 private/no-store。客户端不指定任意服务器路径。GET `/api/v1/artifacts/{id}/entries?offset=0&limit=50` 预览 ZIP 容器目录，limit 在 1 到 200 之间，返回 total、entries 和 next_offset。

元数据包含 id、filename、media_type、size、sha256、created_at，均从 Rust 类型生成接口模式。压缩包使用 application/zip，图片使用 image/png，.json 使用 application/json，.msgpack 使用 application/msgpack。JSON/MessagePack 不支持 ZIP 条目预览。

## MCP 和任务入口
公开操作 `artifact.inspect` 与 `artifact.archive.entries` 接收 artifact_id；预览支持 offset 与 limit。这两项与设备操作采用同一个注册器和任务层，MCP 自动发现同名工具。HTTP 元数据和预览直接返回结果；MCP 调用返回任务，客户端应按任务 ID 查询终态。

二进制上传下载通过 HTTP，不把大文件编码为 MCP 工具文本。浏览器插件与服务器扩展传递产物 ID；服务器插件通过协议 2 获得授权副本和输出目录，见插件产物协议.md。标准编解码贡献见 MessagePack插件接口.md。

## 实现与验收
领域端口位于 crates/domain/src/artifacts.rs；文件适配器位于 crates/infrastructure/src/artifacts；应用贡献位于 crates/application/src/artifacts.rs；HTTP 位于 crates/server/src/artifacts.rs。

验证覆盖流式分块、数据一致、重启、排他锁、临时文件清理、非法文件名与 ID、ZIP 路径穿越、大小限制、上传和下载并发、HTTP 鉴权、附件响应、超过 JSON 上限的上传以及 MCP 操作调用。内容校验范围和存储限制详见适配器 README，未执行真实 APK 签名及安装验收。
