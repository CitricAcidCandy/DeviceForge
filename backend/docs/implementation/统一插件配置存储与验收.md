# 统一插件配置存储与验收

## 边界与数据流

`plugin-sdk::ConfigurationDefinition` 只声明版本、JSON Schema、默认值、生效方式和旧旁置文件名，不改变既有任务请求协议。领域端口 `PluginConfigurationStore` 不读写文件；基础设施 `FilePluginConfigurations` 独占持久化、模式校验、旧配置兼容和敏感遮蔽；应用用例负责条件保存与生命周期应用。HTTP 使用 `/api/v2/plugin-configurations`，不经过 settings 插件。

配置目录与插件部署目录必须独立，同一目录由一个宿主持有排他锁。受限阻塞工作池执行文件读取和模式处理，原子发布 `state.json` 与不可变修订文件。单份配置限 256 KiB，最多保留 1024 份修订；到达上限时明确拒绝继续保存。

首次显式保存前，每次读取都会重新读取原 `--config` 或旁置文件，任务调用不注入管理路径。首次保存后才创建宿主管理状态；新任务通过 `DEVICEFORGE_PLUGIN_CONFIG` 获得不可变修订文件。旧任务继续持有旧路径，保存不会改写旧文件。未声明模式的旧插件只展示只读兼容入口，不回传无法可靠识别敏感字段的旧配置原值。

## 修订与生效

保存和恢复默认均携带 `expected_revision`，过期修订返回 409。JSON Merge Patch 中的 `null` 删除字段；遮蔽占位符 `********` 保留对应原敏感值。非法字段不落盘，响应保留当前已保存值和修订，并返回不含原值的字段定位。

`next_invocation` 保存后推进保存和生效修订；`plugin_reload` 只推进保存修订，并保留旧生效指针。应用配置复用插件生命周期管理队列：先完整验证新贡献，再原子检查活动任务、会话、排空状态及清理失败；允许切换代际后才标记新修订生效。活动调用拒绝重载，不取消原任务。未确认清理状态不能通过配置重载消除。

升级时保留独立存储的原值。声明版本变化或原值不再符合新模式时返回不兼容状态，不重置配置；用户修正并显式保存后才更新声明版本。恢复默认是明确操作，也必须经过条件修订检查。

## 模式与安全注解

模式必须是对象，默认值必须通过相同模式校验。禁止外部引用和 `$id`；配置引用支持 `#` 与未经过百分号编码的 `#/...` JSON Pointer。锚点、`$dynamicRef` 和 `$recursiveRef` 明确拒绝，避免校验器与安全注解解析器使用不同引用语义。

遮蔽、占位符保留和只读检查共用注解解析器，覆盖本地引用、组合模式、条件分支、动态映射、数组元组和递归对象。组合分支及条件分支中的敏感与只读注解采取保守合并，修改判别字段不能解除已有保护；这也意味着互斥分支中的同名字段会继承更严格的注解。

`writeOnly`、`format: password`、`x-sensitive` 的当前值与默认值返回遮蔽值；模式中的叶子敏感默认值和示例移除，根级或嵌套对象默认值、示例按实际字段递归遮蔽。错误与运行日志不记录配置值。`readOnly` 检查合并后的完整值，覆盖删除父对象、分支切换和数组整体替换。

管理状态同时记录敏感字段的 JSON Pointer，不存额外原值副本。升级后即使模式删除旧字段或敏感注解，已保存值和默认对象仍按当前模式与历史指针的并集遮蔽；提交历史占位符也会保留原值。旧状态缺少该字段时按空指针列表兼容读取。

## 验收入口

基础设施回归：

```text
cargo test -j1 -p apk-infrastructure --test plugin_configurations
```

覆盖首次保存前的旧配置读取、敏感映射、条件保存、只读与非法字段、删除与默认恢复、不可变调用快照、需要重载时的旧生效指针、旧包兼容、引用与组合分支、元组与递归对象、并发 CAS、重启及升级不兼容保留。

真实宿主 HTTP 验收使用当前已构建产物，脚本不触发 Cargo，启动前将宿主复制到本次独立证据目录并记录 SHA-256：

```text
node backend/scripts/plugin-configurations-smoke.mjs
node backend/scripts/plugin-configurations-smoke.mjs --release
```

脚本使用临时端口、独立数据目录和协议 1 / 3 Node 夹具，不访问 7031 预览实例或设备。覆盖配置真实消费、旧配置、保存与恢复默认、409、非法字段、活动调用快照、活动任务拒绝重载、空闲重载、加载失败保留旧贡献、未确认清理拒绝重载、升级保留与宿主重启。每次运行输出 `artifacts/plugin-configurations-<profile>-<uuid>/report.json`，保留宿主退出码、端口释放和直接夹具进程退出证据。

本文件列出验收方法；实际通过状态以本次报告及集成门禁日志为准。Node 夹具验证宿主契约，不等同第三方原生工具、真实设备或性能验收。
