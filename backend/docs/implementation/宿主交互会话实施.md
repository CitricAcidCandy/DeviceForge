# 宿主交互会话实施

日期：2026年10月12日。研发与测试并行，本批不等待截图分发，具体产品界面仍不开发。

## 架构裁定

采用已有领域会话端口与独立协议5，应用管理会话生命周期，HTTP和MCP调用同一用例。普通Job终态模块不承担持续会话，终端插件不依赖宿主内部实现。

| 单元 | 职责 | 边界 |
| --- | --- | --- |
| domain/interactive/view | 可序列化会话、终态和输出页 | 不持进程、HTTP或存储 |
| application/registry_sessions | 会话模式编译、命名与默认预算 | 与普通贡献一起原子发布和撤销 |
| application/interactive | 准入、输入、输出缓存、监督登记和删除 | 通过SessionProvider调用，不执行平台程序 |
| 既有infrastructure/plugins/interactive | 协议传输与真实资源确认 | 保持原期限、合作取消与未确认粘性 |
| server/interactive | 薄HTTP及MCP边界、关联日志和OpenAPI | 不复制生命周期规则 |

## 所有权与容量

会话记录固定插件ID和代际，贡献只允许所属命名空间。准入与插件撤销、服务关闭使用现有应用准入锁排序；纯同步open返回的监督与输出消费分别登记应用及owner跟踪，锁外运行。插件纯会话贡献可以装载，普通任务目录与会话目录分开。

默认最多8条保留记录、4条活动会话。每条最多16MiB原字节输出、65536块，保留真实序号直到显式删除；慢客户端不阻塞插件输出。读取为排他游标，页长1至100；超前游标拒绝，不重编号输出。容量满时拒绝新会话，不静默删除历史。

输入单块8192字节、累计1MiB、最多65536次输入或EOF，EOF与输入共享顺序。取消或卸载立即撤销输入，等待方取消不表示服务器会话已停止。打开预算在准入时一次计算，握手和所有输入共用原截止点，不因轮询或重等刷新。

监督不因客户端取消、输出消费者失败或删除请求而abort。终态独立记录业务结果、清理报告、直接进程确认与宿主失败；Failed或Unconfirmed保持owner未确认，卸载保留draining并拒绝同ID重载。只有终态记录可以删除，删除不充当外部资源恢复。

测试角色独占应用层集成回归，主代理实施生产及公共接线。先定点编译、会话行为、模式和卸载回归，完整workspace、两模式服务和正式分发在阶段节点统一执行。内存提供者证明应用规则；真实终端插件、HTTP/MCP和浏览器消费分别验收，不以插件14项通过表示宿主已接通。
