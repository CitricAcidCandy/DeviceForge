## 实现边界

- Android 插件保持原启动命令及成功响应。仅工具失败后读取安装包列表，逐行精确匹配包名；已安装时再读取桌面启动入口，分别说明未安装、无启动入口和设备拒绝启动。
- 两步辨因共用两秒上限，并继承原调用更短的期限、取消及清理确认；诊断不可信时保留原失败，不把未知故障推断为未安装，不重放写操作。
- 工具非零退出只识别明确离线、未授权、无设备、多设备和目标断开诊断，返回固定中文；工具无法启动单独说明。未识别的失败明确表示原因尚未确认，不倾倒原始标准错误。
- 设备注册和发现的错误在产生处改用“插件已更新”“尚未获取设备列表”等可理解文字；错误类型和 HTTP 码不变。
- 清理未确认不再要求先恢复整个插件，保留对应任务的真实风险和无关操作准入。前端兼容旧服务术语，直接展示具体原因，技术原文及各请求日志留在详情。
- HTTP 409 后的目录恢复只有只读查询，最多五秒；显式刷新优先。恢复成功也不自动重发旧动作。页面刷新必须由用户主动点击。

## 验证与限制

独立假 ADB 真实进程回归覆盖缺包、相似包名、无入口、有入口但拒绝、不可用诊断、取消及原期限；前端覆盖真实 HTTP 客户端到公开网关、明确错误首屏展示和新旧提示兼容。专项通过不等于真实应用已启动，也不等于当前用户运行中的旧预览服务已升级。完整门禁、编译和剩余失败以根目录 `todo.md` 及本次制品记录为准。
