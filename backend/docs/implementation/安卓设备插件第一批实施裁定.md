# 安卓设备插件第一批实施裁定

日期：2026-10-10。模式 architecture-first / Hybrid，执行采用 feature-dev-architect。依据第一批契约草案及总监复审，本文件冻结具体实施边界；实现与验收结果另记根 todo.md。本批目标是独立可部署的真实 Android 设备插件，随后撤除宿主对应七能力与发现装配。

## 路线与影响

选择独立 `android-device` 进程插件，生产只依赖公开 SDK、plugin-runtime、tool-process 及基础库；HTTP/MCP、任务、代际、发现目录、锁、在线安装均复用通用宿主。不采用在 DeviceTools 增加平台声明或把宿主内部实现链接进插件的路线，后者保留平台耦合，无法独立升级。

API3、协议4、每任务一进程，八个短贡献与七项能力全部采用草案：discover；connect、disconnect、packages、app.start、app.stop、app.uninstall、input。对外命名空间只映射一次。七能力与发现不声明普通 execution 预算。APK/APKS 安装、截图、性能、Harmony 和常驻会话继续独立实施，不声明空贡献。

## 三项裁定与兼容

1. 配置采用二进制旁 `android-device.config.json`，唯一覆盖为部署参数 `--config <绝对路径>`。严格 JSON、格式1、最多65536字节、逐层未知字段拒绝，形状为 `{"format_version":1,"tools":{"adb":"adb"}}`。tools及adb可省略；缺省旁置文件为空工具配置，显式文件不存在失败，执行时未配置ADB为确定依赖错误。首批不创建临时目录，不接受未使用的scratch_root。
2. ADB允许不含控制符、最多4096字节的绝对文件路径或单一程序名；相对目录、父路径和自由参数拒绝。绝对文件与配置及每段祖先拒绝符号链接、重解析点和特殊文件。PATH程序名沿公开Restricted环境解析；只继承PATH、SystemRoot、TEMP、TMP、HOME、USERPROFILE，不继承APK_ADB、ADB_SERVER_SOCKET、ANDROID_ADB_SERVER_*或服务令牌。业务输入不选择工具、配置或server端点。首发Windows x64，跨平台不记已验证。
3. 允许标准ADB客户端自动启动默认共享server。server和持久设备连接由部署者管理，不归单Job或插件代际所有；没有server时允许标准启动，启动失败为有界依赖错误。取消和卸载只清理本次客户端及本次任务资源，不执行kill-server或断开其它用户连接，不承诺恢复设备状态。cleanup=complete只确认该声明范围，不证明server/派生树退出，真实ADB自动启动和设备行为须独立实测。

serial与宿主local_id资格一致：原文非全空白、最多200 UTF-8字节、无Unicode控制字符、不以连字符开头。不得收紧为ASCII identifier；发现按ADB空白分隔token读取serial，动作封套保留传入原文。任一坏serial、坏状态、坏model或重复ID使整次发现失败，不发布部分目录；最多128设备，model最多200字节。原状态最多100 UTF-8字节、非空白且无控制字符，未知合法状态保留unknown及原文。只device归online且允许五项device能力，provider connect/disconnect独立。

address与package采用草案安全规则。start/stop的package从旧宽泛identifier收紧为点分包名，须在部署说明列为兼容变化。发现保留旧版丢弃的未知状态属于行为修正。packages不再以任意failed/error等子串拒绝合法包名；保留非零退出失败，并精确识别ADB诊断行，不把`package:com.failed.example`当错误。connect/start/stop、uninstall、input各自沿草案诊断资格，错误仅固定有界中文，不泄露工具输出或输入文本。input沿旧ASCII/%s/单引号/enter命令规则，不能以宿主argv替代设备端引用。

## 总期限与清理

发现总30000毫秒。connect/disconnect/packages/app.start/app.stop/input能力总30000毫秒，app.uninstall总120000毫秒，清单显式声明。同一InvocationContext原D_L覆盖配置、锁等待后的执行、全部子命令及结果处理；不按now刷新总期限。

connect工具短限额5000毫秒，其余直接沿原D_L；短限额为min(D_L,启动前单调时钟+5000ms)。短点先到、宿主总D未到时接受现有字符串失败映射为dependency_failed，不新增通用类型错误契约，不宣称宿主Timeout。总到期/取消按公开上下文优先到期。启动前、下一笔命令前与结果交付前复核。

工具使用公开capture_with_lease、Restricted环境、固定argv和每路1MiB输出上限。真实直接PID退出才释放租约；CleanupFailed或仍在飞租约为粘性未确认，返回cleanup=failed，不以请求Future结束确认。首批没有同步worker、临时目录、文件输出或后台轮询，不能借其它插件的目录回归证明本插件完整资源安全。

## 文件职责与独占写集

以下根路径为 `backend/plugins/android-device/`。不在已有混合宿主文件追加业务。

| 所有者与文件 | 责任、输入输出 | 副作用及边界 |
| --- | --- | --- |
| Galileo：Cargo.toml、README.md、manifest.json、manifest.example.json、package.json、aliases.example.json | 公开依赖、八贡献/七能力及旧绑定同源；两个manifest逐字节一致 | 仅本插件元数据；不改workspace和宿主 |
| Galileo：src/operations.rs、src/operations/、src/rules.rs、src/rules/、src/discovery.rs及其子模块 | parse短名和严格封套为Input；纯校验、固定argv、业务输出与发现PluginDevice | 仅经主代理Control调用工具；不读配置、不导入宿主 |
| 主代理：src/lib.rs、main.rs、error.rs、config.rs、config/、control.rs及其内部单元测试 | 公开协议装配、固定中文错误、有效Start后有界配置、原D和直接进程租约 | 配置文件及受控客户端进程；不构造平台命令 |
| 测试助理：随后独占tests/，须明确交接后再开放 | 独立手工协议帧、假ADB、清单/旧绑定/服务验收 | 不复用生产解析器构造预期，不运行主代理命令队列 |
| 主代理：backend/Cargo.toml与架构检查、部署驱动、后续宿主装配 | workspace接入、公开边界和实际插件部署；通过验收后撤除对应内置贡献 | 不给通用路由新增Android分支，不静默fallback |
| Lagrange：只读审核 | 契约、资源、实际装配与覆盖核对 | 无写入、构建或服务 |

跨写集接口固定为 `operations::parse(operation: &str, input: &serde_json::Value) -> Result<Input>`、`operations::execute(control: &Control, input: Input) -> async Result<serde_json::Value>`；Control提供`capture(args: &[String], short_limit: Option<std::time::Duration>) -> async Result<deviceforge_tool_process::Output>`与`check() -> Result<()>`。Error提供Cancelled、Timeout、TooLarge、Invalid(&'static str)、Dependency(&'static str)、Io(&'static str)、CleanupFailed。调用者不能传工具路径。discover在execute里序列化公开PluginDevice数组，不返回私有wrapper。

## 实施与最低验收

Hybrid顺序：先纯规则与命令，再协议/假ADB真实进程，再清单加载及HTTP/MCP实际发现与能力，最后撤除宿主装配并复跑门禁。普通缺陷按验收项回流，阻断即时回流；开发交接后继续不冲突的下一项。

必须覆盖八短名及拒绝完整前缀、严格封套/未知字段、serial/raw/model字节边界、未知状态/重复ID、connect明确成功、合法failed包名、精确诊断、卸载独立Success、text引号/%s/多命令同D、预取消/预到期零工具、短点先到、取消时直接PID退出与清理资格。清单必须经真实validator加载，三种发现入口/旧绑定/直接任务共享代际和锁；卸载撤销贡献并保留历史、重载旧引用拒绝、空插件宿主能启动。

本批先按最小读入范围编译，新插件未冻结前不加入整workspace全量命令输入。所有新增source/tests冻结后执行后端六门禁、两runtime及受影响设备/生命周期/日志/在线服务；release和正式TGZ/npx另验。假工具只能证明协议、命令及直接进程行为，不代表真实ADB、外部server、另一主机或真机通过。
