# 工具来源缓存回退裁定

日期：2026-10-12，UTC。模式：架构优先。本批迁移旧工具更新器的清单缓存回退，不扩展宿主、交互会话、产品界面或离线归档安装。

## 选择与边界

选择工具供应插件独占来源快照和缓存，前端同步消费结果；拒绝在宿主添加业务缓存或仅修改后端后继续让前端拒绝缓存结果。请求输入、协议4、六贡献名称及移除行为不变。部署配置新增 `manifest_cache_enabled`，默认 `true`；仅 `manifest_url` 使用缓存，`local_manifest` 不回退。关闭缓存不删除既有文件。

每次调用先读取配置来源一次；来源失败后至多读取一个缓存快照，不增加重试、TTL或重置原绝对期限。成功清单必须完整验证后才缓存。缓存只提供清单，归档仍从清单URL下载；已安装模块可零下载复用，不表示新模块可离线安装。采用契约先行加行为测试，先证明错误分类及持久快照，再验证真实HTTP/MCP。

## 快照身份与结果

封装包含 `schema_version=1`、规范配置URL的SHA-256、确定性序列化完整清单的SHA-256及清单内容；保留模块顺序。读取重新检查当前来源身份、摘要和当前全部清单资格。版本号不代替身份；摘要不等于签名或远端真实性证明。

`catalog`、`plan`、`install`、`runtime_feature.status`、`runtime_feature.prepare` 的外层结果新增：

| 状态 | manifest_source | manifest_sha256 | source_error | manifest_version |
| --- | --- | --- | --- | --- |
| 当前来源成功（包括本地清单） | live | 有效64位十六进制 | null | 有效版本 |
| 当前远端失败、缓存成功 | cache | 有效64位十六进制 | 静态脱敏来源错误 | 有效版本 |
| 来源失败且无缓存（仅查询可降级） | null | null | 静态脱敏来源错误 | null |

既有 `source_error` 仅表示本次配置来源获取或清单验证失败，不承载缓存、安装或清理错误。无缓存时catalog保留local_only行，status为空且found/ready=false；其余三操作失败。准备返回的每个安装子项仍只有既有四字段，元数据仅在外层。单模块install新增外层manifest_version以关联来源快照，不改变子项。

前端兼容旧插件：元数据组未出现时保留原结果与校验，不伪造来源或摘要；新组必须完整出现并满足上表。新组中的有效版本与source_error允许同时存在，但只在cache状态接受；live携带错误、null携带版本/摘要、缺组/错摘要均拒绝。恢复继续只查询原Job，不因来源错误自动重提。公开生成类型由主代理同步，通用Job结果不新增手写HTTP DTO。

## 错误分类

允许回退的远端来源阶段：连接/DNS/TLS失败、非2xx、响应中断、正文超限、JSON/清单字段或完整资格失败。必须由加载阶段显式分类，不能笼统捕获所有Io/Invalid/Dependency。

请求/部署配置非法、URL策略拒绝、客户端初始化失败、本地来源错误不触发远端回退。查询保留本地来源错误的旧降级语义，但不得把缓存硬错误降级。

缓存仅NotFound为未命中。损坏、身份不符、链接/非普通文件、其他元数据/读取IO、锁Busy均硬失败。缓存写入、flush/sync、原子提交失败硬失败并保留旧快照；来源成功但缓存提交失败不换旧快照继续。临时资源清理未确认返回Cleanup，不把直接进程退出当作资源确认。

任意阶段取消/到期均失败，回退及提交前后检查同一原预算。模块Busy、状态损坏、摘要和事务清理错误不属于来源错误。保持status的全局稳定本地预检，不让未知功能或来源失败掩盖损坏状态。

## 职责、锁与写集

| 单元 | 负责 | 不负责 | 输入输出及副作用 |
| --- | --- | --- | --- |
| manifest/source加载 | 单次获取、验证、来源阶段分类、不可变快照 | 归档安装、宿主 | 配置/预算→快照或明确来源失败；异步网络 |
| cache独立模块 | 有界封装、身份/摘要验证、短锁与原子替换 | 网络、模块事务 | 已验证清单→持久快照；文件IO |
| config及公开模板 | 部署开关与限额 | 请求选择来源 | 读取部署配置 |
| operations/feature | 五操作来源元数据、明确查询降级、共享安装 | 缓存底层与重试 | 快照→业务结果；保持原模块事务 |
| 前端tool-supply | 旧结果兼容、新元数据校验、日志及查询恢复 | 缓存IO、产品UI | unknown结果→公开业务类型，无新网络入口 |
| 独立测试及驱动 | 文件/网络故障、真实Job和输入身份 | 修改生产期限 | 临时文件、合成HTTP、真实宿主 |

缓存位于安装根下专属 `.manifest-cache`，内部锁和快照不得被当作模块，也不得沿用模块ID充当缓存锁。网络不持缓存锁；缓存短锁释放后才进入后续模块锁。旧install保持模块锁早于来源读取；缓存读写不获取模块锁，防止反向锁序。有限临时文件不成为绕过既有遗留事务检查的理由。

## 最低验收

live A→新进程503→缓存A，live B更新后回退B；来源切换不能串用，同版本不同内容摘要不同。覆盖允许来源故障、未命中、缓存损坏/IO/Busy、提交无损、清理失败、取消/自然到期不回退、单快照多模块、旧install锁序及并发原子读写。前端覆盖新组三态、错组、旧兼容、日志和零重提。真实服务与分发分别验收，库测试不代替HTTP/MCP，当前npx旧包不借记本增量。
