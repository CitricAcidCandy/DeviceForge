# 安卓安装截图宿主撤除接缝

日期：2026-10-10。模式为先确定架构再实现；契约依据为[插件实施裁定](安卓安装截图插件实施裁定.md)。本批将安装和截图从服务器直接装配迁出，继续使用公开设备提供者、统一任务、设备锁及产物端口。

## 落点与职责

| 文件或模块 | 责任、输入与输出 | 副作用与边界 |
| --- | --- | --- |
| android-device插件 | 十贡献、九能力，APK私有副本安装与授权PNG输出 | 独立工具与资源清理；不导入宿主内部模块 |
| device_artifacts/remaining.rs | 固定声明和执行Harmony安装、卸载，接收HDC与ArtifactStore | 两执行入口先拒Android及未知操作；不接收ADB部署配置 |
| device_artifacts/remaining/tests.rs | 两Harmony流保留；已迁出Android入口零工具、零产物调用 | 独立假工具；不计Android新插件或真机验收 |
| server/main.rs | 使用新的两流构造函数 | 不装配Android安装与截图；APKS和性能残余另批迁出 |
| backend/scripts/android-device-deployment.mjs | 真实插件部署与格式2包、设备绑定合并 | 固定本次临时目录，假ADB由测试部署者配置 |
| backend/scripts/runtime-smoke.mjs | 先发现设备，再通过显式旧绑定回归安装、截图和输入 | 不重新装回旧内置执行器；工具、签名及包为假样本 |

保留原完整DeviceArtifactActions用于兼容回归，生产残余侧车的ADB字段固定为空。采用固定两项白名单，避免增加可配置黑名单或平台路由分支。Android安装和截图必须来自同一android-device当前代；没有插件或卸载后旧绑定目标缺失，不提供内置回退。

无需更改HTTP字段、设备API、前端生成类型或插件SDK。前端消费边界见所属前端文档；业务请求只携带公开设备引用、能力版本和产物ID。安装与截图的预算、取消、文件排空和目录删除由插件实施裁定约束，侧车不提高残余Harmony的旧清理承诺。

## 验证顺序与证据边界

先验证两流白名单和两入口拒绝，再验证新插件严格输入、私有副本、PNG、取消与实际资源收口，随后完整后端门禁、真实HTTP/MCP、公开浏览器消费和当前release/npx包。服务测试必须覆盖无插件时安装、截图旧名缺失，加载后贡献存在，卸载后无回退，实际产物字节和历史保留。

旧八贡献版本在当前会话已取得819项工作区测试、debug/release构建、四种普通服务回归及两种设备驱动证据。这些证明原八贡献批次，不转计本批十贡献版本。真机、APKS、Harmony迁出、动态性能和常驻会话仍分别推进。
