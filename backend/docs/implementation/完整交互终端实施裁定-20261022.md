# 完整交互终端实施裁定

日期：2026-10-22。用户要求补齐网页终端操作，直接运行交互式 Codex CLI。

## 架构门禁

模式为 architecture-first，采用契约先行与真实进程行为验证结合的 Hybrid。影响公共工具执行库、终端插件、前端会话用例与终端页面；通用宿主 HTTP、领域和协议5封套保持不变，不增加平台业务分支。现有普通管道模式保持兼容。此次范围是本机 Windows，其他平台不静默降级为伪终端。

采用 ConPTY 加网页终端模拟器。仅隐藏孙进程窗口或在文本输入框追加控制字符不能提供屏幕、光标与尺寸能力，不采用该路径。后端必须在程序开始执行前固定进程树归属，确认整个作用域退出后才返回清理完成；不全局查杀同名程序。

## 业务契约

- 原 `{"profile":"powershell"}` 保持原始管道字节语义。
- 交互终端打开为 `{"profile":"powershell","terminal":{"protocol":"deviceforge.terminal.v1","cols":120,"rows":30}}`。尺寸均为整数，列20至500、行5至200；不接受未知字段。
- 该模式每个协议5输入块是一个独立 UTF-8 JSON 消息：`{"type":"input","text":"原始按键或粘贴内容"}` 或 `{"type":"resize","cols":120,"rows":30}`。消息校验后才进入 PTY；不能把错误消息当成 shell 输入。前端串行、有界发送，网络结果不明确时不自动重放按键。
- 输出仍为协议5原字节 stdout，包含 UTF-8、ANSI/VT 转义和终端查询；PTY不拆分stderr。前端增量交给终端模拟器，不能按行重新拼接或删除控制序列。
- 页面尺寸经 ResizeObserver 与 fit 同步，输入包括方向键、Tab、Ctrl+C、中文输入和多行粘贴；关闭会话继续使用宿主 Cancel。PTY模式的协议EOF表示撤销终端输入并收口该会话，键盘Ctrl+D仍作为真实控制字符传递。
- 仅继承查找程序、用户目录和系统运行所需环境，不继承宿主令牌；声明 TERM、色彩与必要终端环境。保留原绝对期限、容量、输入输出上限、日志ID和owner/generation保护。终端原始内容不进入生产日志。

## 职责与落点

| 单元 | 责任与输入输出 | 不负责 | 副作用 |
| --- | --- | --- | --- |
| tool-process 新 pty 模块 | 固定argv和尺寸到ConPTY，原字节I/O、resize、Job归属、截止点与取消清理 | 插件消息、HTTP、shell命令解析 | 本次拥有的PTY、进程树和I/O |
| terminal 插件 operation/control/session | 严格打开和终端消息校验，选择管道或PTY，将公开会话映射至工具句柄 | 通用宿主路由、前端展示 | 调用公共工具库 |
| interactive-sessions 公开门面 | 显式打开PTY及发送终端消息，保留原send/openTerminal兼容 | ANSI渲染、原生进程 | 沿用公开会话网络接口 |
| terminal 页面私有视图与控制器 | xterm增量渲染、按键/粘贴、fit/缩放和销毁，页面只编排 | HTTP、服务端程序路径 | DOM、观察器和事件订阅 |
| 独立验收驱动 | 当前二进制真实HTTP、原生PTY及真实浏览器交互，校验退出与无新窗口 | 设备操作、模型任务、用户登录 | 独占测试进程与临时数据 |

先拆出页面专属终端视图与发送队列，不把终端模拟器生命周期继续堆进页面。公共库不依赖终端插件，插件不依赖宿主内部。前端HTTP类型由主代理生成，不手写或改生成文件；终端业务消息属于版本化插件协议。

## 写权和最低证据

后端角色独占 tool-process 的新 pty 模块、必要导出/依赖及 terminal 插件和所属文档；前端角色独占 interactive-sessions、terminal 页面私有实现、xterm依赖及相关前端测试文档。测试助理独占新的终端PTY验收脚本与产物，兼图片审核；主代理负责契约、共享构建、生成器、集成门禁、部署与根记录。无关并发改动保留。

先验证尺寸/消息拒绝、真实TTY识别、连续输入输出、ANSI、resize及取消后的整个进程树退出，再验证真实浏览器的Tab、方向键、Ctrl+C、中文、粘贴和Codex界面进入/退出。Codex验收不提交模型任务、不代替登录；验证失败如实记录并继续定位。所属端门禁与完整工作区结果分别记录，不把模拟工具或旧版本通过外推为本次交付。
