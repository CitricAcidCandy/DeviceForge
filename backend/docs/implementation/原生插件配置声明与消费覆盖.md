# 原生插件配置声明与消费覆盖

本轮为工作区 18 个独立服务器插件增加 `configuration` 声明，不改变任务 Request、操作输入或会话协议。`spreadsheet` 尚不属于当前 Rust 工作区，未计入这 18 项。

## 职责与配置选择

| 文件范围 | 责任 | 不承担的副作用 |
| --- | --- | --- |
| 各插件 `manifest.json` / `manifest.example.json` | 声明配置版本、JSON Schema、默认值、生效策略、旧旁置文件名 | 不执行配置或插件 |
| 各插件 `src/config*`、AI SDK 的 `src/deployment.rs` | 优先读取 SDK `managed_config_path()` 指向的宿主不可变修订，再沿用旧启动参数或旁置文件 | 不改写宿主配置、不绕过原有工具和路径资格验证 |
| `scripts/native-plugin-source.mjs` | 读取正式或兼容示例清单，检查公开模板关联，只收集受限公开 JSON | 不收集真实配置和凭据 |
| `scripts/native-plugin-package.mjs` | 携带配置声明和模板，生成部署说明，继续经过真实安装器入口映射和 Rust 校验 | 不运行包内脚本 |

宿主通过 `DEVICEFORGE_PLUGIN_CONFIG` 提供修订文件。该值存在时，插件把它作为明确配置：文件缺失、格式错误、路径错误均报错，不静默改用旁置文件或默认值。未提供时，原有 `--config` 和旁置读取方式继续保留。工具供给插件原本只有旁置入口，本轮保持这一兼容范围。

当前 12 个有配置的插件均在下一次任务或会话打开时重新读取，因此声明 `next_invocation`。已启动任务和会话继续使用其启动时快照；保存配置不会替换运行中的工具进程。其余 6 个插件声明空 `properties` 和空默认对象，管理端可以明确显示“无需配置”。

默认对象通过 Schema 校验。包含绝对路径的默认值来自公开部署示例，用户必须填写部署机器实际路径；合法的 JSON Schema 配置不代表工具文件、设备或固定 SDK 资格已经可用。配置表单检查与插件执行前检查共同生效。

## 敏感字段与目录变化

AI 插件环境变量和设置插件远端请求头的动态值声明 `writeOnly: true` 与 `format: password`。宿主遮蔽、保留和清除逻辑须递归处理 `additionalProperties`。签名材料仍只引用本机密钥库和密码文件，包中不会携带实际密码。固定 SDK 档案和版本声明 `readOnly` 与 `const`，运行时仍按原资格检查。

工具供给的相对本地清单在管理模式下保留插件部署目录语义，避免修订文件迁移造成清单失联。AI 助手省略 `state_root` 时保留旧配置旁 `ai-state` 语义。明确填写新的存储或安装根目录只改变后续读写位置，本轮不自动移动原数据。

## 验证入口与证据边界

- `node --test scripts/tests/native-plugin-source.test.mjs scripts/tests/native-plugin-plan.test.mjs`：声明结构、公开模板限制、18 插件便携清单、实际模板复制和安装入口映射。
- `node --test backend/plugins/configuration-tests/schema.test.mjs`：复用前端 Ajv，检查 18 个 Schema、默认值、公开配置模板、未知字段、AI 固定资格、工具来源互斥与敏感标记。
- 原生插件定点 `cargo test --lib`：沿用各插件的严格解析、资格与工具失败测试，并新增市场来源校验、修订路径优先、AI 状态目录和工具清单相对路径兼容测试。

上述检查不代表真实 ADB/HDC/Frida/投屏/AI 提供者运行、真实设备、Release/npx 分发或性能已经完成。真实配置保存与下一次调用消费仍须结合宿主集成和浏览器验收；记录实际运行结果后再扩大结论。
