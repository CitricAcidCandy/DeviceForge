# 插件产物协议（版本 2）

## 能力声明
部署者在插件清单中选择 protocol_version=2，并声明 artifacts。协议 1 继续支持原有请求和成功结果，不能声明产物能力。HTTP / MCP 调用方不能修改清单权限或指定服务器路径。

```json
"artifacts": {"input_fields":["artifact_id","source_ids"],"outputs":true}
```

input_fields 为最多 8 个唯一顶层字段名，字段名只允许 ASCII 字母、数字和下划线，最多 80 字节。任务输入中的对应值可以是 UUID 字符串或 UUID 字符串数组；缺失字段跳过。总输入最多 8 个产物、64 MiB，先复制并核对 SHA-256 和大小。

## 请求上下文
Request 保留 protocol_version、request_id、operation、input，新增 artifacts：

```json
{
  "inputs":[{"field":"artifact_id","artifact_id":"UUID","filename":"source.apk","size":123,"sha256":"摘要","path":"宿主提供的临时副本路径"}],
  "output_directory":"宿主提供的独占输出目录"
}
```

每个输入都关联原字段和原产物 ID。output_directory 在未授权输出时为 null。插件只使用这些路径执行本次操作，不应把路径当成可持久化标识。工作目录及临时环境目录也指向本次调用目录。

## 输出与宿主结果
插件把文件写到 output_directory，再通过标准输出返回响应：

```json
{"protocol_version":2,"request_id":"原请求 ID","result":{"message":"完成"},"outputs":[{"filename":"result.zip"}]}
```

outputs 默认空数组，最多 8 项；只声明单一文件名，不传文件路径或服务地址。文件总量最多 64 MiB，允许 APK / APKS / AAB / HAP / ZIP / PNG / JSON / MSGPACK；JSON/MessagePack 单文件最多 16 MiB、64 层和 100000 节点。拒绝链接、非普通文件、路径与重复名称，内容检查沿用产物服务。PNG 当前仍仅检查头部。

宿主先预校验所有声明输出，再逐个发布。协议 2 的任务成功结果固定为：

```json
{"result":{"message":"完成"},"artifacts":[{"id":"新 UUID","filename":"result.zip","media_type":"application/zip","size":123,"sha256":"摘要","created_at":0}]}
```

result:null 合法，artifacts 为空时仍保留结果结构。模型 PluginArtifactResult 从领域类型生成到 OpenAPI。客户端下载使用既有产物接口，后续操作继续传新产物 ID。

响应必须匹配协议版本和 request_id，result 与非空 error 只能提供一个。失败响应不能同时声明 outputs。准备 / 发布各阶段最多 120 秒，插件进程最多 60 秒；请求最多 512 KiB，标准输出 / 错误各最多 1 MiB。

## 一致性与信任边界
多输出发布没有事务回滚：存储错误或取消发生在发布过程中，已经发布的产物可能保留。所有文件预校验可以避免后续明显无效文件导致的部分提交，但不能消除存储故障和并发修改。

清单能力限制宿主提供的访问，不构成操作系统沙箱。管理员部署的插件运行于服务账户权限，仍属于可信本机代码；目前没有网络隔离、磁盘硬配额或完整派生进程树回收。插件不得启动后台进程，不应依赖服务凭据。宿主进程环境不会向插件传入 APK_API_TOKEN。

## 实现与验收
SDK 位于 crates/plugin-sdk；宿主编排位于 infrastructure/src/plugins.rs，产物准备 / 发布位于 infrastructure/src/plugin_artifacts。公开示例 plugins/artifact-copy 只依赖 SDK。

真实子进程测试覆盖输入副本、摘要篡改、输出授权、路径和格式错误、协议版本 / 请求 ID / 空错误 / 空值、数量 / 体积和临时目录清理；runtime-smoke.mjs 覆盖 HTTP / MCP 插件调用、新产物下载与字节摘要。通用进程插件运行中管理见 [运行中插件生命周期](运行中插件生命周期.md)，任务执行仍复用本协议；多租户权限、设备提供者、常驻会话及跨插件调用仍待实现。
