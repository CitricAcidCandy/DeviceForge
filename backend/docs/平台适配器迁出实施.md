# 平台适配器迁出实施

## 目标与当前状态

模式为 architecture-first / Hybrid：冻结公开端口及资源归属后，按模块实施并验证旧行为。上一阶段嵌套产物选择已经通过当前 debug/release/npx；本文件是下一阶段实施边界，不是平台迁出完成证据。工程仍位于 G:\Rust\DeviceForge，旧 Electron 工程只读取证。

目标是独立 Android/Harmony 设备插件与 Android 包工具插件。宿主只装配任务、产物、日志、目录、生命周期和 HTTP/MCP；移除具体 ADB/HDC/Java/Apktool 业务装配和隐式内置回退。空插件部署不检查平台工具或签名材料，也能正常启动。iOS、常驻协议、其他旧业务和真机继续独立推进。

## 已核对的影响范围

当前 server/main.rs 直接装配 DeviceTools、DeviceArtifactActions、AndroidInput、AndroidSplits、AndroidPerformance，以及 AndroidBundles、AndroidPackageTools、AndroidReverse。不能仅把发现搬到插件目录，仍由宿主执行其他平台命令。

| 单元 | 职责与边界 | 目标落点 |
| --- | --- | --- |
| 公共工具执行库 | 异步独立 argv、限定环境、输出限额、总期限、取消和直接进程退出；独立错误类型，不依赖宿主 domain | crates/tool-process，宿主 process 仅做错误映射及协议适配 |
| 公共包处理库 | Android 两插件共享的受限容器校验、提取、打包及纯解析；不访问宿主存储 | crates/android-package-core，按规则与副作用拆分 |
| Android 设备插件 | ADB 发现、应用操作、输入、安装、截图、分包安装及采样 | plugins/android-device，按业务拆模块，只依赖公开 SDK/公共库 |
| Harmony 设备插件 | HDC 发现、包列表、HAP 安装/卸载；准确声明现有能力 | plugins/harmony-device，不扩大为尚未实现的输入/性能/完整应用管理 |
| Android 包工具插件 | APK/APKS/AAB 分析、签名、构建、反编译与 SDK 检测 | plugins/android-packages，不持有宿主设备锁 |
| 通用旧操作绑定 | 显式绑定旧名称与插件贡献，转换输入/结果并保留当前 owner/generation 准入 | application/operation_aliases，不拼平台命令，不再次提交嵌套 Job |
| 性能会话基础设施 | 暂停/恢复/结束、采样排空、存储、分页及恢复 | application/performance、infrastructure/performance/store 留宿主，采样源动态绑定 |

影响 Cargo.toml/lock、各依赖清单、架构门禁、公开 SDK、domain 设备/性能端口、application 注册/执行/设备锁/生命周期、infrastructure 进程适配，以及 server 装配和生成接口。包部署、CLI、runtime-smoke、设备/浏览器/性能与分发验收同步更新；前端文档继续放 frontend/docs，不实施产品 UI。

## 实施约束与选择

迁出采用独立进程插件和公开版本化协议，不采用 Rust 动态库热卸载。新公共库必须有独立职责、中文 README 与行为测试；禁止通过依赖 infrastructure 复用整套宿主实现。当前 tool-process 的首个实施范围是文本/字节及文件输出执行，不包含合作协议帧解析或平台命令。

旧操作最终显式绑定到当前插件贡献。当前内置 owner=None 会绕过设备准入，桥接必须在同一次任务内完成映射后共享提供者代际、设备写锁、provider 写屏障、队列和清理；不得在持锁或占用执行槽时再次提交 Job。多个提供者暴露同一本地 ID 时，由明确配置绑定，歧义拒绝，禁止按 platform 或目录顺序猜提供者。

输入与结果兼容需要单独映射：旧裸 device_id 没有提供者代际；旧 recovery/sideload/bootloader 状态不能静默折叠丢失；截图的旧 Artifact 返回与协议 2/3 的 result/artifacts 包装需明确定义。历史任务保留其原操作和结果，不能卸载后重写旧记录。

长安装需要有界期限的公开加法。现有设备调用默认 30 秒，旧 APKS 为 120 秒且协议 2 进程默认 60 秒；不能以更短固定窗口冒充等价迁移，也不能绕过宿主期限。下一项契约需以能力声明和宿主上限决定整体预算，省略声明保持 30 秒，长安装上限按既有 120 秒边界审查；排队、锁、副本、执行与发布共享准入起的同一截止点，协议传输不能另行截短或重计时，清理预算独立且仍有界。准确字段与版本、映射及失败路径须先形成测试，再进入平台实现。

性能会话不能永久持有不受热卸载管理的 probe，也不能依赖 protected 禁止卸载。每个会话显式绑定当前 owner/generation 和设备引用；每次采样共享设备准入。卸载撤销入口、取消并等待会话排空，保留历史；重载不能令旧会话继续调用新代。PerformanceAccess 当前协议 2 兼容须保留，协议 3 加法与清理确认另定义。

工具路径、签名材料及共享 daemon 归部署配置；业务调用只传公开参数和产物 ID。插件自有资源必须可取消、可清理；部署者共享 ADB/HDC daemon 不得被卸载误杀，连接借用与自有连接分别记录。离散插件进程退出只证明本次调用退出，不证明持续连接、后台派生进程或真机事务已回滚；常驻会话仍是后续必要实施项。

现有 Response.error 为字符串，任务准入错误和执行失败分开验收，不宣称已有完整平台结构化错误。新配置和别名不得导致空插件宿主启动检查任何平台工具。资源未确认仍保持 draining/cleanup_failed 并拒绝新代与排队任务。

## 分步实施和验收

1. 提取公共工具执行库，独立验证 argv、两路输出限额、字节/文件输出、预取消、运行取消、超时、Future 丢弃与进程退出；宿主保留协议和错误映射，当前行为回归。同步 Cargo 架构门禁，插件可引用该公共库。
2. 补能力总期限、旧操作绑定及性能生命周期的最小公开加法；验证旧清单默认、显式长安装、总截止点、原子绑定/撤销、旧代拒绝、别名与新能力共享写锁，禁止嵌套提交及直接绕过执行器。
3. Android/Harmony 与 Android 包工具按 disjoint 文件所有权并行实施。主代理管理 SDK、生成类型、门禁和构建；各插件只依赖公共契约，无私有宿主依赖。提供真实模拟进程回归，不拷贝业务到通用路由。
4. 去除 main.rs 的所有平台装配和隐式性能回退。无工具、无平台包也能启动；在线安装平台包后 HTTP/MCP/直接 jobs 统一准入，卸载后贡献与旧操作全部撤销。性能会话排空及历史查询独立验证。
5. 覆盖 APK/HAP/APKS 副本、截图/提取输出下载摘要、非零退出/零退出失败文本、断线、取消/超时/丢弃与限额。随后后端六门禁和所有受影响 smoke、前端 generate/check/test/build，再重建当前 release/npx 及实际平台包分发。

每步完成记录实现、真实命令退出码和边界。运行中自有服务与 Cargo/build 不并行，生成接口只由主代理执行；不提交、恢复或删除无关修改。真实包、Android/Harmony 真机、常驻/iOS、其他平台与局域网远端客户端仍分别验收，模拟提供者和本机 npx 不能替代。
