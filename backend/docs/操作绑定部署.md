# 操作绑定部署

部署者可用 APK_OPERATION_BINDINGS 指定 JSON 文件；不配置时无别名。文件最多 64 KiB，格式 1 最多 256 项。Rust 直接启动时按其工作目录读取相对路径，CLI/npx 按启动器工作目录解析相对路径后传给后端。

以下示例把普通旧入口映射到公开 echo 示例插件，输入和结果原样保留。目标插件须先安装并加载；别名与目标贡献一起发布或撤销。

```json
{
  "format_version": 1,
  "bindings": [{
    "operation": {
      "id": "legacy.echo",
      "title": "兼容回显入口",
      "input_schema": {"type": "object"}
    },
    "target": {
      "kind": "operation",
      "plugin_id": "echo",
      "operation": "plugin.echo.echo"
    },
    "input": "identity",
    "result": {"kind": "identity"}
  }]
}
```

将配置保存为 bindings.json，再在启动器工作目录设置环境变量并执行现有 npx 启动命令：

```powershell
$env:APK_OPERATION_BINDINGS = '.\bindings.json'
npx --package .\artifacts\deviceforge-cli-0.1.0.tgz deviceforge start
```

该变量属于部署配置，不接受业务请求修改或选择服务器路径。路径为空、无法读取、文件超量、未知字段、错误版本、非法模式或转换规则都会拒绝启动，不悄悄忽略配置。

设备能力目标使用 device_capability、plugin_id、capability 和精确 version。device_envelope 把旧顶层 device_id 移到固定封套，其他字段作为能力 input；设备范围要求真实当前代目录和可用观测，提供者范围只允许缺省/null 的 device_id。普通 operation 目标只能指向该插件自己的非设备、非发现贡献。

结果规则提供 identity、value、artifact、object。wrapped 为 true 或出现 artifact 源时，目标必须由宿主提供已发布产物包装；协议 1 的业务 JSON 即使长得像包装也不能使用这些规则。产物按本次发布列表的文件名唯一选取。optional 只省略缺失源，显式 null 保留，重复产物、错误包装和非法遍历仍失败。

绑定预留其入口名称；目标未安装、未加载或已撤销时，HTTP/MCP 不发现该入口，提交为 not_found，不回退同名内置操作。注册失败不留下部分贡献，旧名称和旧输入保留在唯一 Job 中，执行与目标共享所有权、代际、锁、期限和取消清理。

本批拒绝 android.devices、harmony.devices 旧发现别名，原始特殊状态与统一发现发布另行实施。配置通用能力不表示 Android/Harmony 平台代码已经迁出，常驻连接、实际平台包、真机和非设备包长期限仍分别验收。冻结规则见 [第一批契约](操作绑定第一批契约.md)，实际证据以根 todo 最新记录为准。
