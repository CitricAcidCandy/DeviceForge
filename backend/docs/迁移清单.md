## 通用进程插件生命周期阶段（2026-10-09）

领域 PluginCatalog 作为异步部署端口；应用注册层完整校验后原子发布，持有修订、代际、取消树与任务跟踪。基础设施按固定部署根与 ID 受限读取；HTTP/MCP 管理只转换协议并调用同一服务。加载/卸载管理有界且串行，取消客户端等待后继续收敛；保护长期性能探针依赖。

卸载撤销新任务，取消并等待排队/运行任务；重载生成新代际，旧快照不能通过准入。当前提供鉴权 v2 插件目录与 load/unload，MCP 动态发现带修订分页，旧游标失效。具体路径、模型、限额及失败语义见 [运行中插件生命周期](运行中插件生命周期.md)。
