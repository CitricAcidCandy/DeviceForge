# 三星 FPS 实机复核

日期：2026-10-23，Asia/Shanghai。

## 结论与修改边界

用户已打开目标游戏后，当前 Android 插件可以读取可信游戏图层的实际展示窗口，宿主持久性能会话也保存了有效 FPS。生产前端性能模型可以接受并合并这些读数。本轮没有发现需要放宽归属规则的证据，因此没有修改 FPS 源码、构建、热更新或重启宿主及插件。

最初 10 秒会话的三点 FPS 缺测原因仍未确定，不能用本次通过倒推当时一定在加载阶段或一定没有有效图层。两次会话的来源代次不同，也不能把本次结果当成旧运行包的复验。

## 当前设备与操作范围

- 目标：三星 SM-G991U，Android 11 / API 30，ADB 地址 `192.168.208.237:8100`。
- 宿主目录最初保留旧在线观测，但真实 ADB 中目标已断开。仅对用户原地址重连一次，随后重新核对机型；没有把目录缓存当成实时在线。
- 目标包 `com.ChillyRoom.DungeonShooter` 由用户打开，当前 PID 31362、UID 12851。只读读取进程身份、图层二进制、窗口文本和 latency，未执行应用启动、触摸、重启、设置修改或息屏。
- SurfaceFlinger 的原生数值父链、应用 UID、完整窗口会话 PID/UID 与声明 Surface 均可关联；两次 latency 原始返回具有持续前进的实际展示时间戳。没有执行全局 latency-clear，也没有用屏幕刷新率代替游戏 FPS。

## 前端与证据边界

使用该真实会话的原始公开响应，经生产 `createPerformance` 的会话/样本校验和合并，四点 FPS 与保存结果逐项一致。测试网关只回放原响应，没有生成帧率或代替浏览器渲染；不计 Canvas、截图视觉或产品页交互通过。

本轮未改公开类型或业务源码，因此未重新运行 Cargo、API 生成或前端整包门禁。前一轮前端接线修复仍独立适用，不借本次 FPS 实录覆盖已有图表测试失败。

原始证据位于 `artifacts/fps-samsung-20261023/live-02`：`capture.json`、`current-plugin-sample.json`、`session-start.json`、`session-samples.json`、`frontend-consumer.json`。首次断线失败与游戏尚未运行时的只读返回分别保留在证据根和 `live-01`，不覆盖失败原件。

采集已自然完成，没有遗留运行中的本次性能会话。生产前端消费校验进程自然退出；共享 ADB server、调试连接和用户打开的游戏保持原归属，没有代杀或断开。
