# 插件展示与配置入口验收

## 问题与修复范围

用户反馈已安装插件仅显示 ID、缺少名称和描述，配置入口返回“接口不存在”。现场 7031 预览仍运行旧宿主，部署的 13 份插件清单没有源码已有的 `configuration` 声明，市场本地条目也没有消费插件自己的展示资料。

本轮保留运行清单职责，新增可选 `PluginInfo.metadata`，由部署根 `market.json` 提供名称、简介和完整描述。缺失或坏资料兼容降级，不阻止插件运行。工作区 18 个插件补齐中文资料，原生打包和 CLI 安装共同保留它；具体边界见 [插件展示元数据](../contracts/插件展示元数据.md)。

真实浏览器进一步发现 `OPTIONS` 虽返回 204，但跨域允许方法缺少配置保存使用的 `PATCH`。本轮补齐允许方法，并扩展既有带令牌预检回归，精确检查配置端点允许 PATCH、公开日志关联头且不启用 Cookie 凭据。

## 证据边界

插件元数据、配置声明与公开模板不等于 ADB、scrcpy 或其他工具已随服务器打包。配置保存、进程消费、浏览器页面和设备投屏分别验收；本轮没有重做真机播放、音频、LAN/NAT/TURN、长时稳定性或性能专项，也没有公开发布 npm 或市场资源。报告不记录真实配置正文和凭据。
