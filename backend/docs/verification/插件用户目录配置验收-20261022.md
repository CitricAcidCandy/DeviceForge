# 插件用户目录配置验收

用户确认初始插件程序可留随包或部署目录，插件配置统一归属用户目录。本轮实现将配置根从业务数据根分离，默认 `<home>/.deviceforge/plugin-configurations`；`DEVICEFORGE_USER_DIR` 可显式指定隔离用户根。服务器插件使用 `server/<id>`，浏览器插件使用 `browser/<id>`。更改 `APK_DATA_DIR` 或 CLI `--data-dir` 不改变配置归属。

服务器旧状态和不可变修订仅在目标没有状态时复制，原文件保留；首次默认值或旁置模板也物化到用户根。插件实际进程消费用户目录快照，`plugin_reload` 继续保留当前生效修订。浏览器通过版本化 API 保存完整原值记录，使用修订比较拒绝覆盖；路径和原值不进入日志。

已完成的当前证据：

- 基础设施浏览器存储定点 9 项通过，1 个锁探针由父测试调用并在普通清单中忽略；服务器存储定点 7 项、浏览器 HTTP/OpenAPI 4 项、配置根解析 1 项通过。
- 后端架构及架构测试 6 项、fmt、完整 Clippy、完整 debug 构建通过。后续新增正版本校验纳入最终门禁收口。
- 隔离真实 HTTP 与 Edge 组合验收 32 项通过，浏览器首次阶段 10 项行为通过；两个业务根顺序启动、同一用户根，重启后新浏览器上下文仍取得原值与修订。受控 Node 插件实际消费用户快照。浏览器失败行为采用注入 transport 故障，与真实 HTTP 成功链路分别记录。
- 本机预览 13 个插件配置实际落入 `C:\Users\柠檬果\.deviceforge\plugin-configurations\server`，投屏仍为修订 1。迁移后 JSON 内容、应用标记与原值一致，旧文件摘要不变。宿主程序、工具和业务数据仍在原部署位置。

证据位于根 `artifacts/plugin-user-configurations-20261022/`：`debug-browser/report.json`、两个 `browser-*/report.json`、`deployment-report.json` 与 `validation/`。实际运行范围为当前 Windows、本机服务和受控插件；不涉及设备操作、媒体连续性、外网发布、其他机器或性能验收。
