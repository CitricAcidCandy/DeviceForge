# 插件用户目录配置验收

用户确认初始插件程序可留随包或部署目录，插件配置统一归属用户目录。本轮实现将配置根从业务数据根分离，默认 `<home>/.deviceforge/plugin-configurations`；`DEVICEFORGE_USER_DIR` 可显式指定隔离用户根。服务器插件使用 `server/<id>`，浏览器插件使用 `browser/<id>`。更改 `APK_DATA_DIR` 或 CLI `--data-dir` 不改变配置归属。

服务器旧状态和不可变修订仅在目标没有状态时复制，原文件保留；首次默认值或旁置模板也物化到用户根。插件实际进程消费用户目录快照，`plugin_reload` 继续保留当前生效修订。浏览器通过版本化 API 保存完整原值记录，使用修订比较拒绝覆盖；路径和原值不进入日志。
