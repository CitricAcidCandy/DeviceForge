## 实施范围

- 公开依赖库及 SDK 导出；独立组件 dependencies.json 与完整发布 v2，同名 release/server/browser 目标隔离和组件归属归并。
- 环境、PATH、声明用户位置、全仓库索引及已登记本地工具发现；跨插件实际版本/入口匹配，不按安装者或内置插件名单分支。
- 正常安装先检测并复用，只下载缺失必需项；可选依赖显式补装，启动和普通重新检测不下载。高级手动覆盖不是前置步骤。
- 本地工具只登记内容身份、不删除原文件；共享工具不可变包修订、独立消费者引用、活动租约与失败保旧。
- 脚本组件通过公开 runtime dependency 引用启动解释器；实际解释器随本次资源快照取得租约，不将 helper 子进程冒充插件本体。
- 正常安装失败保留部署及 dependencies_required，补救成功按原启用意图恢复；失败诊断独立于有效绑定，不为显示错误破坏旧快照。
- 在线依赖保存市场基址、同源解析相对摘要；离线归档使用既有资源缓存；完整性失败直接报告，不换源掩盖。
- HTTP/MCP/CLI 共用用例；初始 CLI 使用运行包明确能力及宿主准备模式，不另建工具仓库或启动监听。
- 市场 v1/v2、打包器、十八份官方声明与指南 v3。无可信来源的工具不伪造摘要或下载地址。
