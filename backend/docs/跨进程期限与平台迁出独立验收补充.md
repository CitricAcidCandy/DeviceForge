## 当前公开接缝能表达什么

| 接缝 | 已有表达 | 不能从它推得的保证 |
| --- | --- | --- |
| `plugin-sdk::Contribution.execution` | 可选预算 `{api_version:1,total_timeout_ms}`，宿主固化有效普通预算；默认与范围沿已冻结普通契约 | 声明不是剩余预算、执行开始点或 Request 中的宿主 D |
| `plugin-sdk::Request` | protocol_version、request_id、operation、input、可选 ArtifactContext；严格拒绝未知字段 | 当前无 deadline/剩余预算；不能增私有 JSON 字段、环境变量或业务 input 来冒充公开上下文 |
| `plugin-runtime::serve_once/serve_io` | handler 接收 Request 和 CancellationToken；协议 3 匹配控制帧通知取消；Execution 另报告 cleanup | handler 令牌无 timeout/cancelled 原因，也无宿主单调点；插件自身 Cancelled 不能反推宿主 Job 分类 |
| `cooperative::ControlFrame` | cancel 命令、匹配 request_id 与 CancelReason；CooperativeResponse 有 Complete/Failed | 线上 reason 与 handler 令牌是不同证据；complete 自报不能替代全部资源的真实结束 |
| `ArtifactContext/ArtifactOutput` | 授权输入的 ID、field、正文摘要及宿主副本路径；输出只报有限文件名 | 插件不能自行分配可信宿主 Artifact ID；业务 JSON 的伪 result/artifacts 不是发布证明 |
| `PerformanceAccess/PerformanceSample` | sample_operation、fps 声明和有界采样值/帧窗口 | 没有因此获得热装卸会话 owner/generation、常驻协议、真 FPS 或完整采样源排空 |

宿主 std::time::Instant 只能在本进程内按原点传播，不能把其数值直接序列化为跨进程绝对点。现 SDK 能证明的路径是宿主坚持原 D、到期通知取消、拒绝后续宿主副作用与成功；插件依已知令牌和经裁定的本地控制停止工作。该路径不能证明控制帧抵达前插件每笔新 I/O 均按宿主剩余 D 拒绝。强保证需要主代理先裁定公开上下文和兼容，再分配实现与测试；本文不设计或冻结字段名。

## owner、代际与实际资源结束

注册 owner、资源租约和业务会话是三个观测对象。注册撤销阻止新调用，不说明执行器物理退出；直接 PID 退出不说明同步闭包、输出监测或共享 daemon 已结束。租约释放必须由它实际保护的工作结束作证，不能用 Job 终态或固定延时删除目录顶替。

| 编号 / 层 | 最小控制点与断言 | 证据与限制 |
| --- | --- | --- |
| O01 公开 owner/代际 | 先成功发布一代，取得设备引用并令一个任务 ready；卸载后撤销入口，再重载得到新代；旧设备 ref 精确 409/conflict，历史原 operation/input/result 不变 | HTTP/MCP 各查询同一旧 Job；记录 provider/plugin、generation、实际调用与宿主未重启。普通名称查找与设备旧 ref 的错误分类分别沿所属契约，不能统一套任意 4xx |
| O02 清理风险门禁 | 用所属协议已裁定的未确认场景使 owner 风险粘住；后续新提交和已排队获槽任务零首次执行，另一个任务成功不能清零 | 按生命周期契约核对 conflict、卸载 cleanup_failed/409、draining 和同 ID 重载保护。没有公开确定性触发时保留缺口，不以进程非零退出或伪 cleanup 字符串代替 |
| O03 同步 worker | 公开操作输入准备后让同步工作实际进入门闩，丢弃外层等待或取消，再探测容量和工作目录；只在真实闭包结束后允许其许可/lease 释放 | 宿主受控时钟负责 D，真实闭包门闩负责物理结束。公开路径没有稳定阶段接缝时，由所属内部测试证明；不新增 hook 或重复私有 Pool 四槽测试 |
| O04 直接工具租约 | 通过新公开租约入口，以本次真实 Child ready 为起点，分别覆盖正常退出、短 D、显式取消、等待 Future 丢弃和文件输出 | 交出调用方最后一个 Arc 后，资源析构见证必须独立核对本次 PID 已退出；夹具 process_exit 标记或只读 Arc 计数不能单独证明。Future 丢弃无返回值，不伪造 Cancelled/CleanupFailed 结果 |
| O05 工具与监测 | 两者均在飞时触发停止，分别让一边先收敛、另一边继续受控阻塞；只使用停止时取得的一次两秒清理点 | 按第二批裁定保留 CleanupFailed，禁止最终 pack/put；后台仍持其许可/lease。各边串行等待两秒、工具退出后忽略监测都不合格；内部 monitored 定点与公开产物流分别记录 |
| O06 卸载/服务退出 | 正常在途任务汇合后卸载或 shutdown；未确认路径维持保护，不强杀未知 PID、不删除目录制造成功 | 直接进程、跟踪器、包容量和服务端口分别取证；卸载十秒边界不扩大。一次正常 shutdown 不能证明任意故障或进程树排空 |

真机性能资格另需设备/系统版本、工具版本、权限、目标 PID 与启动身份、观测区间和来源口径。主进程 CPU/PSS/RSS 不代表全包；各命令顺序采样不是原子快照；源报 FPS 不证明设备实际渲染帧。派生树、常驻会话、日志性能和包工具吞吐各自独立，不能互相借用结论。

每次动态运行应先固定真实执行输入范围、逐文件 SHA 与命令/session，再分别保留开始和终态。共享工作区另有活跃写集时，完整清单的差异与执行范围清单的差异分别报告，不能隐去原差异，也不能将 execution-only 零差异描述成全工作区未变。本次 tool ownership 只关联上述 022650 冻结版本，后续源码或测试变更不能借用这四项结果。

包身份记录原压缩字节 SHA256、包内清单/入口及实际成员数；不固定历史的 24 成员。npx 的真实 shim 内容应解析到当次缓存入口，随后核对该 runtime 实际 host 的 hash。缓存静态身份、服务提供的前端资产与 Rust 进程身份分别记录；无直接 PID 的链可保留静态与服务证据，但不得反推直接进程身份。

失败时保留正式归档、临时根、原失败请求路径/方法、checkpoint、marker 与脱敏日志，不输出环境、鉴权头、签名材料或响应正文。finally 独立记录 shutdown 尝试、响应、子进程 exit、浏览器 exit 和两个端口结果；任一端口未释放不得先标成功，也不能因为第一个检查失败跳过第二个。后续清理失败追加记录，不覆盖业务失败。

成功报告至少包含本次 Job 子集及启动前基线、每个 request/log ID、协议/operation、进程 ready 与 OS 退出、产物发布/下载 ID及摘要、宿主实际 hash和清理结论。多次运行、debug/release、正向/受控失败的版本分别关联，不把历史未变包或旧报告借作新输入通过。样本性能另记录样本规模、并发、工具/机器、构建模式和多次统计；一轮退出成功或短时间完成测试不构成吞吐/尾延迟保证。
