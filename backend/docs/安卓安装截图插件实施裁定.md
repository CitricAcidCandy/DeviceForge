# 安卓安装截图插件实施裁定

日期：2026-10-10。状态：主代理已明确冻结，生产实施中；尚未执行本批测试。模式为architecture-first，验证顺序为Hybrid：先公开契约与零副作用失败，再真实独立进程、宿主撤除和分发。本文采用架构门禁与实现技能，实施时不重新扩张本批。

## 目标、选择和影响层

同一android-device提供者追加APK安装与PNG截图，继续公开设备API3、协议4及原InvocationContext。比较第二提供者与同提供者：第二提供者将相同serial置于不同锁键，不能与input/uninstall自然互斥；选择同提供者。截图为device/write，与安装、卸载、输入保持明确顺序；无需公开SDK版本、Request字段、平台HTTP路由或前端生成类型变更。

本批不增加Android包核心依赖，不把旧安装资格提高为完整Manifest、CRC或签名验证。ADB默认共享server、持久远程连接仍由部署者管理，不运行kill-server、全局disconnect，不把客户端退出写成设备事务回滚。APKS、Harmony、性能、常驻、真机和其它宿主系统分别验收。

影响层为独立插件的纯输入、工具适配、文件资源、清单/别名、测试/说明，以及主代理所属的宿主残余装配与集成门禁。宿主通用设备目录、任务、锁、产物端口保持既有职责。新增贡献通过原公开接缝接入，不复制平台路由或宿主ArtifactStore。

## 冻结公开行为

| 项目 | APK安装 | PNG截图 |
| --- | --- | --- |
| 短贡献、能力版本 | app.install，1 | screenshot，1 |
| 对外完整ID | plugin.android-device.app.install | plugin.android-device.screenshot |
| scope/access | device/write | device/write |
| 总能力预算 | 120000毫秒 | 30000毫秒 |
| 严格业务封套 | `{device_id:<原文serial>,input:{artifact_id:<规范UUID>}}` | `{device_id:<原文serial>,input:{}}` |
| argv | `-s serial install <私有input.apk>` | `-s serial exec-out screencap -p` |
| 工具短点 | 无，直接原D_L | 无，直接原D_L |
| runtime Output | value为`{artifact_id,output}`，artifacts为空 | value为null，artifacts为唯一`{filename:"screenshot.png"}` |
| 旧别名 | android.app.install，device_envelope，Value wrapped=true | android.screenshot，device_envelope，Artifact filename=screenshot.png |

不声明Contribution.execution。清单追加后十贡献、九能力；discover仍不是能力，online每设备availability为七项，非online为false并带固定有限reason，connect/disconnect仍provider/write。两个manifest逐字节同源，schema与运行时均拒未知字段和错误完整贡献名。serial保留原资格；artifact_id严格36字符标准连字符UUID，不接受路径、flags、预算或工具入口。

整个插件声明`ArtifactAccess {input_fields:[],input_pointers:["/input/artifact_id"],outputs:true}`。安装要求ArtifactContext.inputs恰好一行，field严格为`/input/artifact_id`，ID严格等于业务输入；额外、重复、错pointer、错ID和缺行都拒绝。截图和旧动作要求inputs为空；合法Some空上下文不能误拒。安装不依赖output_directory；截图必须有唯一授权输出目录。

## 输入与输出资格

安装沿旧规则接受显示名的.apk后缀，最多64MiB，SHA256为64位十六进制。metadata与实际打开句柄必须是普通文件；绝对路径及各祖先不得经过链接、重解析点或特殊文件。验证声明长度，分块计数不得超过声明size或64MiB，完整摘要按实际读到的字节核对；提前EOF、超额或不一致均零工具。

固定私有input.apk通过create_new创建，复制、flush和关闭实际句柄完成后ADB只读该副本。打开前后复核路径与句柄的资格/元数据，发现换路径、换长度等变化拒绝；文件内容稳定仍属于调用者约束，不宣称单句柄等于不可变快照。stdout和stderr均要求有效UTF-8，合并后失败文本优先、必须有独立Success行；返回文本中的私有路径替换显示filename，错误只含固定中文。

截图先写插件独占screenshot.png，标准输出最多64MiB，stderr最多1MiB，零退出和真实写端关闭后才验证；不将ADB直接指向宿主输出目录。PNG沿宿主最低规则：文件至少45字节，24字节头中8字节签名、长度13与IHDR、宽高均非零；不新增图像库或完整CRC/解码。授权输出目录及祖先须为普通目录且无链接/重解析点，固定目标使用create_new，已有目标拒绝、不覆盖；沿原D_L完整复制、flush、关闭和最终检查后才声明输出。发布实体仍由宿主生成。

## 原期限、任务丢弃与目录删除确认

业务每个I/O、分块、工具首poll、复制交接及成功交付前沿InvocationContext.check复核；D_L固定，不按阶段重新授予120/30秒。到期与取消同刻为Timeout优先，CleanupFailed优先于普通成功/错误。清理允许在业务已到期后继续，不能用业务到期跳过清理，也不能把清理预算用于继续准备、工具或发布。

每调用仅一个实际活动的阻塞文件闭包。许可在提交工作前沿原D_L取得；闭包拥有许可、目录lease、实际std文件句柄和只读取消回调，按64KiB边界检查，最终flush/关闭句柄才真实返回。等待Future被丢弃不abort正在运行的闭包，只通知子取消并置粘性unresolved；闭包继续持lease直到真实退出，不能先删目录。没有新CPU解析、后台采样或轮询。目录建删同样经该槽，尚未移交的创建工作也要记录真实创建结果，不能靠TempDir::Drop吞删除错误。

截图文件捕获由独占异步文件任务拥有Tokio File和目录lease。使用公开capture_to_file_with_lease，额外资源lease随公共直接进程所有者保留；插件共用既有ToolGuard，不复制spawn、kill、等待PID或Pending实现。捕获返回后，不论成功或错误，文件任务继续flush并用into_std.await确认内部文件工作排空，再关闭真实句柄，最后返回和释放自己的lease。普通capture返回仅证明直接进程/公共输出路径的结果，不自行提升为目录或文件排空确认。

等待截图任务被丢弃时通知它的子取消并置粘性unresolved，不abort它、不先drop自动删目录。结束等待真实文件任务；若任务panic、join失败、排空失败、直接进程CleanupFailed或期限内未结束，资源结果为Failed，目录保持可审计。运行时丢弃任务也没有自动删除目录。明确外层丢弃并未“稍后后台完成”而获得complete；宿主原未确认资源门禁继续保留风险。

同次收口第一次观察到取消、业务到期、丢弃或进入finish时固定清理点C，不为每个worker、flush或目录delete重新计时；本地最多两秒。取消/到期分支继续轮询公共工具Future与真实文件任务，但外层等待受同C约束；C到期丢弃等待时公共库继续持直接进程租约，插件保留Failed。公共工具错误发生时刻没有通知接缝，普通错误返回且公共库已确认直接进程后才进入目录确认，不扣正常工具等待耗时，也不声称其内部回收与C精确同点。直接CleanupFailed绝不提升为Complete。宿主合作窗口与最终进程兜底不扩大，未能在宿主窗口交付确认时仍属于未确认。

finish先真实排空本次已提交工作和实际文件任务，再检查工具结果、粘性unresolved及目录lease归还；只有确认无使用者才提交目录删除。删除worker持自己的lease，复核自有目录与祖先路径资格，只删本次独占目录，不删scratch_root、授权output_directory或其它任务目录。必须收到实际remove_dir_all成功及目录不存在确认才可Complete；I/O失败、join失败、C到期或等待丢弃均粘性Failed，目录保留，不以Drop重试、定时删除或“文件已关闭”代替确认。

失败时SDK授权输出根归宿主。插件仅撤除已明确由本次create_new获得的固定目标文件，撤除也要求实际完成；不删除原有同名文件、不删除根目录。业务失败且清理全确认可Complete(error)，任何资源未确认必须Execution.cleanup=Failed且固定CleanupFailed，不返回输出声明。安装准备已创建目录后的失败也走同一收口，不能提前Execution::complete。完成结果在目录删除后再次复核业务上下文，清理耗时导致业务D_L到期不能恢复晚成功。

## 最低失败与验证矩阵

| 行为 | 必须证明的结果 |
| --- | --- |
| 两层未知字段、错误短名/完整名、坏UUID、缺/多/重复/错pointer或ID | 配置、目录、输入读取与ADB之前纯拒绝；旧空上下文继续合法 |
| 非.apk、超64MiB、坏hash格式、size不符、提前EOF、hash不符、链接/重解析点/特殊文件 | 无ADB，已创建资源明确收口，失败无输出声明 |
| 安装私有copy | ADB argv仅指本次input.apk，字节等于核验输入；绝不读宿主授权原路径 |
| 安装零退出但失败stderr、缺Success、非UTF-8、非零退出、输出超限 | 固定失败，原显示结果字段与路径遮蔽，目录删除已确认或Failed |
| 截图有效PNG | 原始字节复制、唯一固定声明；宿主真实Artifact实体及下载SHA256相等 |
| 8字节假PNG、坏IHDR、零宽高、少于45字节、stdout/stderr超限 | 无成功声明，关闭实际文件任务后收口 |
| 创建、输入copy、工具、输出copy任一阶段取消/到期 | 共用原D_L，禁止阶段续期/晚成功；真实PID、文件任务、worker与目录分别确认 |
| worker/file任务Future丢弃、panic、真实工作未结束 | 粘性Failed、活动者持lease、目录不提前删除，宿主保持cleanup_failed/draining |
| 删除失败或清理点到期 | 无complete、保留自有目录；不隐式重试或扩大清理窗口 |
| 旧八贡献 | 旧结果和strict边界保持，空产物上下文通过，不额外创建新目录 |
| 同provider锁与声明 | 两能力共享原provider/device写锁，HTTP/MCP/直接Job/旧别名预算与availability一致 |
| 宿主撤除与分发 | 无对应内置回退；空插件部署可启动，新包热装卸/代际/取消，release重建和真实npx消费新声明 |

先做纯边界及模拟工具独立协议测试；测试助手独占测试写集，后端开发不抢其文件。主代理串行跑完整后端门禁、设备/嵌套产物及取消/生命周期服务smoke，debug/release分别证明；重建正式包后真实npx安装两类声明、新能力、输出字节、取消与代际。静态、模拟进程、真机、共享ADB daemon及性能分别报告。
