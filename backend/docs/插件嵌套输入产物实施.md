# 插件嵌套输入产物实施

## 架构门禁

模式为 architecture-first，采用 Hybrid：先冻结加法契约与纯选择规则，再证明实际设备共享任务读取副本、发布产物、取消及热装卸。此项为 Android/Harmony 平台迁出前的必要端口能力，不代表适配器或常驻连接已经迁出。

影响公开 plugin-sdk、infrastructure 的产物选择/复制与清单验证、独立进程测试、在线包与分发验收及两端文档。领域设备封套、HTTP/MCP 请求与前端 SDK 不新增服务器路径或手写 DTO。旧工作树改动保留；注释和文档使用中文 UTF-8。

两条路线是重新解释 input_fields 中的点号路径，或新增 input_pointers。选择后者：顶层字段继续按原名称选择，新插件显式选择 JSON Pointer，避免改变旧字段含义。清单省略新字段时序列化与行为均保持旧形态；不支持该加法能力的旧宿主会明确拒绝新清单，不能静默少复制输入。

## 单元职责与落点

| 单元 | 负责及输入/输出 | 不负责 | 副作用 |
| --- | --- | --- | --- |
| plugin-sdk/ArtifactAccess | 可选 input_pointers，旧清单反序列化兼容 | 文件解析、宿主服务或工具路径 | 无 |
| infrastructure/plugin_artifacts/selectors | 校验两类选择器，选择字符串/数组 ID 与原标签，提前拒绝坏输入 | 存储、文件复制或设备命令 | 无 |
| infrastructure/plugin_artifacts | 复用选择结果，限量复制、摘要校验、临时目录和产物发布 | JSON 路径规则、HTTP 或平台命令 | 文件/存储，沿现有取消与期限 |
| infrastructure/plugins | 复用清单门禁，性能采样不得借嵌套选择声明产物读写 | 第二套路径解析或设备路由 | 原插件执行 |
| 根嵌套产物 smoke/独立进程测试 | 在线安装协议 2/3 设备提供者，调用并核对副本、产物、历史与热装卸 | 模拟真机或常驻协议 | 自有进程和临时文件 |
| 前端文档 | 指导 devices.invoke 的 input 传产物 ID，沿用日志与结果消费 | 手写 HTTP DTO 或服务器文件路径 | 无 |

选择规则从已混合复制/发布的模块拆出，保持纯函数；不继续在 prepare 内叠加路径语法分支。主代理拥有 SDK 加法、选择器及纯规则测试和集成记录；后端代理拥有复制接入、插件门禁及对应测试；前端代理拥有本端说明；测试助理拥有新的真实集成脚本；交付总监只审查冻结契约和覆盖。

## 冻结契约

- artifacts.input_pointers 为可选字符串数组，默认空且为空时不序列化；适用于协议 2/3，协议 1 仍拒绝产物声明。
- 路径采用 RFC 6901 字符串形式，必须以斜线开头，拒绝空根、非法波浪号转义；支持 ~0、~1、Unicode 对象键和数组索引，没有通配符、递归搜索或 URI 片段语义。每条最多 256 UTF-8 字节、8 段。
- input_fields 与 input_pointers 合计最多 8 个选择器；同类重复及顶层字段与等价 /field 路径重复均拒绝。旧顶层名称仍只允许 ASCII 字母/数字/下划线、80 字节。
- 缺失路径跳过，可由操作 input_schema 声明必填；存在的终值只允许字符串或全字符串数组，null/对象/数字/混合数组拒绝。遇到非容器中间值、数组非法索引也拒绝，不能把坏结构当缺失路径。
- 数组索引使用十进制规范形式，0 或不以 0 开头的数字；对象键中的数字按原键处理。超界索引（含超过宿主整数范围的规范数字）视为缺失。全部选择器与值先完成纯校验，再创建调用目录或读取存储。
- ArtifactInput.field 对旧字段保留原名称，对嵌套选择保留原 JSON Pointer，其他协议帧不变。业务 input 仍保存原产物 ID，path 只存在于本次进程 artifacts 上下文，不进入设备任务公开输入。
- 总输入仍最多 8 个实际产物、64 MiB；相同 ID 被不同选择器选择时按各引用计数和复制，不静默丢失标签。文件类型、摘要、取消、期限、临时清理及输出发布沿既有端口。
- 设备动作沿现有 30 秒总期限及共享资源锁；本项不扩大安装时限，不宣称可满足所有真实大包安装。平台提取时另界定能力期限与常驻会话。

## 最低验证与实施顺序

1. 旧清单默认/序列化、规范/转义路径、重复与合计上限、空根/非法转义/深度/长度、数组规范索引、缺失与坏结构及无副作用选择。
2. 实际存储副本、SHA-256、总数量/大小、未声明 ID 不读取、提前坏输入不复制、取消及目录清理；性能探针不能绕过产物门禁。
3. 独立进程与本机 HTTP/MCP：协议 2/3 在线安装保留声明、设备封套输入、输出下载摘要、精确坏清单错误、热卸载/重载和旧引用拒绝。设备均明确为 synthetic_demo。
4. 后端六门禁、受影响的既有运行回归、前端生成/check/test/build，随后重建 release/npx 及当前真实集成；旧第一阶段包不作为新契约分发证据。

门禁已完成，可按上述职责实施；本项不增加用户批准步骤。Android/Harmony 适配器迁出、常驻连接、iOS、真机和其余迁移仍保持原目标。
