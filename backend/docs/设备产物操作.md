# 设备安装、卸载和截图接口

## 调用方式
先调用 `POST /api/v1/artifacts?filename=应用.apk` 上传原始二进制内容，然后调用 `POST /api/v1/jobs` 提交公开操作。任务返回 202 和任务 ID，使用任务查询接口读取终态。MCP 自动发现同名操作，共用注册器、校验和任务层。

```json
{"operation":"android.app.install","input":{"device_id":"设备序列号","artifact_id":"上传返回的规范 UUID"}}
```

| 操作 | input 参数 | 成功 result |
| --- | --- | --- |
| android.app.install | device_id、artifact_id | artifact_id、output |
| android.app.uninstall | device_id、package | output |
| android.screenshot | device_id | id、filename、media_type、size、sha256、created_at |
| harmony.app.install | device_id、artifact_id | artifact_id、output |
| harmony.app.uninstall | device_id、package | output |

截图终态的 result.id 可用于 `GET /api/v1/artifacts/{id}/content` 下载。二进制仍通过 HTTP，不放入 MCP 文本。

## 类型与执行边界
Android 仅安装单个 APK，HDC 仅安装单个 HAP。APKS / AAB 仍可存为产物，但需要后续分析及拆分工具链，当前直接安装会失败。上传通过容器检查不代表安装包结构或签名有效，设备工具仍可能拒绝。

卸载 package 要求至少两个点分段，每段以 ASCII 字母开头，后续仅字母、数字或下划线，最多 200 字节。device_id 沿用受限标识符；额外参数由输入模式拒绝。可执行工具路径由部署者配置，不接受请求中的服务器路径。

安装准备阶段校验流大小和 SHA-256，单文件上限 64 MiB；复制和安装分别最多 120 秒，卸载最多 120 秒。Android 截图输出最多 64 MiB，工具期限 30 秒，产物写入最多 120 秒。取消任务不能撤销设备端已经完成的安装或卸载。

安装、卸载必须同时满足工具退出成功、无已识别失败文本、出现明确成功文本。标准错误也参与检查。安装输出中的受控临时包路径替换为产物文件名。

截图当前沿用 PNG 头部检查，不进行完整解码或 CRC 校验。没有实现 Harmony 截图、分包安装、AAB 转换、可选升级策略和设备输入操作。

## 验证与来源
实现位于 crates/infrastructure/src/device_artifacts，服务启动时装配 ArtifactStore。独立模拟工具测试覆盖参数和失败分支；runtime-smoke.mjs 验证真实 HTTP / MCP 操作发现、设备任务与截图下载。尚无真机验证记录。

命令依据 AOSP ADB 手册和 OpenHarmony 官方 hdc 使用指导；HDC 成功文案采用指导中的 install / uninstall bundle successfully. 形式。相关工具版本兼容性仍需在部署环境验收。
