# 插件调试器 v1：实施契约与边界

状态：2026-10-27 开始分批实施。本文不是首期生产验收报告。

## 架构裁定

采用 `architecture-first` 与契约先行、失败回归结合的 Hybrid 模式。
选择“官方浏览器插件＋宿主公开底座”，不把 UI 检查、执行器、安装与日志拼成新的万能调试服务器。
复用原任务、会话、安装与产物服务，减少两套运行事实及回归面。

| 单元 | 输入与输出 | 职责 | 不负责与副作用 |
| --- | --- | --- | --- |
| application/debugger | 实例、目标、会话、命令、回执、事件 | 有界状态、期限、一次领取、旧代拒绝 | 不调用 DOM、不安装插件；仅内存与异步通知 |
| server/debugger | HTTP/MCP 参数与同一用例结果 | 真实回环、来源、模式、关联响应 | 不创建另一执行器；复用已有业务端口 |
| 浏览器观测底座 | 指定插件、DOM、公开语义登记 | 树、查询、差异、断言、受约束动作 | 不读 Fiber/Props，不把 DOM 冒充扩展点 |
| 浏览器桥与装配 | 本机端点、明确实例、命令与回执 | 心跳、按会话采集、有界交换 | 不自动重放变更，不选择任意标签页 |
| 官方 Debugger 插件 | 公开服务结果 | 悬浮球与面板 | 不读宿主私有代码，不新增安装体系 |

已有装配文件只追加依赖注入与路由注册，具体逻辑拆入新模块。生成类型由主代理统一生成。

## 协议与目标

- 协议版本为 `1`，能力清单按真实实现返回；没有能力明确拒绝，不返回伪空成功。
- HTTP 根路径为 `/api/v2/debugger`，沿用真实日志关联与 v2 包装。
- 公共浏览器服务为 `host.debugger@1`；`context.debug` 为可选能力，旧插件不强制升级。
- 目标必须指定运行实例、插件与当前代次；宿主结构概览不等于对全部插件开启详细采集。
- 浏览器页面刷新产生新实例。队列命令仅领取一次，未确认结果不自动重放。
- 真实回环检查独立于原“同机网卡”判断，不信任请求转发头；浏览器来源也必须是回环来源。
- 市场本地导入与 MCP 导入继续走共同安装用例，不提供 `debug_upload`、`debug_install`。

## 有界性与诚实状态

- 会话默认闲置 30 分钟；实例、会话、队列及历史均设容量，退出和过期撤销相应等待。
- 每浏览器最多 4 项在途、32 项排队；读取默认 5 秒，动作与条件等待默认 10 秒。
- UI 树每页最多 500 节点、响应最多 1 MiB，最近 10 个快照。事件页最多 200 条，缓冲最多 10,000 条或 16 MiB。
- 断线、取消、超时、换代和重复回执分别返回原因。已派发不等于业务成功，取消等待不等于取消原 Job。
- 断言返回通过、失败或无法判定。截断、虚拟列表、不透明结构与未知遮挡必须保留，不能据不完整树断言不存在。
- 默认只存元数据，不采密码、输入值、凭据及任意网络载荷。主动试调用另作脱敏，不能声称识别所有秘密。
- 旧清理告警只作历史诊断，不能封锁独立新调用；不承诺识别未登记的全局副作用。

## 交付门槛

先证明显式目标、容量、超时、不重放、旧代拒绝、脱敏及不完整树断言的直接单元行为。
新 UI 必须先有 Ardot 可编辑设计、落盘并取得用户确认。
只在该功能需要时进行最小本机桥接联调，不操作设备，不替换用户服务，不扩大到全仓回归。
可导入插件、共用导入更新与恢复、报告产物、第三方独立示例和真实闭环未全部验收前，不标记生产可用。
