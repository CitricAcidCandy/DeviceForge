# 包工具公共库迁出契约

状态：PKG-LIB-DESIGN 候选契约，供主代理与交付总监冻结实施输入；本次只冻结文档版本，不表示公共 API 已获裁定、库已实现或迁出已验收。日期：2026-10-09。

## 目标与裁定范围

模式为 architecture-first / Hybrid。沿 [平台适配器迁出实施](../implementation/平台适配器迁出实施.md)、[Android 包公共库提取方案](../implementation/Android包公共库提取方案.md) 的边界，给独立 Android 包插件提供受限 ZIP 机制和 Android 解析，避免插件通过 infrastructure 复用宿主。影响为新增公共库、旧基础设施薄适配、独立包插件、通用旧绑定及装配/分发门禁；本稿不修改这些源码。

推荐一个公开 crate：`backend/crates/android-package-core`，包名候选 `deviceforge-android-package-core`，内部严格分 `archive` 与 `android`；暂不增加第二个归档 crate。通用宿主若复用容器机制，只引用 archive 接口，不调用 Android 业务解析。拆成两个 crate 也是可行替代，但须先证明通用复用需要，并保持同一份路径/限额/复制规则。

库不依赖 domain/application/infrastructure/server，不包含 ArtifactStore、Job、插件注册、设备连接或锁、ADB/HDC、Java/Apktool 调用、HTTP/MCP、环境探测及自建运行时。工具 argv 与业务编排归插件；产物 ID、授权副本、摘要验证和真实发布归宿主。它不是安装器、设备适配器，也不是操作系统隔离层。

本次仅定点核对 package_tools、bundles/validation、reverse/scanning 与两处 packing，以及已有公开 SDK/runtime/tool-process；没有重新扫描全库。旧包工具当前仍有按阶段 120 秒的调用和宿主实体依赖，这些是迁移来源，不能据此声称已经使用普通任务总期限。

## 最小职责、输入输出与路径归属

| 单元 | 输入与输出 | 副作用与所有权 |
| --- | --- | --- |
| 公共 archive | 调用方已打开的本地文件、精确成员名、受控目录、显式 profile 和控制值；返回目录描述、完整复制/打包摘要 | 允许受限同步文件 I/O；借用或持有传入文件句柄，不解析产物 ID、不选择输出父目录、不删除调用方目录 |
| 公共 android | 有界清单 XML、签名报告、已检验目录描述、模式和 SDK 路径规则；返回独立数据值 | 文本/路径规则与受限容器读取；不启动工具，不补宿主归属和平台状态 |
| 独立 android-packages | SDK Request、授权 inputs、授予的 output_directory、部署者工具配置 | 创建本任务 scratch、独立 argv 调用、受限阻塞工作和资源排空；Response 只返回业务值及输出文件名 |
| 宿主通用适配 | 浏览器产物 ID、冻结选择器、owner/generation 和任务总期限 | 读取/复制输入、验证并发布输出、产生真实 Artifact 与历史；不得搬入平台 argv 或自动回退 |

工具 executable、JAR、固定前缀、签名材料由部署者在插件部署配置中指定，包内相对工具路径只由可信配置映射为绝对路径。业务请求不得指定程序、shell、签名材料路径或服务器目的目录。公共库不读这些配置，不从 PATH 查找工具；进程执行复用已公开 `deviceforge-tool-process`。

输入只来自宿主 SDK artifacts.inputs 的本次授权副本。插件按已声明 field/原 artifact_id 匹配，拒绝缺失或多匹配，不自行访问宿主产物仓库或原始客户端路径。公共库接文件句柄后不再解析该 ID。顶层普通操作继续使用 `input_fields:["artifact_id"]`；嵌套设备安装由另一插件使用已冻结 input_pointers，不把设备封套带入本库。

scratch 是插件本次私有目录，输出最终文件只能进入授予的 output_directory，名称由插件固定。输入副本与 output_directory 的最终删除权属于宿主；插件只关闭自己使用的句柄、停止工具/worker，并回收自己创建的 scratch。库无递归删除入口，不回收共享 TEMP、工具目录或管理员材料。

## 拟冻结的最小 Rust 接口

以下名称、输入输出和完成语义是本稿的候选实施契约，不是已存在的 API。借用生命周期与内部类型必须保证资源有效，不能为了简化函数签名把守卫提前释放。

| 接口 | 最小输入 | 输出与完成语义 |
| --- | --- | --- |
| `Control::new(deadline, is_cancelled)`、`Control::check()` | `std::time::Instant` 绝对点、借用的同步取消检查函数 | 独立 Result；点已过返回 Timeout，否则已取消返回 Cancelled；库不创建 token/计时器 |
| `Archive::open(file, profile, control)` | 已打开只读 File、显式 ArchiveProfile | 持有文件的 Archive 与有界 Directory；仅证明外层结构/路径/声明限额，未证明所有 CRC |
| `Archive::select_exact(name, control)` | 精确成员名 | 借用该 Archive 的 SelectedEntry；零/多匹配失败，调用方在此成功后才创建目标文件 |
| `SelectedEntry::copy_to(destination, byte_limit, control)` | 调用方以 create_new 创建的输出 File、独立字节上限 | CopiedEntry `{name,bytes}`；实际读到 EOF、长度一致、CRC 成立后才产生，不返回部分成功 |
| `tree::scan(root, profile, control)` | 本次私有输出目录、TreeProfile | 有界 TreeSnapshot，包含排序相对名/长度；没有宿主 ID 或不受控输出路径 |
| `tree::pack(snapshot, destination, control)` | 同一目录有效快照、空的受控输出 File | PackedTree `{files,unpacked_size,archive_size,entries}`；Stored ZIP 收尾、sync 和最终大小复核后才成功 |
| `android::parse_manifest(xml, control)` | 受限 UTF-8 XML | ManifestData，字段见下表；没有 artifact_id/format/module |
| `android::parse_signature(report, control)` | 已按展示名称脱敏的受限签名报告 | SignatureData；没有 artifact_id；不会以零退出代替解析规则 |
| `android::validate_apks(archive, mode, control)` | 已打开 Archive、独立 BuildMode | ApksSummary `{apk_count,universal_entry}`；完整读外层成员并核对 CRC/长度及 APKS 规则 |
| `android::validate_decoded(directory)`、`android::scan_sdks(directory, rules, control)` | 有界目录描述、独立 SdkRule 列表 | 反编译必要成员校验、SdkFinding 列表；路径观测，不读取 DEX 或宣称 SDK 版本识别 |

Archive/SelectedEntry/TreeSnapshot 的关键状态不可由调用方伪构造；选中成员必须绑定原 Archive，不能用另一文件的下标或元数据。Directory 是有界观测描述，不是“所有成员均安全”的通用证明。TreeSnapshot 携带的本地根只用于同次打包，不能序列化成 SDK 路径结果。输出 File 由调用方独占创建，库不得覆盖已有文件；复制/打包失败的半文件留给同次所有者回收。

| 独立值 | 保留字段与兼容边界 |
| --- | --- |
| ManifestData | package_name、version_code/version_name、min_sdk/target_sdk、application_label、debuggable、permissions、xml；字符串、缺省/None 和排序语义沿当前解析，format/module/源 ID 由插件按合法输入补业务归属 |
| SignatureData | verified、signers、schemes、report；Signer 保留 number/distinguished_name/certificate_sha256，Scheme 保留 scheme/verified；无宿主实体和存储字段 |
| SdkRule/SdkFinding | 规则 name/package_path/class_name；发现 rule/package_found/class_found/evidence；无 artifact_id，最多 100 条唯一规则、每条最多 10 个排序证据，指定检测点不遗漏 |
| BuildMode | 独立 Default/Universal 值；不引用领域 enum，不扩展新 bundletool 模式 |

序列化使用独立 serde 模型，结构应能形成原业务值的有限转换；不携带 schemars/OpenAPI/领域派生依赖。公开业务 schema 与旧实体由插件和宿主兼容层维持，本库不自动定义 HTTP 字段。

## 显式 profile、校验层级与错误

| profile/解析 | 候选冻结限额与规则 | 成功证明范围 |
| --- | --- | --- |
| ArchiveProfile::Structure | 最多 10000 条目、声明展开量 2 GiB；拒绝分卷/ZIP64、越界路径、链接、不支持的类型及无效目录范围 | 外层目录结构；保留重复成员供精确选择判断，不悄悄去重，也不强制读取每个成员 |
| 精确 APKS APK 复制 | 名称最多 500 字节、合法相对路径和 APK 后缀；唯一普通成员，单输出 64 MiB | 选定成员完整读取、实际长度和 CRC；不是整个 APKS 或真机安装证明 |
| Android APKS 校验 | 输入压缩文件 64 MiB、外层累计展开 256 MiB、拒绝重名；完整读外层成员并核对长度/CRC | 非空 toc.pb、至少一个 APK 的 ZIP 标识；Universal 模式唯一 universal.apk；不解析 toc.pb 设备匹配，也不证明 APK 内层所有 CRC |
| TreeProfile::Reverse | 文件和目录合计 10000 条、深度 128、普通文件总量和最终 ZIP 各 64 MiB | 通用树和打包规则；最终 Android 校验要求非空 apktool.yml/AndroidManifest.xml，工具运行中监测不能提前要求两文件完成 |
| TreeProfile::Splits | 文件和目录合计 1000 条、深度 128、普通文件总量和最终 ZIP 各 64 MiB | 最终目录非空、仅 APK，逐 APK 作结构校验；返回排序 APK 名称，不采用 Reverse 的必需文件规则 |
| Manifest XML | 1 MiB、20000 节点、128 层；Android 命名空间、唯一根及主要结构，拒绝 DTD/未定义实体/歧义 | 当前 XML 字段观测；不解析资源标签、不读取二进制 AndroidManifest.xml，也不证明包可安装 |
| Signature report | 1 MiB；明确 Verifies、至少一个成功方案、1–32 个连续完整签名者、64 位十六进制 SHA256 | 当前 apksigner 报告解析，保留警告；不启用新 -Werr、不扩大为 AAB JAR 或 APKS 所有分包验签 |

profile 是有限枚举及已冻结常量，业务 input 不提供任意放宽限额。CRC/长度和累计量用溢出检查；最终打包限额包括头部和中央目录，不能只限制源文件和当前写位置。扫描到复制之间至少复核普通文件、路径、长度；同长度内容被外部替换的竞态不能由旧扫描算法完全排除。本稿不承诺操作系统句柄级隔离；更强保证另裁定。

路径规则保留绝对路径、点路径穿越、反斜杠、冒号、控制字符、符号链接和现有重解析路径拒绝。精确成员名不映射为服务器目录树。同步工作在每次新 I/O、成员/目录循环、64 KiB 复制块、XML 节点批次以及返回完成前复核控制；取消/到期/CRC/长度错误均不得返回半成品摘要或继续下一成员。

独立 `Error` 候选为 `InvalidArgument`、`InvalidArchive`、`InvalidManifest`、`InvalidSignature`、`EntryMissing`、`EntryDuplicate`、`LimitExceeded`、`SourceChanged`、`Io`、`Cancelled`、`Timeout`。格式/限额/阶段使用有限枚举和受限条目标签；Io 保留原 io::Error，但插件不直接把绝对路径、任意 stderr 或签名材料写入协议/日志。库不含 HTTP code、host Error 或 CleanupFailed：能否确认排空归调用方资源追踪。

| 原行为 | 过渡基础设施错误适配 | 独立插件兼容边界 |
| --- | --- | --- |
| 参数无效、坏 ZIP/APKS、重复精确成员 | Invalid，沿当前具体文案 | 协议 Response.error 字符串；已创建 Job 的执行失败不变成安装或提交层 HTTP 400 |
| 精确条目不存在 | NotFound | 插件失败字符串，不宣称当前线协议能携带宿主结构化 not_found |
| XML/签名工具文本不满足规则 | Dependency | 不把退出 0 视为成功；保留业务失败语义 |
| 文件/包超限、I/O、打包期间变化 | TooLarge、Storage、Conflict | 独立错误在插件统一有限转换，不泄露本地路径 |
| 工具 Spawn/ProcessIo、捕获超 1 MiB、文件输出超限 | 仍由 tool-process 适配为既有 Dependency/TooLarge，库不接管 | 非零退出和零退出 FAILED 文本由插件处理；不复制宿主 process 模块 |

错误类别精确回归，不接受任意 4xx/任意字符串代替。未来平台结构化执行错误是另一个版本化契约，本稿不补 Request/Response 私有字段。

## 异步期限、取消与外部资源排空

公共核心同步执行，不引入 Tokio、spawn_blocking、Semaphore 或后台删除；它只接绝对点和取消检查。调用层负责异步调度、取得许可、持有目录 lease 和追踪真实 JoinHandle。拟定插件每个任务进程最多 2 个阻塞名额：工具输出监测最多 1 个，主解析/复制/打包最多 1 个；监测退出后才进入最终打包。此数值需主代理冻结。宿主过渡适配必须使用已有共享受限工作池，不能给每个请求临时建池而绕过全局容量；跨进程总量仍受宿主工作队列/并发门禁约束。

许可和涉及的输入/scratch/输出目录 lease **一起移入阻塞闭包**，持有至实际工作返回；异步等待 Future 被丢弃或 timeout 不能释放名额、删除目录或声称 worker 已停止。获许可后、第一次 poll/第一笔 I/O 前再次查取消与期限，过期或预取消不得新建半文件、启动工具或 worker。已开始的阻塞工作合作停止、受 tracker 持续跟踪；不可中断文件 I/O 的尾部可能晚于到期，必须保留实际排空边界。

同一进程已有 `Some(D)` 时，所有工具、等待许可、复制、解析、扫描、打包及后续输出使用 D；局部工具短限额为 `min(D, t_step + short_limit)`，不每阶段获得新的总额。外层普通 Job 的 D 按 [普通操作总期限第一批契约](普通操作总期限第一批契约.md) 已冻结计算，贯穿准入、队列、副本、传输、结果转换、逐产物发布和成功资格；设备预算不用于这七项普通操作。底层 context None 只保留旧直接调用兼容，不成为宿主 Job 的旁路。

**跨进程接缝必须单独裁定。** 当前 SDK Request 不含预算或 D，公开 plugin-runtime handler 仅取得 Request/CancellationToken。宿主 std::time::Instant 不能直接序列化为跨进程绝对点，本稿不新增 Request 字段、环境私有通道或依靠重新计算本地预算冒称精确继承。当前可成立的最小路径是：宿主坚持原 D、到期发送合作取消，插件以该令牌停止工具/worker，同时按已冻结的本地阶段短限额有界执行；插件本地截止点不是宿主剩余 D。这能收敛任务资格和取消边界，但不证明宿主到期后控制帧抵达前所有插件内部新 I/O 都已零启动。若要求该强保证，须先另冻结公开剩余预算/上下文加法，不能在库或平台插件偷偷实现。

当前 handler 的取消令牌本身不携带 timeout/cancelled 原因。插件局部返回 Cancelled 不能反推宿主 Job 也是 Cancelled；宿主按自己的 D/已提交终态与线上控制原因分类。验收分别观测 Job、真实控制帧、插件本地结束和清理，不从错误字符串猜总期限已传播。

协议 3 的清理处理器必须先停止接纳子工作，通知工具/worker 取消，等待所有已开始工作返回及工具直接进程退出，关闭本次文件句柄，再清理 scratch；确认后才返回 cleanup complete。库函数成功、文件被删除、直接进程 kill、响应已写均不能单独作为所有外部资源释放证据。tool-process 只保证它所管理的直接子进程，不保证 Java 派生树、共享 daemon、设备事务或系统服务；本库和包插件不拥有设备连接，也不得杀管理员共享 daemon。

业务预算不扩大既有合作 1250 毫秒、杀后等待 500 毫秒、外围 2 秒和卸载 10 秒门禁。tool-process 清理最多 2 秒与宿主合作窗口是不同上界，串行相加不能保证合作确认一定赶上；必须真实验证，并发通知后按原窗口排空。超过窗口、Future 丢弃或任何使用者未确认，返回/保留清理失败和未确认风险，不能抢先报 complete。取消前已提交的终态不由稍后到期重写，粘性 owner.cleanup_failed 不由另一成功任务清除。

插件输出阶段只生成有限文件名和业务值，宿主验证输出普通文件/链接/大小/类型后发布。多个输出逐项发布不等于批量事务，晚到期可能留下已发布项；本库没有回滚或孤立产物回收权。宿主发布流持有目录 lease 到实际结束，协议 complete 不替代宿主自己的发布和目录排空。

## 七项普通操作及产物兼容

以下目标后缀、业务值与唯一输出名建议一次冻结，完整插件 ID 由主代理配置；不在宿主按平台硬编码预算或工具命令。普通总预算声明由已交 [实际平台插件普通任务预算清单](../reference/实际平台插件普通任务预算清单.md) 另裁定，不能将旧 120 秒阶段相加就认为等价。

| 旧公开名称 | 插件业务及库调用 | 固定输出/旧结果来源 |
| --- | --- | --- |
| android.package.manifest | APK 用 apkanalyzer manifest print；AAB 用 bundletool dump manifest、合法 module 默认 base；库 parse_manifest | 无文件输出；ManifestData 转旧字段，artifact_id 从原合法 input，format/module 从输入资格推导；APK 带 module 继续拒绝 |
| android.package.signature | apksigner verify --verbose --print-certs；库 parse_signature | 无文件输出；保持 verified/signers/schemes/report，源 artifact_id 从 input，临时路径换展示文件名后再成业务 report |
| android.package.extract_apk | 精确唯一 APKS 成员、copy_to、输出 APK 结构检查 | 单文件 extracted.apk；source_artifact_id/entry 从 input，artifact 仅从宿主真实列表唯一同名匹配 |
| android.package.extract_splits | 有界合法 DeviceSpec，bundletool extract-apks；监测/最终 Splits 树检查及 pack | 单文件 selected-apks.zip；source_artifact_id/device_spec 从 input，apk_entries 从本次排序摘要，artifact 来自真实发布；不连接或发现设备 |
| android.package.build_apks | AAB default/universal、固定签名配置、bundletool build-apks；validate_apks | 单文件 built.apks；source_artifact_id/mode 从 input，apk_count/universal_entry 从校验摘要，artifact 来自真实发布 |
| android.package.decode | apktool decode、运行中 Reverse 目录限额监测、最终必要文件校验及 pack | 单文件 decoded.zip；source_artifact_id 从 input，files/unpacked_size 从本次摘要，artifact 来自真实发布 |
| android.package.scan_sdks | 反编译 ZIP 结构/必要文件及 smali 路径扫描 | 无文件输出；artifact_id 从 input，findings 为独立规则观测，不升级为 DEX 二进制识别 |

SDK Response.result 只含有限业务值；Response.outputs 只填 ArtifactOutput.filename，不提交伪 Artifact ID/SHA/本地路径。协议 2/3 的严格 host `{result,artifacts}` 由真实发布层产生，旧实体的 artifact 通过已有绑定的宿主来源投影获取；缺少或重复同名输出必失败。业务 JSON 自带 result/artifacts 不是可信发布证明。新插件失败沿现有 Response.error 与原 Job 生命周期，不创造第二 Job、另一套存储或 HTTP 包装。

包插件建议采用协议 3，支持工具/worker 清理确认；协议 2 可作为受控兼容测试，但杀直接进程不证明派生进程或文件外部资源已释放。构建、解码、提取与设备 install-apks 严格分开：后者属于 android-device、使用公开设备预算/锁/归属，不能被普通包操作绕过。

## 宿主替换步骤与实施可启动条件

1. 主代理裁定下述三个冻结项、分配不重叠写集，并同步公共 crate/Cargo/架构白名单。先写独立纯规则与受控文件回归，再提取机制/模型；本轮文档不能被计为该步骤已完成。
2. 旧 infrastructure 改薄适配：输入资格、ArtifactStore/materialize/发布仍属旧调用层，库仅做对应工作；比较旧成功值、错误、限额与排序，验证无新反向依赖。过渡层仍须保持目录 lease/受限池，不复制旧无界 spawn_blocking 缺口。
3. 独立 Android 包插件接七项普通贡献、公开产物上下文、部署配置、工具进程和清理追踪。阶段短限额与总预算分别声明/验收，跨进程预算接缝按裁定执行，不隐瞒弱保证。插件二进制在缺工具机器上可启动协议，合法调用按确定错误失败；不把工具存在性变成宿主前置条件。
4. 显式配置旧别名，注册/卸载原子发布与撤销目标和绑定。停止重复注册旧内置包操作，不并存两个相同公开操作、不静默回退。旧 history 保留原 operation/input/result，别名调用直接使用本次目标执行，不嵌套提交 Job。
5. 主代理去 main 的 AndroidPackageTools/AndroidBundles/AndroidReverse 及纯包部分直接装配；AndroidSplits 中 install-apks 留给设备插件迁出，不能把整个模块当纯包删除。领域旧端口与 application 包调用按实际引用裁定撤除，历史公开 DTO 不随源码迁移丢弃。
6. 当前构建/生成/静态与真实插件门禁通过后，再重建 release/runtime、平台插件便携包及 npx 原包，实测安装、加载、旧/新调用、产物下载、卸载、失败保留。原归档压缩字节/SHA 与实际 runtime 身份由主代理保存，不用同源重打包代替。

空插件宿主必须在无 ADB/HDC/Java/Apktool/签名材料时启动通用 HTTP/MCP 和任务/产物服务，且不发布未部署的包旧入口。安装不自动加载；加载后贡献与绑定同时可见，卸载后同时撤销，cleanup_failed 时删除、同 ID 重载和未启动排队任务仍受门禁。纯包插件从未持设备连接或设备锁；设备插件/性能 provider 迁出、常驻/iOS/真机是独立批次，不能由本稿或空宿主通过代签完成。

## 最小验收矩阵

以下全部为后续必须取得的证据，本轮不运行任何项。先用纯规则/受控存储证明边界，再用真实工具进程、真实包和宿主集成证明完整路径，不能以一层成功借计另一层。

| 编号 | 最小验证 | 通过与失败必须分开的证据 |
| --- | --- | --- |
| PKG-01 依赖 | 公共库及独立插件生产/构建依赖门禁 | 核心无四层宿主、设备、runtime/process 依赖；插件只使用公开 SDK/公共库；dev-dependency 不泄漏 |
| PKG-02 结构与复制 | 坏目录/ZIP64/分卷/越界/链接/重复名/缺成员、CRC/长度坏包、64 MiB 边界 | 精确零/多匹配先于目标创建；部分读取不报 CRC 通过；坏包整次失败，无半产物发布 |
| PKG-03 树与打包 | Reverse 10000 与 Splits 1000、深度 128、大小含 ZIP 开销、源改变、最终业务必需项 | 包含目录的计数、排序 Stored、create_new、收尾/sync；监测期不要求尚未生成的必需文件；两个 profile 不互换 |

| PKG-08 七操作协议 | 真正启动独立包插件，七项成功/确定失败，协议 3 合作取消及响应后 EOF | Request/Response 匹配、零退出、明确清理分别核对；SDK 上限不靠无限缓冲绕过；无第二 Job |
| PKG-09 真实产物 | 授权输入副本、未声明不读、四个唯一命名输出、HTTP/MCP/旧别名/下载 | Artifact 来自本次宿主真实列表，下载大小/SHA 对应；伪包装、缺输出、多匹配和晚输出拒绝 |
| PKG-10 生命周期与空宿主 | 无平台工具/包启动；安装加载卸载重载；cleanup_failed/排队及部署删除 | 原 owner/generation 共享准入、绑定原子撤销、历史不改；不以离线目录删除证明在线仓库并发门禁 |
| PKG-11 真实包与分发 | 有已知期望的 APK/AAB/APKS、实际工具版本；当前 debug/release/npx 原包 | 样本/工具/runtime/便携归档实际 SHA、命令和退出码；不复用旧 binary/同源重打包；真机不计入纯包验收 |

纯解析输入允许 1 MiB 不保证序列化后的完整 SDK 响应仍小于 1 MiB：XML/report 转义和字段开销必须在 PKG-08 验证，超限沿公开 runtime 明确失败，不静默截断 XML 或抬高协议额度。业务原 XML/report 可以是有界结果，日志只记录关联和有限诊断，禁止任意原文、环境、签名凭据和请求正文。

最终由主代理串行执行架构、fmt/Clippy/test/build、必要类型生成及受影响在线/生命周期/合作取消/产物/日志和真实分发门禁；插件角色只交冻结输入，不抢构建锁。真实包失败保留原样本摘要、stage、有限错误、工具退出/清理观测，不把收尾成功改记成业务成功。

## 最多三项待主代理冻结

1. **公共库 API 与兼容 profile。** 推荐一个 android-package-core、本文 Archive/SelectedEntry/TreeSnapshot 与独立模型/错误、现有依赖版本和显式 profile；确认 serde 特性、旧错误适配和全部常量后再分配库写集。不能只换文件目录或把旧宿主实体直接导出。
2. **执行上下文与排空门禁。** 确认采用“宿主 D 权威、插件合作取消加本地短限额”的明确弱保证，还是先冻结公开跨进程剩余预算加法；同时确认 2 槽插件池、宿主共享池/lease/tracker 的职责及合作窗口内的真实证明。该选择未决会阻断宣称插件内部每笔 I/O 精确继承宿主 D，但不妨碍无进程核心纯规则先实施。普通总预算数值仍按所属冻结流程，不由库默认扩大。
3. **插件部署与旧结果接线。** 推荐协议 3、七项普通目标、四个固定输出名和宿主真实来源投影；冻结工具/签名配置如何进入可信部署及缺配置在加载还是调用失败，随后原子切换旧绑定与 main 装配。没有明确部署配置来源就不能假设 APK_* 会穿过受限插件环境。

冻结以上选择后，公共核心和过渡适配可首先按纯规则/受控文件测试实施，独立插件按确定上下文与配置接入。任何未决项不得通过实现默认值偷偷冻结。本文只交付可评审的契约设计：没有新增 crate、Rust 接口、平台插件、Cargo 依赖或宿主替换；没有运行构建、测试、生成器、包工具、Node/npm/Cargo 或服务。
