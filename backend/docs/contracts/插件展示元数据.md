# 插件展示元数据

服务器插件的运行清单 `manifest.json` 仅声明身份、协议、贡献和可管理配置。名称、摘要和完整描述保存在部署目录根部的独立 `market.json`，与市场发布使用同一份资料。直接部署、在线安装和 CLI 安装应把资料与生成的运行清单一同放在插件部署根部；不能依赖当前市场服务在线。

宿主在受限阻塞工作池中固定读取 `market.json`，不接受请求指定文件或目录。只采纳 `metadata_version: 1` 且 `id`、`version` 与本代运行清单一致的资料。名称、摘要、描述均须为非空字符串，分别最多 200、2000、20000 个 UTF-8 字节；整个文件最多 64 KiB。文件须为部署目录内普通文件，符号链接、Windows 重解析点、目录和越界路径不被读取。

公开插件列表及加载、卸载响应的 `PluginInfo.metadata` 为可选对象，包含 `name`、`summary`、`description`。缺失或不合法的资料返回不带 `metadata` 的旧兼容视图，插件本身仍可加载和执行；损坏资料只记录插件 ID 及固定警告，不记录资料正文、系统路径或解析异常。元数据随注册代次固化，修改后须重载插件才会更新当前代展示信息。

该对象不声明配置字段或覆盖工具路径。配置继续由运行清单的 `configuration` 提供 Schema、默认值、生效策略和旧配置文件名，并通过已有 `/api/v2/plugin-configurations` 接口管理。运行请求、普通插件协议及会话传输均保持原有字节契约。

实现职责：领域类型和 `Executor.plugin_metadata` 传递可选展示值；基础设施的 `plugin_catalog/metadata.rs` 负责受限文件读取和身份校验；注册表把信息与代次一起发布。HTTP 和 MCP 复用同一注册视图，市场页面可离线展示本地插件资料。
