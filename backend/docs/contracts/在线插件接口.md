# 在线插件包接口

接口模式由 Rust 生成，以 `/openapi.json` 和导出的 OpenAPI 为准。默认免鉴权；设置非空 `APK_API_TOKEN` 后管理接口使用 Bearer 请求头。浏览器 GET/HEAD 静态资源公开，供原生 ES 模块加载，包内不得包含访问令牌等部署凭据。

## 部署与运行

| 请求 | 用途 | 成功响应 |
| --- | --- | --- |
| GET `/api/v2/plugin-packages/{kind}` | 读取在线安装目录，kind 为 server/browser | 200，包视图数组 |
| POST `/api/v2/plugin-packages/{kind}?format=zip` | 上传 ZIP 原字节，媒体类型 application/zip | 201，安装包视图 |
| POST `/api/v2/plugin-packages/{kind}?format=tgz` | 上传 npm TGZ 原字节，媒体类型 application/gzip | 201，安装包视图 |
| DELETE `/api/v2/plugin-packages/{kind}/{id}` | 删除在线安装的部署文件 | 200，已删除包视图 |
| POST `/api/v2/plugins/{id}/load` | 加载服务器插件贡献 | 200，运行视图 |
| POST `/api/v2/plugins/{id}/unload` | 撤销贡献、取消任务并等待资源清理 | 200，停止视图 |

业务响应使用 `{log_id,data}`，错误使用 `{log_id,error:{code,message}}`；响应头同时携带 `x-deviceforge-log-id`。包视图含 kind、id、version、runtime、entry_path、entry_url、api_version、installed_at；服务器包的浏览器入口和 API 版本为空，安装时间为毫秒时间戳。CLI 既有部署未生成在线安装视图，因此不出现在这个在线目录中；运行目录仍由 `/api/v2/plugins` 读取。

上传不是 multipart，不接收服务器目的路径。包须自包含，不执行 npm 安装脚本，也不在线解析或下载 npm 依赖。在线部署提供 HTTP 接口；MCP 继续通过 list/load/unload 及插件操作管理运行实例，本阶段没有二进制包上传或部署删除工具。

同 ID 不覆盖；更新先停止并删除旧部署，再安装新包。服务器包仍已加载、排空或清理未确认时删除失败，不用删除文件代替卸载。安装/删除等待取消后应重新查询目录，不推断事务回滚，不自动重放。运行启停状态目前不跨服务器重启保存。

## 浏览器静态资源

GET/HEAD `/api/v2/browser-plugins/{id}/assets/{path}` 读取包内普通资源。每次启用生成新的运行 UUID，从 `/api/v2/browser-plugins/{id}/runs/{run_id}/assets/{path}` 加载入口；相对模块、动态导入及相对资源继续沿用该路径前缀。run_id 只改变模块 URL，不创建后端会话。

成功返回原字节，JSON 资源也不套业务包装；失败返回标准错误包装。响应设 no-store 和 nosniff，保留媒体类型、长度和关联头。浏览器已执行的原生模块无法从内存模块缓存强制卸出；停用通过代次、取消和已登记清理释放资源。部署删除无法停止其他同事浏览器中已加载的可信代码，各实例须自行停用或重新载入。

上传最多 64 MiB，解包最多 256 MiB/4096 条目，安装总等待期限 120 秒；上传、文件工作和注册验证各自有界。限额用于运行稳定性。包格式及失败规则见 [在线安装架构](../implementation/在线插件安装架构.md)，真实服务与当前构建模式的验收记录见根目录 todo.md。
