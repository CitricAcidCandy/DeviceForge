# 后端架构与开发约束

## 文件骨架
```text
backend/
  crates/domain/            领域实体、错误和可替换端口
  crates/plugin-sdk/        稳定、可序列化的公开插件协议
  crates/plugin-runtime/    有界异步传输、合作取消和清理确认
  crates/tool-process/      公开异步工具执行、限额与直接进程回收
  crates/tool-repository/   公开同步工具内容、跨进程租约与显式引用仓库
  crates/data-codec/        独立受限编解码公共库
  crates/observability/     日志上下文、有界写入、轮转和统计
  crates/infrastructure/    工具进程、SQLite、插件进程适配器
  crates/application/       用例、任务生命周期和贡献注册
  crates/server/            HTTP 路由、鉴权、启动装配和契约测试
  plugins/                  示例插件，不混入宿主业务代码
  docs/                     仅后端文档
```

核心采用端口与适配器架构。HTTP 层不得拼接 shell 命令；领域层不得依赖 Axum、SQLite 或操作系统进程。工具执行器、存储和插件执行器可以替换；新能力通过命名空间操作贡献接入，禁止每增加一项能力都修改通用任务路由。

## 基础平台与设备提供者

目标边界见 [设备适配器插件架构](../implementation/设备适配器插件架构.md)：宿主提供插件注册、统一设备目录、能力路由、任务/互斥、产物、鉴权和日志；Android/Harmony/iOS 等平台发现、连接和工具命令归独立适配器插件。新增平台须通过公开 SDK 接入，不扩展宿主的平台分支。

离散设备第一阶段已实现公开 SDK 声明、统一当前代目录、精确版本能力调用及共享写锁，HTTP/MCP 复用原贡献注册和任务生命周期，见 [设备提供者第一阶段实施](../implementation/设备提供者第一阶段实施.md)。实际验收以根 todo.md 为准。当前 Android/Harmony 仍在基础设施中并由 server 直接装配，平台迁出、常驻会话、iOS 与真机未完成。设备封套的嵌套输入产物选择已通过 debug/release/npx，见 [嵌套输入实施](../implementation/插件嵌套输入产物实施.md)；该契约不表示旧安装/截图能力已经迁出宿主。

## 开发规则
- 全部注释、说明和错误文案使用中文，协议字段采用稳定 snake_case。
- API 推荐 `/api/v2`，成功返回 `{log_id,data}`，失败返回 `{log_id,error:{code,message}}`；v1 保持兼容。例外及 MCP 关联方式见日志与关联契约。
- Tokio + Axum 承担异步 I/O。线上任务存储入口使用 `*_async`，任务与性能存储分别限制最多 4 个阻塞工作；同步领域端口只供启动、受限工作池及兼容测试使用，不能在 HTTP/MCP 调度线程直接调用。
- 输入必须验证，设备编号不得以 `-` 开头；参数使用独立 argv，禁止 shell 字符串执行。
- 设备写操作作为任务：排队 → 运行 → 成功 / 失败 / 取消。取消终态不可被晚到结果覆盖。
- 子进程超时、取消和输出上限必须受控；释放句柄必须终止子进程。Windows 插件不得自行派生后台进程，后续进程树管理验收单独跟踪。
- 持久化任务及事件，启动后把遗留排队 / 运行任务收敛为失败，禁止假装继续运行。
- 本地/同事局域网部署默认免鉴权；APK_API_TOKEN 可选，配置后执行令牌检查。令牌不写日志、数据库或插件环境。请求大小、在途请求和任务队列保持有界，以保证运行稳定性。
- 工具路径由部署者配置；浏览器可在线提交可信插件包，安装器从受控包内容生成部署入口，不接受任意服务器目的路径。在线包/部署规则见在线插件安装架构；插件是可信扩展，独立进程不是操作系统沙箱。
- 数据目录内存放受控产物，浏览器传产物 ID，不传任意服务器路径；上传需大小限制和内容验证。
- 通过信号量限制并发，任务事件具有递增序号，可按游标读取。慢消费者不阻塞任务。
- 协议结构使用公开 SDK；禁止复制 Rust 类型到手写 OpenAPI 后遗忘同步。
- 每个新增模块附 README；测试覆盖失败输出、超时、取消、注册冲突、鉴权和服务重启。

## 验收
无设备的测试不等于真机验收；ADB、HDC、aapt 和系统差异需要可复现真机测试。迁移清单必须如实标识已实现、待验证、待迁移。

完整执行要求见本端 AGENTS.md。`node scripts/check-architecture.mjs` 检查 Cargo 已解析生产依赖，包括构建依赖；用例不得引用适配器，领域和公开 SDK 不引用宿主，独立插件只引用 SDK 和公共库。开发依赖用于真实适配器集成测试，单独允许。未知模块必须先补职责规则，新增领域外部依赖需要审查。该门禁不判断标准库副作用、数据库阻塞、算法复杂度或真机性能。

设备提供者另在项目根执行 `node scripts/device-provider-smoke.mjs`，发布重建后执行同命令 `--release`，记录第三方模拟进程证据；常驻与平台设备验证分别交付。
