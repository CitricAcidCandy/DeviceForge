# 六项业务迁移实施

日期：2026-10-10。用户再次明确先迁移 Frida、自动化、投屏、AI、配置及工具供应；交互会话底座停止扩展，已有未提交改动保留。模式为 architecture-first，按本文件直接实现业务，不另建通用框架。

## 目标和边界

旧 Electron 只读。业务通过独立进程插件和现有协议 4、任务、产物、HTTP/MCP 接入；前端只实现严格 TS 用例，产品 UI 等设计稿。工具路径和凭据由部署者配置，业务请求使用设备、项目、模块及产物 ID。长任务先按既有取消和固定期限落地，持续流媒体与会话必须保留实际缺口，不能将录制或单次调用写成完整投屏或多轮会话。

选择独立插件复用既有公开 SDK/runtime/tool-process；不把六模块塞进通用宿主，不继续扩展会话底座。公共类型生成和 workspace 变更由主代理负责，插件实现写集互斥。

| 模块 | 原业务依据 | 实现职责与落点 | 输入输出及副作用 | 验证重点 |
| --- | --- | --- | --- | --- |
| Frida | frida.ts、AppPermissionsAnalysis、FridaManage | plugins/frida：部署、进程、注入、权限 hook、结果与清理 | 设备/包/脚本产物 → 工具调用和日志产物 | 独立 argv、自己 PID、spawn/attach、取消与真实退出 |
| 自动化 | auto_mator、AutoMouse、InputTrace Record/Playback | plugins/automation：结构化动作、重复点击、录制/回放 | 设备/动作或脚本产物 → 输入与录制产物 | 顺序、计时、取消、脚本校验；全局 Windows 输入另明确 |
| 投屏 | Tools/scrcpy 及旧设备入口 | plugins/mirroring：设备视频、录制、输入控制 | 设备/编码参数 → 视频产物/后续浏览器流 | 工具退出、文件资格、真实解码及直播范围 |
| AI | case_assistant facade、CLI 与 SDK 会话 | plugins/ai-assistant：运行状态、项目上下文、单次及多轮 | 项目 ID/提示词 → 响应/事件产物 | 凭据独立、取消、线程归属与解析 |
| 配置 | custom_config、配置 repository | plugins/settings：用户/工作区分离、版本、CAS、原子写和旧配置导入 | 作用域/配置区/JSON → 修订及内容 | 跨进程竞争、版本拒绝、导入与失败无损 |
| 工具供应 | tool_updater manifest/io/storage/service | plugins/tool-supply：清单、计划、校验、安装/回滚 | 模块 ID → 下载/固定目录安装状态 | SHA256、解压边界、备份恢复、取消及版本 |
| 前端 | 旧 renderer 业务用例 | features 对应六目录 | 公开任务服务 → 用例状态、日志与产物 | 严格 TS、取消和晚到结果，不实现占位 UI |

配置、规则、文件及进程分文件，副作用不进入 SDK/domain；插件只引用公开库。采用 Hybrid：先业务清单和模块签名，再必要规则/真实进程测试，冻结后主代理运行 Cargo 和服务门禁。静态、模拟工具、真实工具/设备、浏览器和分发分别记录。

## 写集

- 后端代理：plugins/frida。
- 工具供应代理：plugins/tool-supply。
- 前端代理：六个 features 及对应测试；不手改生成类型。
- 主代理：plugins/settings、automation、ai-assistant、mirroring；workspace、接口与集成门禁。

完成依据是实际业务与旧能力对照，不用新增框架、文档和测试数量替代迁移完成。持续会话、全局输入、SDK 会话、浏览器直播以及真机验收逐项保留，后续继续实施。
