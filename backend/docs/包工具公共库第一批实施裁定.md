# 包工具公共库第一批实施裁定

日期：2026-10-10。模式：architecture-first；开发顺序为契约与关键失败测试先行的Hybrid。主代理依据《包工具公共库迁出契约》候选稿及总监审核冻结本批公共核心实施输入；用户已授权整体迁移，本裁定不另加确认步骤。本文不表示实现或验收完成。

## 目标与选型

新增`deviceforge-android-package-core`，提取独立归档机制和Android纯解析/容器规则，为Android包插件提供公开依赖。选择一个crate、内部archive/android分层；当前没有足够通用消费者需要第二个归档crate，两层不得相互堆叠业务或复制路径规则。

候选稿的最小API、数据值、错误、profile及数值全部沿用。生产依赖冻结为zip 8.6（default-features=false、deflate）、quick-xml 0.42、serde derive和thiserror 2；开发依赖可用tempfile 3。复用当前版本，不升级算法或依赖。不依赖宿主四层、SDK/runtime/tool-process、Tokio、网络或数据库。

| 单元 | 本批职责与输入输出 | 不承担的职责及副作用 |
| --- | --- | --- |
| control/error/profiles/models | std绝对点与取消回调、独立有限错误/规则/值 | 不建运行时、后台线程或资源清理资格 |
| archive | 已打开File和显式profile到有界目录/精确复制/树与Stored ZIP摘要 | 允许受控同步I/O；不解析产物ID、不创建目的父目录、不删除调用方目录 |
| android | 有界XML/报告/容器/目录到清单、签名、APKS与smali规则观测 | 不启动工具、不读环境、不持设备连接或锁、不返回宿主Artifact |
| 主代理Cargo/架构接入 | 新库工作区登记、生产依赖方向与拒绝测试 | 不在本批切换旧装配或提前发布平台插件 |
| 测试与README | 规则、坏容器、精确失败、取消/到期和真实受控文件的证据 | 不把模拟解析或静态门禁当作真包、工具、分发或真机通过 |

固定Structure上限10000条与声明展开2GiB；Reverse树10000条、Splits树1000条、深度128，文件总量与ZIP完成大小各64MiB。精确成员唯一、复制EOF/长度/CRC；APKS外层完整读与256MiB累计、非空toc.pb及APK标识；业务最终规则与监测期规则分开。XML/签名/路径/SDK边界沿候选稿，排序和None语义不得缩减。

Archive、SelectedEntry及TreeSnapshot不可伪造；后续实际I/O与完成前复核Control，取消或到期不返回半成品摘要。输出借用调用者create_new取得的File，核心不覆盖文件。保留原io::Error，调用层负责有限错误适配，不向协议直接泄露路径或任意工具文本。

## 写集、拆分与交接

Galileo独占新增`backend/crates/android-package-core/`的Cargo.toml、README、源码与所属测试。先落控制/错误/profile/纯模型，再分archive/{preflight,paths,index,copy,tree,packing}和android/{manifest,signature,apks,smali}；不把工具、宿主适配或文件发布堆入lib.rs。职责清楚的窄实现可精简文件，不能为了目录名产生空壳。

主代理独占backend/Cargo.toml、Cargo.lock、backend/scripts/check-architecture.mjs及architecture.test.mjs、共同记录。Galileo不改旧infrastructure或这些接入文件；引用旧代码只用于提取已确认规则，不复制宿主实体或编排。其他角色不得修改新库。库测试完成冻结后，Galileo可继续不冲突的已分配下一项；Cargo/Node/格式化/测试仍只由主代理执行。

旧基础设施薄适配、七项独立包插件、别名替换和main平台装配撤除不在本批写集；必须继续后续迁出，新增库本身不能关闭平台插件目标。本批可立即实施，不依赖未冻结跨进程字段或部署来源。

## 后续接缝的保证边界

同进程Control构造签名明确冻结为`Control::new(deadline: Option<std::time::Instant>, is_cancelled: &(dyn Fn() -> bool + Sync))`，借用回调与Control同生命周期；`check(&self) -> Result<()>`。Some(D)使用同一绝对点，None仅表达调用者没有提供截止点，不自行补总预算；检查先判断点已过的Timeout，再判断取消的Cancelled。回调应只读已共享取消状态，不允许隐含I/O/阻塞或重置预算。调用层受限池、真实worker与目录lease必须到物理工作结束才释放，库不替它们宣称清理完成。

跨进程SDK Request当前没有D或剩余预算。本批不新增私有JSON/env通道，不把本地短期限称为宿主剩余D。宿主按原D发出合作取消的现有保证继续有效；后续是否增加公开执行上下文及传输延迟语义须在平台插件编排前另冻结，不能用本批库实现默认选择保证强度。

tool-process最多2秒清理与宿主1250毫秒合作窗口不合并或延长。后续插件只能在所有已开始工具/worker/句柄实际排空后报complete，超窗或Drop保持未确认；直接子进程退出不等于Java派生树、共享daemon或设备事务清理。部署配置来源和缺配置边界也留下一批显式裁定。

## 必须取得的验证

先写有意义的失败回归：结构坏包/ZIP64/分卷/路径/链接、精确零或多匹配及CRC/长度坏包；两个树profile、含目录计数、深度、ZIP开销和源变化；XML命名空间/DTD/重复结构、签名不完整与SDK前缀边界。核心控制需覆盖预取消/过期零新I/O、中途取消与完成前复核，断言具体错误类别；不以只调用同一实现的测试当独立证据。

主代理接入后执行架构及拒绝规则、fmt、Clippy、核心测试和全工作区test/build，检查旧行为未被误改。读取实际输入前后摘要，保留失败原件。当前真实长任务验收只读取已构建宿主及冻结根脚本，新库写入不得修改这些输入；新库变更不借记已完成的旧源码门禁。

旧成功值/错误的薄适配对照、真实APK/AAB/APKS与工具、协议清理/在线热装卸、当前release/runtime/npx都仍在后续完整迁出验收中。没有这些证据，不声称七包能力或平台层已迁出。
