# 终端业务插件

通过公开协议5打开一个部署profile，使用同一真实工具进程持续收发原字节。当前没有PTY和resize，不把重复普通Job当作交互。完整合同见 [终端业务插件实施裁定](../../docs/终端业务插件实施裁定.md)。

`manifest.json`声明唯一会话贡献 `plugin.terminal.open`，普通operations为空。打开业务为 `{"profile":"python"}`；profile只选择部署者定义的程序、固定argv及可选工作目录。默认旁置 `terminal.config.json`，可使用 `--config`绝对路径；示例配置见 `terminal.config.example.json`。

单块8192字节、通道8、累计输入1 MiB、双路合计输出16 MiB。输出保留UTF-8、非法UTF-8和零字节；EOF关闭工具stdin，取消仍可停止会话。所有行为消耗原截止点，取消、期限和背压不重新授予业务预算。工具使用Restricted环境，输入、配置和原始输出不进入生产诊断日志。

`resource_scope:direct_process`限定当前资源承诺为直接工具进程及本地管道。实际进程退出和租约释放才允许Complete；清理失败或丢弃等待保留Failed。该范围不能证明部署shell派生树或远端资源已清理，配置不是沙箱。需要额外资源所有权的工具应采用专门平台插件，不借本插件声明全部清理。

本批提供独立插件源码、清单及回归，主代理负责workspace注册、编译、宿主会话目录、HTTP/MCP和分发。尚无本批服务、浏览器、真实部署工具或跨平台验收，不计完整终端迁移完成；具体产品界面继续等待设计稿。

库内已写14项回归，含4项真实Node工具的公开协议帧与PID退出检查；目前未运行编译或测试。宿主登记、慢消费者背压、网络接口、正式分发及真实部署工具仍分别待验，不能以插件源码或回归数量代替完整交付。
