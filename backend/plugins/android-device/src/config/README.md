# 部署配置与 APKS 工具资格

`config.rs` 定义严格格式 1、可选工具与工作根，并核验字符串、程序名和绝对路径的纯资格。`reading.rs` 在有效 Start 后沿原调用上下文异步读取最多 65536 字节配置，未知字段与重复字段拒绝；`paths.rs` 核验普通文件及无链接、无重解析点的全部祖先目录。

`apks.rs` 仅消费部署者配置，要求 Java、`java_jar` 和 ADB，输出 Java 程序、固定 `-Xmx256m -jar <JAR>` 前缀及绝对 ADB 文件。ADB 单程序名按 PATH 查找，Windows 无扩展名时另尝试 `.exe`；路径元数据与 canonicalize 等待均受原截止点和取消控制。它不读取业务参数、不启动工具、不创建私有目录。

Java/JAR 可省略，其它设备动作不要求它们；APKS 执行时返回固定缺依赖或文件资格错误。业务请求不能设置工具、JAR、自由参数、环境或临时根。配置测试只核对解析与资格，独立假工具验证由主代理执行，真实部署可用性仍需真实工具证据。
