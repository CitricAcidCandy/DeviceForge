# Android 短动作编排

- `../operations.rs`：输入封套解析、动作分流及调用上下文检查。
- `models.rs`：公开输入结构，不读取设备或部署配置。
- `commands.rs`：固定参数与现有成功响应校验，不自行启动进程。
- `start.rs`：保留原启动命令；仅工具执行失败后只读辨因，不重新启动、不安装应用、不替换包名。安装列表和启动入口均限定当前 Android 用户，包名按完整字符串匹配，明确区分未安装和没有桌面入口。
- `tests.rs`：固定命令和输入解析单元测试；独立进程失败回归见 `../../tests/cases/start_failure.rs`。

失败辨因最多查询安装列表和启动入口，两步共用两秒上限，并继续受原调用的期限、取消及清理确认约束。查询失败或输出不可信时保留原错误，不将未知故障推断为“未安装”。公开错误仅含固定中文，不透出原始工具诊断、路径或用户输入。
