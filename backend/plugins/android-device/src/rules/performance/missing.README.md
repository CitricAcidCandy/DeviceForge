# 可选CPU和内存接口缺测规则

本模块输入固定只读命令的完整双流输出或公共工具错误，输出真实可用正文、明确权限拒绝或接口不支持；不访问设备、时钟、文件、日志或宿主。

只有全文匹配固定命令诊断才能缺测。非零退出限退出码1且stderr全部为认可诊断；成功输出不可混入任何指标正文。来源使用linux_proc.stat和android_dumpsys.meminfo，访问方式由实际ADB或已确认Root通道给出。

进程身份读取不进入本模块。未知诊断、错误PID、重复header、缺少内存数值和非法计数由原严格规则拒绝，取消、期限、限额和未确认清理继续传播。纯规则回归位于上一级tests.rs，工具协议回归位于tests/cases/performance.rs。
