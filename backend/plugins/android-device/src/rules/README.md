# 纯设备响应与产物规则

本目录仅处理内存值、输出资格和固定错误映射，不读取配置、访问文件、启动进程或删除资源。普通设备动作保持既有响应规则；`artifacts.rs` 负责 APK 安装的严格 UTF-8 与独立 Success 行，以及截图最低 PNG 资格。

`apks.rs` 单独保留旧 APKS 规则：调用方先确认直接工具零退出，再对两路输出做 UTF-8 lossy 合并与 ASCII 小写匹配；任一旧失败子串使调用失败，空输出合法，不要求独立 Success 行。返回固定中文错误，不透传原诊断。

`performance.rs`负责性能独立包名规则、双流UTF-8 lossy合并与旧八失败子串、唯一PID、带括号进程名的stat、系统CPU累计/核数和meminfo身份/汇总。它只返回原始计数，逐行解析接收只读检查回调；不读取时钟、不计算CPU百分比或FPS，不启动工具。包名允许每段首下划线，避免普通应用动作较严的规则改变旧性能目标合同；全部整数和累计溢出、重复核编号与互相矛盾的汇总均拒绝。

公共包错误保持取消、到期、成员数和体积分类；结构声明超过 2 GiB 与 APKS 展开超过 256 MiB 分别映射，CRC/长度/外层结构失败固定归为输入无效。公共包库负责真实归档验证，本模块不重复实现 ZIP 或嵌套 APK 验证。
