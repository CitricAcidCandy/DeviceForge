# Android 调用栈 folded 导出

本模块只接收已解析的 `Report`，不启动工具、不访问设备或文件。调用者在既有受限阻塞工作中传入原取消与截止点检查。

## 入口与边界

`folded(report, options, check)` 返回文本及内部汇总。生产归档使用默认选项：每个非空调用链样本权重为 1，导出可选成员 `flamegraph.folded`。内部选项还支持精确事件计数权重、进程、线程及 `[begin_ns, end_ns)` 的 boottime 窗口。样本时间及事件计数按规范十进制 u64 读取；累计用 u128，再转换成十进制字符串，不换算为精确 CPU 耗时。

每条链首先输出事件、进程及线程三层元数据，然后把原来叶到根的调用链逆转成根到叶。每个输出行按完整标签串的 UTF-8 字节排序，以最后一个空格分隔整数权重。

## 固定标签

- 事件标签：`event=` 加事件名的 JSON 字符串，缺失为 JSON null。
- 进程标签：`pid=` 加十进制进程号，缺失为 null；线程标签为 `tid=` 加十进制线程号。
- 帧标签：JSON 数组 `[execution_type, file, symbol, address]`。空符号与缺失符号统一为 null；有符号时 address 为 null，同模块、执行类型及同函数可合并不同采样地址。无符号时保留模块和地址；模块缺失与空字符串不同。
- 每层标签中的百分号、分号、回车和换行分别转义为 `%25`、`%3B`、`%0D`、`%0A`。JSON 本身先完成字符串转义，随后才应用上述编码，不会从原符号插入额外调用层或行。

## 质量与限额

展开错误、缺元数据、缺符号、单帧和空链按被选中的原样本统计，不补造缺失帧。空链没有可绘制路径，在内部汇总的空链权重中保留；归档质量仍由原 `stack-quality.json` 承担。

最多 100000 样本、1000000 帧、每链 256 帧、每个文本字段 4096 字节；累计输入文本及保守估计的 folded 输出分别不超过 32 MiB。输入非法、超限、取消或期限错误直接交还调用者。循环、标签编码及最终导出均继续检查取消。

单测覆盖链方向、模块与地址身份、递归、半开时间窗口、大整数、事件隔离、空链与展开质量、转义、排序、取消和限额。真实原件重放与 ZIP 集成由主代理统一验收，单元测试不代替真实设备验证。
