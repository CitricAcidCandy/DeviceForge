# SDK 公开实时流契约

## 入口与终态

- 独立会话贡献为 `sdk.stream`，协议版本为 5；普通贡献保持协议 4。
- 开始输入为 `{project_id,prompt,thread_id?}`。项目标识为 1—80 个 ASCII 字母、数字、下划线或连字符；提示词非空白且最多 131072 个 Unicode 字符；线程标识为规范 UUID，不接受 `null`。
- 公开输出仅使用 `stdout`，内容为 UTF-8 JSONL。每个 JSON 对象都有 `format_version:1`。
- SDK 提供者的 `turn.completed` 先记录为内部候选；只有真实 CLI、Node、监督进程与完整资源范围退出已确认，调用临时目录已清理且线程资格成功提交后，才向公开流发送 `turn.completed`。
- 协议 5 的 `Closed` 是会话最终状态。失败或取消不发送成功的 `turn.completed`，不得凭最后一条回答或提供者候选认为会话成功。
- 成功的 `Closed.result` 为 `{provider:"codex_sdk",sdk_version:"0.162.1",project_id,thread_id,text,turns,resource_scope:"sdk_worker_proxy_and_cli"}`；其中 `turns` 为十进制字符串，`text` 与公开流完成的回答一致。

## 精确事件字段

| 类型 | 精确对象 |
| --- | --- |
| 线程开始 | `{format_version:1,type:"thread.started",thread_id:string}` |
| 轮次开始 | `{format_version:1,type:"turn.started"}` |
| 条目开始 | `{format_version:1,type:"item.started",item:Item}` |
| 条目更新 | `{format_version:1,type:"item.updated",item:Item}` |
| 条目完成 | `{format_version:1,type:"item.completed",item:Item}` |
| 完整成功 | `{format_version:1,type:"turn.completed"}` |

`Item` 精确字段为 `{id:string,type:ItemType,status?:ItemStatus,text?:string}`，不附加其他字段。

- `id` 是本次轮次内稳定别名 `item_1`、`item_2` 等，不公开原提供者条目标识。
- `type` 为 `agent_message`、`reasoning`、`command_execution`、`file_change`、`mcp_tool_call`、`web_search`、`todo_list` 之一。
- `status` 如果存在，只能为 `in_progress`、`completed`、`failed`。
- `text` 只允许出现在 `agent_message` 或 `reasoning` 条目中。完成的 `agent_message` 必须有正文。
- 每个条目对象是当时安全字段的完整快照，不表示正文增量。客户端根据相同 `id` 替换旧快照，不能把每次 `text` 直接拼接。
- 单条目完成后不能继续更新或再次完成；轮次完成前已公开的条目均须完成。

## 限额与脱敏

- 原始 SDK 事件单条最多 64KiB，整个轮次最多 10000 条真实事件。
- 公开 JSONL 单行最多 512KiB；整个公开流最多 4MiB；协议传输按最多 8192 字节分片，分片不对应 JSON 行边界。
- 原始回答合并与脱敏后回答各自最多 512KiB，多个完成的回答按顺序以换行合并。
- 公开字段不含工具命令、服务器目录、文件更改路径、工具参数、工具结果、部署环境、原始诊断或提供者原始条目标识。
- 文本中的已配置环境值及部署入口、项目目录、状态目录、提供者历史目录替换为 `[已隐藏]`。替换后超限则失败，不截断。
- 未识别的提供者事件或条目类型不公开；提供者失败、线程身份冲突、重复终态、未完成条目、候选与实际事件冲突均导致失败。

## 当前证据边界

契约和独立规范化实现已落地，普通 Rust 基础批与 Node SDK 批分别验收。公开实时会话仍需协调器、公共完整进程树能力和真实服务接线验证；此文档不表示真实模型、三个操作系统或正式分发已通过。
