# SDK 运行资格聚合

`runtime_status.rs` 只聚合严格配置、实际版本、官方 SDK 加载、当前平台监督和模型历史资格，并为普通协议返回独立清理结果。项目 ID 来自部署映射，程序路径、专用环境和原始探测输出不公开。

`probes.rs` 通过公共 `OwnedTree` 异步执行 Node 与 CLI 版本查询，限定五秒业务时间、1 KiB 标准输出、8 KiB 诊断输出及原取消信号。只接受单行版本格式，实际范围未确认时报告清理失败。

`probes/sdk.rs` 使用固定包内 `probe.js` 走私有监督，核对实际启动身份、SDK 固定内容和版本、自然成功候选、内部范围及外层监督真实退出。它不准备模型认证、不提交提示词，也不创建模型历史资格。

`tests.rs` 回归配置不能替代探测、任一范围未确认阻断资格、模型历史与实际版本独立、错误原因保留及版本字段不能携带额外输出。通过单元回归不等于真实程序、模型或跨平台验收。
