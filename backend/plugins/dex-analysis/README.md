# DEX直接分析插件

独立公开协议4插件，提供`plugin.dex-analysis.inspect`和`plugin.dex-analysis.scan_sdks`。输入仅为宿主授权单一`.dex`产物；SDK扫描另传有界规则。输出为统计、摘要观测及已定义类证据，不发布产物。完整合同见[DEX直接分析插件实施裁定](../../docs/implementation/DEX直接分析插件实施裁定.md)。

支持035、037、038、039、040单一标准DEX、112字节头、little-endian和空链接区。明确拒绝041容器、Compact DEX、reverse-endian。核对宿主SHA256、内部SHA-1与Adler32，检查表/映射/引用和MUTF-8名称；不解释全部代码指令、注解或编码数组，不把摘要一致视为Android完整验证器通过。

SDK证据只来自`class_defs`实际定义的类，外部`type_ids`引用不算命中。包前缀按完整`/`边界，内部类保留`$`；每规则至多10项排序证据，指定检测点命中不会被前十项挤掉。不识别SDK版本或运行行为。

文件64MiB、百万字符串、其它表65535项；字符串65536个UTF-16码元/196608编码字节，名称4096码元，类型名称缓存合计16MiB。读取、摘要和解析均在每进程最多一个真实阻塞worker内，按原总截止点及取消检查；File和许可随物理返回。取消后沿一次两秒清理点等待，超窗、panic或Drop保留未确认。不创建/删除输入副本、临时目录或输出文件。

SDK结果按保守JSON转义体积累计最多512KiB，超限失败，不静默删减已选证据。六类头部主索引经范围、引用与排序检查；调用点、方法句柄及其它数据条目目前只有映射范围观测。

生产日志不打印输入、文件路径或工具文本。独立源码和回归不表示宿主服务、正式包/npx、真实DEX或跨平台验收已经完成，实际结果由主代理集成记录。
