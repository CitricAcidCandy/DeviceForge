# 十二项业务输入

`models.rs` 定义拒绝未知字段的设备、提供者封套与业务对象，`operations.rs` 先纯校验十二个短贡献与显式封套，再执行固定 HDC 参数。连接与断开先要求 `device_id:null` 并薄委派给 `network`，其他设备能力继续要求合法字符串设备标识。安装与截图分别进入独立私有资源流程；截图仅接受空业务对象且不经过 JSON 动作结果分支，输出授权在配置读取和工具派发前检查。完整详情、应用启停与重置由 `applications` 编排，自动 ability 推导复用同一详情解析与调用截止点。输入模式、固定工具档案、远端回执和单路资格观察由独立 `input` 模块负责，发现分支只委派资格观察；其余动作不读取产物。包名、UUID 和设备标识资格由纯 `rules` 提供，测试在副作用之前验证拒绝边界。
