# 安装私有资源

`session.rs` 编排安装与最终清理结果；`worker.rs` 薄委派公共 `Control::work`，继续使用同一单槽、租约、原截止点和工作真实返回确认；`directory.rs` 创建独占目录、在固定清理点内实际删除并确认不存在。

`input.rs` 只处理唯一授权 `/input/artifact_id`，把源产物流式复制到固定 `input.hap`，核对真实大小、SHA-256、元数据和刷新关闭后副本。`files.rs` 核对普通绝对路径、全部祖先和文件句柄，拒绝父路径、链接与 Windows 重解析点。模块不创建宿主产物实体、不承诺设备安装回滚。

内部确定性测试覆盖工作槽与租约、Future 丢弃、工作线程异常、粘性失败、固定清理点和 Windows 文件锁；独立进程集成测试由 `tests/` 负责。两类测试均不能代替真机。
