# Harmony 离散输入

本模块使用固定OpenHarmony `uitest 5.0.1.1` 档案；官方不可变源码、私有模式和当前验收边界见 [实施裁定](../../../../docs/implementation/Harmony输入插件实施裁定.md#10-官方取证后的私有实现合同)。它不依赖Android插件、宿主内部模块、HTTP DTO或设备端常驻辅助程序。

- `models/rules`严格解析 `{action}`，坐标为1至32767，滑动采用200至40000像素每秒的 `velocity_pps`，不接受Android `duration_ms` 或按键长按标志。
- 文本必须提供 `x/y`，支持最多1024个UTF-8字节，拒绝控制符；设备工具先点击定位，随后逐键输入或通过剪贴板粘贴，剪贴板可能改变。可选enter发送Harmony原生码2054。
- `scripts`只生成固定前台命令，以独立HDC argv及设备端单引号引用保留文本字面量。关联标识用于本次帧匹配，不是权限或安全秘密。
- `receipt`区分工具版本、帮助、完整终端帧和动作 `No Error` 诊断；不能只用HDC退出码或公共错误子串扫描判定成功。
- `execution`复用原InvocationContext和Control。远端帧缺失、取消或Future丢弃保留粘性未确认，不以客户端退出证明设备端结束，不重试或撤销已输入事件。
- `observation`在最多128台设备中单路探测，以8秒启动窗口限制新工具调用；窗口到期的剩余条目明确不可用。已启动工具继续按原总期限及同一清理点收敛，不创建新预算。现有Control独占捕获限制下，不另建独立租约伪装并发。

成功仅返回设备标识、动作名称和 `dispatched:true`，没有产物，不证明焦点、应用收到或界面变化。输入实际执行重新探测资格，发现的available仅代表当时观测。普通工具不支持属于明确不可用，未确认远端资源阻止整次发现交付并保留宿主draining。
