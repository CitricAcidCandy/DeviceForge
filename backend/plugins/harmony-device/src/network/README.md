# 连接管理模块

`network` 只提供离散 `connect@1` 与 `disconnect@1`。业务输入严格为 `{address}`；外层由 `operations` 校验显式 null 的提供者封套，不要求地址已在发现目录中在线。

地址支持规范 IPv4 或小写字面 `localhost`，显式十进制端口为 1–65535；最多 21 字节。拒绝其他 DNS、IPv6、IPv4 前导零、空白、控制字符及额外参数。合法请求字面值原样交给 HDC，插件不做 DNS 查询或地址改写。

固定 argv 为 `[tconn,address]` 或 `[tconn,address,-remove]`，不带 `-t`，每次任务只执行一条命令。连接仅认可 `Connect OK` 或 `[Info]Target is connected, repeat operation` 完整行；断开仅认可无失败诊断的静默完成。共同失败诊断优先，未知非空断开输出、乱码和非零退出不算成功。业务结果为 `{output}`，静默断开为 `{"output":""}`，不返回设备状态。

`models` 管严格业务形状，`rules` 管地址资格与响应规则，`tests` 管纯规则回归；模块根只编排固定命令并复用已有 `Control`。总期限、捕获上限、进程租约、取消和两秒固定清理点沿原调用上下文，不新增工具执行器。

提供者写屏障由宿主统一持有。此模块不发现设备、发布目录或改变选择，完成后由调用方显式刷新目录。共享 HDC server、设备 daemon 和持续连接归部署者；取消或卸载不发送全局关闭、反向断开或调试模式切换命令。客户端命令完成不代表物理断开、回滚或常驻会话完成。

完整批准合同见 `backend/docs/Harmony连接与断开插件实施裁定.md`；纯规则源码、独立协议、真实服务、分发和真机分别验收。
