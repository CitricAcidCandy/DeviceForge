# 统一插件安装真实验收

在根目录执行 `node scripts/plugin-installations-smoke.mjs`；当前源码重建 release 后追加 `--release`。脚本不编译程序，也不连接在线手机或已有预览端口。

每轮启动独立 Rust 资源服务和宿主，分配临时端口、用户根、业务根。HTTP 代理只记录资源请求次数，原字节来自真实资源服务。第三方协议 1 插件、浏览器 ESM 与共享资源通过公开发布工具构包，宿主通过公开安装任务处理；不按官方插件 ID 编写安装分支。

覆盖一次安装与默认启用、实际工具绑定和用户配置、安装阶段与下载字节、两插件共享资源只下载一次、不同工具版本并存、更新保留停用状态、旧修订拒绝、无效更新保留活动版本、更换业务根后恢复、市场停止后离线导入、摘要错误/缺依赖/平台不符在启用前拒绝、卸载保留配置、清理不破坏共享工具以及 HTTP/MCP 读取一致。

最新报告在 `artifacts/plugin-installations-smoke-{debug,release}.json`，每轮独立原件另存其 `directory/report.json`。宿主必须通过公开 shutdown 正常退出；市场是本轮独占测试进程，结束后回收。临时目录保留为审计证据，不删除用户文件。

本脚本读取浏览器资源原字节，没有执行浏览器模块。它不能替代真实市场页面、两独立 npm 缓存、Windows 正式分发、投屏真机、局域网另一台物理主机或性能验收。进程中断恢复、清理失败、忙碌切换和回滚边界另由对应生命周期及存储失败路径测试覆盖。
