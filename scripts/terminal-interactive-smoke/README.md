# 终端交互真实服务验收

在项目根运行`node scripts/terminal-interactive-smoke.mjs`；`--release`消费已构建的release宿主和终端插件。脚本不构建、不修改已有部署，使用独立数据根和端口，并复制本轮二进制、清单、Node工具及驱动原件后逐件核对SHA256。

覆盖纯会话插件在线加载和动态HTTP/MCP目录、两个入口打开、退出前stdout/stderr原字节、多次输入、EOF、输出分页、非零退出与清理完成分离、显式取消、卸载等待、撤销和新代重载、旧记录保留、已结束记录删除、活动会话关闭及宿主exit0与端口释放。六个打开请求分别与后台准入和结束日志关联，全部响应日志ID核对落盘。

工具以Node进程作为可控真实子进程，PID消失使用`process.kill(pid, 0)`观测；不宣称持OS句柄取得退出码、进程树清理、PTY、浏览器、真机或正式TGZ/npx通过。成功仍保留报告、数据与日志，故障只回收本次宿主。报告和命令退出码共同确定终态，打印passed后的共享启动辅助计时器短暂保活不表示宿主挂起。
