# 真实操作绑定验收

在工程根运行 `node scripts/operation-alias-smoke.mjs`，当前 release 重建后另运行 `node scripts/operation-alias-smoke.mjs --release`。脚本不编译，只启动主代理已构建的当前宿主，报告写入 artifacts。

- config.mjs：临时部署配置与在线模拟包。复用设备提供者夹具；普通贡献无设备声明。
- checks.mjs：公开 HTTP/MCP 注册、单任务、转换、设备准入、共享锁、取消和卸载重载验证。
- artifact-provider.mjs：协议 2/3 真实文件输出；宿主发布后核对命名产物投影、元数据和下载摘要，并在业务对象中放入伪造 ID 验证不能取错来源。
- 根入口：有界就绪等待、自有宿主启动退出、实际宿主及配置摘要、日志关联和夹具清理证据。

验收使用真实 Rust 服务和 Node 协议 2/3 进程，使用 android.app.stop、harmony.packages 旧名称验证显式预留和无内置回退；模拟贡献不实现平台命令，不能作为旧平台已迁出或真机完成的证据。期限由应用/传输定向回归另行验证；本脚本不重复等待真实 120 秒任务。

不记录凭据、原始业务请求或任意插件输出。仅成功且本次宿主与夹具已清理退出时删除临时目录，并先核对实际路径在系统临时目录下。任何验收或清理失败都保留本次复现目录；失败时仍按原有期限关停自有宿主，不终止未知 PID。

## 普通证据补项

- BIND-E01：报告保留失败阶段、原失败请求的路径/方法/状态/日志 ID 等元数据，避免关停请求覆盖。`temporary_retained` 和 `failure_evidence` 指向完整配置、数据库、日志及夹具标记；`failure_log_files` 记录采集时的相对日志路径、字节数和 SHA256，读取失败另记错误名称/码。报告中的最近二十五项夹具事件及十五项相关日志仅为摘要，完整复现依据保留目录。
- BIND-E02：协议 2/3 两次产物下载均保存 `download_log_id`，加入共享客户端日志 ID 集合，在宿主正常退出后与 HTTP/MCP 响应一起逐项核对真实日志落盘；原字节、大小、SHA256 和非伪造业务 ID 的断言保持。
- BIND-E03：分别在 HTTP 和 MCP 坏包加载被精确 `invalid_input` 拒绝后，检查 HTTP 原操作、MCP 原工具及两入口提供者列表均无该包残留，并将两组端点结果记录在 `rejected_load_snapshots`。

本脚本只采样加载/卸载管理调用返回后的公开入口，不能凭这些采样证明中间注册快照原子性。原子发布/撤销、锁、预算和真实协议 2/3 跨六十一秒证据关联独立的 `backend/crates/application/tests/operation_aliases.rs`；主代理已执行该批十七项全部通过，后续变更仍须单独登记运行版本和结果，本脚本不代跑或推定其通过。

本批补项冻结时仅完成源文本语法审查及 UTF-8/空白静态检查，未运行 Node、Cargo、npm 或服务。语法检查和 debug/release 实跑由主代理统一排程，旧报告不作为这些新增断言的运行证据。
