## 根脚本接线

主代理负责根 `package.json`，增加：

```json
"pack:plugin-release": "node scripts/pack-plugin-release.mjs"
```

```powershell
npm run pack:plugin-release -- pack --source backend/plugins/mirroring/release.json --inputs artifacts/plugin-release-candidates-20261022/mirroring-inputs.json --destination artifacts/my-mirroring-release --platform win32-x64
npm run pack:plugin-release -- plan --directory artifacts/my-mirroring-release --market backend/plugins/mirroring/market.json --server http://127.0.0.1:7040
```

输出目录必须不存在。`plan` 只读本地，不访问远端。`publish` 使用同一组 directory/market/server 参数，才上传缺失资源、在线清单，最后提交目录；不完整依赖、摘要或入口会拒绝。真实市场发布由主代理集成。

## 必须阻止整体发布的缺口

1. 其余17份当前组件 TGZ 尚待主代理统一构建并冻结；旧 AI SDK TGZ 不能冒充本次源码版本。
2. Node24.14.0、Codex CLI/SDK0.162.1 尚未下载成品与核验归档入口。已取得可信官方元数据，但元数据不等于实际闭包。
3. 官方 Codex0.162.1 Windows 主 EXE 的发布资产声明大小333479728字节，超过服务器工具解包单文件256MiB。现门禁须拒绝，不能改用裁剪、不明或旧二进制假通过；限额变更需主代理裁定。完整 npm 平台包声明展开457335400字节，也超过当前 JS 总展开256MiB；工具总展开应与后端1GiB规则协调。
4. Frida缺真实Windows CLI/Python/依赖闭包；旧本地名为frida的文件实际上是ELF，不能当Windows程序。PyPI wheel不是完整CLI。
5. HDC只确认本地工具版本5.0.0.71，尚未完成必要DLL/许可证闭包再包装。原目录含用户日志，不得整目录打包。
6. 其他官方组件仍有构建机器绝对路径默认值/公开模板。当前打包会真实拒绝；须便携化并保留必要用户输入。用户凭据、项目、签名与设备Root资格不能伪造成下载工具。
7. 当前 JS归档成员限额16384与后端4096不一致；组件/工具展开限制也尚未区分。冻结版本不宣称与后端所有边界等价。
8. 真正完整的工具依赖包、许可证再分发资格、新宿主安装/启停/升级保配置、真实市场/第三方小包和npx均待主代理集成；没有远端发布或手机命令。
