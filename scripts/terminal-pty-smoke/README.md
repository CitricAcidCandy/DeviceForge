# Windows完整终端独立验收

主代理先构建并冻结终端插件，再执行：

```powershell
node scripts/terminal-pty-smoke.mjs <宿主exe绝对路径> <终端插件exe绝对路径> <可选报告绝对目录>
```

驱动只启动独占临时数据根与随机本地端口，不访问7031预览会话。报告保存受检二进制与清单摘要、HTTP日志ID、TTY身份、控制台窗口身份、三层进程树及清理终态，不记录宿主环境、用户终端历史或窗口标题。宿主可明确指定上一冻结版，报告不可据此声明当前源码宿主已构建通过。

覆盖真实TTY识别、原始中文/表情/Tab/方向键/Ctrl+C、ANSI原字节、resize、真实PowerShell交互提示符、命令中断后复用同一shell、非法消息不能进入shell，以及Cancel/EOF/卸载/宿主关闭后的整个三层派生树退出。窗口观察使用Win32 Toolhelp32及EnumWindows，不依赖CIM/WMI，不全局查杀程序。夹具派生进程故意不设置隐藏窗口，验证PTY控制台继承。

浏览器生产构建验收使用独立驱动：

```powershell
node scripts/terminal-pty-smoke-browser.mjs <宿主exe绝对路径> <终端插件exe绝对路径> <生产前端目录绝对路径> <可选报告绝对目录>
```

该驱动重新启动独占宿主并冻结受检二进制，设置只有PowerShell的测试配置，调用真实Edge/xterm输入探针。Codex在报告目录下新建的空工作目录进入，只核对CLI版本、可见进入界面、进程归属、Ctrl+C退出和无新增可见控制台，不提交prompt或处理授权。浏览器包含中文组合事件及合成多行剪贴板事件；后者不是系统剪贴板操作。真实PTY尺寸必须随1440宽缩到760宽而减少列数，不能仅凭窗口截图声明resize通过。截图另由测试助理图审。

普通键盘使用CDP的原生keydown/char/keyup事件并按每键20毫秒节奏发送，避免自动化瞬时填满生产有界队列。中文组合使用imeSetComposition和insertText提交，不直接改textarea或调用xterm内部API。Edge在此CDP提交中产生受信任的compositionstart/update，但compositionend的isTrusted为false；独立空白页诊断同样如此。报告保留该边界，不能据此声明操作系统物理输入法已验收。PowerShell5对表情输入的限制单独记录，Node原始TTY中的表情完整通过也不外推到该编辑器。

短原生子进程复核使用`node scripts/terminal-pty-smoke-native-child.mjs <宿主exe绝对路径> <插件exe绝对路径>`，不补写测试环境变量。夹具经真实PowerShell启动绝对Node入口，独立记录三个标准句柄是否TTY/字符设备、两路原始写入及退出码。该项用于排除上游插件环境丢失导致的命令识别/启动失败，不能用直接启动Node的TTY通过代替shell派生链路证据。

最终浏览器探针还会打开本次终端后真实刷新页面，等待keepalive释放达到Complete，再从页面历史删除结束记录；另创建本次拥有的活历史终端，从页面显式关闭并确认Complete后删除。不自动接回交互，不批量回收其他会话。

PowerShell测试档案在首次交互读取前将PSReadLine历史路径指向本次报告目录并设置SaveNothing，支持时禁用历史预测；不读取或追加用户命令历史，不修改全局配置。Edge正常关闭最多等待15秒，超时强制回收仍将报告判为失败，随后读取本次浏览器派生树确认无残留。

窗口报告保留所有可见控制台及本次宿主派生树，断言只关联本次树PID，避免其他并发开发窗口导致误报。

可见窗口轮询只能证明取样时未出现额外控制台，不能冒充连续桌面录屏。真实浏览器、中文输入法组合、粘贴、Codex界面进入/退出及页面视觉需另行执行并记录。不得提交模型prompt、代登录、读取用户密钥或执行设备操作。

热更新预览前应只读冻结宿主PID/绝对exe/创建时间、插件代次、配置修订及摘要和活动会话目录。有活动终端会话时不卸载、替换或自动取消；通过独占服务验收后等待用户会话正常结束。更新只通过公开卸载/加载及精确部署入口进行，保留可恢复副本，复核宿主身份不变、配置不变、插件新代且清理保护未触发。用户已有会话不计为本轮拥有资源。
