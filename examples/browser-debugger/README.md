# DeviceForge 官方调试器插件

这是普通浏览器插件 `deviceforge_debugger`，使用公开 SDK v2，向 `developer.tools` 槽位追加一个全局悬浮工具，`panels` 为空。插件可独立启停，不内置到宿主导航。运行时只依赖宿主公开 React 入口、SDK 上下文和 `host.debugger` v1 服务；源码中的 SDK 类型导入在编译时消除，分发产物不导入宿主源码。

## 使用

将完整浏览器包导入插件市场并在当前浏览器启用。安装清单入口为 `dist/index.js`；源码需要先由交付方构建成浏览器 JavaScript，不能直接上传 TypeScript 源码代替产物。包内应包含 `package.json`、`plugin.json`、`market.json`、本说明及 `dist`。本工程的隔离样式与 bundle 由集成方提供，包内不维护第二套构建脚本，也不自动安装或替换任何用户服务。

启用后首次仅显示 48 像素悬浮球，不登记调试桥、不打开会话、不采集结构。点击打开后连接当前浏览器实例并读取目标目录。选择插件时同时明确浏览器实例、插件 ID 和代次；服务器目标独立列出。市场“调试”动作会带入单组件或整套候选，多候选必须明确选择组件，不任意挑选。

收起隐藏面板并暂停面板自身的周期状态读取，保留调试会话；标题关闭会结束本面板拥有的会话，不停止业务插件或原任务。悬浮球保留以便再次打开。卸载时撤销事件订阅、定时器、React 根和样式，取消本插件等待，并尝试有界关闭已知会话；宿主撤销调用权限时的最终会话收敛由宿主生命周期与空闲期限负责。

## 专用界面

- 调试目标：浏览器与服务器目录、当前实例默认筛选、市场候选组件选择、身份代次、实际能力、历史清理告警和公开检查详情。
- UI 树：明确选择挂载根，稳定快照分页，按名称、角色、隐藏与禁用证据过滤，树的键盘上下移动和展开折叠，节点引用、所属表面、动作约束和布局证据。查询结果可补入第一页以外的节点详情。
- 节点动作：临时高亮、公开拾取，以及点击、填值、选择和滚动。交互每次需要确认本次动作与未知副作用，输入变更或节点变更后撤销确认；不会自动试点或重放。拾取到其他插件只展示归属，不切换目标；宿主普通节点只展示标签、名称、角色及真实最近公开槽位等只读身份，清空插件节点动作选择，不把普通节点当作插入槽位。
- 快照与断言：同一挂载根最近十个逻辑快照可显式比较，断言使用 JSON 输入，显示通过、失败或无法判定；未知可见性不当作通过。
- 公开目录：单独展示槽位、路由和挂载贡献。普通 DOM、面板和目录条目不自动成为插入槽位；未实例化路由不伪造 DOM 树。导航需明确确认并由宿主目录白名单裁定。
- 试调用：根据当前 catalog 的输入模式生成表单，复杂模式与缺失模式提供 JSON 输入；浏览器命令/服务和服务器操作/服务均保留原准入。浏览器默认仅结果元数据，显式勾选才读取脱敏正文；服务器始终沿原任务查询实际结果。
- 事件与日志：生命周期事件按游标分页、级别与关键词筛选、包含旧代开关及显式跟随；公共服务器日志支持 ID 或关键词搜索，保留 `limited`。可复制真实日志 ID，任务 ID 不替代日志 ID。前端最多缓存最近 500 条事件。
- 报告与重载：本地 JSON / Markdown 下载，宿主报告按 `export: none/json/markdown` 请求，产物由公开产物接口下载。报告的实际快照页从 `report.evidence` 读取，未加载页通过 `ui_tree` 绑定原 `snapshot_id` 继续读取，并入本地报告。重载只针对明确选择和确认的插件，回执后再核对真实目录中的新代次，不自动跟随或重复重载。

断线保留最后快照与事件，显式标记“已过期 / 只读”，节点动作停止。可独立打开最后快照、返回摘要、查看历史和选择其他目标。重连会创建新浏览器实例，不重放旧命令；旧快照保持过期，直到明确选择目标并取得新的观测。

## 窗口与键盘

桌面 1424×805 时面板初始位置为 `(368,88)`，尺寸 `1032×640`；940×760 时为 `(16,64)`、`908×624`。白卡、12 像素圆角、发丝线 `#E6EAF3`、主色 `#6C4CF5`、主要间距 16 像素，普通文字使用无衬线，标识与读数使用等宽。

标题空白可拖动；面板移动结束时，任一边距视口对应边缘不超过 24 像素，即吸附到保留 16 像素留白的位置，角落可同时吸附两边。窄窗先夹取到可用范围，极小视口沿用现有自适应留白；初始 R2 尺寸不变，缩放结束不触发吸附。悬浮球拖动结束吸附最近左右边缘，拖动不会顺带打开。右下角 28×28 抓手调整尺寸；底栏“键盘调尺寸”进入调整模式，方向键每次 8 像素，Shift 每次 32 像素，Enter 应用，Esc 撤销并返回尺寸入口。普通查看时 Esc 收起并返回悬浮球；拾取中 Esc 优先取消拾取。悬浮球也可用 Alt+方向键移动。视口变化时夹取位置与尺寸。

界面按已授权 R2 七态的文字规格落地。940 窄窗保留树与详情双列；700 像素以下为防溢出的单列降级，这是实现补充，尚无对应独立设计稿。试调用、目录、报告和尺寸调整中状态也未在 R2 七张静态稿中逐一呈现。没有以源码检查或单元测试代替实际图片审核、浏览器交互或完整无障碍验收。

## 公开合同与限制

所有调试业务经 `context.extensions.callService('host.debugger','1',request,signal)`，无业务 HTTP `fetch`。浏览器命令成功回执读取 `response`，失败读取 `response.error`，原错误信息、错误代码与日志 ID 保留。取消和期限只停止等待，不能证明可信插件副作用已经停止；未知结果不自动重试，也不永久禁用独立新操作。

服务动作为 `capabilities/status/start/reconnect/call/logs/installation`，市场通过 `host.debugger.target_requested` 事件带入候选。普通请求总等待 15 秒；重载使用独立 50 秒默认预算，可消费宿主 `reload_timeout_ms`，至少 45 秒且最多 120 秒。后端、桥和原插件各自更短的真实期限仍可能先结束，面板如实显示未确认结果。

UI 树只反映公开可观察 DOM，不能读取任意框架私有状态、运行脚本或设置源码断点。像素遮挡、虚拟内容和布局完整性不足时保留未知。旧独立包摘要可能缺失，界面显示未知，不由版本号推断代码已经更新。报告不等于真实设备、整套部署或生产验收；自由文本脱敏范围仍以宿主公开说明为准。
