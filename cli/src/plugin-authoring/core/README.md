# 共享插件清单规则

CLI 与浏览器使用同一份纯规则，统一 `manifest.json`、市场字段、发布与依赖约束。此包无文件系统、网络、构建脚本或插件执行能力；文件读取和归档分别由调用端处理。

配置声明会提前检查版本、对象模式、对象默认值、生效策略及必填字段名的形状。开发清单省略apply_policy时生成next_invocation，显式plugin_reload原样保留。初始默认配置允许缺少使用者必填输入，不编造地址或凭据；完整模式和已提供值的校验由宿主执行，保存及运行仍要求完整配置。旧完整离线包按原字节安装，宿主读取缺省策略时使用相同默认值，不改摘要。

前端通过声明的本地包依赖消费公开入口，不跨工程导入宿主源码。CLI 发行时连同本目录分发；目前这是工程内共享包，不代表已经发布到 npm registry。
