# 插件开发清单与生成工具

本模块面向独立插件工程，只读取一份 `manifest.json` 和显式构建产物，不执行构建脚本、不启动服务、不操作设备。旧安装协议继续使用生成后的便携包与完整发布格式，不修改现有安装器。

- `manifest.mjs` 校验并归一化开发清单、身份继承、运行字段及统一依赖。
- `market.mjs` 校验市场字段，从功能和组件生成完整展示资料。
- `components.mjs` 收集显式产物、生成便携清单与浏览器身份入口。
- `pack.mjs` 编排新目录暂存、依赖、组件 TGZ、真实摘要与完整离线发布。
- `commands.mjs` 解析开发命令，装配打包、只读计划与显式发布。

归档、资源验证与发布复用随 CLI 一同交付的公共发布工具；根 npm 包显式包含这些模块及其 semver 依赖，不要求开发者获取宿主源码。市场资源摘要仅在在线清单生成后进入 catalog，不能写回自身归档。已存在输出不覆盖，取消/失败只清理本次独占暂存；源工程保持原样。

直接验证使用 `node --test cli/tests/plugin-authoring.test.mjs`。此命令只供本仓库维护者使用，对外流程及字段分别由 MCP 的 manifest、packaging 和 examples 主题提供。
