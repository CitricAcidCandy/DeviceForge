# Svelte 前端开发要求

## 范围与落点
- 当前项目为 `G:\Rust\DeviceForge\frontend`，采用 Svelte 5 + TypeScript 严格模式。旧 renderer 仅作取证，不复制 Electron、preload 或本机全局状态。
- 本阶段只交付最佳实践骨架、生成 API 类型与公开插件契约，不实施完整业务页面。
- 前端文档只放 `docs/`。注释、README 和文档使用中文与 UTF-8。开发前阅读架构与开发约束及插件开发文档。

## 依赖与文件职责
- `src/app`：启动、路由、全局样式与装配，不堆积业务规则、HTTP 调用或插件逻辑。
- `src/features/<功能>`：该功能的组件、状态和用例，只依赖本功能、shared 与 SDK，禁止引用其他功能内部实现。
- `src/shared/api`：生成类型、HTTP 适配器、统一错误与取消；组件不直接 fetch，令牌不进入 URL 或 localStorage。
- `src/shared/ui`：纯展示与可访问性组件，不引用 API、features、app 或宿主插件逻辑。
- `src/plugin-sdk`：独立版本化公开契约，不依赖 app/features/shared/plugins，不暴露服务令牌或私有类型。
- `src/plugins`：贡献校验及后续加载/卸载编排，只通过 SDK 与宿主交互，不导入功能实现。
- 禁止反向依赖、循环导入和跨工程源码路径。新增模块附中文 README，复杂规则拆为可测试纯函数。

## 基础工作台与设备扩展
- 开发设备相关界面前阅读 `docs/设备能力与插件面板.md`。通用工作台消费宿主设备目录和能力，平台特有交互通过公开插件面板扩展。
- 设备使用公开宿主引用定位提供者；平台名称只用于展示和筛选，按能力版本、可用状态和权限决定入口，不增加按平台硬编码的连接/命令分支。
- 设备提供者和浏览器面板可独立存在；面板只通过公开 HostContext 调用，不读取宿主私有状态、工具路径或服务令牌。设备上下文尚未实现前，不用手写 DTO 或私有导入绕过公开契约。
- 提供者停止、断线、移除和插件面板失败须收敛入口与订阅；切换设备后晚到结果不得覆盖当前视图。热装卸、完整设备 UI 和真实运行仍需单独验收。

## 类型与行为
- 保持 strict、noUncheckedIndexedAccess、exactOptionalPropertyTypes，不得以 any、类型断言或关闭检查绕过接口边界。
- HTTP 类型由 generate:api 生成，禁止手改 generated.ts 或手写重复 DTO；公开 SDK 独立版本化，由适配器映射。
- 异步调用显式传 AbortSignal，处理失败、取消、销毁和晚到结果；插件卸载释放事件、订阅和 DOM。
- 日志 ID 由 shared/api 按公开响应契约提取并传递，失败界面应支持复制排查；任务 ID 不代替日志 ID。日志响应升级需同步生成类型、适配器和公开 SDK，不把协议包装或服务器日志路径混入组件。
- 日志消费遵守 `docs/日志ID与接口消费.md`：默认 v2，v1 从响应头兼容，产物原字节与 OpenAPI 不按业务 JSON 拆包。当前只有生成类型，客户端和复制交互仍需实施。
- 同页面插件视为可信扩展；动态加载、来源信任与隔离机制未实施前，不宣称已支持浏览器插件安装/运行。
- 服务器插件管理遵守 `docs/服务器插件生命周期消费.md`：只使用生成类型与公开 ID，区分服务器插件、设备提供者和浏览器面板；取消等待后重新查询状态，不假定管理变更回滚。
- 采用语义 HTML、键盘操作和可访问标签；新增业务交互补浏览器验收，构建通过不代表视觉或真机验收通过。

## 必须执行的门禁
在前端目录执行并确认退出码：
1. `npm run generate:api`
2. `npm run check`（包含架构、Svelte 与 TypeScript 检查）
3. `npm test`（包含架构拒绝用例、插件契约及外壳测试）
4. `npm run build`

新增可见交互补行为测试；静态架构检查不能代替运行时插件信任或资源清理。

## 协作与交付
- 不自动提交、恢复或删除用户无关修改，不向旧工程写新实现；大型写入分批进行。
- 修改后更新新项目根目录 `../todo.md`，记录实际检查与未验证范围，终端摘要使用中文。
- 前端仍是骨架时明确范围，不能以占位页面或契约存在证明完整功能完成。
