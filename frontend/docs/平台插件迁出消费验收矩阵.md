# 平台插件迁出的前端消费验收矩阵

## 状态与依据

本文件为 FE-PLATFORM-MATRIX 独立文档设计，冻结的是消费验收方案，不是新增公开契约或平台迁出完成结论。本轮仅新增本文，不修改生产源码、生成 DTO、已有文档或冻结脚本，不运行 Node、npm、Cargo、生成器、服务和浏览器。具体产品 UI 等待设计稿，main.ts 仍未装配产品 runtime。

职责沿用 [平台适配器迁出边界](平台适配器迁出边界.md)、[旧操作绑定迁出接入](旧操作绑定迁出接入.md) 和 [前端运行架构](前端运行架构.md)，本文只补验收场景及证据分层，不重写既有设计。冻结语义优先核对后端 [操作绑定第一批契约](../../backend/docs/操作绑定第一批契约.md)、[统一发现第二批契约](../../backend/docs/统一发现第二批契约.md) 与 [普通操作总期限消费契约](普通操作总期限消费契约.md)。旧文档中的候选、延期和历史门禁描述保留其批次含义，不作为本轮现状或通过证据。

当前只读核对确认：前端已有操作目录失效、通用任务、完整设备引用、原始状态映射、目录修订和作用域取消；backend/crates/server/src/main.rs 仍可见 DeviceTools、具体 Android 执行器及性能 probe 装配。因此公共工具库和通用浏览器插件通过，不能单独证明宿主平台装配已撤除。后续实施及当前分发结论由主代理按实际输入版本记录。

## 可沿用的公开链路

| 消费入口与源码落点 | 可沿用行为 | 验收时不能扩大解释的范围 |
| --- | --- | --- |
| HostContext.listOperations/subscribeOperations；src/features/operations/index.ts、state.ts | 当前目录查询、快照刷新、订阅和本地失效；撤销时发布空列表，旧等待不能复活目录 | 公共 Operation 没有 owner/generation/alias 或服务器注册修订字段；不从名称推断来源，不增加猜测字段 |
| HostContext.submit/getJob/cancelJob；src/features/tasks/index.ts、app/public-api.ts | 提交一次 operation/input、查询实际终态、显式取消；既有 beforeTaskSubmit 钩子继续适用 | runtime.tasks 另有 list/events/select，SDK 当前未公开这些方法；不由此增加轮询、事件重连或进度协议 |
| 可选 HostContext.devices；src/plugin-sdk/devices.ts、features/devices/index.ts、state.ts | refreshProviders/refreshDirectories 查询，refreshProvider 发现，invoke 返回 Job，select/snapshot/subscribe 管理当前观测 | 没有 devices 的旧 HostContext 仍兼容；扩展存在不表示已有平台包、可用设备或常驻连接 |
| src/app/device-gateway.ts、public-api.ts 与 shared/api | 生成 HTTP 类型到独立 SDK 的显式映射、受控包装及真实日志 ID | 不新增浏览器 shell、工具路径、服务器文件路径、绑定管理或客户端预算覆盖接口 |
| runtime.serverPlugins/pluginPackages/artifacts；src/app/catalog-refresh.ts、runtime.ts | app 负责包部署、启停、产物及本实例管理后的目录撤销与重查 | 这些 app 入口不是浏览器插件 SDK 的管理或产物权限；平台面板不能私有导入它们 |
| src/plugins/device-access.ts 及既有运行/挂载作用域 | 合并调用者、宿主、插件实例、挂载子信号，撤销订阅和登记资源 | 退出面板不等于卸载服务器提供者；取消等待不证明可信回调副作用或服务器外部资源停止 |

平台名称只用于说明和筛选。设备动作依据完整 providerId/generation/localId、精确能力 ID/版本、作用域、归一化状态与可用性；普通包工具依据当前操作及 input_schema。提供者 generation 是不可解析身份，不比较大小；本地请求或目录修订是内部保护，不是新增 HTTP/SDK 字段。

## 平台候选与证据分层

| 候选 | 按已声明贡献安排的消费范围 | 必须独立补齐的证据 |
| --- | --- | --- |
| Android 设备插件 | 发现、应用、输入、安装、截图、分包等只核对实际冻结清单；特殊模式按 rawState 原文消费 | 实际平台包接入、旧绑定兼容、产物与期限/取消；真机系统版本、连接方式和模式逐项记录，不能由模拟提供者替代 |
| Android 包工具插件 | 通用 operations/tasks 与产物链路；不要求伪造设备引用或借设备锁 | 实际包处理贡献、旧结果兼容及非设备长任务期限；有限 default 或预算读取不证明真实长执行、签名和构建正确 |
| Harmony 设备插件 | 仅核对实际声明的发现、包列表、HAP 安装/卸载等能力 | 不因 platform 为 harmony 推断 Android 输入、性能或完整应用管理；HDC 模拟和真实 Harmony 设备分别验收 |
| iOS 候选 | 当前通用目录与能力模型可容纳新的提供者；仅在具体清单和契约冻结后列可执行用例 | 本矩阵不定义 iOS 操作名、能力、工具、结果 DTO 或旧别名，不计入已支持/真机通过 |

证据分为四层：受控传输/SDK 行为回归，真实生产浏览器与模拟提供者，实际平台插件与模拟工具，真实平台设备。前两层可证明消费和生命周期，第三层可证明平台包与工具适配路径，均不能代替第四层的设备效果、断线或事务清理。平台名称、清单声明、进程启动或 mock 成功各自不能跨层升级结论。

## 消费验收矩阵

以下为待执行判据，编号不表示已经通过。每项记录实际贡献清单与用例身份，目标插件撤销不要求无关插件的目录也为空。

| 编号 / 触发 | 前端必须观察的行为 | 最小证据与额外边界 |
| --- | --- | --- |
| FPM-01 平台包未加载或空宿主部署 | 成功空目录与未查询、错误、本地撤销区分；目标能力/旧绑定未发布，不从历史或内置默认值补入口。现有 browser 插件可加载、登记贡献；依赖不存在的调用正确失败 | 真实生产 host 导入、目录响应与日志、插件生命周期。无平台工具仍可启动及无内置回退另由后端/部署验收，不能只看前端空数组 |
| FPM-02 在线上传但未启用 | 上传仅部署；查询确认目标尚未运行，浏览器不将上传成功当作提供者/操作已加载，不自动开始发现 | app 的实际 upload/refresh/enable 调用及包摘要；SDK 不直接获得这些管理方法 |
| FPM-03 加载成功或加载失败 | 成功后按查询到的完整 ID/schema/能力版本消费；旧绑定仅在显式配置及目标存在时出现。坏声明或绑定导致加载失败，不发布半份贡献 | 真实目录、提供者及管理结果；原子注册由后端核对，不凭两次浏览器 GET 证明原子性，不按加载顺序选目标 |
| FPM-04 查询与发现分开 | refreshProviders/refreshDirectories 只读取已有观测；refreshProvider 才触发发现。直接 discover 或发现别名经任务入口只提交严格空业务对象，不用 GET 代替自己的发现结果 | SDK 到真实 HTTP/Job 的身份关联；三入口单 Job/单执行和坏输入零副作用属于统一发现集成证据 |
| FPM-05 同名设备及能力准入 | 两 provider 的同名 localId 保留完整引用；缺能力、版本不符、错误作用域及不可用不放行，设备范围还要求 online。提供者范围使用 deviceId=null，不因没有设备伪造引用。失败不切换提供者或回退旧入口补做 | 确定性 SDK 回归加真实生产浏览器；本地拒绝日志为 null，精确服务器准入、锁和歧义拒绝由后端另验 |
| FPM-06 原始状态与整份替换 | API3 rawState 原样保留，不 trim 或按特殊模式放行动作；API1/2 缺省/null、API3 None 在 SDK 省略。新观测 None 清除旧原文，未知原文不改归一化 state | raw/API3 既有校验和替换回归可复用；真实包验证 recovery/sideload/bootloader 等原文来源，真机模式需独立记录。限制沿 RAW-02，不自造状态枚举 |
| FPM-07 预算声明或目录预算变化 | 设备 executionTimeoutMs 与普通 Operation.execution 分开读取；缺省/null 不在 SDK 猜默认值。普通有效预算和 source 由服务器明确发布，旧别名不按名称推导目标预算 | 复用 device-budget/operation-execution 回归和公开适配；submit/action/input 不增加预算控制语义。预算元数据读取不证明执行超过旧窗口 |
| FPM-08 本实例停止、卸载或管理失败/取消 | 管理收敛回调先整体失效 operations，再撤销目标提供者缓存、选择及相关等待并重查。draining/cleanup_failed 按 app 实际状态消费，不清除标记、自动重装或声称资源释放 | catalog-refresh、SDK 空列表通知及真实管理日志；当前没有管理 HTTP 等待开始即撤销的承诺。取消等待不假定管理变更回滚 |
| FPM-09 撤销后的重查失败、取消及恢复 | 操作快照保持已撤销空目录和实际错误，目标旧设备/选择不复活；后续成功查询可恢复新观测，不自动恢复旧选择。撤销前旧 list/refresh 晚到仍拒绝 | operation-migration、devices 既有行为回归可复用；普通显式操作刷新可保留尚未失效的旧观测，不能与管理撤销后的失败规则混写 |
| FPM-10 其他实例撤销后显式刷新 | 未收到推送的实例不假装实时同步；refreshProviders/refreshDirectories 更新观测并撤销失效引用。未重查的缓存不能保证提交资格，服务器仍可拒绝 | 真实双实例或受控远端变更、显式查询与旧引用 HTTP 错误日志；SDK 本地缓存拒绝和服务器最终拒绝分别记录 |
| FPM-11 同 ID 提供者换代 | 新 generation 保留为新身份，撤销旧目录/选择/等待；旧 DeviceRef 不因同名设备、新包版本或新能力出现而复活。旧绑定排队任务不自动切换到新执行器 | 精确代次、旧/新引用、真实旧引用拒绝及新代显式发现；服务器排空、代际准入和旧任务执行来源另验 |
| FPM-12 同代修订与 A/B 晚到 | A 请求后本地已消费 B 或被替代，A 不覆盖 B；旧聚合 GET 不复活被撤销目录，A 的失败/finally 不清掉 B。不以 observedAt、数组顺序或平台推导优先级 | 受控门闩回归证明请求身份/本地修订保护；真实浏览器记录各自 discoveryJobId。修订不新增为公开 DTO 字段 |
| FPM-13 自己回执、取消与历史成功 | refresh 只消费自己的 Accepted 结果；B 的 GET 不冒充 A。作用域或修订已变则 A 沿现有 stale/cancelled 结束。Job Succeeded 可与目录拒绝并存，历史不改写；本地先清目录与服务端排队不清目录分别解释 | 真实服务决定点/受控门闩加浏览器结果；接受先赢后取消等待不回滚目录，取消先赢不发布。浏览器 abort 时间不能独自证明服务端先后 |
| FPM-14 普通/旧操作单次提交 | 从当前目录按实际 schema 提交原 operation/input；钩子顺序和失败停止沿既有规则。失败不自动再调 devices.invoke、换来源或补交包装任务 | 实际 POST/Job 数与 input、hook 行为；旧名称/结果转换、同任务 owner/锁/取消/期限由绑定层集成验证，不在浏览器重实现 |
| FPM-15 产物及结果包装 | SDK action.input 传已有 artifact_id；app 承担产物上传下载。普通协议2/3严格区分 Job 与 result/artifacts 业务包装，旧绑定按实际投影保留，不能统一拆平所有结果 | 真实发布/下载摘要及同次 Job/产物关联；引用规则沿 [设备产物说明](插件开发.md#设备动作的嵌套输入产物)。不向设备动作提供服务器路径 |
| FPM-16 卸载、重载或重启后的历史读取 | 已接受任务继续按 ID 查询实际状态，历史 operation/input/result 不按新目录、别名目标或预算补写。历史成功观测不重建当前目录/选择；查询旧 Job 不要求旧 operation 仍在目录 | SDK getJob 与 app tasks.list/events 的适用调用分别记录；真实持久化、重启和终态恢复由后端另验，不承诺事件推送、自动续跑或回执持久化 |
| FPM-17 浏览器实例/模块退出及请求取消 | 模块退出撤销其子请求、订阅与 DOM，保留插件其他贡献；实例卸载撤销其全部登记入口。旧 HostContext 与晚到结果不得回写，新代也不复活旧引用。HTTP Abort、cancelJob 和提供者卸载各按真实结果消费 | 公开运行/挂载入口、真实 DOM 与取消证据；默认不因消费者退出取消已接受 Job 或停止服务器会话，不宣称未登记副作用已被强制中断 |
| FPM-18 结构化错误与日志 | 保留实际 HTTP status/code/logId 和 Job.error；未知版本/非法目录为 protocol 错误，不变空成功、不重放写请求。本地撤销/准入拒绝不构造服务器 logId | 有效响应内的协议错误保留响应日志；网络失败没有响应时保持无日志。具体错误按已冻结契约核对，不以任意4xx或错误字符串猜平台类别 |

FPM-06/12/13 的详细原始状态、回执和发布竞争规则分别链接 [设备原始状态接入方案](设备原始状态接入方案.md) 与 [统一发现发布回执消费边界](统一发现发布回执消费边界.md)。消费文档保留的未决历史以 RAW-02 裁定为准；本矩阵不重新开放已冻结选择，也不新增回执类型。
