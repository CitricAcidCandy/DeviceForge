## 背景配色建议与采用方案

现有图片包含暖米色墙面、浅木色桌面与鼠尾草绿色植物/柜体。原黑色表面会与暖色环境形成过强反差，建议采用浅奶油底、暖纸表面与深橄榄文本。主代理已选择以下方案：

| 用途 | 色值 |
| --- | --- |
| 页面底色 | `#e6dcc7` |
| 卡片与浮层暖纸色 | `#f8f4e7` |
| 正文深橄榄 | `#2e372b` |
| 次要文本 | `#5c634d` |
| 主操作/焦点鼠尾草绿 | `#606d43` |
| 输入描边 | `#83896f` |
| 分隔/描边 | `#c9c6ae` |

背景应仍能在顶部和边缘被识别；内容表面应有足够不透明度，避免文字叠在照片细节上降低可读性。设备页局部布局与全局当前设备摘要由不同文件承担，避免重复右侧摘要。

主代理计算了指定令牌组合的对比度：次字/页底 4.61、次字/卡片 5.70、主色/白字 5.48、输入描边/卡片 3.31、正文/卡片 11.24。以上只覆盖这些颜色组合，不代表全页面或所有状态已满足 AA。
