## 范围与分工

本轮仅重排性能采样工作区及画面、指标、调用栈的选择展示，使用页面私有组件和Tailwind工具类。前端开发实际写集仅 `src/pages/performance/components/SampleBoard/`，页面入口与Props不变，持续采样、归档和Root三处原调用直接复用；测试代理拥有 `tests/performance-board.test.ts`；交付审核代理只读检查契约与实现；主代理集成设计源文件、记录与审核结果。没有后端实现变更，未修改投屏插件、生成接口或用户服务。

主布局去除三图外共同白框，三个指标各有完整边框、圆角和16px背景间隔。顶部恢复采样画面带；全部内容共用时间比例、滚动画布与当前采样索引。真实归档保持原采样点画面归属；持续采样保持现有服务器时间近邻关联和偏差说明，不宣称设备物理精确同步。缺帧不复制别的画面补位，缺测指标不补零。

生产实现与本轮定向单元验证已完成。测试范围限定为 `tests/performance-board.test.ts`，覆盖画面选择与三图／调用栈联动、时间坐标、密集帧原索引、键盘选择、指标单位与缺测、空态。首轮 `node --test tests/performance-board.test.ts` 共17项，16通过、1失败；唯一失败为测试从整页提取刻度混入顶部画面编号／时间，已将断言限定到各指标轴。

修正该断言并补两项窄窗口测试后，执行：

```powershell
node --test --test-name-pattern='时间轴刻度按跨度|点击画面或三张曲线|各指标时间轴键盘|窄窗口只在|选点变化仅横移' tests/performance-board.test.ts
```

最后5项精确复验全部通过，退出0、耗时3.80秒。它覆盖原刻度失败、受影响的画面／三图回调及键盘选择、新增横向边界规则与共享容器滚动行为；组件测试确认 `scrollTop` 没有写入。首轮已通过且未受影响的指标域、低帧率告警、面积缺测分段等未重复运行。当前测试文件共19项相关用例，证据由首轮与最终定向复验组成，未将本轮说成整个文件或全项目重新运行通过。

## 差异与未验证范围

产品必须使用真实样本、画面及主题令牌，设计中的两张历史游戏截图、九个示例位置和固定指标读数均不嵌入产品。实际样本密度、窗口宽度和当前宿主侧栏状态影响可见帧数量，不能以静态示例九帧限制真实数据。

有意差异：共享画布最小宽1132px，窄窗口横向滚动，不压缩成难辨认的小图；缩略图按90px宽与12px间隔稀疏，选中真帧优先保留，指标数据不稀疏。无采样保持120px紧凑状态；无栈36px，有栈至少200px、最多同时显示六层并保留省略提示。内存底层KiB数据及域保持既有合同，轴显示换算成GB；实时关联详细说明置于看板底部并保留悬浮／读屏入口，可能比静态稿多一行。页面外壳和工具条未改，绝对y位置随实际宿主布局；当前不能宣称像素级对位已验。

用户明确限定最小必要单元测试。本轮不执行全量测试、完整检查、构建、产品浏览器／端到端验收、真机采集、FPS精度或性能测量；产品实际像素对位与真实设备数据关联仍不计为已验。没有自动提交、重启或替换用户预览服务。
