## 实现范围

- 桌面使用 184px 内部分组目录；连接、外观、工具配置和插件扩展按分类显示，面板仅隐藏不卸载，草稿、请求和插件挂载实例持续保留。
- 默认服务连接使用连续白色工作面、36px 输入和按钮；市场与 MCP 继续分章节，不使用独立圆角卡片。窄屏以分类选择器代替目录，沿用宿主小屏 44px 触达规则。
- 服务地址在调用原重连能力前校验 HTTP(S)；令牌只保留在当前内存，提供显示切换；测试、取消等待、失败原因和真实日志 ID 均可见，无日志不编造 ID。
- 市场覆盖仍由现有浏览器存储服务管理，保存／恢复不写服务器配置，也不取消连接请求。主题仍消费现有主题注册表。
- 配置读取、带修订写入、删除确认、配置区导入、旧备份导入、远端读写与本地备份状态继续使用原业务用例；服务器产物入口移动至工具配置分类。
- `settings.plugin.section` 继续作为公开插件追加挂载点，在插件扩展分类内展示，分类切换不重复挂载；卸载撤销原贡献。
- 删除设置专属旧 CSS，所有新增样式使用 Tailwind；移除旧 UI 政策豁免。外壳只给设置路由移除额外内衬并提供全高，不改变其他页面业务。

## 设计差异与未验项

- 宿主原有品牌、设备上下文、任务与状态栏维持当前真实实现；设计中的简化外壳不是本次重做范围，现有底栏 26px，稿件为 28px。
- 字体沿用项目宿主 Inter／微软雅黑等回退栈，地址使用现有等宽令牌；没有为本次页面下载或替换全局字体。
- 窄屏分类选择器和 44px 触达、其他三个分类内部为已有功能迁移，原 V6 没有其逐像素专稿；早期曾检查可用性与溢出，修后最终干净截图未复验，不记为全部视觉验收通过。
- 分类多项滚动和长名换行由布局支持，本轮不新增公开动态分类协议或伪造插件分类；插件设置继续使用既有追加槽位。
- 真实服务切换成功、跨机器局域网、实际配置写入和设备操作未由受控夹具替代，须按实际执行证据分别记录；不自动提交或公开发布。
