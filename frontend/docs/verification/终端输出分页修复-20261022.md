# 终端输出分页修复验收

日期：2026-10-22，Asia/Shanghai。

## 缺陷与修改

用户截图提示“输出游标须为非负安全整数，页长须为1至100”，由图片审核子代理确认。终端页面创建后自动读取与暂停后继续读取均传入 `limit:200`，违反既有会话1至100块约束，错误在发出输出HTTP请求前发生。现场已有运行中的终端记录，不能把输出读取失败直接解释为创建失败。

仅将两个页面调用的读取选项改为 `{}`，复用公共会话工厂默认50块；公共API、后端校验和分页上限不变。

## 验证

- 页面回归使用真实React组件、ProductServices与受控HTTP，55块输出分两页读取，游标0→50→55；覆盖暂停不发cancel、继续读取保留游标、中文输入和明确关闭。旧代码失败，修改后定点及完整测试中的此用例均通过。
- `npm run generate:api`、`npm run check`、独立输出到本轮证据目录的 `npm run build` 均退出0；生成类型无净差异，架构检查覆盖406源码。
- `npm test` 执行100文件，99通过，1失败；失败文件 `product-plugin-startup.test.ts` 中原插件页导航和默认启用两条断言失败。新增终端回归通过，未修改并行界面导航实现或放宽原断言。
- 真实Edge、当前Vite5173与Rust7031完成六项业务检查：实际Python档案创建、提示符读取、命令实际输出、暂停后继续、输出请求limit50且HTTP200、页面关闭请求成功。没有设备调用。
- 测试终端到达Finished、Cleanup Complete，删除的仅是测试记录；原用户会话保留。

## 证据与限制

证据根：`artifacts/terminal-pagination-20261022/`。生成、检查、完整测试和构建日志分别为 `generate-api.log`、`check.log`、`test.log`、`build.log`。

首次浏览器报告未保留返回的业务结果，退出事件超时使顶层失败；第二次增加独立结果回传，六项业务通过，`browser-report-retry.json` 的 `business_passed:true`、顶层 `passed:false`。浏览器驱动正常退出事件仍超时，原报告不改写为全通过；`process-observations.json` 后续独立确认两浏览器和两驱动PID均已消失，两调试端口释放。

不将本轮结果外推到PTY、长时交互、其他档案、设备、性能、npx包或公开发布。服务未重启，现有用户会话未关闭，其他会话同步进行的导航与样式改动保留。
