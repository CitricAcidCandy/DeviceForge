# 完整插件上传、指南与市场适配验收

## 范围与架构边界

本轮采用架构优先及混合验证：先按完整发布契约检查本地 ZIP，再以行为用例核对真实上传、市场目录与成套安装。旧独立组件和资源入口继续兼容，不增加市场服务器解包 ZIP 的接口，也不静默降级完整发布。

| 单元 | 输入与输出 | 负责 | 不负责 | 副作用 |
| --- | --- | --- | --- | --- |
| 市场上传入口与两类弹窗 | 文件、市场资料到操作反馈 | 流程选择、状态、取消、日志、刷新通知 | 归档解析及直接网络请求 | React 状态、通知 |
| 页面私有清单与资源模块 | 未知清单和归档到已校验资源 | 路径、字节、CRC、SHA-256 和格式边界 | 远端提交、插件执行 | 文件切片与流式读取 |
| 页面私有发布引擎 | 固定计划到发布结果 | 能力探测、资源去重、缺失上传、最后提交目录 | 设备业务、回滚承诺 | 调用市场公开客户端 |
| 市场功能传输层 | 请求及未知响应到结构化结果 | 日志 ID、错误码、重试信息、取消等待 | 请求重放及发布编排 | HTTP |
| 独立资源服务 | 资源及条目到内容寻址数据和目录 | 发布闭包、真实摘要、永久版本身份 | ZIP 解包及运行插件 | 文件、SQLite |
| 宿主 MCP 指南 | 三目标、七主题到嵌入文档 | 只读知识发现、版本和来源 | 创建任务、读取部署机器源码 | 无业务副作用 |

## 身份与并行边界

本轮宿主和市场分别冻结到 `frozen-02/backend`、`frozen-02/market`，摘要见同级 `identities.json`。宿主来自本轮 Cargo 为集成测试重建的普通程序，不把历史发布候选替代本轮输入；后续完整构建还须核对该宿主身份。

用户已确认保留并行工作区修改。期间设备公开门面迁移曾造成一次构建时缺导出，失败日志保留；没有回退或代改该生产模块，待其公开导出齐全后重新构建，受检输入摘要无漂移。完整 workspace、独立服务功能门禁与网页发布证据按实际版本分别记录，不借旧候选的全绿结果。

## 不包含的验收

本轮不是十八个官方插件设备业务、真实手机、第二台物理客户端、跨平台、正式 npm 发布或性能专项。4 GiB 归档及 2 GiB 单资源是契约上限，不表示本轮已用极限大小实测；浏览器压缩流、资源上传和市场完整校验的容量及耗时仍需独立测量。既有工具再分发许可阻断保持，不替换用户 7031/5173 预览，也不操作设备。
