# 完整插件上传、指南与市场适配验收

## 范围与架构边界

本轮采用架构优先及混合验证：先按完整发布契约检查本地 ZIP，再以行为用例核对真实上传、市场目录与成套安装。旧独立组件和资源入口继续兼容，不增加市场服务器解包 ZIP 的接口，也不静默降级完整发布。

| 单元 | 输入与输出 | 负责 | 不负责 | 副作用 |
| --- | --- | --- | --- | --- |
| 市场上传入口与两类弹窗 | 文件、市场资料到操作反馈 | 流程选择、状态、取消、日志、刷新通知 | 归档解析及直接网络请求 | React 状态、通知 |
| 页面私有清单与资源模块 | 未知清单和归档到已校验资源 | 路径、字节、CRC、SHA-256 和格式边界 | 远端提交、插件执行 | 文件切片与流式读取 |
| 页面私有发布引擎 | 固定计划到发布结果 | 能力探测、资源去重、缺失上传、最后提交目录 | 设备业务、回滚承诺 | 调用市场公开客户端 |
| 市场功能传输层 | 请求及未知响应到结构化结果 | 日志 ID、错误码、重试信息、取消等待 | 请求重放及发布编排 | HTTP |
| 独立资源服务 | 资源及条目到内容寻址数据和目录 | 发布闭包、真实摘要、永久版本身份 | ZIP 解包及运行插件 | 文件、SQLite |
| 宿主 MCP 指南 | 三目标、七主题到嵌入文档 | 只读知识发现、版本和来源 | 创建任务、读取部署机器源码 | 无业务副作用 |
