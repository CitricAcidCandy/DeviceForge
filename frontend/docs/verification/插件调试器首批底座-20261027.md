## 已落地

- 后端有界实例、精确目标、会话、事件环与命令状态机；HTTP 与 MCP 共用实例，不另开端口或常驻进程。
- 真正回环连接与来源校验，未知连接拒绝；原局域网业务规则保留。
- 每实例四项在途、三十二项排队，一次领取、不自动重放；五秒读、十秒动作，两秒长轮询与有限 TTL。
- `host.debugger@1`、可选 `context.debug`、子作用域登记和释放；面板与组件根携带插件身份与代次。
- 选定插件的 DOM／可访问结构、最近快照、查询、三态断言、差异、受约束动作及有界 JSON 报告。
- `developer.tools` 只追加，宿主锚点独立于业务路由；通过原组件贡献挂载，不是另一套插件体系。
- 服务器检查复用真实插件与服务目录；显式服务试调用继续返回原 Job 引用，不复制任意输入输出到调试事件。
- 公开 Rust 契约已由主代理生成 TypeScript 类型，两端现有验证主题补入无宿主源码的调试知识。
