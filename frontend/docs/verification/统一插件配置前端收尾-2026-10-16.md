## 实现修正

- schema 保护沿本地 `$ref`、`allOf`、`anyOf`、`oneOf`、条件分支、数组和字典遍历，遮蔽值与根对象默认值；删除父对象、数组项或只读空值也不能绕过高级 JSON 只读检查。
- 浏览器配置记录保留历史敏感 JSON Pointer。升级移除敏感注解后继续遮蔽已有值，原占位保存保留真实值；记录不保存敏感值副本。
- 浏览器清理失败后，当前运行实例禁止重新启用、重载及删除；不会通过重复操作跳过失败清理。
- App 测试残留的宽泛路由选择器改为工作区直属页面，保留实际设备上下文、草稿与焦点断言；按钮名称和窄屏导航数量跟随当前公开契约。
- 设备工具示例增加配置真实消费回归。在线主题夹具声明强调色、边框和配色配置，并在激活时消费；真实主题 harness 增加保存、重载、保留选择及恢复默认场景。
