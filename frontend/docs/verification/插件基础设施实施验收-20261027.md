## 先红后绿和夹具纠正

- 新增公开服务经公开命令再转调的回归，原实现丢失调用链并递归重开根调用。修复后命令传播父调用路径、取消和绝对截止，递归明确拒绝；失败原件保留。
- 真实组合夹具必须先声明模块对应的具名页面槽位。仅指定 DOM 目标不能绕过公开槽位准入，现改为按 `pageSlotId` 定义目录及独立页面槽位。
- 浏览器业务结果必须在进程退出检查前保存。若浏览器被强制结束，即使业务断言通过，整轮仍失败；不把业务、网络、视觉和回收合并成单个“通过”。

## 验收入口和边界

- 基础门禁：`npm run generate:api`、`npm run check`、`npm test`、`npm run build`。Vite 测试独占串行，普通文件有界并发，不与真实浏览器代理同时运行。
- 公开 SDK 两插件组合：`scripts/service-composition-browser-smoke.mjs`，通过 HTTP 实际上传独立 TGZ，并在生产宿主 ESM 中检查共享 React 实例、路由、界面和服务依赖恢复。
- 既有兼容入口：`scripts/browser-plugin-smoke.mjs`；最终 debug/release 与冻结 npm 包另列独立结果。
- 没有用裸 DOM 元数据、单元测试或旧包代替生产 App 验收；本轮没有新设计稿或视觉最终通过结论。
