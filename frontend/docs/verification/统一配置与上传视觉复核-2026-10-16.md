# 统一配置与上传视觉复核（2026-10-16）

本次复核使用 Codex 内置浏览器，在独立 Vite `127.0.0.1:5198` 上完成；服务器配置接口使用隔离合成 API `127.0.0.1:7098`，资源上传、下载和目录查询使用独立 Release 资源服务 `127.0.0.1:7099`。合成 API 只提供视觉状态和错误分支，不代表真实宿主插件运行证据。

## 复核结论

- 配置弹窗能够展示中文标签、说明、必填字段、枚举、布尔开关、只读协议字段、密码遮蔽、嵌套对象、数组添加/删除和键值映射添加/删除；390 像素下对话框没有横向溢出，复选框为 `44×44`，没有旧的窄屏拉伸问题。
- 插件页和市场“已安装”页都提供“配置”入口；市场元数据请求失败时，旁置服务器插件仍显示并可配置。无 schema 的 `dex-analysis` 明确显示“此插件无需配置”。
- 保存后界面显示“配置已保存，重载插件后生效”并提供“应用已保存配置”；活动任务阻止重载时显示“存在活动任务，无法重载插件”，原值未被静默清空。
- 上传弹窗保持三步：选择资源、填写描述、确认发布。类型和可见性先选，ZIP/TGZ/文件夹有独立入口，确认页显示摘要、文件树、兼容性、权限、重启要求和排除项。
- 真实 Worker 保留中文多层相对路径、排除 `.git`，读取 `market.json` 自动填表；修改描述会回写待发布归档。TGZ 确认页保持 npm `package/` 根目录，单文件 JPEG 发布后从资源服务回读并与原字节一致。
- 浅色与暗色下对话框、卡片和操作按钮均保持足够对比度；上传确认页在窄屏采用内部滚动，不扩大页面宽度。
