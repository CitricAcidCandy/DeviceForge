# DeviceForge 产品页面视觉规格

日期：2026-10-14，Asia/Shanghai。状态：供实施的视觉与交互规格；本文件没有产品页面、浏览器、真实设备或无障碍验收成绩。

## 1. 设计真值与本轮图审

用户已选择 [街角首页 c](site-study-v2-c.png) 的暖阳、生活空间与印刷风格，并接受 [电子设备背景 v4](refinement-v3/workshop-background-devices-v4.png) 作为工坊背景。本轮沿用该 PNG，不重新生成、改模型或以旧维修工具背景替换。页面上的文字、数据、状态、按钮和预览必须由真实组件渲染。

视觉审核角色本轮直接查看了上述两图和 [内页历史初稿](refinement-v3/workshop-ui-v1.png)，并阅读 [v4 审核](refinement-v3/visual-audit-v4.md)。三图用途不同：首页 c 控制空间、暖光与印刷性格；v4 是实际底图；内页 v1 只保留顶部工具和底边设备的组织意图，不复用其巨大米白圆角框、固定左右大区、重复连接状态和维修符号。

v4 可辨认完整手机、平板、掌机、笔记本、开发板、扩展坞、显示器与迷你主机，电子设备陈列方向成立。手机背面的苹果形商标仍在；原约 x20%–80%、y45%–93% 静区穿过显示器底座、后桌沿、柜门和前桌下沿。中央约 y59%–90% 更安静。背景不能被记录成无商标或全静区通过。

处理方式是让场景退到上缘和两侧，让真实工作平面遮住正文下方的物件、商标与横线。正文读写层采用接近不透明的暖纸底色，不依赖模糊或低透明度玻璃来改善可读性。每个验收视口单独确认手机标志没有从工作平面边界漏出；若漏出，调整底图定位和平面覆盖范围，不重绘设备、不复刻商标。原素材存在商标的事实继续保留。

## 2. 全产品构图

### 2.1 四个固定职责

| 区域 | 职责 | 表现 |
| --- | --- | --- |
| 上缘品牌与全局操作 | 回到入口、服务器状态、专注、更多 | 小型 FORGE 与中文设备工坊；右边短状态和常用入口，避免大标题压住场景 |
| 场景中的功能带 | 切换当前工具域 | 一行文字工具，不做左侧后台菜单；选中项用珊瑚红短下划线与文字强调 |
| 连续工作平面 | 当前任务、输入、结果 | 宽幅、低圆角或直边、无大投影；内部用行、细分隔和留白构成阅读顺序 |
| 底边停靠带 | 当前设备、切换设备、运行任务 | 设备文字选择与任务入口同一条边带；设备状态只出现必要一次 |

工作平面属于前景桌面的真实使用层。不得把每段内容套成独立圆角大卡片，不堆统计卡片，不预设“左导航＋中列表＋右检查器”永久三栏。确有任务需要时允许一处连续的双区，如文件目录和文件行、截图和动作说明；详情优先在当前行下面或按需抽屉展开。抽屉关闭后工作区恢复完整宽度。

### 2.2 桌面尺寸基准

以 CSS 像素和浏览器内容视口计，基准为 1366×768、缩放 100%。顶层品牌带高约 56；场景展示及功能带结束位置约 y190–218；工作平面从约 y212–236 接入前景，底部停靠带高 52–60。两侧基本安全间距 32–48，内容区最大阅读宽度 1440，超宽屏留出环境边缘而不无限拉长文本。

工作平面不悬浮成闭合巨大圆角框；边缘使用克制的暖纸渐入或连续面，最多一条淡分界，重点在内容而非框。1366×768 可用内容高度约 470–500，标题与工具不能再占去三分之一。较矮视口优先压缩场景高度，工具、正文和底边选择仍可用。

背景按原比例覆盖场景层，不拉伸、不贴入假视差拆层。具体定位由各视口图审确认，窗、吊灯、上层电子设备保留可辨认的局部；正文区遮住低处手机、柜线和木桌下沿。背景原图为 3:2，浏览器常为 16:9，居中覆盖会裁掉上下内容，不能用原图百分比直接当屏幕坐标。

### 2.3 色彩、字体与密度

| 项目 | 实施基准 |
| --- | --- |
| 工作底色 | 暖纸 #F3ECDD 附近；正文区域实色或不透明度至少 0.96，最终依截图确认纹理不穿透文字 |
| 主要文字 | 深墨 #252821 附近；普通正文 14–16，行高 1.5–1.65 |
| 次级文字 | 灰褐 #6E6B5F 附近；不得因纸色降低至不可读，重要状态不只靠灰度 |
| 强调 | 珊瑚红 #E56D45 附近，只用于当前工具、一个主要动作和焦点提示 |
| 辅助 | 低饱和墨绿 #4A5A42 附近，用于环境与安定状态；不用满屏绿色连接点 |
| 分隔 | 淡灰褐 1px，不使用高对比表格网格和密集边框 |
| 标题 | 页面标题 24–30、粗体；品牌 20–24；每页最多一个主要标题 |
| 代码与数字 | 系统等宽字体、可选择文本；中文操作和状态仍用正文字体 |
| 操作目标 | 主要按钮至少 40px 高；触屏重要目标至少 44×44；图标有可见或可访问名称 |
| 印刷细节 | 沿用现成图像质感和一处短强调；正文和控件保持干净，不生成噪声蒙住内容 |

这些色值是从当前视觉提炼的实施起点，不是宣称已测得对比度。普通文本、控件边界与键盘焦点仍需在实际页面测量。图标采用已批准的统一图标来源；不以手绘 SVG、表情符号或 CSS 景物替代正式资源。组件采用主代理锁定的官方清单，不在本规格中新增库或私有渲染器。

## 3. 导航、设备与专注模式

### 3.1 功能带与顶栏

桌面功能带依次提供：工作台、包与应用、文件、媒体、性能与堆栈、自动化、终端、AI 助手、分析、插件、任务、设置。名称可缩为性能、AI，但页面标题保留全称。每项必须有实际路由和真实业务视图，不能只变选中颜色。窄屏通过“全部工具”露出完整列表，当前工具名称始终可见，不靠拖动找到被隐藏入口。

品牌回到街角入口，进入工坊后保持页面内容与任务状态。顶栏只显示服务器连接短状态、专注按钮和更多菜单；更多容纳主题、动态效果、关于与低频全局项，插件、任务、设置仍在功能带可发现。服务器状态和设备状态分开，服务器断连不能显示为所有设备已被删除。

每页标题下说明当前工作对象，如设备名称、应用包、产物文件或会话，旁边保留一个主要动作。快捷搜索或命令入口仅在真实命令贡献存在时启用，不能为了视觉加入不能执行的搜索框。返回与切换工具保留用户可恢复的草稿、滚动和选中对象；业务状态由功能用例持有，不由背景或主题持有。

### 3.2 底边设备停靠带

桌面左侧展示当前设备的名称、平台/连接类型与文字状态；设备较少时可展示另外 2–3 个切换入口，更多折入设备选择器。名称超长截断但可展开完整名称与提供者来源，序列号不占主视觉。已选设备用墨绿底或明显下划线加“当前”文字，不靠绿点识别。

右侧只保留运行任务摘要及打开任务入口，例如“截图 · 等待设备 / 2 个运行中”；零任务显示“任务”，不常驻无意义的“0”。任务详情中的取消可见，不埋进日志。底边设备选择器支持键盘，切换时先显示新设备的获取状态，旧设备结果作为历史保留并标明来源，不填进新设备视图。

包解析、产物分析、AI 和插件管理等非设备页面仍可看见当前选择，但标明“当前页面不使用设备”或在动作旁明确目标范围。未选设备不阻断这些独立能力；设备动作由公开能力、版本、可用状态和权限决定，平台名只展示与筛选。

### 3.3 专注模式

专注模式收起大部分场景高度，将工作平面上移到顶栏下方；保留品牌返回、当前工具、退出专注、设备/任务入口。背景可作为上缘小条和淡边缘保留，正文用实色纸面。终端、AI、性能长会话可以提示专注，但不得擅自反复切换用户选择。

常规与专注共用同一业务组件和状态，不重启直播、不重建任务、不清空输出。退出专注恢复之前工具和滚动位置。全屏媒体是媒体自身模式，应有独立退出路径；浏览器全屏退出不等于任务取消。

### 3.4 响应式规则

| 视口 | 组织与场景 | 必须保持 |
| --- | --- | --- |
| ≥1366 宽，≥768 高 | 全部功能文字尽量同一行；场景约 150–190 高；连续工作平面可以一处双区 | 主要动作、当前设备、任务、设置及退出入口可见，无横向整页滚动 |
| 1024–1365 宽 | 场景缩至约 100–150；工具带展示当前域与常用项，其余进入全部工具；双区降低辅助区宽度 | 列表主字段完整可读，抽屉不超过内容宽度的约 60%，主动作不被挤成无文字图标 |
| 768–1023 宽 | 工具带改当前工具＋全部工具；主区域单列，详情下展或抽屉；停靠带只留当前设备与任务 | 全部业务入口可达，正文不盖底边；复杂表格仅自身可横滚，页面不能横滚 |
| 360–767 宽 | 顶栏高约 48–56，场景展示约 72–112；品牌缩短；当前工具与菜单一行；内容侧距 16–20 | 主要操作 44px 目标，底边设备与任务两入口；弹层近满屏，关闭和焦点返回可用 |
| 视口高 <650 或 200% 缩放 | 场景自动压缩至小条，正文优先；底部按可用高度收为单行 | 操作、错误说明、表单提交与退出仍可滚动到，固定带不吞掉大部分视口 |

在窄屏不照搬桌面的两列。预览先、动作次、结果再次；性能先指标/时间点、图表、画面和栈依次阅读；终端保留整宽输出，输入固定于终端区而非整个窗口。底部软键盘出现时输入和提交进入可视区域，设备停靠带可压缩，但不得覆盖输入。

## 4. 共用状态语言

| 状态 | 画面与文案 | 用户下一步 |
| --- | --- | --- |
| 尚未选择对象 | 标题、短说明和一个明确选择动作；不放假设备/假截图 | 选择设备、上传文件或建立会话，视当前域而定 |
| 合法空结果 | 保留筛选与标题，说明“没有匹配应用/文件/任务”等 | 清除筛选、刷新或新建；不能把空结果说成接口失败 |
| 首次加载 | 保留页面结构和真实目标，正文局部占位，写“正在获取…” | 可取消等待；不显示假的数据和百分比 |
| 刷新 | 保留旧结果并标“上次更新”；当前刷新状态局部呈现 | 再次操作不会重复提交写任务；完成后切换新代结果 |
| 设备断线 | 保留最近结果，明显写“设备离线，以下为上次结果” | 刷新目录或重新选择；旧预览不宣称实时 |
| 服务器断连 | 顶栏显示断连，正在等待的动作显示范围；不清空历史 | 重连或配置服务；恢复后查询任务实际状态，不自动重放写动作 |
| 功能不支持 | 原入口可发现但有具体原因、提供者与能力版本 | 选择支持的设备/插件；不以平台硬编码隐藏整个域 |
| 权限不足 | 明确设备授权、Root 或可选服务令牌是哪一层失败 | 打开对应说明或凭据设置；不新建多用户权限审批流程 |
| 运行失败 | 对应输入/结果位置显示短原因，详细错误按需展开 | 复制真实日志 ID、查看任务、按资格重试；任务 ID 与日志 ID 区分 |
| 请求取消 | 写“已取消等待”或任务真实取消终态，依公开响应确定 | 可查看任务实际状态；不承诺文件、部署或写动作已回滚 |
| 部分成功/缺测 | 有值的结果保留，缺项显示“—”及明确原因 | 查看来源/权限；不能用 0 填缺测或插值伪造连续曲线 |
| 提供者/插件移除 | 当前域显示来源已不可用，撤销其贡献入口；保留历史出处 | 返回宿主工具、刷新或安装；不留可点击的旧代动作 |

失败不能只用一次自动消失通知表示。错误旁保留可见的重试或排查动作，日志 ID 可选择与复制；复制反馈不泄露令牌、服务器内部路径或敏感输出。加载、成功、取消和断线的颜色必须同时配文字。

默认不自动播放声音。减少动态效果时关闭推进、视差和装饰循环，直接呈现稳定内容；任务与直播的业务状态仍更新。导航短过渡控制在约 120–180ms，进入工坊约 500–700ms 仅属于装饰，不能延迟真实操作或隐藏失败。后台页或不可见装饰停止动画。

## 5. 各产品页面

本节定义页面职责与视觉组织，不证明对应功能已实现。动作必须映射当前公开用例及能力；缺口显示具体原因，不能用本地假结果补齐。生成类型与 SDK 的适配由主代理核对，视觉规格不新增后端 DTO 或公开插槽 ID。

### 5.1 设备工作台

工作台围绕当前设备的一次操作。标题展示设备与连接方式，下方一行摘要列出可用能力、最近观测时间和提供者。中央默认是“现在要做什么”的文字动作带：截图、应用、文件、媒体、性能，动作只有在真实能力可用时启用。非实时状态不放持续跳动的绿灯。

已有截图时，按设备真实比例放一幅预览，宽不超过正文区的约 30%，高不超过可用内容高的约 75%；右边只放当前动作与最近 2–3 个结果，形成连续双区，不增加第三列设备资料。竖屏按比例留白，不能拉伸为面板比例。无截图时显示明确采集动作和说明，不把假手机屏幕当成连接成功。

截图、录像、实时投屏作为不同模式入口，模式选择不等于执行。截图旁显示来源设备、生成时间和“最近截图”；实时流才可标“直播/实时”。设备身份与能力详情按需展开；公开连接/配对动作可打开提供者贡献的实际面板，不复制平台命令。

### 5.2 包与应用

标题工具行提供“设备应用 / 安装包”两个真实工作范围；设备应用显示选择目标，安装包解析可独立于设备使用。应用列表是一组轻分隔行，主字段为名称/包名、版本与状态，搜索筛选保留；单行选择后下展启动、停止、卸载及资料，危险写动作按实际行为确认目标，不用彩色操作按钮铺满每一行。

安装包工作区先是一个紧凑上传入口与格式说明，文件被接受后替换为可选择文件名、大小、产物身份与上传状态。下方按实际操作显示清单、签名、DEX、SDK、反编译、AAB/APKS 等结果页签；无数据的页签写明尚未运行，不显示空假报告。文件名与包名可选择复制；完整技术表格只在该结果里出现。

解析完成后主动作从上传变为当前最合理的解析/安装动作，输出以文件行或报告章节承载。多包安装需明确目标设备、已选 splits 和任务结果，不能把上传成功等同安装完成。后台排队、安装失败、取消等待与实际终态分开显示。窄屏应用行保留名称、包名和一个详情按钮，次要字段下展。

### 5.3 文件

顶部是当前设备与可选择路径的面包屑，右边为刷新、上传、新建等真实能力动作。主体采用连续文件行，名称占主要宽度，类型、大小、更新时间是次级信息；目录只在需要时提供约 220–260 宽的路径树，并允许收起。预览与详情用当前行下展或抽屉，不固定第三列。

浏览器文件与远端设备文件分清：浏览器上传生成产物 ID，远端推送显示明确设备及目标路径；下载使用公开产物入口，不把服务器路径作为可点击链接。队列以同一任务行显示实际阶段与失败，不通过结束上传动画宣称远端写入成功。

长路径中段缩略，当前目录和最后文件名保留，完整值可复制。路径输入有标签与错误，拒绝或不支持时保持用户内容。删除/覆盖说明准确目标与范围；多选时工具行改为选择计数和批量动作。空目录、权限拒绝、路径不存在和设备断线各自呈现。窄屏目录树改为路径选择器，文件详情单列。

### 5.4 媒体

媒体页以真实画面为唯一视觉主体。顶部模式为截图、录像、实时投屏；当前模式旁说明输入来源。主视图等比放置原图或视频，外围为安静暖纸，音频、控制、录制操作放在一条紧凑工具带。不得把背景里显示器当作真实显示区，不能贴假手机 UI 代替媒体。

实时流显示连接、首帧等待、播放、有限重连和结束等真实状态，显示来源设备和会话；画面停住时明确“画面暂停/连接中断”，不保留看似直播的标签。输入控制只在实际可用资格下启用，关闭控制不应停止观看。音量默认关闭或由用户显式开启；音频不可用要独立说明。

下方结果带按时间排列截图与录像产物，优先缩略图＋时间＋文件名，详情后置，不能为每个产物建立巨大卡片。播放失败保留产物下载、错误原因与日志 ID。全屏要有退出和键盘路径。移动视口把控制收为单行或两行，不覆盖画面关键区域；横屏和竖屏切换保持真实比例。

### 5.5 性能与堆栈

先选择设备、应用和采集资格，标题工具行提供开始/暂停/继续/结束等实际会话动作。上方用一条指标摘要列出 FPS、CPU、内存和已公开电气指标，各项有单位、对象范围和来源；不使用一排独立彩色大指标卡。用户已取消温度缺测增量，不在本次页面设计中新增温度采集或承诺补齐缺测兼容；已有后端值仅按当前公开合同展示。

主体上半是共用时间轴的指标曲线，下半是选中采样点画面和堆栈/线程内容；这是一份连续采样报告，不做常驻三栏监控台。点击采样点同步更新指标、画面、实际时间和调用栈。先保证一项指标的阅读，其他指标可选择叠加或切换；曲线颜色旁有文字图例，缺测区断开曲线。

采样画面写明关联时间、偏移或资格，不用“最近截图”假装每个点精确对应。无 Root 时解释当前可用指标与栈不可用原因；有 Root 也不宣称符号完整。栈按真实深度缩进，模块、地址、函数与符号资格可选择，长名称横滚局限于栈区域。缺符号保留地址和来源，空栈、录制失败与权限不足分别呈现。

电池侧/整机值与应用范围的指标必须在正文可见，不把净电池功率写成游戏独占功耗。结果按实际归档提供报告与媒体下载；任务终态后仍可回查采集会话。小屏将曲线、采样画面和栈纵向排列，选择点工具常驻当前段落；长会话推荐专注模式。

### 5.6 自动化

用连续步骤清单表达脚本：左侧序号、中间操作及参数、右边执行状态；编辑当前行时下展表单，不能把每个动作做成流程节点大卡片。标题工具行提供新建、导入、录制或回放中的实际可用项，脚本作用域清楚标明设备或当前桌面。只有实际提供者支持时才显示相应录制动作。

执行前一行显示目标、循环次数、预计动作范围与开始按钮；执行中明确当前步骤、循环轮次和停止入口。实际没有可知总时长时不用倒计时伪造。失败定位到具体步骤，原参数可保留但不会自动重放写动作。录制中的指示常驻可见且可停止；结束必须依真实返回值收敛。窄屏参数纵向排，移动/删除在步骤菜单内，开始/停止仍留在主要工具行。

### 5.7 终端

终端是连续的墨色输出纸面，可独立使用深墨背景与浅字，外壳仍是暖光风格；不再额外套一层大卡片。标题标明会话、目标、工具来源与交互资格；会话切换在一行页签中，正文只显示当前会话。没有真实 PTY 时按双向流/标准输入的实际能力命名，不称为完整系统终端。

输出保留 stdout/stderr 区别和顺序，批量追尾可以暂停；用户向上滚动后不要反复抢回底部。输入行、发送/EOF、取消/停止在会话下缘可见，按当前公开能力启用。历史会话只读与运行会话可交互要明显不同；会话重连不静默重复命令。

工具退出、超时、取消、插件卸载和服务器断线有文字终态；原输出仍可查看和复制，日志 ID 在错误详情。较长输出在终端区域内滚动，不扩撑页面；窄屏输入不被底边设备停靠带或软键盘遮住。终端背景不模拟旧图工具墙和黑客代码。

### 5.8 AI 助手

工作平面是一列可阅读会话，最大文本宽度约 760–860；用户输入与回复用段落、细分隔和角色标题，不为每句话做巨大彩色聊天气泡。标题保留会话名、模型/服务可用状态与新建/恢复入口。底部输入区有可见发送与取消，长输入可扩高但不吞掉全部回复。

流式回复显示正在生成的真实内容和状态；工具调用以小型可展开记录列出操作名、目标、实际运行/成功/失败及产物。工具过程不能伪装成助手已经成功执行。取消等待、CLI 结束、模型错误、凭据缺失与服务器断连分开表达，保留已有内容和真实日志 ID。

默认将工具细节折叠在同一会话中，用户展开才读取长日志；不固定右侧工具大栏。凭据只走现有独立管理边界，缺凭据提示到设置，正文和历史不显示密钥。当前 REA MCP/Agent 只属于后续计划，本轮不新增入口或把规划写为可用工具。移动视口保持完整输入与发送，退出专注和返回会话始终可达。

### 5.9 分析

分析聚焦“一个产物/一份报告的理解”，不是所有业务统计总览。顶部先选产物与真实可用分析操作，再显示数据转换、结构查看或调试分析等已公开工作域。包的清单/签名/DEX 仍归包与应用，不在此重复一套入口；分析页可以引用结果并返回来源任务。

MessagePack/JSON 等结构化结果采用可筛选行和字段详情，分页在结果末端，错误定位到输入与格式；文件转换成功后列出实际产物和下载。Frida 等调试能力用当前会话、目标进程、实际注入资格和日志流呈现，停止入口可见，不用静态“已注入”徽章冒充真实运行。

长报告按章节纵向阅读；目录是可收起的局部导航，不成为所有页面的永久左栏。分析失败保留输入来源、错误和日志 ID，权限不足不以空表代替。无支持插件时说明所需贡献，不展示无法执行的假分析演示。移动视口长代码/结构只在局部横滚。

### 5.10 插件

插件页区分服务器插件、浏览器插件与主题贡献，设备提供者和浏览器面板的关联在详情说明。主要区域是轻分隔插件行：名称、版本、类型、实际生命周期状态、来源和一个适用管理动作；详情下展能力、组件/模块/命令/服务及错误，不把每个插件做成大商业卡片。

顶部主动作是提交插件包，上传区说明当前支持格式、目标端和处理阶段。上传/部署成功、服务器启用、浏览器挂载必须分别显示；不能提交后自动假定运行。装卸过程中状态来自查询或实际返回，取消等待后再查询；失败保持受影响来源，不能只做视觉淡出后宣称资源已清理。

主题作为选择项展示当前名称与真实应用状态，选择成功后才换视觉，失败保持原主题。主题卸载恢复宿主默认视觉，当前设备、业务结果和任务历史不丢失。插件新增功能从公开贡献进入工具带/全部工具，卸载后撤销；若正在其页面，显示来源已移除和返回宿主入口。默认可信包开放运行，不在设计里新增来源审批、多用户授权或强制隔离流程。

### 5.11 任务

任务是时间顺序的记录行：任务名、对象、来源、真实状态、时间和阶段/实际进度，运行项在顶端，历史随后；筛选按运行/成功/失败/取消与来源组合。不要用一排总量卡片占去正文。无百分比的任务显示阶段文字与局部活动指示，不伪造进度。

选择任务下展事件、输入摘要、业务结果和产物；日志详情按需展开，任务 ID 与日志 ID 标注用途。运行项取消可见，取消请求中不提前写“已取消”。页面刷新或断连恢复后按持久任务查询重建真实状态，旧代任务结果保留来源，不覆盖当前操作。

底边只展示最相关一个运行任务与总运行数，点击进入对应任务。多条产物使用文件行，长名称下展或可复制，下载状态与任务执行状态分开。历史查询失败保留已加载记录并标过期/更新失败；空历史、筛选无结果与请求失败分开。

### 5.12 设置

设置用连续条目与小组标题，分为服务连接、可选服务令牌、主题与显示、动态效果、工具/插件提供的实际配置。解释放在控件附近，默认免鉴权的本地/局域网部署写清楚；不创建不存在的账号、角色、在线云空间和来源审批。

服务地址有完整标签、当前连接状态与测试/应用动作，未应用编辑值与当前值区分。令牌输入遮蔽，可见性切换有名称，不放入 URL 或浏览器 localStorage，不在成功通知和复制排查信息中泄露。连接失败保留草稿和错误，不能应用一个坏地址后把整页变成无返回路径的错误屏。

主题和减少动态效果提供即时可理解的预览/状态，但只有公开选择成功才生效。设置控件用正式语义和键盘操作，保存、恢复默认等行为按实际能力表达。窄屏标签、说明、控件纵向排列，长地址可编辑，主要动作不隐藏在无限底部。

## 6. 实施交接与完成口径

实施先锁定外壳与底图装配，在 1366×768 和 390×844 两个视口图审后再扩展页面，避免十二页重复修相同骨架。第一批用工作台、媒体、性能和终端覆盖预览、连续列表、高密度图表与深色输出四种构图；其余页复用结构职责与官方组件，保持真实用例归属。

所有页面图审由视觉子代理进行，主代理负责收集版本、视口、状态和结论，不能把未经审核的截图当视觉通过。静态图审、浏览器行为、公开契约、模拟工具、真机、局域网、分发与生产性能分开记录。规格交付不借记任何历史测试成绩；未覆盖页和状态明确列未验证。

无支持能力的真实界面可以通过对应“不支持/来源缺失”状态验收，但该项不能同时计作业务功能成功。当前任务没有授权新增 REA/Agent 功能、温度增量或性能专项，相关计划继续独立；Root、媒体播放、符号、真机等资格按当前冻结输入记录，不因页面能显示而升级。

| S03 | 设备离线与提供者移除 | 工作台、媒体、性能、底边选择 | 保留历史出处，旧预览不实时，入口收敛，取消等待不声称写动作回滚 |
| S04 | 服务器断连并恢复 | 运行任务、终端或插件管理 | 设备与服务状态不混淆，恢复查询真实任务，不自动重复写入 |
| S05 | 权限不足/能力不支持 | 安装、媒体控制、性能栈、分析 | 具体失败层和来源可见，Root/服务令牌/能力缺口分开，无假 0 |
| S06 | 长内容与多结果 | 超长文件名/路径/包名、100+ 行列表、长栈/终端/回复 | 表格/代码局部滚动，主要名称和操作不截没，无大块无效留白 |
| S07 | A→B 快速切设备，A 晚到 | 工作台、媒体、文件、性能 | B 视图不被 A 覆盖，历史标来源，底边/标题/结果一致 |
| S08 | 运行中装卸插件及主题 | 插件页、贡献页、运行任务 | 公开贡献移除、失败回滚/查询实际状态；主题只改视觉不清业务 |
| S09 | 部分缺测与无符号 | 性能点、栈、采样画面 | 值/原因严格对应，缺测断曲线，符号资格明确，没有每点假截图 |
| S10 | 键盘与焦点 | 十二页导航、设备菜单、表单、抽屉、关闭、取消、复制 | Tab 顺序、可见焦点、Esc 及焦点返回可用，无仅悬停动作 |
| S11 | 错误日志复制与安全展示 | 一个真实失败任务/上传/媒体/AI | 复制真实日志 ID，失败常驻、反馈可见，不复制令牌/内部敏感路径 |
| S12 | 文字/控件对比、浏览器放大 | 普通/专注、深色终端、禁用/焦点/错误 | 实测普通文本与控件对比，状态不只靠颜色；截图不称完整无障碍合规 |

### 7.5 审核交付格式

每批回传：受检版本、页面与状态、视口、截图原件路径、正常/异常操作结果、可见问题、严重度、修正建议、未验证项。只给源文件位置而没有截图的事项是代码审查，不能计视觉通过；只有截图没有实际操作的事项只计静态图审。

通过至少要求：主要任务可执行、来源和结果真实、正文与操作可读、没有框架遮挡/整页横滚、背景商标没有漏出、暖光印刷风格保持、焦点与取消/关闭可发现。重大失败应立即回流，修改后只重新执行受影响页面/共用外壳的必要矩阵，避免无变化重复全套验收。
