## 设计简报

目标是适合每天长时间使用的设备开发与游戏调试平台，强调独立、小众、游戏空间、交互反馈与沉浸感。将用户原文中的“提出大范围的 ai 味”按去除大面积模板化视觉理解。主体是可工作的设备操作界面，场景承担情绪与空间。

用户指定 React、Tailwind CSS、TypeScript、Vite、React Bits；未经审批不自行编写 UI 组件。平台、浏览器模块、组件贡献和主题须支持运行中装卸。

参考来源为[异环官网](https://yh.wanmei.com/main.html)和[星布谷地官网](https://planet.mihoyo.com/home)。视觉子代理直接查看有效截图后提炼：前者提供偏置街景、黑色硬边、印刷质感与明确导航；后者提供暖光、漫反射和前中远景。参考已文字化，未上传到本批生成接口。保留原创场景，不复制游戏人物、标志或世界资产。

## 组件选型与审批边界

建议采用 Tailwind CSS 4 + shadcn/ui 官方组件 + Radix UI 基础交互，图标统一 Lucide。用户已指出 Ant Design 偏中后台，后续方案不以其作为基础。

shadcn/ui 通过官方注册表把组件源码引入项目，不是安装后完全隐藏源码的黑盒组件库。后续先给出组件清单、来源、版本或提交标识、依赖和定制范围，经用户审批后引入；不得以复制源码为理由自行发展另一套组件库。布局可组合既有组件，未批准的新交互基础组件暂停实现。

| 使用位置 | 拟用官方组件 | 定制范围 |
| --- | --- | --- |
| 主操作、菜单、悬浮说明 | Button、DropdownMenu、Tooltip | 主题变量、尺寸与图标，保留语义与焦点行为 |
| 设备工作域、插件页签 | Tabs、Command、ScrollArea | 布局与数据装配，不改键盘语义 |
| 检视区、设置、安装包提交 | Sheet、Dialog、Input、Select、Switch | 使用官方表单行为，不重写弹层与焦点陷阱 |
| 任务行与状态 | Badge、Progress、Table、官方通知方案 | 状态来自真实契约；不凭动画推断成功 |
| 场景进入与低频反馈 | React Bits 的 TypeScript + Tailwind 官方版本 | 候选 AnimatedContent、FadeContent；PixelTransition 仅评估装饰场景，不作为必需依赖 |

版本信息仅用于设计阶段调查，不替代安装与联调。当前检索到 React 19、Tailwind 4、Vite 8；具体锁定组合以项目约束与安装验证为准。官方来源：[shadcn/ui 的 Vite 安装](https://ui.shadcn.com/docs/installation/vite)、[Radix](https://www.radix-ui.com/primitives)、[Lucide](https://lucide.dev/)、[React Bits](https://github.com/DavidHDev/react-bits)。
