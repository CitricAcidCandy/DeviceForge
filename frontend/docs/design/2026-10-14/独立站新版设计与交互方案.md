## 创意交互与长期使用

以下是待实现的行为规格，静态图片不能证明其已经工作。时长是起始设计值，后续根据实际浏览器表现调整。

| 触发 | 画面行为 | 使用者得到什么 | 安静与无障碍降级 |
| --- | --- | --- | --- |
| 首次进入首页 | 原创前、中、远景分层进入，总时长约 650–850ms；品牌和入口先可操作 | 像进入一个有空间的站点，操作不等待完整动画 | 减少动态效果时立即呈现；后续返回不重复片头 |
| 移动指针 | 仅场景层微小视差，最大位移约 4–8px，导航和正文位置固定 | 轻微空间回应，维持阅读与点击稳定 | 无指针、触摸、减少动态效果或用户关闭时静止 |
| 点击章节导航或向下探索 | 场景和标题沿一个方向推进，约 450–650ms；保留稳定的公共导航 | 用空间变化解释设备、插件、任务所在位置 | 使用正常滚动和锚点；不拦截滚轮、不强制滚动吸附 |
| 点击设备入口 | 场景焦点引导至设备位置，再展开官方 Dialog 或 Sheet 中的功能内容 | 在有沉浸感的入口之后完成真正的设备操作 | 同时提供普通文字导航与键盘入口；减少动态时直接展开 |
| 任务开始与结束 | 沿边运行标记先响应操作，真实结果后再给一次克制反馈，约 160–220ms | 清楚区分已提交、运行中、成功、失败和取消 | 不持续闪烁；状态可由文本理解；失败保留可复制日志 ID |
| 选择主题 | 经公开主题接口应用成功后，场景与材质短暂交接；业务内容和焦点保留 | 在不停下工作、不重载页面的情况下改变站点世界 | 减少动态时立即切换；主题应用失败保持原状态 |
| 插件加载与卸载 | 当前扩展入口随目录出现或退出；活动面板按生命周期清理后恢复宿主入口 | 可感知能力变化，同时不把动画当作成功回执 | 失败、取消和 cleanup_failed 按真实状态展示，不提前显示已卸载 |

工作状态提供展开内容区、收纳场景、暂停装饰与全屏专注。环境声音默认关闭，用户主动开启后才播放；隐藏页面暂停场景与声音。没有自动摄像机漂移、无限粒子或循环闪动的任务提示。设备切换、主题切换和回到首页不丢失正在进行的任务；订阅与生命周期取消继续遵守现有公开合同。

React Bits 只选官方 TypeScript + Tailwind 版本。候选 AnimatedContent 与 FadeContent 用于低频内容进入；PixelTransition 只可用于场景素材交接，不能像素化文本或重要状态。已查看官方来源中的释放逻辑，但不据此声称平台装卸集成通过；减少动态效果需要逐项验收，不能假定所有官方组件自动覆盖。

## 主题和平台热拔插

现有合同依据[主题插件与宿主样式](../../guides/主题插件与宿主样式.md)与[前端运行架构](../../guides/前端运行架构.md)。公开 ThemeContribution 当前提供 variables、css 和 colorScheme；ThemeAccess 提供 snapshot、select 和 subscribe。组件与模块有独立贡献、挂载根、AbortSignal、代次和撤销规则。

| 内容 | 接入路径 | 必须保持的行为 |
| --- | --- | --- |
| 色彩、字体、间距、圆角、边框与背景材质 | 现有主题变量、可信 CSS 和配色方案 | 不写死于业务组件；卸载选中主题后精确恢复基础样式 |
| 场景、导航表现、功能入口与内容排布 | 既有组件／模块贡献和具名插槽；主题 CSS 可调整布局表现 | 插槽仍有稳定身份与默认内容；替换失败或撤销可恢复 |
| 动效、场景逻辑和交互服务 | 浏览器插件公开组件／模块／服务生命周期 | 不擅自在纯主题声明新增未经冻结的行为字段 |
| 用户选择的设备、任务、日志与数据请求 | 现有 runtime、features 与公开宿主服务 | 不由主题持有，不随着场景卸载而销毁业务状态 |

首页场景、导航呈现、功能内容、上下文扩展与沿边运行反馈是拟评审的插槽职责，不是声称已存在的具体槽位 ID。选定视觉后再核定插槽清单，避免为了某一张图改写公开 SDK。

装卸必须释放动画时间线、观察器、事件、媒体、订阅和自有渲染根。主题只通过公开 select 管理选择，不按插件加载顺序覆盖主题。可信 CSS 可作用于文档，当前实现没有强制样式隔离保证；设计和测试不能忽略这一边界。卸载恢复依赖真实生命周期结果，不使用视觉淡出来假定清理成功。

## 组件来源与实施前提

建议使用 React + 严格 TypeScript + Vite + Tailwind CSS，shadcn/ui 官方组件提供 Button、Tabs、Dialog、Sheet、Command、Tooltip、ScrollArea 等，Radix 提供基础交互，Lucide 统一图标，React Bits 只承担批准的场景与动效。用户已否定 Ant Design 作为本次基础。

shadcn/ui 会把官方组件源码引入项目；React Bits 也需要跟踪官方源码与依赖。先提交逐项组件清单、版本或提交身份、用途与定制范围，再经用户审批引入。没有获准时不得安装库、复制组件、手写替代组件或自行创建渲染器。原创景物使用正式图像资源，不用 CSS 图画或手绘 SVG 冒充场景。

用户记得前端已经切换 React；本轮核对当前 G:/Rust/DeviceForge 工作树发现 package.json 仍声明 Svelte，src/app/main.ts 导入 svelte 并挂载 App.svelte，vite.config.ts 使用 Svelte 插件。当前仅一个 master 工作树，未定位其他 React 版本。设计继续按用户指定 React；这一源码差异单独记录，不擅自把设计任务扩大为框架迁移，也不据旧文档推断其他版本不存在。
