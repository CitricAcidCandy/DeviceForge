# 任务历史与事件公开接口第一批裁定

日期：2026-10-10。模式 architecture-first / Hybrid。依据同目录的裁定草案和现有后端任务接口，本文件冻结实施契约；不代表实现或验收完成。产品界面继续等待设计稿。

## 公开契约与兼容

采用 SDK API2 可选 `HostContext.taskHistory?: TaskHistoryAccess`，保留原 Job、getJob、提交和取消签名。草案中的 HistoricalJob、JobEvent、TaskHistoryQuery、TaskEventQuery 和 list/get/events 三方法形状全部采用；方法返回 HostResult 的只读数组或对象，显式传入 AbortSignal。未注入该端口的旧上下文不补实现。

HistoricalJob 仅增加持久化 input 与 createdAt；JobEvent 公开 sequence、jobId、status、timestamp。时间单位为 Unix 毫秒。历史不补当前操作、预算、设备或提供者代际，不依赖插件当前是否已卸载。只消费已有 HTTP 端点与生成类型，不新增服务器路由、重复 DTO 或产品 UI。

## 校验、取消与关联

- limit 省略交由服务器默认，显式值为安全整数 1 至 200；after 为非负安全整数。标识非空白，保留原文，get 响应 id 与请求精确匹配。
- sequence 为正安全整数，每次响应严格升序且全部大于有效 after；允许跨任务造成的序号间隙。每项 jobId 与请求精确匹配；重复、倒序、错任务或不安全数值拒绝整次响应。
- createdAt 和 timestamp 为非负安全整数，允许 0，不要求事件时间单调。input、result、status、error 沿现有公开规则，不取整或补造数据。
- 本地参数错误为 protocol/invalid_history_query；历史和事件映射错误分别为 invalid_history、invalid_job_events。沿现有错误适配保留真实 code、status、retryAfter 和 logId，客户端不生成日志 ID。
- caller、runtime、插件实例及挂载子作用域撤销均及时结束等待，包括忽略信号或永不返回的注入端口；晚 resolve/reject 安全消费并丢弃，结果交付前复核资格。已交付结果不追溯撤回。
- 旧插件引用重载后不复活，子作用域撤销不关闭兄弟。查询撤销不删除历史、不调用 cancelJob，不增加全局缓存、轮询、订阅或重连资源。

开发冻结交接后由主代理执行 generate/check/test/build，覆盖旧 API2 缺省、原字段及日志、参数/关联/整数边界、序号间隙、忽略信号取消、晚拒绝、子作用域与同 ID 重载。真实生产浏览器使用公开上下文查询服务器实际任务和事件，服务器插件撤销后历史仍可读取。静态契约和纯映射通过不替代持久化、真实浏览器或正式分发验证。
