## 实施门禁

模式为 architecture-first，范围是 v2 通信、操作/任务/服务器插件管理、两类在线包部署、可信浏览器插件热装卸与开放扩展，以及设备提供者第一阶段目录/选择/离散动作。保留现有外壳，不增加页面或 UI 库；设备范围见 [第一阶段实施](设备提供者第一阶段实施.md)。生成类型、后端、根 todo 与 AGENTS 由所属代理管理。

选择分层的类型端点、独立用例及注入式运行管理器。将请求与生命周期堆入 app 虽然改动集中，但混合令牌、状态和资源所有权，不采用。SDK 升级为 v2，公开模型由生成 DTO 映射，插件不依赖生成类型。网络响应先作为 unknown 校验，不以 any 或断言绕过边界。

依赖保持 app → features/plugins/shared/SDK；features → 本模块/shared/SDK；plugins → SDK；shared → shared；SDK 独立。各功能仅经 index 公开入口装配，没有跨功能内部导入。拆分后再实现，保持 strict、noUncheckedIndexedAccess、exactOptionalPropertyTypes。

采用契约先行与行为测试结合：先证明包装和未知响应拒绝，再证明取消及插件失败回滚，最后运行 check/test/build。生成工作由主代理执行；PluginInfo 直接从 paths 推导，运行校验要求 cleanup_failed，不伪造第二份 DTO。

## 生命周期约定

用户最新选择本地/局域网免鉴权和可信代码运行，不要求来源审批或强制隔离。动态模块 loader 由宿主注入，模块 unknown 返回值经贡献校验，SDK v1 插件须升级。安装目录映射为独立 SDK InstalledWebPackage，运行时每次 load 创建 UUID，经 resolver 放入资源路径前缀 `/api/v2/browser-plugins/{id}/runs/{run_id}/assets/{path}`，ESM 相对依赖共享本代路径。在线 HTTP 类型已由主代理生成，客户端/包用例均直接消费 paths；上传部署与运行 enable 分开。

每代插件拥有 AbortController、资源栈及独立面板根节点。卸载一经请求立即取消当前代请求、停止订阅并移除专属 DOM；装卸、激活和挂载经串行队列收敛，晚到结果不得重新发布或覆盖新代。异步激活/挂载必须响应生命周期信号；同页面无法强制终止恶意或永不完成的 JavaScript。释放失败汇总报告，不阻止其他已登记资源清理。

## 开放扩展实现

WebPlugin.contributions 为 SDK v2 可选字段：components（slot、mode、mount）、modules（route、mount）、commands（execute）、services（version、invoke）、beforeTaskSubmit（priority、transform）。所有贡献以插件 ID/运行代次登记，动态 register 返回撤销函数。组件/模块专属根与子信号由宿主持有；插件不跨模块引用私有状态。

`SlotAdapter.acquire(SlotRequest, AbortSignal) → Promise<SlotLease>` 是框架无关渲染入口。`createNamedSlotAdapter([{id,target,renderDefault}])` 登记默认 renderer；append 保留默认渲染，replace 释放默认渲染并拒绝第二替换者，卸载或失败恢复默认 renderer，保留宿主无关 DOM。插件仅接触自己的 lease 根，没有私有 DOM monkeypatch。适配器由注入方销毁，runtime 不擅自销毁共享槽位。

beforeTaskSubmit 在 tasks.submit 的真实请求前按 priority 升序（默认 0），同优先级按 id.localeCompare 串行调用，与插件加载先后无关；失败/撤销立即停止后续钩子并阻止本次 HTTP，返回值运行校验。卸载删除该代钩子，剩余钩子继续生效，全部卸载后恢复原提交。钩子失败本身不自动停用插件。

服务通过 callService(id, version, input, signal) 调用。A 调用 B 时组合消费者、调用者和提供者代际信号；B 卸载立即撤销在途信号，新调用收到 service_unavailable，A 继续运行。已绑定旧 B 的调用结果即使在重载后到达也被拒绝，旧 B 上下文不复活；A 此后按 ID 发起的新调用可使用新 B。命令、服务和提交钩子的等待与取消竞速，回调忽略信号且永不返回时，调用者取消、所属插件卸载或注册表关闭仍结束宿主等待；晚到成功/拒绝被消费。该行为不强制终止可信 JavaScript 副作用，资源清理仍由插件登记并负责。

extensions 提供公开目录、事件与状态。插件只能发布自己的事件和修改自己的状态，可订阅 host.*；卸载撤销订阅并清空代际状态。可信插件的未登记全局副作用由插件自身负责。

页面模块的 route/title 只作为发现元数据，不自动创建路由界面。宿主进入模块调用 extensions.mountModule(id)，退出调用 extensions.unmount(id)，仅取消挂载子生命周期、清理 DOM/资源，保留插件和模块登记；再次进入可重新挂载。插件卸载则撤销所有模块、命令和其他贡献。模块或组件挂载失败回滚整代。

可运行源样例 `src/plugins/examples/task-lab.ts` 通过公开 SDK 注入组件/模块、发布命令/服务、变换示例任务输入并传递日志 ID；不修改产品外壳或引入 UI 库。

主题加法通过 `PluginContributions.themes` 与可选 `HostContext.themes` 提供独立目录、选择和订阅，`runtime.themes` 明确公开。主题纯校验/注册表/DOM 适配拆在 plugins/themes，runtime 只注入可选 themeTarget；缺少目标拒绝非空选择，不触碰全局 document。主题随统一贡献 ID、所有权和代次撤销，行内变量与 color-scheme 精确恢复，可信 CSS 节点独立删除。具体产品页面继续等待设计；本批门禁与真实浏览器证据由主代理另记，契约与完整验证边界见 [主题插件与宿主样式](主题插件与宿主样式.md)。

服务器管理取消只取消等待，不能推断后端回滚。取消/网络失败/后端拒绝后重新读取服务器插件与操作目录，不自动重放变更；cleanup_failed/draining 保留原值。服务器状态与浏览器运行实例分离。

## 设备目录与调用

runtime.devices 和可选 HostContext.devices 已接入。SDK v2 保留 camelCase 独立模型与 refreshProviders/refreshDirectories/refreshProvider/invoke、select/snapshot/subscribe；app 显式映射生成 HTTP snake_case 字段，插件不导入宿主功能内部实现。设备身份包含 providerId/generation/localId，同名设备由完整引用区分；动作按精确能力版本、作用域和可用状态准入，返回共享 Job。

refreshDirectories 同步提供者与已有观测，不触发发现。refreshProvider 开始即撤销该代旧目录/选择，失败保持空；清理后记录修订，允许自己的成功发布，拒绝替代请求与旧代晚到覆盖。提供者消失/代变和切换设备取消受影响请求；不同提供者刷新互不干扰。

本实例 server load/unload（含 pluginPackages 的服务器启停）成功、失败或取消后，catalog-refresh 先撤销目标缓存/选择及相关请求，再重查操作和设备目录。重查失败仍不保留目标旧观测；远端变更需显式刷新。设备所有入口检查作用域关闭，实例和面板/组件/模块子生命周期合并请求取消，订阅随卸载释放。HTTP 错误保留服务 logId，本地准入错误不伪造日志 ID。

## 在线包与公开入口

runtime.pluginPackages 的 refresh/snapshot/subscribe 管理 server/browser 目录，upload(kind, Blob, mediaType, signal) 发送原始包和唯一 format=zip/tgz；enable/disable 显式启停，remove 先清理再 DELETE。安装/删除取消或失败后以独立生命周期重查实际目录。清理失败不发送 DELETE；HTTP 删除失败时部署可能仍存在，可依据新目录重新启用。重查失败也会向调用者报告，不能据等待结果假定变更回滚。

浏览器 remove 先停止当前 runtime 实例并撤销本实例包源。服务端删除静态包无法强制释放其他同事浏览器中的已运行代码；ESM 内存模块缓存不能卸出。新的 UUID 资源前缀保证入口及相对依赖使用新模块图，不能据此宣称旧模块从浏览器内存消失。

生产入口 `/assets/plugin-host.js` 导出 createFrontendRuntime/createNamedSlotAdapter，供实际宿主原生 ESM 导入。公开 HostContext 提供操作查询/订阅、任务提交/读取/取消，以及可选 devices、extensions、artifacts、taskHistory 和 themes；artifacts 提供原字节上传下载，taskHistory 提供持久任务与事件查询，旧宿主可省略这些入口，插件须先检查。serverPlugins、pluginPackages 仍属于 app 返回值，没有插件 SDK 管理入口。上传下载沿归属与挂载子作用域传递取消，取消等待不自动取消服务器 Job、不删除产物或承诺上传回滚；main.ts 现已通过无界面 bootstrap 装配产品 runtime，具体页面仍等待设计稿。
