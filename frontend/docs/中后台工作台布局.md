# 中后台工作台布局

日期：2026-10-14。用户授权沿用现有电子设备背景，以常规中后台布局实现前端。

## 职责与边界

本次采用 architecture-first。影响范围为应用外壳、导航、全局展示样式及行为验收；公开 HTTP、SDK、业务工厂与设备采集契约沿用现有实现。设备状态和入口继续来自实际操作目录与能力，页面不使用演示设备或虚构统计。

| 单元 | 职责与输入输出 | 副作用 | 不承担 |
| --- | --- | --- | --- |
| product/navigation.tsx | 路由元数据、当前路由、导航回调进入；输出分组导航 | 用户导航回调 | 网络、设备动作、业务状态 |
| product/shell.tsx | 订阅既有目录、设备与服务器状态，编排桌面折叠、移动抽屉和专注 | 原有刷新/设备选择与本地显示状态 | 业务规则、HTTP 请求实现 |
| app/styles.css | 背景、主题变量、工作面和响应式布局 | 样式渲染 | 页面生命周期、服务选择 |
| tests/App.test.ts | 导航、当前入口、折叠及草稿生命周期 | 受控 DOM | 视觉与真机证明 |
| scripts/product-ui-smoke.ts | 冻结生产构建，真实隔离宿主与浏览器行为、截图和进程回收 | 临时测试宿主与浏览器 | 连接设备、模拟器或桌面输入 |

从外壳拆出纯导航组件，避免把分组渲染、设备服务和界面状态继续集中。App 的已访问页面节点与草稿保留机制不变；外壳通过注入的服务读取和刷新，禁止直接 fetch 或以平台名称决定业务资格。主题变量与插件挂载点继续复用。

## 布局与交互

桌面采用左侧四组工具导航、顶部面包屑及服务器状态、设备上下文工具栏和主内容工作面。导航可以折叠为图标，仍提供完整无障碍标签。背景作为环境层保留，业务内容使用可读底色。窄屏使用官方 Sheet 导航抽屉，支持键盘关闭与焦点返回；业务表格局部横向滚动。专注模式只收起外围，页面节点和编辑草稿保留。

## 验证

采用 BDD：布局与键盘/草稿行为测试和开发并行，主代理串行执行生成接口、架构与严格类型检查、全部前端测试和生产构建，随后执行实际浏览器验收。全部截图交由子代理审核。结果与实际未验证边界在本轮交付记录汇总；不执行设备输入、息屏或性能压测。

## 公共组件与功能分层补充

用户要求公共目录覆盖自行封装的其他第三方 UI，因此公共根采用 `src/components`。现有官方控件迁到 `components/ui`，通用标题、空态、字段、结果和错误展示放 `components/common`，第三方封装按需放 `components/integrations/<库或能力>`；功能专用组件归 `features/<功能>/ui`。业务错误解析、服务订阅与能力判断保留在应用适配层，公共组件只接收普通数据和回调。功能目录按 application/domain/infrastructure/ui 分责，外部生产代码经功能根 index，具体规则由架构门禁执行。
