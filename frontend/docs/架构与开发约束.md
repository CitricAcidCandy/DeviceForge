# 前端文件骨架与开发约束

## 基础骨架
```text
frontend/
  src/app/               启动、路由装配、全局样式
  src/features/          后续设备、产物、任务、插件管理功能
  src/shared/api/        生成接口类型与后续 HTTP 客户端
  src/shared/ui/         纯展示组件与可访问性基础交互
  src/plugin-sdk/        公开扩展契约
  src/plugins/           贡献校验及后续加载、生命周期
  tests/                 插件契约与基础外壳测试
  scripts/               接口生成等开发工具
  public/                部署静态资源
  docs/                  仅前端文档
```

## 依赖方向
app 装配 features/plugins；features 使用 shared 与 plugin-sdk；plugins 依赖公开 SDK；shared 不引用 app/features；插件只依赖公开接口，不访问宿主私有模块。功能按业务用例划分，避免还原旧 renderer 目录和跨页面单例。

设备工作台按提供者贡献及能力驱动，平台特有流程通过面板扩展；规则见 [设备能力与插件面板](设备能力与插件面板.md)。通用界面不复制设备工具命令，不按平台枚举决定功能是否可用。当前设备上下文及能力 UI 尚未实现。

## 开发规则
- 只在接口适配器处理 HTTP、令牌、重试和错误映射；组件使用明确的状态与用例函数。
- HTTP 类型从后端模式生成，不复制后端实体定义。插件契约独立版本化，适配器承担 DTO 映射。
- 本阶段只提供骨架和契约，完整页面不得提前混入。
- 所有文档和代码注释使用中文；接口字段保留协议定义。
- 开启严格类型、索引检查与准确可选字段；不得用 any 绕过接口边界。
- 每个异步任务明确取消、销毁及失败行为；插件卸载必须释放订阅和 DOM。
- 不读取本机绝对路径，不使用 Electron 桥接，不将访问令牌保存在 localStorage 或 URL。
- 组件采用语义 HTML、键盘操作及可访问标签；长列表后续使用分页或虚拟化，并以实际数据测量性能。
- 仅从管理员认可的来源加载插件。第一阶段同页面插件视为受信任；面向非可信插件应设计隔离 iframe 与消息协议。
- 门禁：生成接口类型后执行 npm run check、npm test、npm run build。业务 UI 正式加入时补浏览器交互测试。

## 当前限制
外壳只展示开发进度，不提供设备交互。动态加载器、宿主上下文实现、完整 UI 及独立浏览器插件示例留待前端实施阶段，不能把类型定义当作已经可加载的插件系统。

## 自动架构门禁
完整执行要求见本端 AGENTS.md。`npm run check:architecture` 已接入 `npm run check`，使用 TypeScript 和 Svelte 解析器检查 import、重导出、类型引用及字面量动态导入。路径别名按 tsconfig 解析，拒绝跨工程源码、反向依赖、功能之间直接耦合及循环导入；UI 不引用 API，SDK 不引用宿主。网络直接调用只能放 shared/api，手写源码禁止 any；generated.ts 的生成类型独立保留。

规则及失败用例包含在 npm test。门禁检查静态导入和直接调用，不能证明网络函数别名、运行时模块加载、插件信任、视觉效果或资源释放正确；这些仍需审查与行为验收。新增动态加载方案须先更新契约和相应门禁。
