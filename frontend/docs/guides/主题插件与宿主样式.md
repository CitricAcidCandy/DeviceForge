# 主题插件与宿主样式

## 范围与实施门禁

本轮按 architecture-first 与 Hybrid 实施公开主题契约、运行中贡献和生命周期回归，具体产品页面与视觉设计继续等待设计稿。主题与组件、模块、命令等贡献共用插件所有权和运行代次；宿主显式选择主题，不按插件加载顺序覆盖当前样式。

选择独立纯校验、主题注册表与 DOM 适配，app 只装配目标节点。不把样式变更直接写入插件管理器或产品外壳，以免混合贡献规则、资源所有权与 DOM 副作用。

## 公开契约

SDK v2 增加可选 `PluginContributions.themes` 数组。每项 `ThemeContribution` 为 `{id,title,variables?,css?,colorScheme?}`：`variables` 为只读字符串映射，`css` 为可信插件的 CSS 原文，`colorScheme` 为 `light`、`dark` 或 `normal`。贡献 ID 延用 `<插件ID>.<名称>`，与同组其他贡献统一拒绝重复；跨登记的 ID 冲突也在发布前拒绝。

变量最多 128 项；名字必须为以 `--` 开头的 CSS 自定义属性、总长度不超过 128；值必须非空、长度不超过 4096。CSS 原文不超过 256 KiB UTF-8。标题不得为空。声明校验后复制并冻结，调用方之后修改原对象不能变更已登记内容或绕过限额。CSS 按可信代码处理，限额用于运行稳定性，不提供安全隔离或 CSS 语法保证。

变量名的支持字符为 Unicode 字母、数字、下划线和连字符。变量映射必须为普通对象或无原型对象，拒绝数组、Map 与类实例。SDK 类型不替代运行校验；在线 ES 模块的未知声明同样经过此门禁。

可选 `HostContext.themes` 为 `ThemeAccess`，提供：

- `snapshot()` 返回 `{themes,selected}`，其中 `themes` 为只读 `ThemeInfo[]`，`selected` 为当前 `ThemeInfo` 或 `null`。
- `ThemeInfo` 包含 `id/title/pluginId/generation` 与可选 `colorScheme`，不暴露可变贡献对象。
- `select(id)` 显式应用已登记主题；`select(null)` 清除当前主题并恢复宿主基础样式。
- `subscribe(listener)` 立即提供当前快照，后续目录或选择变化继续通知；返回释放函数。监听异常不能阻止其他监听、所有权撤销和基础样式恢复。

目录发布前先登记整组贡献、ID/route 所有权和撤销监听；通知回调重入卸载提供者时，不留下半登记主题。通知采用修订号与串行刷新：回调中选择或清除主题会中止本轮旧快照，剩余监听随后读取最新状态，不在选中已变更后继续发布旧选择。

`RuntimeOptions.themeTarget?: HTMLElement` 明确指定宿主主题目标。`runtime.themes` 与该 runtime 的 `host.themes` 始终提供发现和订阅能力。`createFrontendBootstrap` 将页面根节点作为默认主题目标，启动入口只装配 runtime，不自动加载或选择插件主题；主题选择仍由插件或后续宿主设置入口显式调用。未配置目标时不接触全局 `document`，选择非空 ID 抛 `HostError(protocol, theme_unavailable)`，不能把登记成功视为样式已应用。未知或已撤销 ID 使用同一错误代码；清除仍可调用。

## 样式所有权与恢复

可信 CSS 写入目标所属文档中独立的 `style[data-deviceforge-theme]` 节点，值为贡献 ID。每次只保留当前主题自己的节点；撤销删除该节点，不删除宿主或其他插件样式节点。CSS 原文可作用于整份文档，不承诺目标节点隔离。

CSS 变量与 `color-scheme` 临时写入目标的行内样式并带 `important`，使主题可以覆盖宿主原有行内 `important` 基线。应用前只记录主题所拥有属性的原值和优先级。切换、清除、卸载和运行实例关闭时精确恢复这些属性，保留其他行内样式，不删除整个 `style` 属性。宿主在主题生效期间应通过公开选择管理这些属性；独立修改主题占用属性不构成另一份可合并的主题层。

DOM 应用失败保留此前主题及其选择状态，不发布假成功。当前主题的提供者被撤销、停用、激活失败或卸载时恢复基础样式，不自动选择其他插件主题。其他已登记主题继续可发现和显式选择。

## 生命周期与验证

静态主题在激活前登记，插件可在 `activate` 中使用主题入口。动态 `extensions.register({themes:[...]})` 返回撤销函数；撤销后同 ID 可重新登记。动态和静态主题随 owner/generation 收敛，激活失败整代回滚。

实例、面板、组件和模块子作用域关闭后，旧 `themes.snapshot/select/subscribe` 拒绝调用；已登记订阅随作用域释放。退出单个挂载不自动清除其他作用域选择的全局主题，也不关闭兄弟作用域。提供者卸载与运行实例关闭负责清除该提供者主题。重载相同插件 ID 不复活旧上下文。

最小回归覆盖：限额和未知结构、统一 ID 冲突、静态/动态热登记、显式选择、变量/CSS/配色方案、行内重要基线恢复、切换、撤销、激活失败、旧代和挂载子作用域、监听异常、缺失目标及 runtime 关闭。前端生成器、check/test/build 与真实生产 ESM/在线包浏览器验收由主代理统一执行；源码交接不等于这些门禁或产品视觉已通过。

## 最小公开插件样例

以下 TypeScript 入口只依赖公开 SDK。实际在线包按既有流程编译为 ES 模块，不在浏览器直接导入宿主源码。`activate` 显式选择自己已登记的主题；若插件只提供主题目录而不要求自动选用，去掉该回调，宿主稍后调用 `runtime.themes.select('example-theme.dark')` 即可。

```ts
import type { WebPlugin } from '@deviceforge/plugin-sdk';

const plugin: WebPlugin = {
  id: 'example-theme',
  version: '1.0.0',
  apiVersion: 2,
  panels: [],
  contributions: {
    themes: [{
      id: 'example-theme.dark',
      title: '示例暗色主题',
      variables: {
        '--workbench-background': '#172033',
        '--workbench-foreground': '#f1f5f9',
        '--workbench-accent': '#7dd3fc',
      },
      css: '.workbench { background: var(--workbench-background); color: var(--workbench-foreground); }',
      colorScheme: 'dark',
    }],
  },
  activate: async (context) => {
    if (!context.themes) throw new Error('宿主未提供公开主题入口');
    context.themes.select('example-theme.dark');
  },
};

export default plugin;
```

`@deviceforge/plugin-sdk` 表示消费方配置的公开类型别名，不是本工程已发布的 npm 包。当前工程样例的实际公开类型入口是 `src/plugin-sdk/index.ts`；在线包只携带编译后 JavaScript，类型导入在构建时消除。样例 CSS 类名是消费方提供的公开样式选择器，本文不创建或假定现有产品页面。

宿主通过生产入口 `/assets/plugin-host.js` 的 `createFrontendRuntime` 注入 `themeTarget`。主题通常应用于宿主工作台根节点；可信全局 CSS 与变量的继承范围由消费方决定。运行实例、主题提供者和已有样式基线的实际恢复需要独立行为/浏览器证据，代码示例不能代替验证。
