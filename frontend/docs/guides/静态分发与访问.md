# 前端静态分发与访问

## 构建与访问

前端是独立 Svelte 5 / TypeScript 工程。开发执行 `npm ci` 与 `npm run dev`，Vite 将同源 `/api`、`/mcp` 转发到本机 Rust 开发端口 7031。正式构建执行 `npm run build`，生成 dist；根目录分发脚本复制 dist 到运行包 web，npx 启动器负责静态服务。

统一启动默认允许局域网访问，前端默认地址为 `http://服务器地址:7030`。CLI 的 `--ip` 和 `--port` 可修改监听；前端后续 HTTP 适配器继续使用同源相对地址，不写死服务器 IP 或端口。开发代理配置与正式静态分发分别维护。

## 职责与约束

- 静态资源不包含令牌，当前没有登录或令牌输入页面。默认免鉴权；配置令牌时由 shared/api 可选令牌提供器负责，禁止把凭据放入 URL 或 localStorage。
- 浏览器只传业务参数和产物 ID，不读取部署主机路径，不依赖 Electron 或本机进程桥接。
- 服务器与浏览器插件使用独立的包类型和运行生命周期。公开浏览器加载器、实际 HostContext、组件/模块/命令/服务/逻辑扩展与可选 devices 上下文已实现，在线上传和热装卸分别验收。
- 本端交付基础外壳、真实通信和插件运行框架，具体产品界面等待设计稿；开发遵守本端独立 AGENTS.md。

## 验证范围

本端检查为 `npm run generate:api`、`npm run check`、`npm test` 和 `npm run build`。根目录 npx 集成验证静态首页能够通过本机与本机局域网地址访问，不能据此宣称页面视觉、完整业务交互、另一台局域网客户端或真机已经验收。

当前设备版本的 production/runtime 已重建，独立 debug/release 真实浏览器验收覆盖两类在线包、动态依赖、界面替换与停用恢复、逻辑钩子及公开设备调用。分发包宿主与验收生产 ESM 摘要相同；真实 npx 安装公开设备示例并经 HTTP/MCP 验证设备能力。这些框架行为不替代产品页面视觉验收。
