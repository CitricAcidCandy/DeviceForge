# 浏览器插件开发契约

## 贡献
公开入口为 `src/plugin-sdk/index.ts`。插件声明 `id/version/apiVersion` 和 `panels`，当前 SDK 为 v2；v1 须升级版本、显式信号和 HostResult。每项贡献使用插件命名空间 `<插件ID>.<贡献名>`；重复插件、贡献 ID、模块路由和跨空间贡献拒绝注册。

`PanelContribution.mount(target, context)` 返回 Dispose，插件可声明 activate/deactivate。宿主已实现失败回滚整代、逆序清理与清理错误汇总。请求显式传信号，插件用 context.onDispose 登记 DOM 外资源，避免遗留定时器或全局监听。

可选 contributions 包含 components（slot/mode/mount）、modules（route/title/mount）、commands（execute）、services（version/invoke）和 beforeTaskSubmit（priority/transform）。components.mode 缺省 append，replace 须注入 SlotAdapter；createNamedSlotAdapter 管理具名默认 renderer，卸载恢复。

模块进入由宿主 extensions.mountModule(id) 挂载，退出 extensions.unmount(id) 撤销子信号与 DOM，保留模块登记与插件其他逻辑；再次进入可重挂载。插件卸载撤销全部入口，挂载失败回滚整代，路由元数据不自动创建 UI。

任务钩子实际在 tasks.submit 前执行，按 priority 升序（默认 0）再 id.localeCompare 排序，失败/撤销停止后续钩子及 HTTP；卸载后恢复剩余或原流程。动态 extensions.register 返回撤销函数，所有贡献与状态绑定插件运行代次。

## 宿主上下文
HostContext 已提供 listOperations/submit/getJob/cancelJob、subscribeOperations、signal/onDispose 及可选 extensions/devices，成功返回 data/logId，错误为 HostError。上下文不包含传输或服务令牌；本地免鉴权缺省不发送鉴权头。任务提交后仍应查询终态再展示执行结果。

runtime.serverPlugins/pluginPackages 属于宿主 app，公开 SDK 不提供这两类管理入口。SDK v2 已通过可选 `HostContext.artifacts` 提供 `ArtifactAccess`，`upload(filename, content:Blob, signal)` 返回 `HostResult<Artifact>`，`download(id, signal)` 返回 `HostResult<Blob>`；可选 `taskHistory`、`devices` 和 `themes` 分别提供 `TaskHistoryAccess`、设备和主题访问。旧宿主可省略这些字段，插件使用前须检查；独立契约以 [SDK README](../../src/plugin-sdk/README.md) 为准。extensions 支持版本化服务、命令、事件及自身状态命名空间。

A 调用 B 服务时，B 卸载取消在途信号；新调用收到 service_unavailable，A 保持启用。B 重载不复活旧上下文和旧调用结果，A 按 ID 发起的新调用可使用新 B。忽略信号的处理函数可能继续执行，宿主等待收敛后拒绝晚到结果。

服务端插件可独立贡献操作；浏览器插件面板通过公开操作 ID 调用它。前后端插件可以独立发布，无面板的服务器插件仍能被 API/MCP 调用，无服务器插件的前端插件可以展示宿主数据。

设备提供者与平台面板的交互目标见 [设备能力与插件面板](../implementation/设备能力与插件面板.md)。HostContext.devices 已作为 apiVersion 2 可选加法扩展接入；旧宿主可省略，插件使用前检查字段。异步入口为 refreshProviders(signal)、refreshDirectories(signal)、refreshProvider(id,generation,signal) 和 invoke(action,signal)，返回 HostResult；select(reference|null)、snapshot() 和 subscribe(listener) 提供公开选择与状态，subscribe 返回 Dispose。

独立 SDK DeviceRef 使用 providerId/generation/localId，DeviceAction 使用 providerId/generation/deviceId/capability/version/input。完整引用用于区分同名设备，动作按精确能力版本与作用域调用；无需导入生成 HTTP DTO 或宿主内部实现。refreshDirectories 读取已有观测，refreshProvider 才触发发现，刷新开始即清该代旧目录/选择，失败保持空；晚到结果不能恢复旧选择或旧代。

设备提供者声明 API 1/2 与浏览器 SDK apiVersion 独立。能力目录的可选 executionTimeoutMs 显式映射服务器 execution_timeout_ms，仅设备声明 API 2 可提供 1–120000 毫秒；API 1 仅允许未声明。null 与缺省均在 SDK 省略字段，宿主默认 30000 毫秒。插件只读取该元数据，不给 action、业务 input 或 invoke 增加预算覆盖语义；排队、锁、输入副本、执行与产物发布的总截止点由宿主控制。客户端取消等待与 cancelJob 沿现有规则，不自行重计时或自动重放。前端已补兼容测试源码，生成同步及门禁由主代理统一，未据此宣称长安装或平台迁出已验收。

设备全入口检查作用域关闭；异步请求合并调用者、宿主、插件实例和挂载子信号。退出面板/组件/模块取消子请求与订阅，保留插件其他逻辑；卸载实例取消全部设备访问。订阅可手动释放，也随 onDispose 收敛，关闭后不接收晚通知。HTTP 错误保留真实 logId，本地准入错误的 logId 为 null，不能构造服务日志 ID。invoke 接受任务后仍需 getJob 查询终态。

## 设备动作的嵌套输入产物

本轮冻结契约见后端 [插件嵌套输入产物实施](../../../backend/docs/implementation/插件嵌套输入产物实施.md)。浏览器通过 `HostContext.devices.invoke(action, signal)` 在 `action.input` 中传已有产物 ID；例如 `input: { artifact_id: artifactId }`。ID 必须来自宿主已上传或已有的产物，不能填写服务器绝对路径、浏览器本地文件路径或下载 URL。

下例中 context 为公开挂载上下文，reference 与 capability 来自当前提供者目录，已核对设备作用域、精确版本和可用状态，artifactId 为已有产物 ID：

```ts
const devices = context.devices;
if (!devices) throw new Error('宿主未提供设备能力');
const submitted = await devices.invoke({
  providerId: reference.providerId,
  generation: reference.generation,
  deviceId: reference.localId,
  capability: capability.id,
  version: capability.version,
  input: { artifact_id: artifactId },
}, context.signal);
```

对应服务器插件须在清单中声明以下片段；这是服务器插件的产物访问声明，不是浏览器 WebPlugin.contributions：

```json
{
  "artifacts": {
    "input_pointers": ["/input/artifact_id"]
  }
}
```

`/input/artifact_id` 相对于服务器操作接收的完整设备输入封套，浏览器只填写 action.input 的业务字段，封套由宿主处理。冻结契约要求宿主按声明选择 ID 并复制输入；业务 input 仍保留 ID，临时副本路径只存在于本次服务器插件进程的 artifacts 上下文，嵌套引用的 field 标签保留原 JSON Pointer。input_fields 继续只表示旧顶层字段，不解释成点号路径。

input_pointers 适用于服务器插件协议 2/3，协议 1 不支持产物声明。路径采用 RFC 6901 字符串形式，以 `/` 开头，支持 `~0`、`~1` 转义和规范数组索引，无通配符。终值可为 ID 字符串或全字符串数组；缺失路径跳过，必填应由操作 input_schema 约束，存在但为 null/对象/数字/混合数组或中间结构错误时拒绝。选择器合计最多 8 个，实际输入最多 8 个产物、64 MiB；单路径长度/深度及重复规则以冻结门禁为准。产物输入不扩大设备动作当前 30 秒总期限，不代表任意大包安装均已支持。

invoke 返回 `HostResult<Job>`，继续用 getJob 查询任务终态。带输出产物的协议 2/3 任务结果按 `{ result, artifacts }` 消费：SDK 的 `HostResult.data` 是 Job，`Job.result` 是该 JSON 包装，包装内 result 才是业务结果，artifacts 是发布产物信息；不能把 HTTP 的 data、Job.result 和业务 result 混作一层。读取前检查 JSON 对象、数组和实际业务字段，沿现有 HostResult.logId/HostError.logId 排查，不把任务 ID 或产物 ID 当日志 ID，也不公开服务器路径。

公开 SDK 已支持该标准 input：DeviceAction.input 为 JSON 对象，设备网关原样映射 input，Job.result 保留 JSON；HTTP/SDK 不新增 DTO 或接口版本。插件检测 `context.artifacts` 后可通过公开上传取得产物 ID，再填写设备业务 input，或下载任务实际发布的产物；不导入宿主私有模块或获取令牌。上传元数据映射为 camelCase `Artifact`，Job.result 内的产物包装仍保留其原 JSON 字段。

`artifacts.download` 返回 Blob 原字节，包括 JSON、NUL 和非法 UTF-8；成功下载保留响应头中的日志 ID，未取得日志时为 null，HTTP/协议错误沿 `HostError` 传递。下载请求的 logId 与提交、任务查询的 logId 分开，不能以任务 ID 或产物 ID 代替。公开下载不自动解析业务封套，也不自动比对产物大小或 SHA-256；需要完整性检查时由消费者依据任务实际发布的元数据核对。

上传下载显式传 AbortSignal，调用者、宿主、插件归属及挂载子作用域共同约束等待；退出或卸载撤销旧入口和晚到交付，已交付结果不会被撤回。取消产物等待不自动调用 cancelJob、不删除产物，也不承诺已接纳上传回滚；需要取消服务器任务时显式调用 `cancelJob` 并查询终态。产物下载按 ID 调用，不绑定设备 selection，切换设备后的旧内容显示由消费者以自己的信号或引用检查收敛。SDK 不创建 Blob URL，插件自行创建时须通过 onDispose 登记回收，替换内容时也须释放旧 URL。

实例与挂载子信号、取消和旧代保护沿现有设备生命周期；取消不表示服务器回滚，不自动重放写动作。当前嵌套副本、发布/下载、日志及热装卸由主代理完成 debug/release 各 42 项真实检查及 npx 两协议分发验收，报告见根 artifacts/nested-device-artifacts-smoke-*.json；不以旧第一阶段报告替代。

## 实施状态
公开生产入口 `/assets/plugin-host.js` 导出 createFrontendRuntime/createNamedSlotAdapter。宿主注入 esmImporter 加载已安装包；每次 load 创建 UUID 资源路径，相对依赖共享代次。上传、目录、启停与删除经 runtime.pluginPackages；安装只部署，不自动执行。`main.ts` 已通过 `createFrontendBootstrap` 装配产品 runtime，并把页面根节点作为默认主题目标；具体业务界面和主题设置入口仍等待设计稿。

browser 删除先停当前实例并撤销其源；其他同事浏览器实例不能由服务端强制停止，已执行 ESM 内存缓存不能卸出。在线代码按可信代码运行，未登记全局副作用由插件负责；同页面不能强制终止不响应取消的函数。

前阶段通用在线扩展的 debug/release 独立浏览器验收覆盖生产公开入口、两类在线包、ESM 相对依赖新代、面板/组件替换/模块、命令/服务/状态和真实任务钩子/停用恢复，记录位于根 artifacts/browser-plugin-smoke-debug.json 与 browser-plugin-smoke-release.json。保留当时的验收范围；设备第一阶段的独立历史见 [第一阶段实施](../implementation/设备提供者第一阶段实施.md)，上述历史记录不证明本轮嵌套输入产物或产品视觉已验收。
