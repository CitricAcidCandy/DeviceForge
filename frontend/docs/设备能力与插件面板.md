# 设备能力与插件面板

## 前端职责与当前状态

设备界面的候选目标为基础工作台、设备目录、任务/产物视图和扩展面板。设备发现与连接由服务端提供者贡献，浏览器通过宿主公开 API 调用；前端不运行 ADB/HDC，不接触设备工具路径，不按 Android/iOS 枚举编写连接实现。

本文保留候选界面职责与后续交互评估；第一阶段设备 HTTP 客户端、目录/选择/离散动作基础用例，以及 SDK v2 可选 `HostContext.devices` 已实现，见 [第一阶段实施](设备提供者第一阶段实施.md)。通用客户端、运行宿主、面板和在线开放扩展已有 debug/release 浏览器证据；设备页面、常驻设备会话和完整设备热拔插仍需独立实施与验收。本文不新增手写 DTO 或具体页面。

## 设备目录与能力驱动交互

- 设备列表读取宿主聚合结果，按公开的宿主设备引用选择设备；显示名称或序列号不能代替调用身份。提供者不可用、未授权和离线状态需明确呈现。
- 平台名称用于展示和筛选。安装、截图、输入、性能等入口根据所选设备的能力版本、当前可用状态和权限启用；不能以 `platform === 'android'` 代替能力判断。
- 通用连接入口发现提供者及其公开连接操作模式。配对、远程地址等平台特有流程可由对应插件面板呈现，通用组件不复制平台命令与参数规则。
- 不支持的功能显示具体原因；设备断线后保留可理解的状态和任务历史，不展示虚假成功或自动重复提交写操作。
- 设备能力和操作列表发生变化时更新入口，保留观测时间；销毁页面、切换设备和移除插件时取消请求并清理订阅，晚到结果不能覆盖当前设备。
- 同一能力由多个提供者贡献时呈现宿主已选定的来源；需要用户选择时显示明确来源，不依赖注册顺序。

## 浏览器扩展契约

服务端设备插件与浏览器面板可以独立发布。无专属面板的提供者仍可通过通用设备视图和公开操作使用；平台面板增强特有体验，不能成为 API/MCP 可用的必要条件。

当前面板通过版本化 `HostContext` 获取操作/任务、开放扩展和可选 devices。设备入口保持 apiVersion 2 加法兼容：refreshProviders/refreshDirectories/refreshProvider/invoke 返回 HostResult，select/snapshot/subscribe 访问公开状态。SDK DeviceRef 使用 providerId/generation/localId，HTTP 字段由宿主显式映射。旧宿主可不提供 devices；面板不得导入 `features` 内部状态、生成的后端私有实现或自行获取服务令牌。声明式输入模式仅用于明确支持的表单类型，复杂流程由公开面板贡献完成，不执行任意字符串脚本。

通用管理器已记录挂载、失败回滚对应插件整代，并逆序释放 DOM、事件和订阅，其他插件保持运行。设备请求合并插件实例和挂载子信号，卸载撤销订阅及晚到结果；提供者消失/代变撤销旧目录与选择。本实例服务器管理后立即撤销目标旧缓存再重查，其他实例变化需显式刷新。设备任务/产物的具体视图仍未实施。上传只部署，显式 enable/mount 才执行或挂载；通用插件热装卸不能证明常驻设备层已动态热拔插。

## API、日志与验收

### 设备动作与产物 ID

本轮嵌套产物契约见后端 [插件嵌套输入产物实施](../../backend/docs/插件嵌套输入产物实施.md)，具体调用示例见 [插件开发](插件开发.md)。面板通过 HostContext.devices.invoke 在 action.input 填写已有产物 ID，例如 `{ artifact_id: artifactId }`；对应服务器插件声明 `artifacts.input_pointers: ["/input/artifact_id"]`，从完整设备输入封套选择产物。业务输入始终是 ID，不能给服务器路径；副本路径只供本次服务器插件进程使用，不进入公开设备输入或面板状态。

宿主 app 保留 runtime.artifacts 上传/下载入口；SDK v2 已通过可选 HostContext.artifacts 提供 ArtifactAccess 原字节上传/下载，可选 taskHistory 提供持久任务/事件查询，可选 devices 提供设备目录与动作。旧宿主可省略这些字段，面板使用前须检查，不直接调用 app 私有入口。产物等待沿 caller、宿主、插件与挂载子作用域取消，撤销后拒绝晚到交付；取消等待不自动取消服务器 Job、不删除产物或承诺上传回滚。协议 2/3 带产物任务的 Job.result 保留 `{ result, artifacts }` 包装，result 是业务结果，artifacts 是发布产物信息；面板先查询任务终态，再校验 JSON 结构，不将原始路径作为下载入口。

DeviceAction.input 已支持标准 JSON 对象，SDK 与 HTTP 不新增 DTO，日志继续使用 HostResult.logId/HostError.logId。设备切换、子挂载退出、实例卸载的取消与晚到保护沿既有规则，取消不代表写动作回滚。当前嵌套副本、输出产物和真实调用已由主代理通过 debug/release 各 42 项检查及 npx 两协议分发验收；报告见根 artifacts/nested-device-artifacts-smoke-*.json。该证据不代表设备 UI、远端推送、平台迁出或真机验收。

设备接口类型继续由后端 OpenAPI 生成，`shared/api` 映射为公开前端 SDK；禁止在组件或插件各写一份设备 DTO。能力和面板契约独立版本化，升级保留明确兼容范围。

现有 HTTP 适配器已读取关联日志 ID 并通过公开 SDK 传递；后续设备错误界面应提供复制入口。任务 ID、请求日志 ID 和插件请求 ID 各有用途，不混用。二进制下载从规定响应头读取关联 ID；响应包装变更必须与生成类型及客户端一起升级，不在页面拼接协议细节。浏览器不读取服务器日志路径或敏感日志内容。

实施后的最低行为验收包括：不支持能力、未授权/离线、提供者崩溃或移除、多个提供者、切换设备后晚到响应、插件挂载失败与卸载清理、失败日志 ID 的可见与复制。新增交互执行浏览器验收，类型和构建通过不能证明真实设备交互通过。

设备宿主上下文已实际接入 runtime，设备 UI 仍未实现；`main.ts` 已通过 bootstrap 装配产品 runtime，但不自动提供设备页面或主题设置入口。check/test 的设备作用域、能力和竞态回归不代表真机交互或视觉通过；生产设备浏览器证据由主代理独立汇总。后端适配器实现与传输协议说明保留在后端项目，本端只约束公开接口消费与浏览器交互。
