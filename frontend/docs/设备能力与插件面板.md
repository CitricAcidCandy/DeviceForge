# 设备能力与插件面板

## 前端职责与当前状态

浏览器工程提供基础工作台、设备目录、任务/产物视图和扩展面板管理。设备发现与连接由服务端提供者贡献，浏览器通过宿主公开 API 调用；前端不运行 ADB/HDC，不接触设备工具路径，不按 Android/iOS 枚举编写连接实现。

本文为候选职责与后续交互评估，具体设备 API 和面板上下文尚未定稿；热拔插是整个项目的明确目标。当前仍只有 Svelte 外壳、生成 API 类型、公开 SDK 和贡献校验；设备页面、运行时宿主上下文、面板加载器及能力接口尚未实现。本文不新增手写 DTO，也不修改现有 `HostContext`。

## 设备目录与能力驱动交互

- 设备列表读取宿主聚合结果，按公开的宿主设备引用选择设备；显示名称或序列号不能代替调用身份。提供者不可用、未授权和离线状态需明确呈现。
- 平台名称用于展示和筛选。安装、截图、输入、性能等入口根据所选设备的能力版本、当前可用状态和权限启用；不能以 `platform === 'android'` 代替能力判断。
- 通用连接入口发现提供者及其公开连接操作模式。配对、远程地址等平台特有流程可由对应插件面板呈现，通用组件不复制平台命令与参数规则。
- 不支持的功能显示具体原因；设备断线后保留可理解的状态和任务历史，不展示虚假成功或自动重复提交写操作。
- 设备能力和操作列表发生变化时更新入口，保留观测时间；销毁页面、切换设备和移除插件时取消请求并清理订阅，晚到结果不能覆盖当前设备。
- 同一能力由多个提供者贡献时呈现宿主已选定的来源；需要用户选择时显示明确来源，不依赖注册顺序。

## 浏览器扩展契约

服务端设备插件与浏览器面板可以独立发布。无专属面板的提供者仍可通过通用设备视图和公开操作使用；平台面板增强特有体验，不能成为 API/MCP 可用的必要条件。

面板只通过版本化 `HostContext` 获取设备能力、操作及任务服务。宿主公开设备上下文和贡献过滤方式后，再升级 SDK 并提供适配器；面板不得导入 `features` 内部状态、生成的后端私有实现或自行获取服务令牌。声明式输入模式仅用于明确支持的表单类型，复杂流程由公开面板贡献完成，不执行任意字符串脚本。

插件面板失败应局限于对应扩展。加载器记录挂载结果，失败回滚，卸载按顺序释放 DOM、事件和订阅；提供者移除后关闭依赖它的交互入口，但任务与产物视图保留。运行中热装卸尚未实现，安装完成不代表页面已动态加载插件。

## API、日志与验收

设备接口类型继续由后端 OpenAPI 生成，`shared/api` 映射为公开前端 SDK；禁止在组件或插件各写一份设备 DTO。能力和面板契约独立版本化，升级保留明确兼容范围。

后续 HTTP 适配器读取服务端返回的关联日志 ID，并随错误对象传递给任务/错误展示；用户可复制 ID 供排查。任务 ID、请求日志 ID 和插件请求 ID 各有用途，不混用。二进制下载从规定响应头读取关联 ID；响应包装变更必须与生成类型及客户端一起升级，不在页面拼接协议细节。浏览器不读取服务器日志路径或敏感日志内容。

实施后的最低行为验收包括：不支持能力、未授权/离线、提供者崩溃或移除、多个提供者、切换设备后晚到响应、插件挂载失败与卸载清理、失败日志 ID 的可见与复制。新增交互执行浏览器验收，类型和构建通过不能证明真实设备交互通过。

当前文档修改不代表上述 UI 和宿主上下文已经实现。后端适配器实现与传输协议说明保留在后端项目，本端只约束公开接口消费与浏览器交互。
