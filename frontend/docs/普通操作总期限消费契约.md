## 公开模型与读取

普通目录非空 execution 表示服务器已经固化的有效总预算，而不是客户端请求参数。HTTP 字段与独立 SDK 的对应如下：

| 生成 HTTP 字段 | SDK 字段 | 接受规则 |
| --- | --- | --- |
| `execution.api_version` | `execution.apiVersion` | 严格为数值 1 |
| `execution.total_timeout_ms` | `execution.totalTimeoutMs` | 数值、安全整数，闭区间 1–3600000 毫秒 |
| `execution.source` | `execution.source` | 严格为 `default` 或 `declared` |

execution 非空时必须是恰含三个规定字段的对象；缺必填项、未知字段、数组、非数字、非整数、非有限数字、越界值、未知版本或来源均拒绝。不将字符串转数字，不更正版本或来源，不裁剪预算。`default` 表示服务器选择普通缺省，`declared` 表示服务器采用贡献声明；前端不自行决定来源，也不从操作 ID、平台或插件名称判断预算类别。旧别名的有效预算由服务器发布，前端不根据别名反推实际目标。

下例放在插件异步回调中，context 为公开 HostContext，operationId 与 signal 由调用方提供。只读取目录，不增加提交参数：

```ts
const directory = await context.listOperations(signal);
const operation = directory.data.find((entry) => entry.id === operationId);
if (!operation) throw new Error('当前目录没有此操作');

const execution = operation.execution;
const apiVersion = execution?.apiVersion;
const totalTimeoutMs = execution?.totalTimeoutMs;
const source = execution?.source;
// 三项均可能未发布；不能以缺省数值替换，更不能传作执行覆盖。
const responseLogId = directory.logId;
```

客户端成功继续从 HostResult.data 读取数据，响应日志使用 HostResult.logId。直接 listOperations 仅返回查询结果；需要发布缓存和 SDK 订阅时，由宿主调用既有 runtime.operations.refresh，不能把直接查询等同于订阅状态已经刷新。

## 缺省、null 与协议错误

旧 HTTP 目录缺少 execution 或 execution 为 null，SDK 都省略 execution 属性；不保留 `execution: undefined` 或 `execution: null`，也不猜测补 60000 毫秒。新版普通目录由后端明示有效值，前端不能把旧响应缺失或特殊操作的省略解读成普通缺省。设备能力仍按独立的 executionTimeoutMs 及设备 API 规则消费；设备发现和性能专用采样不继承普通目录预算。

未知版本、未知 source 和其它非法执行元数据属于 protocol 错误，不降级为无预算操作。合法 v2 包装内的非法目录由客户端拒绝为 invalid_response；SDK 映射为 HostError，保留响应状态和真实 logId。公开适配器自身再次校验失败时使用 invalid_execution，publicCall 继续补入该次响应的真实 logId。裸映射函数没有响应上下文，不构造日志 ID。

```ts
try {
  await context.listOperations(signal);
} catch (error) {
  if (error instanceof HostError && error.kind === 'protocol') {
    // HostError 从公开 SDK 导入；关联现有响应日志，不用任务 ID 代替。
    const responseLogId = error.logId;
    const protocolCode = error.code;
  }
  throw error;
}
```

非法响应不能作为新目录发布；这不等于服务器实际目录为空，也不能据此自动重放提交或管理变更。

## 提交与总期限所有权

浏览器只能读取 execution，不能通过提交参数、HTTP 查询、SDK 选项或业务 input 延长、覆盖或重新开始服务器总期限。业务 input 保持原样；若业务 schema 自身含同名字段，它仍只是业务数据，不取得期限控制语义。不要因目录预算变化给 submit 自动加字段。

```ts
const accepted = await context.submit(operationId, businessInput, signal);
const jobId = accepted.data.id;
const submitLogId = accepted.logId;
```

服务器按冻结契约在准入时取得实际目标及有效预算，覆盖验证、创建、排队、输入准备、执行、输出发布与成功资格，子步骤不刷新预算。前端不从浏览器发请求的时刻计算服务器剩余时间，不按预算自行写入 Job 终态，不把长预算理解为清理或卸载等待也被延长。取消或到期不能证明所有副作用均停止或全部产物回滚。

## 目录撤销与历史任务

execution 随当前完整操作目录发布、替换和撤销，listOperations 与 subscribeOperations 共用公开映射。本实例服务器管理沿既有 app/catalog-refresh 装配撤销操作目录并通知空列表，再通过公开查询重查；管理失败、取消或重查失败不能恢复不可靠旧目录。撤销前旧查询即使忽略 AbortSignal 晚到，也不能复活目录；随后新的成功刷新可以恢复可用入口。

未刷新初始状态、真实空目录、撤销后的空目录和查询错误须区别消费。真实空响应保留本次响应日志 ID；本地撤销没有服务器响应，日志 ID 为 null，不沿用旧日志冒充新查询。远端同事实例的管理变化仍需显式刷新，没有新增推送或自动后台重查承诺。目录撤销不自动卸载无服务依赖的浏览器插件；面板应以当前公开目录检查可用操作，不缓存永久可执行资格。

Job 模型、Job.result 业务包装及事件保持原契约。历史 Job 不从当前目录补 execution、有效预算或 source；同 ID 操作重载、别名换目标、目录暂空或新预算发布，都不能改写旧任务结果或据此解释旧任务当年的预算。查询旧任务不要求它的 operation 仍在当前目录，也不能将查询到旧任务等同于该入口当前可提交。未提供历史预算快照，就保持不可得。

## 客户端 Abort 与服务器 Job 取消

| 动作 | 前端应作的解释 | 不能据此断言 |
| --- | --- | --- |
| 调用者 AbortSignal 取消 | 结束本次客户端等待，阻止晚到结果回写本调用 | 已接受的服务器 Job 被取消、事务回滚或进程已停止 |
| 插件卸载或挂载退出 | 撤销所属作用域请求、订阅与登记资源；旧上下文不可复用 | 服务器任务自动取消，可信插件未登记副作用被强制停止 |
| 显式 context.cancelJob(id, signal) | 发出已有 Job 取消请求，消费返回状态与真实日志 ID | 取消一定战胜成功提交，物理资源已完全清理 |
| 服务器总期限到期 | 按后端终态和错误规则消费服务器结果 | 浏览器拥有准确截止点，清理风险可忽略 |

需要取消已接受的 Job 时，通过仍存活的调用作用域和未取消的信号显式调用 cancelJob；已 Abort 的原信号或已卸载插件的旧上下文不能作为新的有效调用入口。是否由宿主主动取消服务器 Job 属于明确的宿主业务策略，本批没有增加自动取消或自动重放。已知 Job ID 后继续使用已有 getJob 查询规则；本批没有新增轮询、事件重连或进度协议。

## 回归与验收边界

六项测试定义覆盖：缺省/null 在公开查询和订阅中省略、上下界及后端明示来源透明映射、别名字段逐项消费、严格非法值拒绝、HTTP/SDK 与适配器协议日志传递、业务提交原样及目录变化不补历史任务。它们使用受控响应，不能证明服务器准入起点、成功资格竞争、真实进程期限或资源清理。别名测试只证明已发布字段的前端消费，不冒称后端别名注册继承已经验收。

截至本说明冻结，前端角色只完成实现交接和 UTF-8、差异、类型绕过文本检查，未运行生成器、类型检查、测试、构建或服务。主代理需要先生成带可选/null execution 的 OperationDto，再统一执行前端门禁；类型字段落盘不等于上述检查通过。

本批真实协议 2/3 长进程尚未由此前端交接验证。至少一次实际执行越过旧 60 秒窗口并成功，才能关闭真实长执行判据；已有设备 120 秒、RAW 浏览器、旧 release/npx 报告均不能代替本批证据。后端确定性矩阵、HTTP/MCP、生产浏览器、全量门禁、release/runtime 和 npx 由主代理分层记录。本说明不宣称平台迁出、常驻会话、真机、产品 UI 或本批分发完成。
