# 服务器插件生命周期消费

当前前端仍是骨架，只同步生成类型与消费约束，不提供插件管理页面或浏览器动态加载器。

## 接口与状态

使用 generated.ts 中插件管理路径的响应类型和 v2 日志包装；PluginInfo/PluginState 由后端 Rust 生成，目前在 TypeScript 中内联于响应，禁止手写重复 DTO。GET /api/v2/plugins 返回已加载或正在排空的服务器插件；POST /api/v2/plugins/{id}/load、/unload 只传管理员已部署的插件 ID，浏览器不得提交服务器路径、入口或清单。

loaded 可贡献操作；draining 已撤销新调用并等待清理，同 ID 暂不能重载；unloaded 是成功卸载返回值，之后不在当前列表中。generation 标识一次加载，重载同 ID 也产生新值。protected 表示启动配置中的长期依赖，当前拒绝运行中卸载，界面后续应解释原因。

## 取消与目录变化

AbortSignal 只中断客户端等待，已接收的管理变更仍由宿主收敛。取消或网络失败后重新读取列表，不推断操作已回滚，也不自动重复提交变更。错误传递 log_id，任务历史与产物不因卸载消失。

操作目录随加载/撤销变化，后续共享 API 适配器重新读取公开目录；当前无推送机制。面板依赖的操作消失时收敛入口和订阅；同 ID 重载不能复用旧代际状态，晚到响应不得覆盖新状态。

服务器通用进程插件热装卸与浏览器面板加载分别验收。设备提供者、常驻设备会话、公开设备上下文及浏览器运行时插件仍待实施；当前接口不能证明设备层热拔插完成。
