# 服务器插件生命周期消费

当前前端已实现客户端、服务器管理与两类在线包基础用例、浏览器动态加载和开放扩展；产品管理页面尚未设计，main.ts 未装配产品 runtime。

## 接口与状态

使用 generated.ts 中插件管理路径的响应类型和 v2 日志包装；PluginInfo/PluginState 由后端 Rust 生成，目前在 TypeScript 中内联于响应，禁止手写重复 DTO。GET /api/v2/plugins 返回已加载或正在排空的服务器插件；POST /api/v2/plugins/{id}/load、/unload 只传已部署的插件 ID，不提交服务器路径。在线部署另通过 runtime.pluginPackages 上传原始 ZIP/TGZ 并显式 enable；默认本地免鉴权，令牌可选。

loaded 可贡献操作；draining 已撤销新调用并等待清理，同 ID 暂不能重载；unloaded 是成功卸载返回值，之后不在当前列表中。generation 标识一次加载，重载同 ID 也产生新值。protected 表示启动配置中的长期依赖，当前拒绝运行中卸载，界面后续应解释原因。

cleanup_failed 是必填布尔字段，客户端原样保留。draining/cleanup_failed 表示仍需收敛，不能以取消等待、管理错误或本地快照删除代替后端实际完成卸载；服务器包删除前重查并卸载，后端拒绝时不继续 DELETE。

## 取消与目录变化

AbortSignal 只中断客户端等待，已接收的管理变更仍由宿主收敛。取消或网络失败后重新读取列表，不推断操作已回滚，也不自动重复提交变更。错误传递 log_id，任务历史与产物不因卸载消失。

服务器管理用例已在加载/撤销成功、失败或取消后重新读取插件与操作目录，不自动重放；当前无服务端推送机制。面板依赖的操作消失时应收敛入口和订阅；同 ID 重载不能复用旧代际状态，晚到响应不得覆盖新状态。

服务器通用进程插件与浏览器运行状态独立。当前 HostContext 仅提供操作/任务和开放扩展；runtime.serverPlugins/pluginPackages/artifacts 属于宿主 app，插件尚无管理/产物 SDK 适配。

browser 删除先停当前 runtime 实例再删静态部署，不会强制停止其他同事浏览器实例；已执行 ESM 内存缓存无法卸出，新 UUID 资源路径仅保证新 load 入口及相对依赖使用新模块图。清理或删除失败向调用者报告，部署仍存在时可重新 enable。

主代理已通过生产公开入口的 debug/release 真实浏览器在线包与运行热装卸验收，见根 artifacts/browser-plugin-smoke-debug.json 与 browser-plugin-smoke-release.json。设备提供者、常驻设备会话与公开设备上下文仍待实施；通用插件证据不能证明设备层热拔插。
