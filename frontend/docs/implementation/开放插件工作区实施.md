# 开放插件工作区实施

## 目标与实施门禁

模式为 architecture-first；采用 Hybrid：契约、依赖撤销与实例规则先写行为单元，新界面先交付真实可编辑设计稿并由用户确认。复用现有 SDK v2、插件管理器、作用域、任务和公共服务，不引入 Cordis，不建立第二套执行或生命周期体系。

最终要求是：独立开发跨页面、前后端配套插件时，不修改宿主业务源码、固定路由或槽位枚举。不得用新增接口存在、空目录扫描或单一夹具通过，替代全部官方业务和外壳迁移完成。

## 分层与首批文件归属

| 单元 | 输入与输出 | 副作用与边界 |
| --- | --- | --- |
| plugin-sdk/points、workspace、transport | 开放扩展点、布局与通信的公开契约 | 仅类型，不依赖宿主私有模块 |
| plugins/points | 定义与贡献进入注册表，输出目录和本地有效贡献 | 订阅与作用域撤销；不运行新的插件管理器 |
| plugins/workspace | 页面、工作区、视图及实例操作，输出不可变布局与目录 | 通知订阅；不创建 DOM、不执行业务 |
| plugins/workspace-rendering、workspace-mounts | 公开挂载请求进入既有扩展挂载层，输出本次释放句柄 | 绑定调用方、实例与提供者代次；不装配可见布局、不新建管理器 |
| app/workspace-storage | 未知 JSON 与模型保存快照，输出布局及存储诊断 | 注入存储并按服务器隔离；不打开实例、不重放动作 |
| plugins/scope 与 extensions/registry | 为现有插件、挂载和功能子作用域提供组合能力 | 使用已有资源追踪与撤销，不共享未经约束的根上下文 |
| app/plugin-transport | 公开请求映射为现有 API 客户端请求 | 网络、取消、流释放；不暴露令牌、不自动重试 |
| 官方插件工程 | 公开上下文和业务输入，输出页面、服务、数据 | 业务由插件自身拥有；不导入宿主私有工厂 |

主代理负责 SDK 总入口、作用域、注册表和 runtime 接线及交付记录；扩展点、工作区纯模型、通信适配分别独占文件。生成 HTTP 类型仅由主代理执行，本批无 Rust 契约修改时不运行生成器。所有注释、文档使用中文和 UTF-8。

## 必须保持的契约

- 同一插件仍由原管理器负责装卸。子作用域撤销只撤销本次贡献、订阅和流；迟到释放不能误删新代。
- 扩展点定义使用插件命名空间和精确版本；贡献允许先于目标出现。等待、版本不符、输入无效分别可诊断。
- 追加项按显式顺序和稳定 ID 排列；替换由用户显式选择。注册不自动抢占当前视图或外壳。
- 本地运行载荷可以包含组件函数，但目录只输出可序列化元数据；跨端不传函数和共享内存对象。
- 布局只保存稳定身份、几何及数据，不保存运行时代次与组件。提供者卸载后保留缺失占位，恢复不重放操作。
- 官方插件与第三方同等使用公开能力。迁移后的业务停用时无内置偷偷回退，最小恢复入口不依赖业务外壳。
- 旧 components/modules/panels、服务和主题接口以及具名槽位原语义保留。

## 2026-10-29 已接线的行为

公开扩展点、页面／视图、数据源随原插件和功能子作用域撤销；服务依赖恢复时建立新功能作用域。真实管理器测试已验证扩展撤销、保留布局、独立功能继续可用和旧结果隔离。

`HostContext.ui.mount` 是可选的公开渲染入口。默认 runtime 经同一管理器注入挂载桥；官方外壳可以使用它渲染另一插件的视图，不需要读取私有注册表。实际 DOM、资源和预算复用原 `createExtensionMounts`；释放句柄绑定本次实例代次。纯模型不实现挂载，也不自动恢复业务操作。

布局存储由 runtime 注入，默认复用浏览器本地存储，并按服务器来源隔离。恢复仅恢复 JSON 和失活占位；新插件需要显式重新认领实例。损坏或拒绝存储仅暂停自动持久写，仍可注册和使用插件；显式重读与保存当前布局分为两个动作。

根公开通信同样绑定 runtime 生命周期；关闭运行时立即结束等待并撤销传输信号，不等待忽略取消的上游返回。该修正先以实际 runtime 单元复现，再接入已有作用域包装；取消等待仍不代表后台 Job 已取消。

通用数据源读写复用版本化服务。服务回调经数据源间接转调仍继承父调用链及绝对期限，不重新起一条不受约束的调用链。调试器按目标及提供者代次消费扩展点、实例和数据目录；统一数据源不要求再次登记调试白名单。持久性省略时保持未知，不推断为内存数据。

SDK 发行物为 `sdk/dist/deviceforge-plugin-sdk-0.1.0.tgz`，实际本地包未发布 registry。最终候选为 15,452 字节、35 个成员，SHA-256 为 `1d192f0c679f6dbbfaa3c50ad3f7de9a288be0943bea39e1479b37ac924534a5`。实际归档在独立严格类型工程中消费，无宿主源码输入；可选 UI 类型依赖如实声明，不内联 React。

公开 MCP 保持八主题及版本 4，在原 `frontend/sdk` 正文拼接组合指南，未增加请求枚举。源码知识与指南单元已更新，运行中的旧宿主不会因此热更新。
