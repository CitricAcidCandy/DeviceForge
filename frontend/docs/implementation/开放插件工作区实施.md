## 必须保持的契约

- 同一插件仍由原管理器负责装卸。子作用域撤销只撤销本次贡献、订阅和流；迟到释放不能误删新代。
- 扩展点定义使用插件命名空间和精确版本；贡献允许先于目标出现。等待、版本不符、输入无效分别可诊断。
- 追加项按显式顺序和稳定 ID 排列；替换由用户显式选择。注册不自动抢占当前视图或外壳。
- 本地运行载荷可以包含组件函数，但目录只输出可序列化元数据；跨端不传函数和共享内存对象。
- 布局只保存稳定身份、几何及数据，不保存运行时代次与组件。提供者卸载后保留缺失占位，恢复不重放操作。
- 官方插件与第三方同等使用公开能力。迁移后的业务停用时无内置偷偷回退，最小恢复入口不依赖业务外壳。
- 旧 components/modules/panels、服务和主题接口以及具名槽位原语义保留。

## 2026-10-29 已接线的行为

公开扩展点、页面／视图、数据源随原插件和功能子作用域撤销；服务依赖恢复时建立新功能作用域。真实管理器测试已验证扩展撤销、保留布局、独立功能继续可用和旧结果隔离。

`HostContext.ui.mount` 是可选的公开渲染入口。默认 runtime 经同一管理器注入挂载桥；官方外壳可以使用它渲染另一插件的视图，不需要读取私有注册表。实际 DOM、资源和预算复用原 `createExtensionMounts`；释放句柄绑定本次实例代次。纯模型不实现挂载，也不自动恢复业务操作。

布局存储由 runtime 注入，默认复用浏览器本地存储，并按服务器来源隔离。恢复仅恢复 JSON 和失活占位；新插件需要显式重新认领实例。损坏或拒绝存储仅暂停自动持久写，仍可注册和使用插件；显式重读与保存当前布局分为两个动作。

根公开通信同样绑定 runtime 生命周期；关闭运行时立即结束等待并撤销传输信号，不等待忽略取消的上游返回。该修正先以实际 runtime 单元复现，再接入已有作用域包装；取消等待仍不代表后台 Job 已取消。
