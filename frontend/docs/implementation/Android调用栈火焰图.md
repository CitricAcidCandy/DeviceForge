# Android 调用栈火焰图

本增量采用 architecture-first 与 Hybrid：采集协议和原栈保持既有版本，纯聚合、归档兼容、React 交互分别落入独立文件。用户已接受缺符号，后续符号包不作为当前使用条件。

| 模块 | 职责 | 输入输出 | 副作用 |
| --- | --- | --- | --- |
| flamegraph.ts | 事件、进程、线程和根到叶树；精确权重与质量统计 | 已解码 StackSample、筛选条件到 ProfileFlamegraph | 无 |
| folded.ts | 重建/核对插件的可选折叠栈 | 同次原栈与 UTF-8 原字节 | 无 |
| flamegraph-layout.ts | 有界可见节点与精确比例映射 | 火焰树、焦点节点到色块坐标 | 无 |
| flamegraph-view.tsx | 搜索、筛选、缩放、区间快捷选择和质量提示 | 原栈、指标区间到 React 展示 | 本地状态与滚动 |
| pages/performance/components/ProfileArchiveView/index.tsx | 性能页私有归档展示 | 已验证 OpenedProfileArchive | 页面内画面、栈和火焰图组件 |
| components/BlobDownload/index.tsx | 跨页面下载入口 | Blob | 对象 URL 生命周期 |

## 数据与行为

默认宽度表示样本数，可切换 event_count；两者都不换算成精确 CPU 耗时。事件始终分组，跨事件计数不能解释为同一时间单位。纳秒、事件计数、累计权重和布局起止坐标为十进制字符串，用 BigInt 计算；转换到 SVG 坐标前先限制整数比例精度。

原始调用链是叶到根，聚合时反转为根到叶，图上根在下方。帧身份包含模块、执行类型和已报告符号；有符号函数忽略不同指令地址，未知函数按模块和地址保留。递归层不折叠，不同模块同名函数不合并。无符号显示模块与地址，原始栈和展开错误仍可查看，不补造完整调用链。

进程与线程筛选可组合；时间使用设备 boottime 的 [beginNs,endNs) 区间。指标点快捷按钮填充实际指标区间，画面与栈继续按原时间索引独立关联，不能将火焰聚合当作逐显示帧结果。非法区间显示错误，空结果不补相邻样本。

色块支持点击、Enter 和空格缩放，提供上一级和重置。搜索函数、模块或地址并高亮，完整字段见节点提示和选中分支。小于可见阈值或超过4000个可见节点的分支计入省略提示，聚合计数保留；可放大父节点检查。

## 归档兼容

旧 Root ZIP 没有 flamegraph.folded 仍可从 stacks.jsonl 本地生成火焰图。新 Root ZIP 的可选成员按同一原栈重建并逐字节核对，最大32MiB；未知地址保留原文本，键按UTF-8字节排序，空调用链不输出。无Root结果不得包含该成员。成员作为 Blob 返回并可下载给通用 FlameGraph 工具，未改变 profile-index v1 和录制结果 v1。

本轮使用已有751条关卡实际栈离线验收，不需要再采设备。功能、门禁和视觉证据以 artifacts 的本轮报告及根 todo 为准；性能压测、采集开销和完整展开未计完成。
