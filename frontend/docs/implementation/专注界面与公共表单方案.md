# 专注界面与公共表单方案

日期：2026-10-15。范围：整体 Web 界面、公共表单与十四个业务路由。用户最新明确暂不生图，直接重排现有路由内部布局；本轮已实施源码并进入浏览器复查。

## 用户目标与当前证据

减少大卡片、长说明和额外干扰，适合长期工作；页面排列整齐，公共表单统一标签、输入、分组与操作区。保留电子设备工坊背景、米白和橄榄色体系。

视觉子代理已查看当前设备页、设置页和背景。设置页存在标题说明占比大、两种表单排法混用、右侧设备空态压缩主区的问题。设备页存在空态与入口重复、分栏和滚动条偏多的问题。设置页原始证据位于 `frontend/artifacts/ui-review-20261015/settings-before.jpg`，不外推其他路由已完成视觉审核。

源码已确认 `.form-row`、`.form-grid` 使用底部对齐，帮助文字长短可能拉开输入基线；现有 `Field` 只封装 Input，选择框、文本域和复选框仍由各页面临时组合。

## 实施门禁裁定

模式：architecture-first。涉及公共展示组件、各页面编排和外壳样式；业务 API、任务状态、生成类型、设备调用和插件生命周期不属于本轮重构范围。

选择组合式公共表单：保留现有受控控件和页面事件，抽出语义、排版、字段关联及反馈。舍弃用通用 JSON/schema 表单替换业务页面的捷径，避免把业务分支和提交状态集中到公共组件。

| 单元 | 职责 | 输入与输出 | 副作用与边界 |
| --- | --- | --- | --- |
| `components/Form` | 分区、字段、网格、动作区的语义与排列 | 标题、标签、控件子节点、帮助和错误，输出语义 HTML | 仅生成控件关联 ID；不请求 API、不接业务状态 |
| `components/FormField` | 保持 `Field` 调用兼容，组合 Input 与公共字段 | 原受控值和回调，可选字段属性 | 不承担提交、格式转换或业务校验 |
| `components/Input` 等现有基础控件 | 键盘、焦点与基础控件行为 | 标准控件属性 | 延续既有组件，不复制实现 |
| `pages/<功能>` | 业务分组、动作、条件字段、文案 | 既有 services 和页面状态，组合公共表单 | 保留取消、错误、修订与操作作用域 |
| `app/product` | 顶栏、导航、按任务展示设备上下文 | 当前路由和外壳偏好 | 保留主题变量与公开插件边界 |
| 本文、根 `todo.md` | 决策、验证与剩余事项 | 本轮真实证据 | 不把候选、构建或静态检查写为运行验收 |

先拆公共表单结构，再迁移页面；不继续向页面复制标签与控件布局。样式通过公共组件私有样式和主题变量组织，避免仅在全局文件尾部叠加选择器。

验证采用 SDD 与定点行为检查：先用视觉目标统一结构，再确认标签关联、错误描述、键盘、禁用态及窄屏单列。遵守用户已有指令，不增加大量端到端测试；源码修改后运行生成器、架构与严格类型检查、生产构建，单独报告是否实际执行测试及浏览器验证。

## 公共表单最小契约

- `FormSection`：短标题和分组；相关控件使用 `fieldset/legend`，无默认卡片背景。
- `FormRow`：标签、控件、必要提示和错误；支持固定标签列或顶部标签，同一任务内统一方向。
- `FormGrid`：一致列宽与间距，顶部对齐，窄屏自动单列；不使用帮助文字参与控件基线对齐。
- `FormActions`：独立操作行，与控件起点对齐；行内小动作明确绑定相应字段。
- `Field`：继续兼容现有 `label/value/onChange/type/hint`，按需要补 `id/name/disabled/required/error/autoComplete`。

公共字段为 Select、Input、Textarea、文件输入和 Checkbox 提供控件 ID、说明 ID、错误 ID；由控件显式接入 `aria-describedby` 和 `aria-invalid`。复选框使用横向标签。公共组件不通过复制或改写任意子节点隐式注入业务行为。

实施尺寸基准：桌面控件 36px，圆角 4px，正文 14–16px，页标题 22px，组内 12–16px，组间 24–32px。标准标签列 144px，640px以下单列；移动端保留44px触控目标。

## 页面收敛规则与推广顺序

第一批：设置、性能与调用栈、应用与包，覆盖选择框、可选密码、JSON、文件、数字、复选框、条件字段和禁用组。

第二批：自动化、Frida、AI 助手、工具供应、插件，复用表单骨架，低频参数按需展开，保留操作范围和失败原因。

第三批：设备、文件与产物、画面与录制、终端、数据分析、任务与日志，整理工具栏、列表、详情和结果区域；列表使用轻分隔，结果保留大块连续工作空间。

简化英文眉题、宣传式标题、重复空态及常驻说明；普通设置页按任务减少设备摘要占位。必要内容继续可见或可达：服务切换结束当前会话、配置修订冲突、删除对象、日志 ID、来源资格、上传安装状态、取消与清理结果。默认不展示常驻操作日志，详情通过已有入口获取。
