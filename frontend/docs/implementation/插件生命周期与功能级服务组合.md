# 插件生命周期与功能级服务组合

## 保留的边界

继续使用 SDK v2、自有注册表、公开槽位和动态路由。普通插件即可消费其他插件，不增加“组合插件”类别。新增服务能力是可选入口，不取消旧 `extensions.callService()`。同页面插件仍按可信代码运行；取消或超时只结束宿主等待，不能强制停止同步死循环或任意 JavaScript 副作用。

## 有界生命周期

- 同插件的装载、挂载、卸载顺序串行；无关插件不共用等待队列。槽位自身另有独立队列，注册表不等待插件回调。
- 加载模块、准备配置、激活及配置应用共用一个绝对截止点，默认 30 秒；槽位申请及实际挂载共用 10 秒。
- 每次插件清理默认总共 5 秒，资源清理与停用并行观察；失败保留到 `cleanupSnapshot()`，独立新代不被历史故障封锁。
- 卸载立即撤销本代信号、贡献和 DOM；迟到释放函数归原作用域，旧租约不得释放新槽位。超时不宣称资源已经释放。
- 测试可通过 `RuntimeOptions.timeouts` / `ManagerOptions.timeouts` 缩小期限，生产缺省保持上述值。预算只接受 1 至 300000 毫秒。

## 服务契约与功能作用域

`ServiceRef` 由 `id` 和精确字符串 `version` 组成，不做范围选择、隐式升级或字符串/数字转换。服务可声明 JSON Schema 输入输出契约，调用前后校验；旧贡献未声明时保持允许任意 JSON 的兼容行为。新模板明确声明 Schema。

`services.catalog()` 返回浏览器注册表中当前服务引用、输入输出契约、提供者版本与代际及可用原因；未激活项可诊断但不能调用。`services.server.list(signal)` 读取服务器同形目录，`services.server.submit(ref,input,signal,generation?)` 返回共享 Job，继续通过 `getJob/cancelJob` 观察和取消。该分支保留异步任务语义，不把 202 提交回执当作业务输出。

```ts
context.services?.whenAvailable('catalog', [{ id: 'example.provider', version: '1' }], async (feature) => {
  feature.extensions?.register?.({ modules: [moduleContribution] });
  return () => releaseFeatureResources();
});
```

`setup` 必须使用收到的 `feature` 上下文，而不是闭包中的插件根上下文。依赖等待、初始化、运行、失败、停止分别记录为 `waiting/starting/active/failed/stopped`；查询 `context.services.diagnostics()` 可取得缺失引用与原因。返回的释放函数也由插件作用域管理。

旧功能清理失败单独保留在 `cleanupErrors`（每功能最近 8 条），不覆盖恢复后新代的 `active` 状态，也不被新成功清除。槽位默认渲染器同样采用挂载/清理期限；迟到默认清理异常可通过适配器的 `cleanupSnapshot()` 查询。

提供者只有激活成功才发布服务。引用缺失、版本不符、提供者撤销或代际变化会立即关闭相关功能信号与贡献，然后有界回收；恢复时重建新子作用域。同插件其他功能、独立插件及历史故障记录不受影响。功能初始化默认 30 秒，清理默认 5 秒。每插件最多 128 个活动功能，每功能最多 64 个不重复引用，诊断最多保留 256 项。

服务调用上下文携带父期限和取消，单链深度最多 8，根链同时最多 4 个活动调用，递归明确失败。调用返回后其专用上下文撤销；不得保存它用于另一次新调用。根插件上下文仍可正常发起独立调用。

服务通过 `context.extensions.executeCommand()` 间接调用另一个服务时，命令收到的上下文仍继承原服务调用链、取消信号和绝对截止点。命令不能重置预算或绕过递归检测；处理器应继续使用本次参数中的上下文，避免缓存根上下文重新发起调用。

## 独立模板与验证边界

`src/plugins/examples/service-provider.ts` 与 `service-consumer.ts` 各为独立插件，彼此不导入源码，只按公开服务引用、SDK、模块和组件接口组合。提供者失效后消费者插件不卸载，只有组合页面、组件和命令撤销；服务恢复后重新注册。

`tests/service-features.test.ts` 覆盖相关功能撤销、独立功能保留、代际恢复、Schema、未激活不发布、迟到初始化和递归。`tests/plugin-lifecycle-bounds.test.ts` 覆盖不返回加载/激活/挂载及槽位申请取消。这些是 Node/DOM 功能证据，不是最终浏览器、冻结包或真机验收。

本轮各构建模式的真实上传、生产 App 路由和冻结包证据见[插件基础设施实施验收](../verification/插件基础设施实施验收-20261027.md)。失败轮与成功轮分别保留，不用单元测试外推未执行的分发或设备验收。
