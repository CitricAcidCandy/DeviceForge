# 服务器插件生命周期消费

本文件保留早期客户端、服务器管理与两类在线包基础用例、浏览器动态加载和开放扩展，以及第一阶段设备目录/选择/离散动作的实施记录；产品 runtime 后续装配见[前端运行架构](../guides/前端运行架构.md)。2026-10-26 已同步本文状态语义，现行硬约束见[插件清理告警与重试约束](../contracts/插件清理告警与重试约束.md)，不将早期门禁结果外推为当前产品验收。

## 接口与状态

使用 generated.ts 中插件管理路径的响应类型和 v2 日志包装；PluginInfo/PluginState 由后端 Rust 生成，目前在 TypeScript 中内联于响应，禁止手写重复 DTO。GET /api/v2/plugins 返回已加载或正在排空的服务器插件；POST /api/v2/plugins/{id}/load、/unload 只传已部署的插件 ID，不提交服务器路径。在线部署另通过 runtime.pluginPackages 上传原始 ZIP/TGZ 并显式 enable；默认本地免鉴权，令牌可选。

loaded 可贡献操作；draining 已撤销新调用并有界等待真实在途工作，该范围内暂不能重载；unloaded 是成功卸载返回值，之后不在当前列表中。历史外部债务不应永久维持 draining，真实排空后可重载。generation 标识一次加载，重载同 ID 也产生新值。protected 表示启动配置中的长期依赖，当前拒绝运行中卸载，界面应解释具体原因。

cleanup_failed 是必填布尔字段，客户端原样保留为诊断，不单独灰掉独立新操作或阻止排空后的重载；recovering 也不作为全插件禁用条件。不能以取消等待、管理错误或本地快照删除代替后端实际完成卸载；服务器包删除前重查并卸载，真实占用或文件事务拒绝时不继续 DELETE，历史组件告警则按公开可重试规则处理。前台结束、后台释放和新准入分开，旧失败不改判新成功，新成功不清旧错误。

## 取消与目录变化

AbortSignal 只中断客户端等待，已接收的管理变更仍由宿主收敛。取消或网络失败后重新读取列表，不推断操作已回滚，也不自动重复提交变更。错误传递 log_id，任务历史与产物不因卸载消失。

服务器管理用例已在加载/撤销成功、失败或取消后重新读取插件、操作与设备目录，不自动重放。app/catalog-refresh 在重查前撤销目标设备提供者缓存、选择和相关请求，重查失败仍不保留旧观测；runtime.pluginPackages 的服务器启停也走同一编排。管理失败时后端提供者可能仍在，重查可重新观察它，但不复活旧选择。当前无服务端推送机制，其他实例或远端管理变更需显式刷新。面板依赖的操作消失时应收敛入口和订阅；同 ID 重载不能复用旧代际状态，晚到响应不得覆盖新状态。

服务器通用进程插件与浏览器运行状态独立。HostContext 提供操作/任务、开放扩展和可选 devices；runtime.serverPlugins/pluginPackages/artifacts 属于宿主 app，插件尚无管理/产物 SDK 适配。设备 SDK 只提供公开目录、选择、能力动作和订阅，不直接授予插件 load/unload 权限。

browser 删除先停当前 runtime 实例再删静态部署，不会强制停止其他同事浏览器实例；已执行 ESM 内存缓存无法卸出，新 UUID 资源路径仅保证新 load 入口及相对依赖使用新模块图。清理或删除失败向调用者报告，部署仍存在时可重新 enable。

主代理已通过生产公开入口的 debug/release 真实浏览器在线包与运行热装卸验收，见根 artifacts/browser-plugin-smoke-debug.json 与 browser-plugin-smoke-release.json。设备第一阶段客户端/SDK/基础用例已实现，本轮 check/test 退出 0（73/73），包括本地管理后目录清理、失败重查和选择撤销。最终设备浏览器证据由主代理独立汇总；常驻会话、平台工具迁出、真机与完整设备热拔插不能由通用插件证据替代。
