# 完整交互终端前端实施

日期：2026-10-22。跨端契约见后端的《完整交互终端实施裁定-20261022》。本批是architecture-first与契约、行为验证结合的Hybrid。

## 职责

- `features/interactive-sessions`保留既有生成HTTP类型、身份、代次、游标、收据与失败日志。新增`openPtyTerminal(profile,size,signal)`、`sendTerminalInput(text,signal)`、`resizeTerminal(size,signal)`，编码插件公开业务消息；旧管道门面保持原字节语义。
- `pages/terminal/index.tsx`保留原页面外壳、档案、公开配置和生命周期操作，只负责装配。清屏只影响本地终端显示，不再调用会撤销选择的`terminal.clear()`。
- `TerminalViewport.tsx`懒加载固定版本`@xterm/xterm 6.0.0`与`@xterm/addon-fit 0.11.0`，保留ANSI/VT、光标、备用屏、真实控制字符、中文IME和粘贴。ResizeObserver跳过隐藏页面的零尺寸，恢复显示后重新测量，尺寸限制与后端一致。首次fit早于可输入状态时，在启用按键前补发当前尺寸并进入同一串行队列，不依赖再次改变容器大小；初始化失败和卸载均释放观察器、帧、订阅和模拟器。
- `input-queue.ts`将按键与resize串行发送，上一条收据结束后才发送下一条；队列最多256条、256 KiB，连续resize只保留最后尺寸。粘贴按Unicode码点和JSON转义后的实际字节数分块，单条不超过8192字节。错误或容量溢出停止后续输入，保留原错误及日志ID，不重放未确认输入。
- `output-cursor.ts`按真实sequence追加原始字节，每块只写一次，不对ANSI按行分割，不重新解码跨块UTF-8。xterm保留5000行本地滚屏，宿主原有输出保留限额继续生效。

终端输入位置是xterm自身的输入控件，用户在屏幕内直接输入；Tab、方向键、Ctrl+C、Ctrl+D均作为程序控制键。Ctrl+Shift+C显式复制选择，浏览器原生粘贴事件交给xterm处理。原来的“输入一行再发送”输入框已移除。

路由切换由产品保留已访问组件，终端隐藏期间保持会话及输出读取，不自动取消。产品刷新、关闭或更换服务连接时，ProductServices在本地消费销毁前显式调用releaseSelectedTerminal，仅释放已选、未结束的plugin.terminal.open；使用公开gateway.release的keepalive端点及独立5秒截止，clear/dispose不能撤销该请求。Promise保留原失败及日志，Stopping不冒充清理完成；该行为仅为尽力释放，不保证浏览器崩溃、断电、断网或打开响应未知时必然回收。

TerminalHistory读取真实服务器记录，过滤终端及当前选择；提供状态、短ID、刷新、指定旧活动终端的关闭并释放，以及已结束记录删除。核心用例先查询并验证归属再变更，在独立记录控制通路执行，不resume、不改选、不撤销当前输入；只供异常退出后收尾，不提供可写接回。页面移除重复的协议EOF菜单，关闭使用现有Cancel；Ctrl+D仍按真实控制字符传递。粘贴提示明确为浏览器粘贴及Ctrl+Shift+V，组合键是否触发paste由浏览器决定。

## 验证范围

终端专属`terminal-pty.test.ts`覆盖版本化打开、旧管道兼容、控制字符、尺寸/未知字段拒绝、JSON转义后限额、大段中文及包围粘贴、串行收据和resize合并、网络失败不重放、容量及销毁，以及ANSI/跨块UTF-8与输出去重。既有`interactive-sessions-consumption.test.ts`保持原行为。

`terminal-viewport.test.ts`以受控模拟器挂载真实React组件，复现初次fit发生在不可输入状态、容器之后不变的时序，验证启用输入后补发80×24尺寸，并且随后按键等待resize收据。模拟器只验证组件生命周期与队列装配，不证明xterm自身的终端解析或真实ConPTY表现。

`terminal-records.test.ts`覆盖刷新前真实记录快照、指定旧终端释放及结束记录删除不改选、不取消当前输入，非终端/当前活动/未结束删除保护，释放失败日志，clear/dispose不撤销独立信号，以及ProductServices销毁实际调用keepalive端点且只发一次。它们是注入网关/传输的门面和装配验证，不证明浏览器退出时网络必然送达。

`terminal-page-lifecycle.test.ts`挂载真实页面、ProductServices和公开HTTP适配，验证关闭收据只返回Stopping时，页面继续消费输出直到独立的Finished、Complete及process_exited，再允许创建新会话。页面对所有未结束状态保持观察，不能在Stopping时停读并假定已完成清理。

这些Node测试不证明真实ConPTY、Codex交互或浏览器屏幕效果。真实服务与浏览器、截图审核由主代理与测试角色按当前二进制执行；前端生成器由主代理统一运行。本批不操作设备或模型任务。
