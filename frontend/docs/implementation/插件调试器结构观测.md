### 主代理接线合同

`app/debugger-local/index.ts` 新增导出 `HostDebugRoute`、`ResolvedTarget`，不修改 SDK。

```ts
interface HostDebugRoute {
  readonly path: string;
  readonly label: string;
  readonly slotIds?: readonly string[];
}
interface ResolvedTarget {
  readonly plugin_id: string;
  readonly generation: string;
}
// 下列三个字段追加到现有 LocalDebuggerOptions。
interface LocalDebuggerCallbacks {
  readonly readHostRoutes?: () => readonly HostDebugRoute[];
  readonly navigate?: (path: string, signal: AbortSignal) => void | Promise<void>;
  readonly reloadPlugin?: (target: ResolvedTarget, signal: AbortSignal) => Promise<JsonValue>;
}
```

路由只接受目录中唯一且精确的本地规范路径，不接受查询串、片段、反斜线、百分号转义或点路径。没有注入目录和导航回调时能力为不可用。导航不要求页面已挂载，不伪造打开页面后的 DOM 证据。目录最多 256 个路由，每路由最多 128 个公开槽位。

共同安装重载先校验 `confirmed` 和实际旧代次，再有界调用 `reloadPlugin` 一次，不预先执行 `manager.unload/load`。钩子必须返回至少 `{status:'loaded',plugin_id,generation,scope}`，其中 `generation` 是规范数字字符串，必须对应管理器中的实际新代次。`scope` 由主代理明确整套功能浏览器组件或单独浏览器包范围；构建修订由共同安装入口核实，本地层不把换代等同于新构建。未注入钩子时保留原运行实例回退，范围固定为 `browser-runtime-only`、`installation_changed:false`。

重载等待只绑定调用方、宿主和本地控制器生命周期，总预算为三十秒，与后端 `config.reload_timeout` 一致；不绑定必然被卸载的旧插件作用域或旧目标选择会话。卸载与加载共享同一截止点，不分别追加三十秒；钩子信号及本地兜底计时器同步使用该预算。其他调用的 `bounded` 默认仍为十秒，试调用与 UI 动作预算没有扩大。网关 `remaining_ms` 和桥接三十秒上限由主代理接线。其他旧代 UI 动作仍因目标撤销而取消。卸载不表示构建更新，失败、取消和未确认不自动重放。

### 公共参数与返回值

| 入口 | 请求增量 | 返回与证据边界 |
| --- | --- | --- |
| `ui_tree` 公开概览 | `{view:'overview',offset?,limit?}` | `{status:'catalog',source:'host-public-catalog',completeness:'catalog-only',nodes,page}`；节点为 `{kind:'slot'/'route'/'mount',catalog}`，不能当作 DOM、React 或真实路由实例 |
| `inspect` | 原空参数 | `slot_catalog` 仍只列全部公开宿主槽；新增 `mount_catalog` 区分 `panel/component/module`，附明确所有者、模式、槽位和实际挂载证据 |
| `ui_tree` DOM | 保留 `{root_id?}`；新增 `{snapshot_id?,offset?,limit?}` | 保留 `{root_id,tree}`；`tree.page` 为 `{snapshotId,offset,limit,nextOffset,total}`，翻页必须携带同一冻结快照 ID |
| `ui_action` 拾取 | `{action:{type:'pick'},root_id?}` | `{status,target,owner,root_id,reason}`；其他插件只返回明确所有者，目标为 `null`，不自动调试或加入选择 |
| `ui_action` 导航 | `{action:{type:'navigate',path,confirmed:true}}` | 不接受 `root_id`；只调用注入的公开回调，返回派发与业务未知 |
| `ui_assert` | 新增条件 `in_viewport/within_root/unclipped/nonzero_size` | 客户端矩形和裁切证据三态断言，不能证明遮挡或像素可见 |
| `invoke` | 新增 `include_result?:boolean` | 缺省 `{data:null,logId,result_metadata:{included:false,type,bytes:null,reason}}`，不遍历或复制原子结果；显式请求才返回脱敏 `HostResult` |
| `report` | 原空参数；新增 `{root_id,snapshot_id,offset?,limit?}` | 默认带 `snapshot_manifest` 与实际 `cached_trees[].snapshots` 页；达到响应预算时给 `continuation`，按快照页继续读取，持久化留给后端 |

应用别名等插件的面板绝不冒充设备应用槽。`mount_catalog` 的 `panel.slot_id` 固定 `null`，挂载状态来源是公开管理器面板状态，另附 `dom_observed`；`component` 的 `slot_id/mode` 来自公开贡献目录，只有当前代已挂载锚点证明挂载；`module` 的槽位通过公开 `pageSlotId` 规则派生。`slot_catalog.target_contributions` 精确关联对应贡献，普通 DOM 的 ID、行或内容不能生成新槽位。路由的 `instantiated:'unknown'` 明示缺少公共实例观测，未访问路由也不伪造 DOM。

拾取未指定 `root_id` 时亦接受宿主普通 DOM，返回 `{status:'picked',owner:null,target:null,root_id:null,source:'host-dom',host:{tag,role,label,insertable:false,nearest_slot?,route?},reason}`。只读取命中元素的有界可访问名称及祖先公开锚点，不扫描全宿主树，不开启新目标或创建可交互引用。`nearest_slot` 只接受已公开目录内真实 `data-deviceforge-slot/surface` 祖先；普通同名 ID、面板和未公开标注均不算槽位，当前命中节点不能插入插件。`route` 仅在当前公开 URL 路径精确匹配注入目录时返回，不推测未观测路由。敏感输入标签脱敏，自身 `data-deviceforge-debugger-internal` 子树继续正常点击，不消耗拾取。关闭 ShadowRoot 内部结构不可见，继续作为未知缺口。

### 布局、引用和容量

`UiNode.layout` 记录 CSS 视口坐标 `rect`、`viewport`、挂载根 `region`、轴向裁切后的 `intersection`，并分别记录 `nonzeroSize/inViewport/withinRoot/clipped`。客户端矩形缺席时布局为不可用，不能将 jsdom 零尺寸当成真实浏览器尺寸。复杂变换、遮罩、绘制包含、多片段布局等不具备可靠裁切条件时保留未知。`occluded` 固定未知，几何落入视口不等同于像素可见。

节点引用绑定精确 Element、局部修订和节点代次。无关兄弟刷新、视口或挂载区域改变不撤销目标引用；节点自身矩形、名称或公开状态变化增加局部修订。布局变化单独参与快照差异。已观测卸载的同一个 Element 再挂载也取得新 ID，旧作用域、旧插件代次或旧挂载根拒绝引用。

每页最多 500 节点、UTF-8 响应至多 1MiB，每根保留最近十个逻辑快照。一次逻辑采集扫描最多 5000 元素，完整采集预算仍为 1MiB，不能宣称未采集的超限节点已存在于下一页。`page.total` 仅是已采集节点总量；`coverage.truncation` 保留字节、扫描和展示页限制原因。翻页不重采、不消耗新的快照名额，过期快照明确拒绝。查询、断言、差异、精确节点动作和等待消费同一有界完整采集证据，不受第一页展示范围限制。

一次拾取默认排除带 `data-deviceforge-debugger-internal` 的完整子树，捕获前置手势与一次点击以免进入业务监听；取消、超时、退出会话释放监听。更早注册的捕获监听依然可能先执行，同页面可信代码无法被强制停止，不能把此机制当成安全沙箱。原有 `createDebugActions.pickOnce` 与公共拾取均带明确 `owner`。

捕获同时登记 `pointerdown/pointerup/mousedown/mouseup/click`，不依赖取消指针事件后浏览器是否继续产生鼠标兼容事件；监听只在点击完成后撤销。因此同一次拾取中的鼠标兼容事件仍独立被拦截。单测完整派发两类事件并确认业务监听次数为零，完成后原监听恢复；这不取代真实浏览器合成兼容事件链的验收。

已知敏感输入按密码、控件名称/ID/自动填充声明等识别，不读取值、不输出敏感名称；登记元数据拒绝敏感字段、getter 和非 JSON。普通字符串过滤 Bearer 和已知凭据赋值模式，不承诺发现任意自由文本秘密。动作与试调用关联事件仅写入当前目标事件环，保存工具名、状态和公开日志 ID，不复制输入、填写值、完整原子结果或污染其他目标。

## 已批准架构与落点

采用契约先行、纯规则与 DOM 副作用分离的实现。拒绝把 DOM 查询、生命周期和产品装配堆入同一调试服务，也不读取 React Fiber 补齐不可靠的组件树。

| 落点 | 负责 | 输入和输出 | 副作用与边界 |
| --- | --- | --- | --- |
| `src/plugin-sdk/debug.ts` | 插件公开主动登记契约 | `DebugAccess`、节点/事件/资源定义与快照类型 | 无宿主依赖 |
| `src/plugin-sdk/index.ts` | 仅新增 debug 类型导出及可选上下文字段 | `HostContext.debug?: DebugAccess` | 不装配、不提升必需能力 |
| `src/plugins/debugger/registry.ts`、`scoped.ts` | 所有权、代际、资源与作用域回收 | owner、signal、track → 登记入口和快照 | 仅调用显式释放回调 |
| `src/plugins/debugger/collector.ts`、`dom-evidence.ts` | 公开 DOM 结构与可访问标签观测 | 精确根、owner、宿主扩展点清单 → JSON 快照 | 只读 DOM，不读取控件值 |
| `src/plugins/debugger/query.ts`、`assert.ts`、`diff.ts` | 查询、三态断言、证据差异 | JSON 快照 → JSON 结果 | 纯规则，无任意对象路径 |
| `src/plugins/debugger/actions.ts` 等 | 受控本机动作与一次拾取 | 明确请求、信号、可选导航回调 → JSON 结果 | 合成事件、短期轮廓类和监听 |
| `tests/debugger-{registry,tree,actions,contracts}.test.ts` | 本批定向验证 | jsdom、内存登记、严格契约 | 不运行用户设备或浏览器 |

公共消费只通过 `src/plugins/debugger/index.ts`；公开插件不依赖该宿主实现目录，只消费可选 SDK 字段。根 `todo.md` 和 app 装配由主代理维护，不在本写集内。

## 核心装配签名

```typescript
type DebugTrack = (dispose: Dispose) => Dispose;
interface DebugRegistry {
  readonly debug: DebugAccess;
  readonly snapshot: () => DebugRegistrySnapshot;
  readonly dispose: () => Promise<void>;
}
createDebugRegistry(owner: DebugOwner, signal: AbortSignal, track: DebugTrack): DebugRegistry;
scopedDebugAccess(parent: DebugAccess | undefined, signal: AbortSignal, track: DebugTrack): DebugAccess | undefined;
createUiCollector(root: Element, options: UiCollectorOptions): UiCollector;
createDebugActions(collector: UiCollector, options: DebugActionsOptions): DebugActions;
queryTree(snapshot: TreeSnapshot, query: TreeQuery): TreeQueryResult;
diffTrees(before: TreeSnapshot, after: TreeSnapshot): TreeDiff;
assertTree(snapshot: TreeSnapshot, assertion: TreeAssertion): TreeAssertionResult;
```

`UiCollectorOptions.owner` 必填，字段为 `pluginId`、数字 `generation` 和可选 `instanceId`。`surfaces` 由外部提供 `{ id, kind, element, owner }` 清单；`hostOverview` 默认关闭；`semantic(element)` 是可选主动语义扩展，仅返回角色、名称、语义代次及结构化元数据。

collector 本地提供 `owner/root/snapshot/snapshots/resolve/reference/dispose`。actions 本地提供 `execute/pickOnce/dispose`；选项必传生命周期 `signal`，可选 `allowedRoutes` 与 `navigate` 回调。DOM、回调和 AbortSignal 只在本机，不进入 JSON 桥。bridge 负责请求运行时解码、选择正确 collector、每次传输一份快照和错误映射，不能直接透传任意宿主对象。

## 生命周期及记录

每代 `createDebugRegistry` 固定 owner 并向 `track` 登记整体清理。插件入口含 `registerNode/emit/registerResource`。语义节点在当前 registry 内唯一，可显式指定已登记的父节点；父引用不存在或形成循环会拒绝。节点更新无变化时不增加修订，撤销重登记则采用新节点代次，旧句柄不能操作新节点。

子作用域通过 `scopedDebugAccess(parent, signal, track)` 包装；退出只清自己的节点与资源，父和兄弟入口继续有效。ID 不自动改写，插件应为面板、功能和实例选用互不冲突的语义标识。子作用域事件不能引用兄弟节点。

资源只代表插件主动声明的归属；不枚举进程、定时器全局表或 React 内部资源。清理逆序且幂等，单项最多等待 1000 毫秒；失败保留 `release_failed`，整体 `dispose` 汇总错误。超时后的可信回调可能仍在执行，不宣称其副作用停止；新 registry 不继承旧代失败，也不清除旧表记录。

事件只留最近 500 条，序号单调递增，带观测时间及丢弃数量。节点和资源各最多 500 项；快照有 owner 和 disposed 状态。元数据必须是有限 JSON 对象，单项最多 16KiB、12 层及 2048 项，拒绝访问器、循环、类实例、函数、非有限数字和敏感字段名。字段名过滤不能识别任意字符串秘密，登记者仍须确保内容不含凭据、输入值和敏感业务正文。

## DOM 证据与容量

识别 `data-deviceforge-plugin`、兼容的 `data-deviceforge-plugin-id`、`data-deviceforge-generation` 及明确的 opaque、virtual、action、confirm 属性。`data-deviceforge-panel/extension/slot` 等普通标注不能代替宿主扩展点清单。其他插件和旧代根被排除，`coverage.excludedPluginRoots` 保留数量；overview 只能展示清单内其他插件的浅层 owner/扩展点引用，不执行其语义回调或采集名称。

DOM 节点 ID 绑定实际 Element，不依赖数组位置；无关兄弟刷新不改变目标节点 ID 或 revision。控件类型、角色、显式 generation 或主动语义代次变化会增加节点代次；标签等证据变化增加 revision。动作每次重新观测并核对引用，插件换代、目标修订、Element 替换、脱离目标根或销毁后拒绝旧操作。跨观测器或跨 owner 快照的 diff 返回无法判定。

单份快照最多 500 节点，UTF-8 JSON 不超过 1MiB，`bytes` 包含字段自身；本机最多保留 10 份快照。队列及扫描最多 5000 个元素，截断分别记录 `nodes/bytes/scan`，不能把未扫描区域描述成空。查询最多返回 500 条，diff 也限制 1MiB，并用 `truncated` 标记因响应限额造成的不完整结果。历史入口仅供本机检索，不应一次跨桥传输 10 份大快照。

只读公开 DOM 和有界可访问标签，不读取 input、textarea 的值、密码内容、当前选择值、可编辑正文、组件 props、Fiber 或任意对象路径。ARIA 引用只在精确根和同一所有权边界内解析；父名称也排除其他插件的后代，防止通过标签旁路采集。输入框和文本域不深入；canvas、iframe、object/embed、可编辑区、可见 shadow root 及声明不透明根作为不透明证据。

可访问名称只是公开标签的有界近似，不是完整无障碍树实现。关闭的 shadow root、未挂载列表、组件名、来源位置和框架状态未知；`coverage.virtual` 始终为 `unknown`，显式 virtual 节点可记 `declared`，不推导完整条数。可选语义扩展失败会明确抛出观测错误，不回退成伪完整成功快照。

`hidden` 只判断 HTML/CSS 是否声明隐藏；`hidden: no` 不能证明实际可见。独立 `visible` 在明确隐藏时为 `no`，否则为 `unknown`。没有布局、尺寸、遮挡或命中证据时，`visible` 断言保持无法判定。原生有效性无显式 ARIA 状态时 `invalid: unknown`，不为观测去读取现有控件值。

## 查询、差异与三态断言

查询只支持精确 id、角色、名称、扩展点、祖先和公开状态，不支持 CSS、XPath、对象路径或脚本表达式。断言支持 exists、absent、count、enabled、visible、valid，结果为 `passed/failed/indeterminate`。

正证据可证明已找到节点，直接反例可证明状态或数量不符合；截断、排除、不透明和声明虚拟内容会阻止依赖完整枚举的消极结论。即使结果可判定，数量和不存在结论也仅限当前已挂载 DOM，不表示整个应用不存在该内容。不完整 diff 不把缺席节点写成删除；状态与原因保留无法判定，不虚构结构变化。

## 受控动作与独立授权

- `click/fill/select/scroll` 必须有 `confirmed: true`。明确声明 `data-deviceforge-action="local"` 的目标可在确认后派发；没有标注的旧插件或宿主节点必须再有请求级 `allowUnknownSideEffects: true`，仅授权当前 collector 内的精确本机目标。
- 双重授权不绕过已知 `device`、只读、disabled、CSS 隐藏、不透明、ARIA 校验失败、链接和原生表单提交限制。已知设备动作始终拒绝自动派发。未知代码经授权仍可能调用设备，不能宣称该授权消除了未知副作用。
- 原生填值在新建空白控件上按 type、required、pattern、数值范围及长度约束验证调用者输入，不读取旧值；不支持密码、文件和富文本。原生选择验证唯一键、数量及禁用/隐藏状态。只写原生属性并派发 input/change，不承诺框架接受或提交。
- 点击只 `dispatchEvent` 合成 MouseEvent，不调用业务私有函数。结果只为 `dispatched`，固定 `businessOutcome: unknown`，不保证默认行为或业务完成；滚动也只证明调用接口。
- 导航只能使用宿主注入白名单里的本地路径，必须确认；拒绝外链、查询串和片段。最多等待 1000 毫秒并支持取消，回调晚到或永不返回不解释成业务成功。
- 高亮临时添加 Tailwind 轮廓类，不创建 TSX 或 CSS 规则；取消、超时及销毁移除本次新增的类。最终样式打包及视觉效果未验。
- 一次拾取在 document 捕获阶段拦截目标根内前置手势及一次点击，只返回精确已观测节点，最多 30 秒；不将其他插件、截断或不透明后代替换成宿主祖先，取消回收监听。
- 等待只轮询结构断言，最多 10 秒；取消返回 cancelled，超时返回 indeterminate，不自动发起设备或业务重试。
