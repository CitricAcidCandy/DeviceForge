## 本地源数据的性质

| 文件 | 用途与限制 |
| --- | --- |
| `Ardot-真实图层树.jsonl` | 从该真实文件完整读取的六块画板节点数据，原样保留；不是伪造的 `.ardot` 文件 |
| `Ardot-可编辑图层源.json` | 从真实节点整理的可编辑数据，保留原节点 ID 与父子关系；不是 Ardot 直接导入格式 |
| `Ardot-重建批次.json` | 将真实图层按不超过 25 项分组，记录新文件重建所需的 ID 映射规则；跨文件重建尚未实测 |
| `整理Ardot图层.py` | 只整理本目录的源数据，不生成图片，不连接或启动设计服务 |
| 六份 `.svg` | 可编辑矢量轮廓，不能代替语义文字源或原生设计文件 |

当前连接公开新建、读写节点和图像导出能力，但没有公开原生整文件下载接口。尝试使用独立浏览器查看原生下载入口时，页面跳转到 Ardot 登录页，未操作认证并已关闭临时页。MCP 的可读写状态不代表独立浏览器已登录。

最小补齐方式：用户在已登录的 Ardot 中打开上述新文件，使用产品自身的下载功能取得原生可编辑文件，放入本目录。实际菜单和扩展名以 Ardot 提供的选项为准；若产品不提供下载，需用户明确确认本地图层数据加云端源能否作为交付，不默认豁免。

- 标题栏空白处拖动；按钮不参与拖动。右下角为缩放区域，缩放时保持标题、身份和关闭入口可见。

- 键盘要求：入口可聚焦，按钮有明确名称；Esc 收起后焦点返回悬浮球；非模态面板不锁住业务焦点。拖动与缩放需提供键盘等价操作。焦点环和键盘调整状态未单独画板展示，实施前需纳入验收。

## 业务语义与状态约束

1. 顶部身份绑定实例、插件、代次，目标切换后旧订阅和晚到结果不能覆盖当前目标。断线时标记为最后观测代次，不能仍标成当前实时状态。
2. 目标来自公开调试目录。浏览器插件可以提供树和日志；服务器插件可能只提供日志；未声明调试协议时只展示已公开能力，不伪造完整 DOM / React 内部树。
3. **可观测不等于可插入。** 可观测节点与公开扩展点独立展示；选中的 DeviceList 未声明为扩展点，不提供任意节点插入、脚本执行或内部状态编辑按钮。
4. 日志按事件时间、代次、级别和日志 ID 排查；支持级别与关键字筛选、暂停跟随、包含旧代、复制日志 ID。稿面“最近 500 条”是有界列表示意，实际容量应与公开合同对齐，不据稿新增强制业务限制。
5. 旧代 g11 的清理失败与当前 g12 成功并存；保留旧失败，不要求先清零、恢复或重启才能进行独立新操作。真实独占冲突只限制对应资源。
6. 断线保留带过期标签的最后快照与历史日志；刷新当前快照不可用，选择其他目标仍可用。重连只恢复观察，不自动重放业务；成功后先核身份和代次再接收新快照。
7. 加载时显示“正在获取目标 / 快照”与取消入口；空目录显示“尚无可调试目标”及刷新；不支持树时解释能力缺失。这些规则已有文字规格，但本轮未为其各画独立画板。
