# 数据分析界面 v4「去 AI 味」· 视觉规格与差异（2026-10-28）

## 为什么有 v4

v1（浅色双栏）、v3（深色渐变）两版用户均反馈"不好看"，第三轮追问后得到的唯一具体约束是**「不要 AI 味道」**。v4 据此把此前所有"AI 设计特征"逐项砍掉。

## 砍掉了什么（对照表）

| 之前的 AI 味道 | v4 的处理 |
| --- | --- |
| 紫色主色 `#6C4CF5` 满屏 | 主色改为**近黑 `#1C1917`**，紫色彻底不用 |
| 渐变填充 / 玻璃拟态 / 发光 | 全部删除，只用纯色 + 1px 发丝线 |
| 胶囊按钮、圆角药丸标签 | 删除胶囊，状态用 6px 圆点 + 灰色文字 |
| 卡片 + 边框 + 大圆角 + 阴影 | **取消卡片**，改成表格化分行（靠 `#E7E5E4` 横线切分） |
| 大而空的指标卡 | 指标压成一行紧凑数字（22px），标签 11px |
| 彩色图标、icon 字体 | 无图标；品牌标记只有 1px 白线勾勒的形状 |
| 饱和绿/橙状态色 | 状态点降饱和（`#22C55E` / `#D97706`），文字保持灰 |
| 深色侧栏 | 侧栏改 `#FAFAF9` 暖白，与主区仅一线之隔 |
| 圆角中空柱状图 | 换成细折线（成功实线 1.6px / 失败红虚线），带峰值标注 |

参考的是 **Linear / Vercel 文档站 / 统计后台** 这一类"工程工具"的视觉：克制、无装饰、靠排版和留白建立层级。

## 字体

- 中文：`Noto Sans SC`（Regular 400 / Medium 500）
- 数字与英文：`Inter`（Regular / Medium）
- 层级：页头标题 14/Medium → 指标值 22/Medium → 表体 12–13/Regular → 标签与轴 10–11/Regular
- **全页没有 Bold/Black**，靠字号和灰阶而不是字重压阵。

## 图表实现

- 成功序列：1.6px 实线 `#1C1917`，7 个采样点（10.20–10.26）
- 失败序列：1.4px 红色虚线 `stroke-dasharray:4 3`
- 峰值点：7px 圆 + 黑色提示牌「周六 312」
- 网格：3 条 `#F5F5F4` 横线 + 1 条基线 `#E7E5E4`，无竖向网格

## 未实现 / 已知缺口

1. 只交付主视图默认态；无悬停、禁用、空态、加载态。
2. 表格 5 行示意数据，无分页、排序、行悬浮操作。
3. 日期选择器为静态文字，未展开下拉；「导出」为纯文字入口，无菜单。
4. 窄屏（1024×640 / 940×760）未出稿。
5. 数据全为示意，未接真实接口。
