## 与已落码实现的差异对照

已实现部分来自 `frontend/src/app/product/slots.tsx`、`routes.ts`、`navigation.tsx`、`chrome.tsx` 与设备页 / 设置页的槽位接入。

| 项 | 稿面 | 实现 | 结论 |
| --- | --- | --- | --- |
| 来源条标题 | 「应用目录」 | `{title}` 原样渲染 | 已回改稿面（初稿误写成「插件视图 · 应用目录」，与图标语义重复） |
| 来源条图标 | 14px Puzzle，主色 | `Puzzle size-3.5 text-primary` | 已补稿面 |
| 来源条 pluginId | 11px 等宽 | `text-xs`（13px）等宽 | **差异待收敛**：按等宽标识尺宜降到 11px，本轮不动代码，登记为后续微调 |
| 挂载失败条 | 30px、警示底 7%、三角图标 | `py-1.5` 自适应、`bg-warning/[0.07]`、`TriangleAlert` | 一致（已补图标） |
| 已关闭条 | `#FBFCFE` 底 | 透明，仅 `border-b` | 差异：与「接管中」同底更容易一眼识别，当前以实现为准 |
| 侧栏「插件」标 | 34×18、`#EFEBFF` 底、11px 主色字 | `rounded bg-primary/10 px-1.5 text-[0.6875rem] leading-4 text-primary` | 一致 |
| 侧栏「插件」分组 | 组标题 12px + 拼图图标 + 页标题 | `Puzzle` + `page.title`，无「插件」标 | 一致（稿内图标以浅色块占位） |
| 状态栏路由读数 | 路由 宿主 10 + 插件 1 | `路由 宿主 {VISIBLE_ROUTES.length} + 插件 {pluginPages.length}` | 一致 |
| 设置页插件分组 | 独立白卡「插件设置」+ 插件自绘行 | `FormSection title="插件设置"` 包 `ExtensionSurface` | 结构一致；稿面副标题「下面每一项都由插件自己渲染；卸载插件后分组随之消失。」实现未渲染，属稿面说明文字 |
| 设备右栏「应用」面 | 页签内嵌「图标块 + 应用名」分组列表 | `ExtensionSurface slot="devices.apps"`，列表由插件自绘 | 一致；「共 12 项 · 3 组 · 命中 11」是插件自绘读数，不是宿主元素 |
| 市场槽位对账 | 警示块「宿主未开放此槽位」+ 可用槽位清单 | 尚未实现（后续步骤） | 未覆盖 |
