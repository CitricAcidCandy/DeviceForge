# 设置界面 V4 设计提示词

日期：2026-10-27。用户已否定前三版，并明确不生成图片；本稿只使用 Penpot 可编辑图层及项目现有 Lucide 图标。

## 任务

为 FORGE 设备工坊重新设计设置页。以当前宿主界面为基准，不混入历史暖绿、珊瑚红或场景抽屉方案。核心任务是填写服务地址、可选令牌，再测试并应用连接。

## 画布与视觉

- 桌面画布 1424×805；保留 236px 侧栏、54px 顶栏和 28px 状态栏，不增加第二条设置侧栏。
- 页面底 `#F5F7FB`，操作面 `#FFFFFF`，发丝线 `#E6EAF3`，主文字 `#23272E`，次文字 `#6C7688`。
- 品牌紫 `#6C4CF5` 只用于唯一主按钮和选中项；浅紫 `#EFEBFF` 只用于导航选中背景。
- 中文使用 Noto Sans SC；地址使用 JetBrains Mono。标题 22/600、卡标题 17/600、标签 14/500、正文 13、重要说明至少 12px。
- 白卡圆角 8px，输入和按钮圆角 6px、操作高度 44px。不要厚重投影、巨大圆角和装饰渐变。

## 信息结构

1. 紧凑标题“设置”，说明“让连接、外观与工具偏好，适合你的工作方式。”
2. 横向页签：服务连接、外观与主题、工具配置、插件扩展；只展开服务连接，其他入口不冒充完成稿。
3. 主卡“工坊服务”：服务地址、可选令牌、测试并应用、会话影响提示。标签、输入和主操作有稳定轴线。
4. 服务地址示例为 `http://127.0.0.1:7031`；令牌占位“留空即可免鉴权”；明确“仅用于当前会话，不保存到浏览器”。
5. 明确“切换服务将结束当前工作会话；已提交任务仍由原服务处理”。不伪造在线状态、延迟或测试成绩。
6. 辅助“插件市场”压成较轻一行，含地址、保存并刷新、恢复默认；仅当前浏览器生效，不改变服务器配置，恢复默认仅针对市场地址。
7. MCP 连接与工具目录作为底部折叠入口，不与连接按钮争夺视觉。

## 状态与实现边界

另画测试中、连接失败、地址格式错误三个局部稿。失败时保留草稿与重试入口；有真实响应日志 ID 才显示复制入口，无响应时不得捏造 ID。局部稿里的日志文本须显式标注示例。

错误信息展开时主体区域可滚动，不能把底部入口推到固定状态栏后面。此稿不是运行中的交互原型，不代表接口或真实连接通过。

## 禁止事项

禁止暖绿空色块、双侧栏、半屏无用途留白、巨大宣传标题、卡片矩阵、虚假统计、满屏等宽文字，以及用图片或近似手绘图标替代可编辑控件。旧稿只保留历史，不作为新稿的视觉真值。
