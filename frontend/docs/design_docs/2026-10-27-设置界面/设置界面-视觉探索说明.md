# 设置界面视觉探索

本轮目标是重新探索 FORGE 设备工坊设置页的视觉方向。用户已否定此前两版 Penpot 草稿，认为其过于接近常规后台；本目录不能视为已确认的设计稿，也不构成前端实现依据。

## 最小设计简报

- 使用者：个人及可信同事局域网中的设备工具使用者。
- 主要任务：配置服务地址、填写可选令牌、测试并应用连接。
- 辅助入口：主题与插件、工具配置与备份、插件市场、MCP 工具目录。
- 行为约束：默认免鉴权；令牌仅用于当前会话；切换服务明确提示当前工作会话的影响；已提交任务仍由原服务处理；恢复默认只针对市场地址。
- 视觉反馈：需要更灵动、更有工坊氛围；避免双侧导航、卡片矩阵、巨大营销标题和装饰节点堆叠。
- 历史参考：既有工坊背景由视觉子代理观察后文字化，提取午后自然光、浅木色、灰橄榄绿与私人电子工作室氛围。本次没有上传参考图片，不保留旧构图。

## 产物边界与后续步骤

用户后续要求该技能每次新设计任务先主动询问是否生图。当前先完成技能规则更新，待本次明确选择后继续：选择生图则恢复候选流程；选择不生图则按上述提示词与已有素材制作可编辑设计，不再自动请求图片。

此前按用户指定的 `product-design-imagegen-fallback` 流程，沿用项目约束的 `gpt-image-2.5`，计划生成三张独立 PNG 候选。三张图片均未取得，因此还没有候选展示、成图审核或用户选图结果；不能据此推断后续新地址的可用性。

当前官方 CLI 对该模型按兼容尺寸处理，本批计划原生输出为 1536×1024、high 质量、PNG；三张均为 `generate`，没有编辑目标、输入图片或覆盖旧资产。最终可编辑设计仍以项目要求的 1424×805 为准，选定视觉方向后另行绘制和核对，不能把生成图片当作可编辑图层交付。

若用户选择生图，应先核对原输出和运行状态，再按技能规则处理确认失败的任务。取得完整候选后，由视觉子代理检查功能文案、可读性、布局差异和裁切，再按实际展示顺序请用户选图。若选择不生图，则直接沿用提示词中的简报与已有素材绘制可编辑稿，不等待图片服务。两种路径均在用户确认设计前不修改产品界面代码。

本轮仅保存三份中文提示词及本说明，补充文档导航和根目录待办。没有运行前后端构建或测试，没有修改业务源码，没有自动提交。
