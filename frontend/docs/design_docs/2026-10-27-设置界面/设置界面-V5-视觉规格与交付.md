## 文件与可编辑性

- `设置界面-V5-图层源.json`：两稿完整层级、几何、文案、字体、颜色、Lucide SVG 数据。
- `设置界面-V5-可编辑源.ts`：以同目录 V4 图层 JSON 提取宿主壳，重排正文并生成 V5 交付；复用现有 React、Lucide 和 bundled sharp，没有新增依赖。
- `设置界面-V5-Penpot恢复.ts`：将上述 JSON 恢复到独立新页的入口；本轮未执行该文件的往返恢复验证。
- 两份 `*-可编辑.svg` 保留文本、控件和分组，支持矢量编辑；两份 PNG 为**同尺寸图层源重建预览**，不是生图或 Penpot 原生 PNG 导出。
- 原生 `.penpot` 导出此前服务不可用，本轮没有重复尝试；在线稿保留原生可编辑图层，本地采用 JSON、TS 和 SVG 交付，不宣称原生文档完整备份。
