## 本地文件与可编辑性

- `设置界面-V4-图层源.json`：四块稿的层级、文案、位置、尺寸、颜色、字体与官方 Lucide 图标数据。
- `设置界面-V4-可编辑源.ts`：图层构建与 SVG/PNG 生成源；使用本项目现有 React/Lucide 与本机 bundled sharp，无新增依赖安装。
- `设置界面-V4-Penpot恢复.ts`：在 Penpot 插件上下文读取图层数据，恢复到独立新页的入口；恢复脚本本轮未另行运行，不计恢复往返验证。
- 四份 `*-可编辑.svg`：保留文字、矢量控件和分组，可在支持 SVG 的矢量编辑器继续编辑。
- 四张 PNG 是**同尺寸图层源重建预览**，不是 Penpot 原生 PNG 导出，不作为像素级一致性证明。
- 当前服务的原生文件导出不可用，故本目录没有 `.penpot` 文件；在线 Penpot 图层保留原生编辑能力。本地 JSON 与在线图层的规范化属性一致，但不包含 Penpot 内部对象 ID、协作历史或原生文档格式。
