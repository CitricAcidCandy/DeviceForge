# 设置界面 V5 设计提示词

日期：2026-10-27。用户反馈 V4“AI 味太重”，本次重排信息结构与控件密度，继续使用 Product Design 技能和 Penpot MCP；不调用生图，不修改业务界面代码。

## 设计目标

做一个每天会打开的设备工具设置页。用户能迅速找到地址、可选令牌并测试应用；界面不需要介绍自己。沿用 FORGE 宿主的侧栏、顶栏、字体、Lucide 图标与紫色，不发散另一套品牌风格。

## 画布与排版

- 1424×805，侧栏 236、顶栏 54、底部状态栏 28，保留宿主导航结构。
- 主体是一块连续的白色工作面，不再把服务、市场和 MCP 各装进圆角卡片。分组依靠间距与 `#E6EAF3` 分隔线。
- 内容左边 x=264，字段左边 x=404，常规输入宽 544、高 36、圆角 5；紫色主按钮宽 116、高 36。章节线宽 856，收在正文区域；避免为填满窗口拉长字段。
- 标题 22/600、页签与标签 14、辅助说明 12；中文 Noto Sans SC，只有地址使用 JetBrains Mono。
- 文字 `#23272E`、次文字 `#6C7688`、输入边线 `#D9DFEA`；`#6C4CF5` 仅用于当前导航、当前页签与测试应用按钮。无阴影、插画、渐变、装饰徽标或统计读数。

## 信息结构

1. 顶部只保留“设置”和四个紧凑页签；删除宣传副标题，不增加面包屑之外的引导段落。
2. 当前页签下直接出现“服务地址”和“可选令牌”，不再加“工坊服务”卡头。首字段在 y=206，避免六层标题后才开始操作。
3. 地址示例 `http://127.0.0.1:7031`。令牌占位“留空即免鉴权”，字段下说明“仅当前会话使用，不保存到浏览器”。令牌显示按钮沿用公开语义，不用装饰图标。
4. “测试并应用”在字段下左对齐。旁边保留实际后果：“切换服务会结束当前工作会话；已提交任务仍由原服务处理。”不放泛化提示。
5. 下一节是插件市场，使用细线分隔；地址旁紧邻“保存并刷新”和“恢复默认”，说明仅当前浏览器生效。
6. MCP 连接与工具目录是一条普通折叠行，采用现有 Lucide ChevronRight，不增加独立框或重复说明。

## 失败态

另画同尺寸的连接失败整页：保留输入草稿，按钮改“重新测试”；错误紧贴主操作下方，市场与 MCP 依次下移且避让底栏。服务不可达时写清“未取得日志 ID”，不能编造占位日志。失败靠文字和错误图标表达，不依赖单一颜色。

## 交付边界

本轮只修正服务连接页的视觉方向，其他页签内部界面不在此稿；可编辑源、图层 JSON、SVG 和同尺寸 PNG 保存在本目录。PNG 是图层源重建预览，不是生图或 Penpot 原生导出。只有在线稿和本地预览均经视觉子代理审核后，才能记录视觉检查结论；用户确认前不实现。
