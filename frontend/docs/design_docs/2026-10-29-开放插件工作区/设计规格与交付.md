## 尺寸与视觉语言

- 桌面导航宽 184px，顶部高 56px，底部状态高 48px。主内容左右留白 24px，卡片间距 16px。
- 设备主视图宽 570px，默认右侧两张卡片宽 606px；视图目录从“添加功能”或编辑布局进入，不常驻占列。
- 布局编辑预览宽 810px，功能目录宽 366px。完成按钮退出编辑，布局变动自动保存；存储失败须显示独立诊断。
- 默认浮窗宽 408px，标题栏用于拖动，右下角用于缩放。最小可见范围、焦点回归和键盘操作在实现时沿用宿主生命周期约束。
- 窄窗导航宽 72px，主内容宽 820px。视图改为单列页签，不通过重复创建实例适配窗口。
- 使用白卡、发丝线 `#E6EAF3`、背景 `#F5F6FB`、主色 `#6C4CF5`、正文 `#222631` 和次要文字 `#596479`。落地只使用 Tailwind 工具类。
- 桌面“平台恢复”固定在底栏右侧，全局调试球位于其右侧；窄窗相应收拢。入口不依赖当前业务页面。

## 交互规格

“添加功能”列出可用视图及来源。用户明确决定新建分栏、加入页签、作为浮窗或作为覆盖层；同一贡献可以打开多个独立实例。切页及隐藏保留实例与草稿，是否暂停采集由视图自己的可见性通知处理。

更换提供者前显示来源及影响；替换方案不能按加载先后抢占。实际渲染失败必须保留可用的回落或恢复操作。当前纯模型的 `selectProvider` 会撤销旧运行代，后续渲染宿主需要另外完成准备、提交与失败回落，不能把模型调用成功当作替换成功。

覆盖层默认只显示。编辑标记时才捕获相应输入，并支持 Esc 退出。画面缩放和坐标映射由对应领域插件提供；挂载 UI 不自动获得设备控制权。这里的输入模式与映射仍需领域能力接线，现有布局 JSON 不承诺自动提供它们。

缺失插件保留位置和说明，重新加载不重放任务或写入。业务被停用时不能静默启用内置实现。“关闭视图”和“卸载插件”是独立操作，涉及草稿丢失时说明影响。

冲突时读取最新值只更新比较区，不覆盖当前草稿。未知结果先查询原调用或重新读取，不自动重试写入。断线标记观察时间，连接恢复后仍须核对目标及真实数据。

外壳失效后最小恢复入口可以检查连接、管理故障插件并显式选择官方外壳。收起恢复面板后原位置仍有入口；恢复界面不静默重启业务，也不重放历史操作。
