# 性能与调用栈 · V2 独立面板

日期：2026-10-27。状态：历史稿。用户认可分隔方向，但否定本稿美感并要求顶部画面与采样点对应；已确认[V3画面联动稿](性能分组-V3-视觉规格与交付.md)实施。V1被用户指出“三个指标类型的数据都在一起了，要分隔开”，V1、V2均不作为当前实施依据。

## 本次修正

V1只增加标题带，帧率、CPU、内存仍共用外框，未达到用户要求。V2将三类指标分别放入完整独立的图表面板：每块有自己的四边框、8px圆角、名称、当前值、单位、图例与时间刻度。面板之间有16px页面背景留白；共同布局容器透明、无描边，不再形成共享白色大框。

时间范围与绘图区横向位置仍一致，实施后选点保持联动。分隔依赖独立结构和背景空隙，颜色作为辅助。折叠时每块仍保留完整边框与间距。
