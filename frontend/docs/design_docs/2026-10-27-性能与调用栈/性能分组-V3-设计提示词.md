# 性能与调用栈 V3 设计提示词

日期：2026-10-27。结合项目现有 FORGE 外壳、白卡、发丝线、紫色主色与中文信息密度设计；使用 Product Design 的上下文梳理和方案收敛步骤，用户要求不生成图片。V3 已获用户确认，作为本轮前端实施依据。

设计一张1424×805的真实桌面窗口，延续236px侧栏和54px顶栏，不增加大标题装饰、渐变、厚阴影或无业务意义的卡片。帧率、CPU、内存必须三个完整独立面板，不能重新合入一个白框。用16px页面背景留白分隔，白底、10px圆角、1px #E6EAF3 描边。去掉整条灰色表头：左侧以名称、26px当前值和单位建立层次，右侧为低干扰趋势图。等宽字体仅用于编号、时间及指标读数。

顶部是采集到的设备画面带，每个画面必须有对应的采样点编号和时间。画面中心与下面三个指标的该时间点保持同一横坐标；选择画面或曲线点时，同步更新画面、三个指标当前值与调用栈。选中态只用细紫边、浅底与清晰选点，避免贯穿整个页面的粗亮线。示例选择#06／20秒，下方读数28.2fps、CPU22%、PSS0.37GB；RSS未采集。缺测留空或说明，不补零，不用别的画面填补缺帧。实时现有时间近邻关联须保留偏差说明，不能冒称精确同帧；归档沿原采样点关联。

画面带168px高，三个指标面板108px高，间隔16px，调用栈空态以36px独立行收束。画面与各指标共用绘图区起点和时间范围；未来密集采样可同步缩放／滚动，但画面带不能独立滑动后与曲线失去对应。保留真实采集控制、归档和调用栈能力。

本稿使用两张现有历史游戏截图交替放入九个静态位置，仅验证布局；显式标记“历史画面 · 布局示例”。所有示例指标和时间均为布局数据，实际产品只能显示本会话真实帧与真实采样关系，不嵌入此处素材。输出可编辑图层、PNG、完整JSON和恢复入口，保存至本目录。
