# 性能与调用栈 · 数据分组设计提示词

沿用 FORGE／DeviceForge 项目现有白灰紫设计语言，优化“性能与调用栈”页面。问题是所有数据类型挤在一个连续白色图表区，用户无法快速识别帧率、CPU、内存和调用栈的归属。

使用 Penpot 创建真实可编辑图层，不调用生图模型。画板采用项目标准 1424×805；复用既有侧栏、顶栏、标题与模式切换，只调整当前页的信息组织。

核心结构是会话状态与操作、紧凑画面行、共享时间轴、纵向指标组、独立调用栈章节。每组使用34px浅灰标题带，依次摆放名称、紧邻的当前值和单位，右侧显示该组统计或缺测状态；曲线区使用独立网格与纵轴。边界依赖标题、间距、对齐与发丝分隔线，不依赖多色卡片。

帧率沿用紫色 `#6C4CF5`，CPU沿用蓝色 `#2F7FE0`，内存使用低饱和绿色 `#168577`。PSS与RSS属于同一个内存组；RSS未采集时明确标注，不补零、不伪造曲线。读数和时间使用等宽字体，普通文案使用宿主中文字体语言；标题14px中等字重、读数15px，次要文字12px。

所有指标使用同一时间映射。选择同一个采样点时，各组同步显示该点数据；不虚构跨时间对应。画面关闭压成34px行，不保留大块空白。调用栈无样本压成74px独立空态；有数据后展开火焰图和选中帧详情。火焰图的条宽必须严格按样本权重，父子与兄弟边界准确，示例数据明确标注为设计示例。

输出两张画板：持续采样的三类曲线展开与空调用栈；归档状态的指标折叠与调用栈展开。保持单层工作容器，不加营销文案、装饰插画、渐变或一排统计卡，不新增采集能力或业务API。交付完整图层JSON、构建／恢复入口、可编辑SVG、重建PNG和尺寸规格。
