# 调试器数据与自动调试面板：设计准备

状态：仅文字规格，尚未产出Ardot可编辑图层、原生源文件或预览图，不能作为新UI开工批准。现有调试器R2稿为 `https://ardot.tencent.com/file/741004518955467`。当前可调用能力只有打开设计、读取文件信息和变量导出，未取得图层编辑及文件导出入口；后续需在可用编辑入口中完成下列稿件并落盘同目录。

## 画板与沿用语言

桌面画板1424×805，必要时另补940×760。背景及已有Debugger外壳沿用R2，不修改业务页面。白卡、发丝线 `#E6EAF3`、主色 `#6C4CF5`；普通正文使用比例字体，等宽只用于插件标识、修订和日志读数。新增页签置于现有调试器内，保持目标、连接状态、收起和关闭入口一致。

桌面展开面板建议宽960、高672，四周最小24；标题区56、目标摘要48、页签40、底栏40，正文间距16。沿用既有面板可调整大小能力，实际尺寸须在可编辑稿中核定，不能以此文字描述冒充已设计像素布局。

## 数据页签

正文左右布局，源目录240，分隔与间距16，其余为详情。目录每行48，展示业务名称、只读/可写和内存/持久化标记；搜索只过滤已登记目录。没有源时说明插件未主动登记数据，提供刷新，不能说插件无内部状态。

详情顶部展示数据源标识、生效方式及可复制的不透明修订。右上刷新，主操作保存。中部编辑区呈现可读JSON和模式约束，底部显示实际模式错误和保存状态。敏感属性省略时展示简短“不完整模式”标记，可展开省略路径，不能恢复凭据或把掩码当原值写回。

读取时不把旧值误标为新值。保存使用当前读取修订，冲突后保留用户编辑内容、显示数据已变化，并提供重新读取；不自动覆盖最新数据，不自动重试写入。保存后回读失败显示结果未确认，提供查回执和读取实际状态。延迟生效显示“已保存，待下次调用/重载”，不显示已应用。

## 自动调试页签

顶部为固定目标与代次、运行和停止。左侧步骤列表每行56，展示序号、工具、状态和耗时；右侧选中步骤展示公开参数、绑定来源、结果或省略原因、日志ID。底部持续说明已完成数与未执行数，结果未知使用琥珀色，明确失败用红色，通过的显式断言用绿色。

初版步骤从结构化计划载入，不增加任意脚本编辑入口。节点绑定只提供前面界面查询步骤，修订绑定只提供前面同源读取步骤；不支持的来源不列入选项。运行前展示此次目标及涉及变更的步骤，沿用一次明确授权，动作自身已有确认约束继续保留。

停止取消当前等待并标记后续未派发。遇到结果未知时保留已完成证据，提供只读回执查询，不出现自动“重跑失败步骤”主按钮。重新运行是一笔新的明确操作，必须先读取实际状态和当前代次。

## 必需稿件与后续缺口

1. 桌面数据读取/编辑态。
2. 数据修订冲突与写后回读未确认态。
3. 桌面步骤执行及失败证据态。
4. 取消、旧代和断线历史态。
5. 940×760窄窗布局。

每份交付必须包含可编辑图层和原生源、导出预览、关键尺寸及交互说明；图片审核交由视觉子代理，主代理只集成结论。确认稿件后再改官方插件UI，落地后回稿核对。当前没有上述设计和图片审核证据，现有代码仅实现Agent公开工具与宿主非UI能力。
