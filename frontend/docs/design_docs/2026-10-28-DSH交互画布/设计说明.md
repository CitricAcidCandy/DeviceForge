## 单一方案与边界

只设计「左侧 DSH 对话，右侧可调宽 Ardot 原生画布」这一条路线。没有同时制作或实现对话内编辑器。沿用主代理已核实的结论：DSH 公共分屏接口版本为 `0.2.1-rc.2`，不再列为待确认项；本轮不重复调查 MCP 配置或 DSH 接口。

公共分屏接口已核实，不等于 Ardot 原生编辑器已经嵌入。R2 只修复当前可编辑设计稿的显式填充，未接入 DSH 插件、原生编辑器、同步事件或实际调宽与关闭恢复行为。

DSH 顶栏和左侧消息是保持对话可用所需的上下文示意，不代表重新设计或已经实现 DSH 原有聊天系统。图中输入与发送表示必须保留的现有能力，未接入真实服务。

右侧仅增加插件容器：文件名、同步信息、原生嵌入区域、在浏览器打开和关闭右栏。文件名、设备数量和同步文本均是示例内容，不能作为实际 DSH 运行、设备在线或数据落盘的证据。

不绘制自创图层树、属性栏、缩放、导出或原生编辑器工具栏。原生交互应由实际嵌入的 Ardot 提供。画面上的选中角点仅说明示例图层处于选中状态，不定义新的宿主图层操作 API。

## 两态行为约定

### 正常分屏

左侧可继续输入及发送；拖动中间分隔条调整右栏宽度。右侧显示当前文件、MCP 已连接和独立同步状态；「已同步」只有真实同步证据到达后才能显示，不能由 MCP 已连接推导。

「关闭右栏」仅关闭当前嵌入视图，保留对话、文件引用和已有内容，不删除文件，也不关闭 MCP。关闭后的恢复入口应复用现有 DSH 能力，具体接口由主代理确认，不在本稿臆造。

「在浏览器打开」指向当前同一 Ardot 文件，不创建另一份文档，不充当第二套编辑模式。

### 嵌入失败

本状态明确选择「MCP 已连接，但画布未成功嵌入」作为失败示例。连接可用和画布失败分别显示；同步显示「待确认」，不假定本地内容已保存或丢失。

错误标题清楚说明「画布暂时无法嵌入」，说明对话不受影响，提供「重试加载」和「在浏览器打开」。重试只恢复当前文件的嵌入，不重新发送对话，不重复创建文件。现有输入区保持可用，不显示 token 输入，不要求重新授权。

若运行时实际是 MCP 链路不可达，应如实更新连接状态与失败阶段，不得继续固定显示「已连接」。不推测 iframe 策略、网络、授权或同步失败的根因。

## 本地源文件与预览

本轮可用的 Ardot 工具没有暴露原生 `.ardot` 文件导出方法。因此本地交付是**分层 SVG + 完整节点 JSON + 重建操作 JSON**，不是 Ardot 原生文件；远端 Ardot 文件才是本轮真实创建的原生可编辑设计。

- `01-正常分屏.分层.svg`、`02-嵌入失败.分层.svg`：文本保留为文字，所有容器与形状保留独立分组，可在支持 SVG 图层的工具中编辑
- `01-正常分屏.预览.png`、`02-嵌入失败.预览.png`：首次设计阶段同一次批量截图的历史预览；保留原文件，不代表 R2 修复后的远端状态
- `01-正常分屏.R2.预览.png`、`02-嵌入失败.R2.预览.png`：全部 109 条 R2 更新成功后，本轮唯一一次 `capture_screenshot` 同批取得的两张远端原始截图，未二次加工；本轮应审核这两张
- `分层设计源.json`：最终109节点及相对父级几何
- `重建操作.json`：按25操作上限拆为5批，使用符号父子绑定，不依赖旧文件节点 ID
- `节点映射.json`：符号键与当前远端真实节点 ID 对照
- `操作批次-01.json` 至 `操作批次-05.json`：最终源对应的操作文本；跨批父级包含当前文件真实 ID，只作当前文件对应参考，不能直接用于新文件
- `生成分层设计.py`：只生成本目录设计资料的辅助脚本，不是插件实现
- `修复操作-R2-01.json` 至 `修复操作-R2-05.json`：本次已顺序应用的 5 批更新，共 109 条 `U`，每批数量为 25 / 25 / 25 / 25 / 9；`修复操作-R2.json` 为汇总
- `测试分层源.py`：检查本设计源、显式填充、SVG 颜色、重建与修复批次一致性，以及原始和 R2 预览文件头的 10 条单元测试
- `R2修复记录.md`：本轮远端应用结果、布局警告、截图配额与实际单元测试结果
- `视觉审核交接.md`：交给另一视觉代理的审查范围与待确认项

重建时先在目标文件定位空白位置并取得目标页面 ID，再顺序读取 `重建操作.json`。每个 `I(parent, node)` 的返回 ID 写入本次重建映射；同批可使用绑定变量，跨批将符号父级换成实际返回 ID。每批不超过25操作，绑定名不得跨批复用。原文件内不得无意重复追加。SVG 是离线分层备份，原生导入后的字体与图层语义仍需另验，不能把可打开 SVG 等同于原生无损往返。
