# 浏览器插件开发契约

## 贡献
公开入口为 `src/plugin-sdk/index.ts`。插件声明 `id/version/apiVersion` 和 `panels`。协议版本当前为 1；每个面板使用插件命名空间 `<插件ID>.<面板名>`。宿主注册前调用 validateContributions，重复插件、重复面板、跨空间贡献拒绝注册。

`PanelContribution.mount(target, context)` 返回异步卸载函数；插件可声明 activate/deactivate。后续宿主应在失败时回滚已经挂载的面板，按相反顺序清理贡献，不让一个插件阻止工作台启动。

## 宿主上下文
HostContext 计划提供公开操作发现、任务提交、读取和取消，并支持 AbortSignal。插件收到可用能力，不收到服务令牌或任意 fetch 权限。调用成功后仍应读取任务终态，再展示执行结果。

服务端插件可独立贡献操作；浏览器插件面板通过公开操作 ID 调用它。前后端插件可以独立发布，无面板的服务器插件仍能被 API/MCP 调用，无服务器插件的前端插件可以展示宿主数据。

设备提供者与平台面板的交互目标见 [设备能力与插件面板](设备能力与插件面板.md)。后续 HostContext 通过版本化升级提供设备身份和能力服务；当前类型尚无这些方法，不允许通过导入宿主内部实现临时补齐。

## 实施状态
当前提供类型与贡献校验测试；动态模块加载、实际宿主上下文、面板管理、发布清单及权限协商尚未实现。后续开发必须先定义版本兼容、信任来源和资源释放，再实现加载器。

服务器通用进程插件已有独立的运行中管理接口，前端消费约束见 [服务器插件生命周期消费](服务器插件生命周期消费.md)。这不改变当前浏览器 SDK，也不代表面板可动态加载。
