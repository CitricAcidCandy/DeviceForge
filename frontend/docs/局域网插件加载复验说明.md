本说明记录 LAN-LOADER-001 的真实失败、最小源码修复和主代理复验步骤。前端角色只做静态编辑与冻结交接，没有运行 Node/npm/Cargo、生成器、格式化、测试、构建、服务或浏览器。本次修复后的生产浏览器结果尚未验证，不能沿用示例单元测试或其他批次浏览器结果宣布问题关闭。

## 已核对的真实失败

| 观测 | 原报告中的值 |

| 页面 origin | `http://192.168.50.5:58041`，实际非 loopback LAN HTTP |

| EXB-01 错误 | `TypeError: crypto.randomUUID is not a function` |

此次错误是浏览器方法缺失，不是后端业务错误；原错误的 `logId=null`，不能为它补造服务器日志 ID。后端诊断另含日志目录读取失败，原文保留在报告中；退出正常和清理错误数组为空不表示所有诊断均无问题。

原生产宿主 `frontend/dist/assets/plugin-host.js` 为 49559 字节，SHA256 `EEB0A7F932C5CADF16A576AEC452B1CF8920CA3C8F1C340DCB43035110D2E83F`；debug Rust 二进制 SHA256 为 `DD12214D8437F54B7D3F642C2E4719815ACF69BCD72AA2BDE1532C374BC345A2`。这些摘要只标识原失败输入。原报告、原生产产物及失败目录不改写，后续结果写入新的独立运行目录。

## 窄修职责与冻结输入

[package-loader.ts](../src/plugins/package-loader.ts) 将安全上下文相关的 `crypto.randomUUID()` 替换为模块初始化前缀与递增计数。计数在同一模块内共享，因此同一包卸载后重载、不同宿主实例启用同 ID 包，都取得不同资源运行路径。该标记不是 UUID，不承担鉴权或安全随机数职责；不新增依赖、公开 DTO、令牌要求或浏览器安全配置。

实际资源仍由已安装包入口适配器解析为 `/api/v2/browser-plugins/{id}/runs/{run_id}/assets/{entry_path}`。入口及其相对依赖继承同一运行目录；只在入口追加查询参数不能替代这项依赖图换代行为。原加载前取消、晚到模块撤销及包声明 ID/版本校验保持不变。

| 冻结文件 | 职责 | SHA256 |
| --- | --- | --- |
| `frontend/src/plugins/package-loader.ts` | LAN 兼容运行路径标记 | `144EF9A38E8847571130C662339EE432993646C9BC11F695C3D4D826EA77D39B` |
| `frontend/tests/plugin-packages.test.ts` | 缺少方法时实际 app 包用例的启停、重载、跨实例及全局恢复回归 | `ED2584B0621A554C7B9AB5F625AF9B9B14D59FC1F26D7DF7965C3B5C383A9C02` |
| `frontend/tests/extensions.test.mjs` | 保留激活/卸载/相对依赖换代断言，改用合法运行路径校验 | `C305F1B4A50D2BDB907120152030BF5107ACC1A3727329E90C2BC9E82F5D2023` |

三文件汇总 SHA256 为 `ECFCCC3E6D7437D2D9B1DF1682F91782A3ABBAE9E497B27D6B89CE12A6EB861E`。算法为仓库相对路径按 Ordinal 排序，每行 `路径<TAB>大写SHA256<LF>`，UTF-8 无 BOM，再计算 SHA256。主代理接管这些输入后的修补须另记版本，不能复用原冻结摘要。

新增回归以缺少 `randomUUID` 的全局属性和注入传输/模块导入器验证真实 runtime 调用链，不发网络请求，也不冒称真实浏览器。它保留重复启用不重复导入、卸载取消旧上下文、重载新代及相对依赖不复用的断言；不同宿主实例也不共享运行路径。释放各 runtime 后，在嵌套 `finally` 中恢复原全局属性，释放失败时仍恢复。另一处原相对依赖回归继续执行 load/unload/load 和两次激活，不把新路径标记伪装成 UUID。

主代理确认输入无并发编辑后，按工程门禁串行执行；以下仅为运行步骤，不是前端角色已执行的记录：

构建后核对新的生产 `assets/plugin-host.js` 摘要、字节数及其源码输入。驱动直接读取该生产 ESM，不用 Vite 开发模块替代。准备与记录本轮实际 debug/release 后端二进制，再在工程根目录执行同一驱动：

不得注入 crypto polyfill、放宽浏览器安全标志，或改成 `localhost`/`127.0.0.1` 后宣布兼容问题关闭。每次保留正式包摘要、生产宿主摘要、Rust 摘要、浏览器版本、真实 origin、安全上下文观测、逐项 EXB 结果及进程 exit/close。主代理执行所得新报告应独立于原失败报告，debug 通过也不能代替 release 通过。

当前已做只读源码/报告核对、UTF-8 与尾随空白检查、`git diff --check` 和冻结 SHA256 计算；由于工程文件多为 untracked，另对交接文件实际字节进行 UTF-8 与空白扫描。Git 提示后续操作可能转换 CRLF，只记录提示，没有执行格式化或改写其他文件。新增测试尚未执行，编译/类型检查尚未执行，生产 host 尚未由本角色重建，修复后的 debug/release 真实浏览器尚无通过结论。

本轮只验证本机经真实 LAN URL 的生产插件加载，不证明另一台同事机器、防火墙部署、npx 分发、平台真机、常驻性能会话或产品 UI。模块路径换代避免 ESM 缓存复用，卸载不会把已执行 ESM 从浏览器内存中卸出，也不能强制终止任意可信插件自身副作用；生命周期内的取消、引用拒绝、订阅和贡献撤销按原公开契约验收。

普通反馈按 EXB 编号和实际失败阶段汇总。非安全 origin 未满足、正式包摘要不匹配、在线启用仍报方法缺失或门禁无法开始均应即时回流；源码/驱动已冻结后，由主代理分配修补写集再编辑。本说明不扩大原驱动矩阵，也不新增产品界面或公开接口。
