# 交互终端公开接口消费边界

日期：2026-10-10。依据 [迁移实施裁定](../../backend/docs/交互终端迁移实施裁定.md) 与 [交互会话协议第五版裁定](../../backend/docs/交互会话协议第五版裁定.md)，本批更新后续前端消费边界；不新增 HTTP 接口、DTO、用例或产品 UI。终端、Frida、自动化和流媒体常驻会话仍属于完整迁移范围。

## 当前可核实入口

| 已有入口 | 可复用部分 | 当前边界 |
| --- | --- | --- |
| [HostContext](../src/plugin-sdk/index.ts) | 操作目录、submit/getJob/cancelJob、signal/onDispose，成功结果和错误关联日志 ID | 没有交互会话或输入/输出流入口；提交任务、取消任务不能替代终端会话协议 |
| [TaskHistoryAccess、JobEvent](../src/plugin-sdk/task-history.ts) | 任务历史与按 sequence 查询状态事件 | JobEvent 只有 sequence/jobId/status/timestamp，没有输出载荷；不能据此承载或还原终端输出 |
| [HTTP 类型与端点](../src/shared/api/types.ts)、[请求适配](../src/shared/api/endpoints.ts) | 从生成 paths 索引 HTTP 类型，显式取消、未知响应校验 | 已有任务请求返回有限 JSON 结果；新流式传输不能假定沿用 JobEvent 或现有 JSON 解包路径 |
| [WebPlugin、ExtensionAccess](../src/plugin-sdk/index.ts) | 面板、组件、模块、命令、版本化服务及可释放订阅 | 是可卸载扩展机制，不表示已有终端服务；普通扩展事件也没有会话持久化、重放和流背压保证 |

tool-process 的原字节双向流负责有界进程管道和直接进程生命周期；新一批继续公开后端插件会话 SDK 与运行库。本次接口边界来自第五版裁定，没有重新运行服务或浏览器验收，不据此声明宿主会话、HTTP/MCP 或浏览器用例已实现。

## 已冻结的插件协议 5 与运行入口

这是后端插件进程与宿主之间的一进程一会话协议，不是浏览器 API。后端 plugin-sdk/session 与前端 `src/plugin-sdk` 是两套独立契约；`protocol_version=5` 不修改浏览器 HostContext 的 apiVersion，也不进入旧协议 1–4 的普通任务请求路径。

| 冻结项 | 后续适配时必须保留的语义 |
| --- | --- |
| 握手和期限 | 一行 JSON 帧以换行结束，关联 protocol_version 与 session_id；Open/Ready/Start 独立握手。C0 在写出 Ready 前固定，Start 的剩余预算加在原 C0 上，等待 Start 不重启业务时钟 |
| 原字节输入 | input.bytes 是 JSON 字节数组，非法 UTF-8 与零字节保留；单块最多 8192 字节。空数组是空输入，只有 eof 关闭输入；EOF 后拒绝重复 EOF 和 input，仍接收 cancel |
| 原字节输出与顺序 | stdout/stderr 保留路标与 bytes；双路输出及所有 SessionOutput 克隆共享一个从 1 开始的递增 sequence，finished 使用下一个 sequence。空字节块不代表 EOF；不能按路各自编号或将流结束从空块推导 |
| 输出准入 | SessionOutput.send 成功只确认有界队列准入，不证明帧已写出、宿主已接收或浏览器已消费；正常结束关闭准入并排空已入队输出，取消后丢弃尚未写出的输出 |
| 容量与背压 | 通道默认 8、允许 1–64；累计输入默认 1 MiB、双路输出默认合计 16 MiB，配置上限各 64 MiB。输入队列满以可观察错误取消会话；输出等待受同一取消和截止点约束，超限在复制/入队前拒绝 |
| 取消和明确清理 | 取消、期限、异常断流、坏帧、输入溢出或传输失败撤销新的 I/O，但继续等待已启动处理器返回 Execution。finished 明确区分 cleanup=complete/failed；result 与非空 error 二选一，null 是合法 result，不能改写 failed 清理或把丢弃 Future 写成 complete |
| 传输宽限 | handshake_timeout 默认 5 秒、最多 30 秒；transport_grace 默认 2 秒、最多 5 秒，均须大于零。终态写出宽限独立且不延长业务截止点，也不是处理器清理超时；处理器不合作仍待未来宿主监督，不能自动确认资源已释放 |

公开运行入口为 `serve_session(options, handler)` 与 `serve_session_io(reader, writer, options, handler)`。处理器接收 SessionOpen、InvocationContext、SessionInput、SessionOutput，返回已有 Execution；这些是后端异步管道入口，浏览器插件不直接调用它们，也不透传内部 JSON 帧作为现成 HTTP DTO。

当前协议未接宿主 owner/generation 管理、持久化游标、HTTP/MCP、前端 SDK 或终端平台插件。session_id 不能代替完整 owner/generation 引用；插件 sequence 不能自行升级为浏览器可续读游标。终态发送失败仍是传输失败，不能据插件已构造或尝试写出 finished 推断宿主收到清理确认。运行库独立行为证据与未来宿主卸载、远端资源、真机及浏览器证据分别记录。

## 前端实施前仍须冻结的宿主公开协议

下面是宿主及浏览器仍需冻结的语义，不规定 HTTP 字段名、DTO、路由、错误码、传输方式或前端容量数值。插件协议 5 已有的字段、顺序和限制由适配保留，不能据此假定浏览器采用相同封套或限制配置。

| 事项 | 冻结要求 |
| --- | --- |
| 会话定位与所有权 | 公开会话身份、服务器资源 owner、其 generation 及当前代准入；浏览器插件运行代次与服务器代次分开，不从名称或本地选择推导服务器所有权 |
| 操作与输入确认 | 打开、读取、输入、关闭输入、停止、重查与清理的能力和顺序；明确输入已准入、已写入与业务已执行的区别，以及请求失联后的核实方式 |
| 输出载荷与顺序 | 插件共享 sequence 如何映射到公开输出、stdout/stderr 路标、终态和流结束语义；协议 5 没有按路 EOF 事件，不预造此类浏览器字段，不以时间戳替代已有顺序 |
| 游标与保留 | 公共游标与插件 sequence 的映射、作用域、重复、缺口、过期、回补、断线续读及日志保留；明确终态后能否继续读取与何时不再有输出 |
| 容量与背压 | 会话数、输入块/累计输入、输出块/累计输出、队列/缓存上限、慢消费者期限、容量拒绝及截断/丢失的可观察结果 |
| 生命周期 | EOF、直接退出、停止请求、取消等待、输出排空及清理确认的关系；远端资源与派生进程树的释放证据由提供者负责 |
| 错误与日志 | 请求和流中错误的关联日志 ID、协议错误、部分输出、非零退出、清理失败和失联重查方式；不得把任务 ID 或会话 ID 当日志 ID |
| 版本与发现 | 公开能力版本、缺失能力时的拒绝和降级范围、SDK 映射；PTY、resize、Frida 专用控制不从普通管道能力推导 |

领域端口、宿主 owner/generation、HTTP 协议和公开 SDK 适配冻结并生成 HTTP 类型后，才实施前端；插件协议 5 单独完成不能越过该门禁。源码、脚本与测试继续维护 TypeScript，保留 strict、noUncheckedIndexedAccess、exactOptionalPropertyTypes；不手改 generated.ts、不手写重复 HTTP DTO，不以 any 或断言绕过校验。当前仍为 Svelte 5，尚未切换 React；本批不变更框架，产品 UI 继续等待设计稿。

## 宿主接入候选（尚未冻结或实现）

新宿主批次第一步仅接交互声明、领域端口和进程适配；以下供接续裁定，不表示 HTTP/MCP、生成类型、浏览器 SDK 或前端用例已经变更。候选采用六个独立会话用例，与普通任务分开；未来 HTTP/MCP 调用同一宿主用例，输出先采用有限 JSON 页，不要求 SSE、PTY 或 resize。

| 候选用例 | 输入与最小结果语义 |
| --- | --- |
| open | 当前交互贡献、完整 owner/generation、符合模式的 input → 实际会话引用与状态。需在发送前具有可查询的打开关联标识，采用预生成会话 UUID 或等价定位机制，保证响应失联后仍可 status/清理；不自动重新打开 |
| send | 完整会话引用、0–8192 字节块 → 暂定只确认有界队列准入。公共流库不提供 flush/write 确认，不承诺已写出、处理器已消费或业务执行成功；空块仍是数据 |
| eof | 完整引用 → 关闭输入控制的准入和可查询输入状态。与 send 按服务器顺序处理，保持 EOF 后拒绝输入/重复 EOF、仍可取消；准入不伪装成插件已经收到 EOF |
| read | 完整引用、after、有限条数 → output/finished 页、后续游标、是否还有已保留数据与状态。立即返回且不破坏共享数据；空页保持游标，缺口/过期/超前明确报告，条数、字节与编码体积分别有界 |
| cancel | 完整引用 → 撤销准入并请求停止后的可查询状态。候选为幂等主动取消；不把 HTTP 等待取消自动变成会话取消，不将请求被接受写成 cleanup 完成 |
| status | 完整引用或冻结的打开关联标识 → 真实会话、输入、输出保留范围和清理状态。区分尚待确认、complete、failed 与失联后未确认，不用直接进程退出替代插件清理终态 |

每次请求和响应关联同一会话、服务器 owner 与 generation；浏览器挂载代次另作晚到保护。候选公共序号/游标采用规范 u64 十进制字符串，避免 JSON 数字精度损失；保留双路共享 sequence 和 finished 的后继序号，不把 JobEvent 或其他会话游标代入。内部 sequence 到公共游标的映射、缓存/保留上限、贡献发现、错误码和日志 ID 仍由宿主契约冻结。

候选接线为生成类型 → `shared/api` 端点/校验 → `app` 的独立 SDK 映射 → 注入网关的 `features/interactive` 用例；浏览器可选 HostContext 入口再经插件作用域包装，不直接公开协议 5 帧。作用域先撤销普通信号和订阅；若其打开的会话需随卸载清理，必须登记资源并使用独立、有界的 cleanup 信号，等待真实确认，不能复用已取消的普通调用信号。仅查看已有会话不自动取得停止所有权；具体退出策略尚待裁定。

## 后续模块职责

- `shared/api`：消费生成契约，校验身份、帧和公开限制，适配被冻结的流传输、取消及日志 ID。组件不 fetch，不持有令牌或服务器路径。
- `features` 中独立的交互用例：通过注入的公开网关处理输入、读取、游标、状态和销毁；把准入与归并规则拆为纯函数。用例不依赖 Svelte/React，不引用其他 feature 内部实现，不构造平台命令或 shell 字符串。
- 公开 SDK：按独立浏览器版本契约暴露必要能力，由 app 显式映射生成 HTTP 类型；插件检查能力是否存在和版本是否匹配。此文不新增 HostContext 字段或承诺沿用当前 apiVersion，不把后端协议 5 当作浏览器 SDK 版本。
- 浏览器插件：通过既有公开面板、组件、模块或版本化服务承接终端专属交互，登记可释放资源；不导入宿主私有模块。产品装配、视觉布局和框架切换继续等待设计。

## 框架无关消费规则

1. **打开与选择**：使用服务器实际返回的完整会话、owner 和 generation 绑定请求、缓存及游标；本地另维护视图/挂载代次以抑制晚到。同名会话不合并；服务器代次更新后旧引用撤销并显式重查，不编造客户端代次 CAS。
2. **输入**：按公开顺序有界提交；关闭输入排在已准入输入之后，确认关闭后拒绝新输入。输入失败、取消或失联均不自动重放；只有冻结的确认/重查协议才能判断其是否被接收，不把一次成功响应写成命令执行成功。
3. **输出**：先校验会话身份、代次、路标和公开游标，再接收与发布。保留插件双路共享 sequence 的顺序后再按路解码；若 HTTP 另设游标，使用冻结的映射，不直接等同。按协议去重，游标不回退；校验或消费失败不推进游标。finished 的 sequence 与输出同属一序列，不把它当普通输出，也不将 JobEvent.sequence 或其他会话游标代入。
4. **缺口与续读**：缺失/过期游标显式标记输出不完整，按协议回补或重查；不能静默跳到最新并显示为完整。只在协议确认同一连续流时恢复旧游标；owner 换代或重新打开时不复用旧缓存。
5. **背压与容量**：输入待发队列、输出待处理队列和展示缓存均有界，按公开上限与消费策略限制；优先使用传输提供的背压。若无法暂停或回补，按协议报告容量拒绝/截断并保留缺失标识，不无限积压或静默丢弃。停止读取不是停止服务器进程。
6. **文本解码**：原字节按每个会话的每一路输出维护独立 TextDecoder，逐块调用 `decode(chunk, { stream: true })`；确认该路连续字节流结束后才做末尾刷新。UTF-8 字符跨块不能分别解码，stdout/stderr 不能共用解码器；空块和输入 EOF 均不触发输出解码结束。失联或缺口不冒充流结束，也不继续把缺口两侧字节拼成完整文本；取消丢弃未写输出后不宣称输出完整。非法字节和末尾残片的展示策略后续确定，必须保留不完整标识。
7. **展示**：输出以文本节点或 textContent 写入，不作为 HTML。需要 ANSI 展示时另实现受限解析与样式映射，不执行输出内代码、链接动作或浏览器命令；原字节与展示文本的限制分别计算。

输入和输出可持续交错；不能等待进程终态才开始读，也不能因发送输入而停读输出。后续测试需证明慢消费者、满队列和等待终态同时存在时，期限/取消仍能收敛。

## 结束、销毁与清理

| 可观察结果 | 消费含义 |
| --- | --- |
| 关闭输入/EOF | 不再发送输入；进程可继续输出和运行，不表示资源已释放 |
| 浏览器请求取消或流断开 | 结束本次等待/接收；服务器输入可能已写入、进程可能仍运行，需独立生命周期重查 |
| 停止请求被接受 | 开始服务器停止流程；必须继续读取公开状态或确认，不直接显示清理完成 |
| 直接进程退出 | 保留真实退出状态和已有部分输出，按协议排空；不推断远端会话或进程树已释放 |
| 公开清理确认 | 仅按协议声明的 owner 和资源范围标记已清理；保留插件 complete/failed 的真实清理结果，清理失败、超时或失联保留不确定性；终态宽限耗尽不是 complete |

销毁和插件卸载先撤销当前输入入口、通知和订阅，取消浏览器在途等待，释放读句柄、解码缓存、定时器和专属 DOM，并登记/等待公开 Dispose。晚到成功、失败或输出都不得回写已销毁实例或新挂载代次。可信 JavaScript 忽略信号时仍可能有副作用，结束宿主等待不能证明它已停止。

是否同时结束服务器会话，必须由公开 owner 协议决定：若本次卸载承担服务器资源清理，调用被冻结的清理入口并等待确认；若只关闭浏览器视图，不擅自停止其他消费者的会话。面板退出、浏览器插件卸载、服务器提供者卸载分别处理。重载创建新的浏览器运行代次；发现服务器 owner/generation 改变时撤销旧会话准入，禁止旧上下文借新代复活。停止或清理失败后允许协议规定的重查，不自动重复有副作用的控制。

打开、输入、读取、停止、重查和清理分别保留实际返回的日志 ID；当前错误关联当前请求/帧，初始请求日志 ID 另行保存。遵循 [日志消费规则](日志ID与接口消费.md)，本地取消或准入失败无服务日志 ID 时保留 null，不把查询日志当执行日志，不从中文错误文本解析错误码，不展示令牌或服务器私有路径。

## 后续实施与验收顺序

1. 插件协议 5 已冻结；主代理继续接领域端口、宿主 owner/generation 与监督清理，冻结 HTTP/MCP 和浏览器公开 SDK，生成 HTTP 类型。前端逐项核对未知响应校验、内部 sequence 到公开游标的映射、独立 SDK 适配和错误日志关联，再实现注入式用例。
2. 用受控传输验证：多次输入与输出交错、原始非法字节/零字节、空输入与 EOF、双路共享序列与终态序列、跨块 UTF-8/分路/尾部残片、重复和缺失游标、满队列/容量拒绝、EOF 后取消、取消丢弃未写输出、传输宽限与明确 cleanup、失联与非零退出、取消后重查、销毁/卸载/重载及旧代晚到。对每项错误验证真实日志 ID 或明确缺省。
3. 主代理执行生成、严格检查、目标及完整测试和构建；再验真实服务器/插件流、公开浏览器入口和资源清理。公共 tool-process 的真进程行为测试只能证明本库边界，不替代这些链路。
4. 终端产品 UI 随设计稿实施后补交互、键盘与视觉验收；Frida 部署、注入、权限分析、自定义 hooks，自动化和流媒体常驻会话按独立插件及真实设备证据继续完成。PTY、resize、进程树清理按实际能力另行设计和验证。

本批交接冻结的是插件协议 5 到未来宿主及浏览器公开接口的消费边界。未实现交互 HTTP、浏览器会话 SDK、前端终端用例、常驻插件或产品界面；不将文档、公共运行库、原字节管道或已有任务事件计为完整迁移完成。
