# 在线插件与开放扩展

## 当前方向与范围

用户最新确定本地或同事局域网部署，默认免鉴权；在线安装插件按可信代码运行，不要求多用户权限或强制隔离。前端提供服务器包和浏览器包上传、安装状态及运行中启用/停用/卸载用例；具体页面与 UI 框架等待设计稿。

模式 architecture-first，采用公开契约与行为回归结合。选用版本化宿主扩展注册表与可注入动态加载器；不让业务组件直接维护插件全局数组或私自改动其他插件的挂载资源。插件可使用自行打包的 UI 库，宿主提供生命周期与扩展点。

## 公开扩展面

| 扩展点 | 插件可做的事 | 宿主责任 |
| --- | --- | --- |
| 界面插槽/组件 | 在具名位置 append 或 replace 自定义渲染 | SlotAdapter 分配专属租约，管理取消/清理/冲突；替换时释放默认 renderer，卸载恢复 |
| 页面模块/功能入口 | 注册模块 route/title 与 mount | 发现与调用；进入 mountModule、退出 unmount 子生命周期，插件卸载撤销元数据 |
| 命令/服务 | 发布可调用逻辑并消费其他公开服务 | 版本、显式依赖、冲突、失效与错误关联 |
| 逻辑钩子 | beforeTaskSubmit 变换真实任务提交输入，订阅公开事件 | priority 升序再 id 排序；失败停止后续钩子与 HTTP，卸载恢复剩余/原流程 |
| 服务器对接（当前 SDK） | listOperations/submit/getJob/cancelJob，操作订阅与扩展服务 | 公开模型映射、可选令牌、AbortSignal、日志 ID 与错误映射 |
| 管理与产物（宿主 app） | 插件 SDK 尚无这些适配入口 | runtime.serverPlugins/pluginPackages/artifacts 提供服务器管理、在线部署及产物上传下载 |
| 插件状态/事件 | 管理自身状态并订阅宿主公开变更 | 命名空间、订阅撤销、资源释放 |

“开放逻辑”必须落实为宿主确实调用的扩展点，并有可运行样例；仅允许 activate 执行任意代码，不能据此宣称已提供模块、服务和流程扩展。可信同页面代码可以产生全局副作用，宿主只保证已登记贡献和资源的收敛，插件应登记清理函数。

## 文件职责与生命周期

- shared/api：只消费后端生成类型，封装无令牌/可选令牌请求、原始包上传和结构化错误。
- features/plugin-packages：部署目录、上传/删除、服务器加载/卸载用例；管理请求取消后重新读取实际状态，不自动重放。
- plugin-sdk：公开版本化包加载、组件、模块、命令、服务、逻辑和取消契约，不依赖 app/features/shared。
- plugins/package-loader：从已安装包入口动态加载 ES 模块，校验运行声明；不把部署和运行加载混为一个动作。
- plugins/package-controller：管理本实例安装源、启停与撤销源；版本/入口变化先清理旧来源。
- plugins/extensions：按插件与运行代次持有贡献注册表，负责发现、冲突、组合与撤销；不实施业务网络或具体 UI 框架。
- plugins/manager、scope：串行启停、激活失败回滚、清理聚合、取消请求及晚到保护。
- app/runtime：装配客户端、公开用例与扩展注册表，提供挂载适配入口；不包含解包或业务路由。

运行卸载立即停止新贡献/新调用，取消请求与订阅，再逆序清理挂载、命令、服务、状态和资源；释放失败可见，其他资源仍继续释放。浏览器停用不自动卸载配套服务器包，两者由公开用例明确编排。

A 调用 B 的版本化服务时，在途信号包含 B 的运行代次；卸载 B 取消该信号，后续调用返回 service_unavailable，不自动停用 A。旧 B 的在途调用及上下文不会因重载复活，旧结果不可写回；A 此后按 ID 发起的新调用可使用新 B。插件应响应信号，忽略信号的函数可能继续执行，等待至其收敛后仍拒绝旧结果。

browser 部署删除只先停当前 runtime 实例并撤销其源，再发 HTTP DELETE；清理失败不删除部署，删除失败后通过新目录确认仍安装时可重新启用。服务端不能强制停止其他同事浏览器的已运行实例，已执行 ESM 的内存缓存也无法卸出。每次 load 使用 runs/{UUID}/assets 路径，入口和相对依赖继承前缀，避免重载复用旧模块状态。

生产公开入口 `/assets/plugin-host.js` 导出 createFrontendRuntime/createNamedSlotAdapter；运行装配由消费方负责，具体 App/main.ts 尚未接入产品 runtime。模块元数据与挂载 API 不等同已实现导航界面。

## 最低验收

无需令牌连接本地服务；分别上传服务器与浏览器包，在不刷新宿主、不重启服务器的情况下启停。样例实际注入组件、增加模块和命令、修改一条公开逻辑流程、调用服务器并返回日志 ID。卸载后所有已登记入口/DOM/订阅失效，旧代结果不污染重载实例。失败安装与激活回滚、同ID冲突、取消管理等待和可选鉴权另行回归。

生成类型、在线包用例与开放扩展已实现。主代理已通过 debug/release 真实生产 ESM 入口、两类包经 runtime.pluginPackages 上传/启停/删除、相对依赖新代、渲染替换/恢复和真实任务逻辑变换；报告为根 artifacts/browser-plugin-smoke-debug.json 与 browser-plugin-smoke-release.json。失败、取消、跨插件服务撤销、多钩子与模块退出另由前端行为测试覆盖。产品界面视觉、设备提供者与生产容量仍未据此验收。
