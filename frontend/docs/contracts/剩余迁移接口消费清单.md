## 各批共同验收与风险

1. **目录与代际**：当前目录为空、查询失败和本地失效分别表达。操作管理收敛先撤销再重查；失败/取消后旧查询不能复活撤销目录，新成功刷新可以恢复。设备保持完整 providerId/generation/localId；同名 localId 不合并、旧代引用不自动重绑。远端变更仍靠显式刷新，不声称实时推送。
2. **发现与历史**：设备主动刷新先清本代本地观测，服务端排队阶段不因此清其目录。refresh 消费自己的发布回执，晚到 A 不覆盖 B；Job 历史成功和当前目录接受不同。新的 rawState=None 整份替换旧原文；未知原文透传且不放行动作。依据 [RAW-02](../../../backend/docs/contracts/统一发现第二批契约.md) 与 [回执消费边界](统一发现发布回执消费边界.md)，不新增前端发布决定点。
3. **等待与取消**：保留插件实例、模块子作用域、caller 和 provider 撤销的信号合并。回调忽略 signal 时宿主等待仍应及时结束，晚 resolve/reject 不改变已结束结果且不产生未处理拒绝。客户端 Abort 不是服务器 Job 取消，也不证明可信插件副作用、工具进程或常驻资源已经停止；取消后管理实际状态按既有独立信号重查。
4. **历史独立**：get/list 返回旧任务不从当前 Operation.execution、设备目录或新代贡献补元数据。已卸载或同 ID 重载不改变历史输入/结果/错误；性能等新业务历史只消费其冻结历史记录，不将当前 provider 装饰成原执行来源。
5. **真实证据**：主代理统一执行适用生成/check/test/build 与真实生产浏览器，不由角色并行启动命令。记录当前 host/包/二进制摘要、HTTP 日志、运行身份、OS 退出与清理结果。确定性回归不能代替浏览器；模拟提供者/工具不能代替 Android/Harmony/iOS 真机，有限默认调用不能代替跨61秒长执行，已有 LAN 报告不能升级为新业务验收。
