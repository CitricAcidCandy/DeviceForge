# 平台适配器迁出的前端消费边界

## 依据与本轮状态

依据后端 [平台适配器迁出实施](../../backend/docs/平台适配器迁出实施.md)。本文最初对应主代理实施首步公共工具执行库 tool-process，只定义前端消费边界与后续审核条件，不独立声明执行库测试或真实进程验收结果；能力总期限冻结后的前端增量与验证缺口记录在下节。

后端目标是独立 Android/Harmony 设备插件与 Android 包工具插件，随后移除宿主的具体平台装配及隐式回退。当前首步限定文本、字节和文件输出执行：独立 argv、限定环境、输出限额、总期限、取消与直接进程退出；协议帧解析和平台命令仍不属于公共库。公共库提取不能证明平台业务已迁出、常驻连接已完成或设备 UI 已实现。

设备第一阶段公开目录、离散动作、旧代拒绝及嵌套产物的历史验证保留原范围，见 [设备第一阶段实施](设备提供者第一阶段实施.md)。那些 debug/release/npx 证据不自动成为本轮工具库、实际 Android/Harmony 插件或真机验收。本轮构建、测试、真实进程与分发检查由主代理串行统一；本文未执行这些命令。

## 公共库与浏览器的职责

| 单元 | 前端消费方式 | 边界 |
| --- | --- | --- |
| tool-process 公共执行库 | 由后端平台插件或宿主适配器使用 | 不新增浏览器 shell、任意命令、可执行文件路径或服务器本机路径接口 |
| 平台设备插件 | 通过公开提供者/能力目录发现，再调用 HostContext.devices | 浏览器不运行 ADB/HDC，不拼接平台命令，不按 platform 硬编码执行分支 |
| Android 包工具插件 | 通过公开操作目录和任务入口消费其贡献 | 不借用浏览器设备状态绕过宿主准入，不将包处理库暴露为本机文件访问 |
| 宿主 app | 装配客户端、任务、产物及服务器/浏览器插件管理入口 | runtime.serverPlugins/pluginPackages/artifacts 不自动成为插件 SDK 能力 |
| 浏览器插件 SDK | 使用独立公开模型、显式信号、日志与错误 | 不导入后端或宿主私有模块，不持有工具路径、签名材料或服务令牌 |

工具路径、签名材料及共享 ADB/HDC daemon 属于部署配置。业务 input 继续传公开参数和产物 ID，不能传服务器路径；输出沿既有任务结果及产物入口消费。协议 2/3 带产物的 Job.result 保留 `{ result, artifacts }` 包装，日志沿 HostResult.logId/HostError.logId，不因公共库提取增加 HTTP/SDK DTO 或浏览器接口。

工具库首步未修改公开类型、生成 DTO、前端源码或产品入口。公开契约加法由主代理冻结并生成 HTTP 类型，再由前端显式映射独立 SDK；本轮预算字段沿此职责实施，生成同步由主代理负责，不预造额外端点或 DTO。

## 能力目录、设备引用与旧操作

当前 HostContext.devices 是 SDK v2 可选字段，旧宿主可省略。既有 refreshProviders/refreshDirectories/refreshProvider/invoke、select/snapshot/subscribe 保持原签名；平台名称只用于展示和筛选，入口按精确能力 ID/版本、作用域、观测及可用状态决定。Harmony 只展示实际声明的能力，不从平台名称推断它已具备输入、性能或完整应用管理。

DeviceRef 的 providerId/generation/localId 是完整调用身份；同名 localId 不足以选择提供者。提供者卸载、消失或换代后撤销旧观测、选择与相关请求，旧上下文和晚到结果不能复活新代。刷新开始清该代旧观测，本实例服务器管理后先撤销目标缓存再重查，其他实例变更仍通过显式刷新获知，没有远端推送承诺。

旧裸 device_id、旧操作名称及 recovery/sideload/bootloader 状态需要后端明确兼容映射。多个提供者拥有同一本地 ID 时，由显式绑定配置确定来源，歧义应拒绝；前端不能按 platform、目录顺序或默认第一项猜测。旧操作别名须共享当前 owner/generation、设备锁和准入，不能由前端再提交第二个任务补做平台调用。历史任务保留原操作与结果，不因卸载或升级重写。

## 安装总期限契约与任务取消

2026-10-09 能力总期限加法已冻结：设备声明支持 API 1/2，字段位于每项 DeviceCapability.execution_timeout_ms，类型为可选整数；仅 API 2 可声明非空值，范围为 1–120000 毫秒。API 1 不接受非空预算，API 1/2 缺省或 null 均由宿主采用 30000 毫秒。浏览器 SDK 保持 v2，公开可选只读 executionTimeoutMs，不改变 DeviceAction/invoke 请求，不增加浏览器覆盖预算入口。

前端沿既有分层最小实现：plugin-sdk/devices 定义独立模型，shared/api/device-validation 校验声明版本及范围，app/device-gateway 显式映射生成字段；未声明时保持 SDK 字段省略，不补默认值或裁剪越界值。HTTP DTO 继续索引主代理生成类型，不手写第二套结构。测试源码覆盖旧 API 1、API 2 缺省/null、上下界、非法值/版本、目录映射及动作无预算字段；生成字段同步和运行门禁由主代理统一，本轮前端未执行 npm、构建、生成器或服务。

公共库具有超时/取消机制或前端能够读取预算，不等于长安装已经等价迁移。旧 APKS 边界为 120 秒，协议 2 进程默认 60 秒；后端须按冻结契约传播整体截止点，设备调用不能被更短固定窗口截断。前端不通过延长浏览器等待绕过宿主期限，实际长预算、取消和清理仍需本轮独立运行证据。

排队、取锁、输入副本、执行和发布须共享准入起的同一截止点，不能各段重新计时或被协议层另行截短；清理另有独立且有界的预算。前端后续只消费正式公开的能力与任务状态，不把工具库局部超时当作整次安装完成或回滚。

现有 AbortSignal 管理调用等待、插件实例及挂载子生命周期；设备动作提交后返回共享 Job，仍需查询终态。取消本地 HTTP 等待不等于已接受任务被服务器取消，更不等于安装事务回滚；任务取消沿公开 cancelJob 入口，是否完成以服务器任务/清理状态为准，不自动重放写动作。下一步须统一验收任务取消如何传递到排队、锁、工具执行及产物发布；取消请求被接受不能替代子进程退出和资源清理证据。

## 性能会话与热卸载的下一步契约

性能暂停/恢复/结束、存储、分页与恢复由宿主会话基础设施负责，采样源动态绑定平台插件。会话须绑定当前 owner/generation 和完整设备引用，每次采样共享设备准入；卸载撤销入口、取消并等待会话排空，历史继续可查，重载不令旧会话调用新代。

这些是后端下一步的公开契约与验收要求，不是当前 devices SDK 已提供的性能会话能力。不能以永久持有 probe、禁止卸载 protected 插件或浏览器面板退出代替会话收敛。现有协议 2 PerformanceAccess 兼容需保留，协议 3 加法与清理确认另行冻结；本文不新增会话 DTO、端点或 SDK 方法。

资源尚未确认收敛时保持 draining/cleanup_failed，并拒绝新代及不再具备准入条件的排队任务。前端不能因取消等待或本地移除条目显示“清理完成”。工具直接进程退出仅证明该次调用退出，不证明后台派生进程、持续连接或真机事务已经结束；共享 ADB/HDC daemon 不得因插件卸载被误杀，自有连接和借用连接需由后端分别记录。

本步非合作服务器插件在直接进程清理失败或执行 Future 被丢弃时也保留 cleanup_failed。前端沿现有错误及运行状态消费，不自动清除、重装或换代；无需新增 DTO。普通取消/超时且直接退出已确认时不标记失败，直接退出仍不等于外部资源已释放。

## 审核风险与证据要求

| 风险 | 审核要求 |
| --- | --- |
| 公共执行库被当作浏览器通用命令入口 | HTTP/SDK 不出现 shell、工具路径或任意本机文件字段，平台业务只走公开操作/能力 |
| 只迁出发现，宿主继续隐式执行平台业务 | 核对后端装配与回退全部撤除；空插件且无平台工具/签名材料仍能启动，库提取不能代替此项 |
| 旧操作或同名设备绕过代际/锁 | 显式绑定、歧义拒绝，别名与新能力共享 owner/generation 和写锁，旧引用及晚到结果失效 |
| 长安装被更短窗口截断或分段重计时 | 审核能力预算、协议兼容、统一截止点、取消与清理预算，不凭局部工具超时宣称等价迁移 |
| 卸载只关闭面板，采样或后台资源仍运行 | 审核会话排空、旧代不复活、draining/cleanup_failed 及自有/共享资源归属 |
| 非零退出、失败文本和设备状态被混为成功 | 区分任务准入错误与执行失败；现有 Response.error 为字符串，不宣称完整平台结构化错误已完成 |
| 历史模拟或分发报告扩大为新平台验收 | 按当前实现记录工具库、平台包、HTTP/MCP、release/npx、真机和远端各自证据，不复用旧报告冒充新范围 |

本文最初交付消费职责与风险说明；能力总期限契约冻结后，前端另增量实现模型、校验、映射和兼容测试源码。构建、测试、真实进程及平台分发证据仍由主代理串行汇总。后续应分别证明执行库行为、公开期限/别名/会话契约、实际平台插件、去除宿主平台装配、当前分发和真机行为，逐步记录退出码与未验证范围。

前端 UI 等待设计稿，main.ts 仍未装配产品 runtime。本轮没有占位页面或 UI 库，新增字段仅为公开能力元数据；不将公共工具库或预算映射写成平台迁出、常驻连接、iOS、产品 UI、视觉、生产容量或真机完成。
