# 独立业务插件开发辅助包

本包仅消费公开 SDK、共享 React 与普通语言依赖，不读取宿主工程。它不是新的插件管理器、服务总线或集中业务容器。

| 公开入口 | 职责 | 不负责 |
| --- | --- | --- |
| `api` | 公开错误兼容构造、取消等待、操作元数据校验 | HTTP 私有客户端、凭据、业务请求重试 |
| `jobs` | 复用既有作业轮询及结果封套校验、原字节摘要验证 | 后台执行器、自动重放、设备调用 |
| `platform` | 公开上下文的作业适配、目录观察与完整设备引用隔离 | 产品页面装配、私有宿主状态 |
| `react` | 可撤销界面操作、内联错误和真实日志显示 | 全局业务对象、强制取消服务器任务 |
| `workspace` | 登记页面、工作区和默认实例，尊重已有布局 | 宿主路由清单、覆盖用户布局 |
| `device` | 完整设备引用、能力模式和任务观测校验 | 平台名称分支、绕过设备准入 |
| `dialog`、`sheet`、`select-field` | 基于共享 React、Radix 和公开基础组件的展示适配 | 私有宿主组件导入、业务状态 |

采用 architecture-first／Hybrid：保持既有业务规则，先将业务实现从宿主集中装配拆出，再用直接单元验证取消、代次和未知结果。任务、操作和产物类型均以公开 SDK 为唯一模型，不维护第二份生成 HTTP DTO。原任务封套按未知值校验，产物映射到 SDK 的 camelCase 字段后才向业务层交付。

此目录提供独立开发的公开包出口。现已生成 `dist` 中的 ESM、严格声明和本地 `deviceforge-business-kit-0.1.0.tgz`；归档移除开发路径条件，保留共享 React、SDK 与普通语言依赖，不内联宿主实现。它是开发依赖包，不是可直接导入市场的插件安装包，也未发布 registry。

在独立工程中，将实际交付的 SDK 与辅助包 TGZ 放入工程 `vendor/`，先按清单安装普通依赖，再同时安装这两个明确本地输入：

```powershell
npm install --ignore-scripts --no-audit --no-fund .\vendor\deviceforge-plugin-sdk-0.1.0.tgz .\vendor\deviceforge-business-kit-0.1.0.tgz
if ($LASTEXITCODE -ne 0) { throw '本地公开依赖安装失败' }
```

此命令不要求宿主源码；普通依赖若不在缓存中仍需要可用的软件包源。本批通过实际 TGZ 解包后的独立 NodeNext 工程验证声明、运行时错误身份以及没有宿主源码输入；没有把该验证扩写成所有业务插件已经发行或真实市场安装通过。

当前公开界面套件没有声明 Dialog、Sheet、SelectField；本包因此显式依赖普通 Radix 语言包并导出展示组件，不通过读取宿主组件源码来运行。后续若 SDK 正式发布相同组件，须经兼容核对再合并入口，不能暗改现有插件依赖。
