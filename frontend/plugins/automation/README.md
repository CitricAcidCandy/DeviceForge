# 自动化工作区插件

身份和版本由唯一 `manifest.json` 提供，工厂入口不维护第二份版本。公开出口为 `.`、`./model`、`./services`、`./view`。

保留设备步骤、桌面操作、输入录制与回放三个视图，页签隐藏时保留草稿。调用沿公开 SDK 的操作目录、完整设备引用、Job 与产物通道；不导入宿主产品对象，也不建立新的执行器。

真实鼠标和回放仍需用户确认。回执只确认派发与服务器结果，不把派发成功说成界面效果通过。停止页面等待不自动重发或取消未知后台任务。

启用只登记 `/automation`，打开视图才读取能力。旧宿主适配保留。尚未生成 `dist`，未进行浏览器、桌面输入或设备验收。
