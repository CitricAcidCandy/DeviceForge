# 分析与数据工作区插件

唯一清单提供插件身份和版本。公开出口为 `.`、`./services`、`./view`、`./dex-analysis`、`./msgpack`。

保留 DEX 直接分析和 MessagePack 编解码、分页与筛选。输入是公开产物 ID，上传、下载与后台 Job 均走公开 SDK。原业务封套先按未知值校验，再映射到公开 SDK 产物字段，不维护第二套 HTTP DTO。

启用只登记 `/analysis`，不会执行分析或读取所选设备。操作取消后保留真实任务票据，恢复查询原 Job 而不重新提交。

原宿主适配保留供集成迁移。本目录尚未生成 `dist`，没有进行浏览器或真实分析文件验收。
