# 任务与日志插件

本工程只依赖公开 SDK、共享 React、`hostUi`、公开独立业务库的Sheet组件和普通语言依赖。身份及版本只在 `manifest.json` 维护，默认导出接收 `{ id, version, apiVersion }` 的工厂，由装配或打包入口注入身份后得到 SDK v2 插件。宿主工程不属于运行或开发依赖。

公开开发入口为 `@deviceforge/tasks`、`@deviceforge/tasks/model` 和 `@deviceforge/tasks/view`。当前清单指向构建后的 `dist/index.js`；源码导出用于工作区开发，不能把未生成的 `dist` 声明为已交付产物。SDK `0.1.0` 目前是本地 TGZ 候选，需先安装实际提供的 SDK 归档，不能假定 registry 已发布。

插件注册 `/tasks` 页面、默认任务工作区与 `taskPolicy: all` 元数据。列表按需读取，支持状态筛选、时间排序、每次增加 50 条直至 200 条。关键词、任务 ID 和日志 ID 搜索通过公开请求查询服务器保留日志；日志扫描上限、缺失关联任务和请求日志 ID 保留可见。构造模型不会读取服务器，隐藏页面暂停自动轮询；重新显示不重放写入。

取消使用公开 `cancelJob`。回执仍运行或取消请求失败时，状态保持“未确认”，只能查询已有任务核对结果；构造、切页和重新挂载不会再次发送取消。任务选择和插件卸载会隔离旧结果。下载只使用结果封套列出的产物，并核对原字节大小及 SHA-256；局域网 HTTP 也不跳过摘要校验。

插件激活时自动向外壳底栏贡献原任务状态行，点击后向上展开任务抽屉，无需用户添加功能。通过公开页面目录的 `operations/taskPolicy` 及默认外壳公开哈希地址匹配当前页，不维护宿主固定路由表；地址缺失或冲突时标明范围未确认，不显示全部任务冒充当前页。任务列表最多200条，数量只代表当前列表观测。

抽屉保留进行中/失败/全部、展开明细、事件、提交内容、结果、复制ID和跳转全部任务。列表轮询不反复撤销正在读取的明细；明细在展开或显式刷新时有界读取，收起、跨页和卸载结束旧等待，晚到结果不能复活。抽屉不派发、取消或重放后台任务，未知状态仅查询核对；布局用Tailwind、流式换行和内部滚动，不整体缩放。Sheet来自实际可独立提供的 `@deviceforge/business-kit/sheet`，不依赖宿主私有组件或假定辅助包已发布registry。

可发现扩展点 `<插件ID>.toolbar@1.0` 只接受追加贡献，数据形如：

```json
{
  "title": "检查任务指标",
  "view": { "pluginId": "sample", "viewId": "sample.metrics" }
}
```

消费者须先注册对应公开视图。用户点击工具按钮后在任务工作区打开该视图实例并追加浮窗布局，实际挂载仍由宿主管理；贡献撤销后工具入口移除，视图提供者卸载后的实例保留缺失说明。

当前实现保持既有任务页面结构与视觉语言。未执行独立分发构建、浏览器或真实服务验收，这些状态不能由模型单元测试替代。
