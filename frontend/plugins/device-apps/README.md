# 独立设备应用视图

唯一插件身份来自 `manifest.json`。本工程通过公开 SDK 登记 `deviceforge_device_apps.main` 视图，能力标记为 `device.apps`；不登记 `/devices` 页面，不接手投屏，不在激活时读取目录、发现设备或提交业务。

## 职责

| 单元 | 输入、输出与副作用 | 边界 |
| --- | --- | --- |
| `src/services.ts` | 完整设备引用、公开能力与产物 → 受目标撤销约束的应用和包分析模型 | 不改选全局设备，不读取宿主私有工厂 |
| `src/model/package-analysis/` | 产物输入、公开 Job 与生成契约 → 七类结果及可核验下载 | 保留旧输入、结果、恢复和产物校验；不重复提交未知写入 |
| `src/instances.ts` | 工作区实例与代次 → 独立模型、草稿和撤销 | 隐藏或 DOM 重挂保留草稿，关闭、换目标、卸载释放所属订阅和等待 |
| `src/drafts.ts`、`src/view/` | 实例草稿、真实结果 → 原列表、菜单、安装区和分析抽屉 | 原布局翻译为 Tailwind，无新增 CSS，无 JSON 表单替代 |
| `src/view.tsx` | 公开工作区目标、可见性 → 挂载和释放 | 完整设备引用不一致时停止交互，隐藏关闭 Portal |

## 保留能力

应用列表支持真实标识筛选、分批显示、原始输出、启动、停止、详情、清除数据与卸载。能力准入复用公开的 `business-kit/device`，按版本、输入字段、设备状态和提供者代次判断，不按平台名称增加业务分支。清除数据与卸载保留二次确认。

安装保留 APK、APKS、HAP 上传、产物 ID 输入和 APKS 模块选择。包分析保留清单、签名、精确提取 APK、AAB 构建、反编译、SDK 规则扫描、APKS 设备规格匹配，以及原结果、产物下载和大小摘要校验。HTTP 类型索引公开生成契约，不手工维护第二份服务器 DTO。

操作订阅尚未收到目录时，不把空状态当成能力不可用，也不在激活或挂载中自动查询。用户显式读取应用或运行分析时先通过公开接口取得操作目录，再验证能力、提交一次业务。已知能力不存在时明确失败。

等待取消只结束本地等待，不证明后台 Job 或设备写入已取消。已知票据可经公开模型显式查询或取消；未知受理保留原错误与日志，不扫描会话、不重复提交，不封锁后续独立操作。此插件不拥有需要批量释放的常驻设备会话。

## 公开包与集成

公开出口为 `@deviceforge/device-apps`、`/model`、`/services` 和 `/view`。生产源码只消费公开 SDK、`@deviceforge/contracts/api`、`@deviceforge/business-kit/*` 及 `@deviceforge/devices/model`；后者已在本包显式声明依赖，用于共同的完整设备目标格式。

工作区引用：

```ts
const provider = {
  pluginId: 'deviceforge_device_apps',
  viewId: 'deviceforge_device_apps.main',
};
```

旧 `devices.apps` 的追加与替换、原持久视图引用的精确迁移由宿主兼容装配处理。本工程不导入旧槽位渲染器，不争用其他实例的旧槽位。

本批交付源码工程和本地开发出口；`dist`、独立发行包与安装后运行验收尚未生成。`file:` 依赖为当前工作区开发方式，不代表这些包已在 registry 发布。正式分发需由平台发行工具提供 SDK、契约、公共业务包及构建后的浏览器组件；不能让第三方依赖本机工程路径。
