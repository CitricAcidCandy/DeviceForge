# 独立终端工作区

本工程通过公开 SDK、HTTP 类型契约和业务基础包实现终端，不读取宿主 `features`、`pages` 或 `app` 源码。唯一开发身份来自 `manifest.json`；入口工厂使用装配器传入的身份，不维护固定插件清单。

## 文件职责

- `src/model/api.ts`：直接索引公开生成 HTTP 契约，校验会话身份、原字节和收据。
- `src/model/`：复用既有会话状态、输入串行、连续游标、取消及晚到隔离规则。
- `src/model/ownership.ts`：只追踪本实例收到真实成功打开回执的会话；清理先读完整身份，再释放并只读查询终态。
- `src/services.ts`：普通业务使用 `context.transport`，释放通过 `context.onCleanup` 提供的独立信号、截止点和请求能力。
- `src/instances.ts`：每个工作区实例独立保留模型和草稿；隐藏、DOM 重挂不会释放，关闭或换代只清理对应实例。
- `src/view.tsx` 与 `src/view/`：复用原终端界面、xterm 模拟器和 Tailwind 外观；公共组件经 `hostUi()` 取得，菜单使用公开 Radix 原语。

## 清理与未知结果

宿主必须提供可选的 `onCleanup`，否则激活失败且不登记 `/terminal` 页面，不偷偷接管旧终端。卸载后普通通信仍然失效，只有已登记资源释放回调可使用短期清理通路。

清理默认最多等待五秒，不扫描关闭其他会话，不删除历史记录。只有完整身份一致、已观察到 `Finished` 且服务器报告直接进程退出及清理完成，才记为已确认释放；`Stopping` 只是受理证据。超时、错误及未知释放保留原日志，不重放释放，不封锁独立新实例。

打开失联可能已经在服务器创建会话，但没有客户端关联键可证明归属。此时保留原错误和日志，显式刷新记录供用户核对，不自动认领、重新打开或清理未知会话。历史列表的关闭、删除均为用户显式操作，不表示浏览器实例自动取得这些资源的归属。

视图隐藏暂停输出读取，保留会话、游标和档案/原始记录草稿；重新显示只继续读取，不重放输入。输入响应未知后停止队列，保持原日志，不能把派发或 EOF 收据解释为目标程序已经消费。

## 公开出口与交付边界

公开开发出口为 `@deviceforge/terminal`、`@deviceforge/terminal/model`、`@deviceforge/terminal/services`、`@deviceforge/terminal/view`。本地工程消费真实 SDK TGZ 与公开 HTTP 类型包；业务基础包仍由当前源码工程提供，不能据此虚构已发布的 registry 包。

当前只交付源码、直接单元和定向 strict 证据；未生成 `dist`、未做独立发行物闭环、浏览器/实际终端子进程或设备验收。旧宿主页面和功能未在此写集中删除，正式装配、别名生成及迁移接管由主代理集成。
