# 文件与产物官方插件

业务模型、字段校验、请求取消和页面均属于本工程，生产源码仅消费公开 SDK。清单身份和版本只由 `manifest.json` 维护，浏览器发布包装或本地装载器把派生身份传入默认工厂。

## 公开入口

| 说明符 | 源入口 | 用途 |
| --- | --- | --- |
| `@deviceforge/files` | `src/index.ts` | 从清单身份创建插件 |
| `@deviceforge/files/model` | `src/model/index.ts` | 纯模型、兼容字段映射及公开类型 |
| `@deviceforge/files/view` | `src/view.tsx` | 复用宿主 React 的专用文件界面 |

SDK 开发依赖使用真实本地发行物 `../../sdk/dist/deviceforge-plugin-sdk-0.1.0.tgz`，当前没有 registry 发布地址。上述说明符必须由实际开发包或本地装配明确映射，不能把本表当作已经发布的包。

构建输出为 `dist/index.js`，打包继续使用公开单清单工具。打包只收集已构建产物，不执行隐式构建。宿主装配读取本清单，不手写第二份 `package.json`、`plugin.json` 或 `market.json` 身份。

## 生命周期和保留功能

激活登记页面、工作区、视图、默认实例及自有工具扩展点，不读取业务数据。只有持久布局仍引用默认实例时才重新认领，用户关闭的视图不会因重载被插回。

每个挂载创建独立模型，提供上传、按 ID 查询、元数据、ZIP 分页、原字节下载及确认删除。范围和身份校验沿用原实现；取消、切换和卸载均隔离晚到结果。未知删除或上传结果不自动重放，界面保留日志并提供重新查询。

## 插件加载即生效的工具

公开 `deviceforge_files.tools@1` 只接受追加，贡献数据为 `{title,pluginId,viewId}`，视图由贡献插件先用公开工作区接口登记。提供者先加载时贡献等待；文件插件出现后自动建立临时实例和分栏，多工具放进同一工具页签组，不要求用户添加视图或编辑布局。

消费方文件插件拥有组合实例；贡献撤销时立即移除对应节点，折叠自有包装并恢复原文件区域，其他插件的草稿、浮窗和覆盖层保留。文件插件重载时先清理自己此前保留的临时工具实例，再按当前贡献重新建立，不能让旧运行代污染新代或在布局中叠加。装配失败写入所属诊断事件，不冻结后续独立新贡献。挂载工具不自动开始采集或重放业务，实际文件业务依然由原视图处理。

旧宿主功能入口只是本模型的字段与错误类适配，不维护第二份业务状态机。新的布局、运行交互和独立分发仍须按各自真实验证结果记录。
