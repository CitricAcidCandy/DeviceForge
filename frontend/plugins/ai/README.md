# 独立 AI 工作区

本工程保留原 AI 助手的 SDK/CLI 切换、会话列表、实时回答、单次任务、线程续聊、SDK 编排助手、原始结果及设置抽屉。业务实现归插件所有，仅消费公开 SDK、HTTP 生成契约和业务基础包，不读取宿主 `app`、`features` 或 `pages`。

唯一开发身份来自 `manifest.json`。公开工厂接收装配器提供的 `id/version/apiVersion`，通过工作区契约登记 `/ai`，激活不挂载业务视图、不刷新业务目录、不调用外部模型。

## 模块职责

| 单元 | 输入、输出与副作用 | 边界 |
| --- | --- | --- |
| `src/model/api.ts` | 从公开生成契约索引协议5会话类型，校验原始 HTTP 数据 | 不手工重复服务器 DTO |
| `src/model/gateway.ts` | 公开请求转为会话网关、Job 网关和 SDK 操作目录 | 显式映射蛇形 HTTP 字段，不创建第二套通信体系 |
| `src/model/sdk/` | 六项 SDK 普通任务、输入规范、最终结果和目录换代 | 不推导真实模型资格，不重提未知任务 |
| `src/model/cli/` | CLI 普通任务、线程管理、旧输入转换及结果校验 | 不读取宿主原模型，不解析任意私有状态 |
| `src/model/sdk-stream/` 与 `cli-stream/` | UTF-8/JSONL、页游标、条目、真实终态和目标隔离 | `turn.completed` 不代替服务器 Finished 与清理证据 |
| `src/model/ownership.ts` | 记录成功打开/受理的本实例资源，有界释放和只读确认 | 历史目录、恢复及未知提交不自动取得归属 |
| `src/services.ts` | 组合实例模型、草稿、目标信号和公开清理注册 | 不抢注册宿主已有 AI 公共服务 |
| `src/instances.ts` | 按实例及代次保留模型，关闭或换代撤销对应资源 | 页面隐藏和 DOM 重挂不删除草稿 |
| `src/view.tsx`、`src/view/` | 复用原 Tailwind 界面、公开组件及设置抽屉 | 无新增 CSS，无宿主业务私有导入 |

## 资源与未知状态

只有成功打开回执且完整会话身份合法，才取得流会话归属；只有成功 Job 回执且操作一致，才取得任务归属。打开或提交结果失联保留原错误和日志，不扫描目录猜测、重复提交提示词或取消其他调用。

关闭实例、停用或卸载使用 `onCleanup` 的独立信号与请求通路，只处理已归属资源。清理先查询完整身份，再最多派发一次释放或取消，随后只读查询实际终态；总等待不超过本次清理截止点及五秒。`Stopping` 只是已受理，流释放还必须观察到 Finished、直接进程退出及清理完成。Job 终态不扩展为整个提供者进程树已释放。

目标变更撤销旧普通请求、轮询和结果，旧目标的已归属资源独立清理，新目标无需等待历史清理错误。SDK 与 CLI 各有独立资源范围。切换提供者只切换界面；切换项目或线程才建立新的目标信号。页面隐藏停止前台观测，保留模型、游标和草稿，不重新发送已提交输入。重新显示后可显式查询或恢复已有会话。

线程 ID 属于提供者持久会话。关闭线程仅确认服务器恢复资格关闭，不证明提供者历史已删除，因此卸载不擅自批量关闭历史线程。客户端取消等待也不冒充后台取消；后台资源撤销单独经清理回执确认，失败保留诊断。

## 与宿主现有 AI 服务的重叠

| 现有公开服务 | 原能力 | 此插件的关系 |
| --- | --- | --- |
| `host.ai-sdk@1` | 六项普通 SDK 操作，宿主模型处理目录、Job 和结果 | 插件拥有等价的实例模型，通过公开 HTTP 执行，不调用其私有模型、不重复注册 |
| `host.ai-sdk.stream@1` | 宿主共享的 SDK 流会话模型及快照 | 插件分别创建每实例流模型，避免跨实例共享选择、游标和清理归属 |

上述旧公开服务仍由宿主维护，主代理后续统一迁公共适配；本工程没有修改它们。原 CLI Task 事件观察器不是现有 AI 页依赖，仍留在旧兼容功能中；本工程不宣称其已迁出。全部旧页面、旧模型和根装配的最终退役需主代理集成。

## 插件命名空间公开服务

`src/public-services/` 已迁入普通和流服务的请求校验、动作派发、有限 JSON、大小限制、公开错误序列化与日志映射。入口只登记服务，不创建模型；第一次实际调用后才创建专属 `createAiServices`，与工作区视图的模型和资源归属隔离。`aiPublicServiceRefs(pluginId)` 从实际插件身份派生引用，当前清单对应：

- `deviceforge_ai.sdk@1`：`runtime.status`、`sdk.single`、`sdk.turn`、`session.get`、`session.close`、`assistant.run`。状态请求为 `{ action }`，其他动作使用 `{ action, input }`，输入继续沿原 SDK 规范。
- `deviceforge_ai.sdk.stream@1`：`definitions`、`records`、`open`、`resume`、`output`、`poll`、`query`、`cancel`、`clear`、`snapshot`。打开使用 `{ action:"open", input:{ project_id, prompt, thread_id? } }`，恢复使用 `{ action:"resume", id, owner:{ project_id, thread_id? } }`，输出及轮询可传 `limit`。

两个服务均限制输入 JSON 为 1 MiB、输出 JSON 为 32 MiB，按 UTF-8 实际字节数计算。返回只含业务数据及真实日志，不把普通任务的内部 Job 封套当成业务结果。未知任务等待保持原 `JobWaitFailure`、任务票据、提交日志、最后已知日志及原因，不压成新请求。

`clear` 只清前台选择和观测，不抹掉该服务已取得的后台资源归属。调用方取消或卸载只撤销本次调用资格，不销毁提供者模型；提供者停用/卸载才独立释放其自有资源。重载建立新模型，旧代晚到成功不能继续提交任务或复活选择。

本工程不注册 `host.ai-sdk` 或 `host.ai-sdk.stream`。宿主可把旧 ID 改为薄转调，使用本次服务调用上下文携带的 `services.call` 继续转发到以上版本化引用，保持父调用链、取消、期限与日志；不得借转调再建立第二份模型、改写动作或自动重试。提供者缺失时应明确不可用，不静默回落旧业务闭包。旧 ID 的实际装配、停用恢复及全局接管由主代理集成验证。

## 公开出口与验证边界

公开出口包括 `@deviceforge/ai`、`/services`、`/view`、`/model/sdk`、`/model/cli`、`/model/sdk-stream`、`/model/cli-stream`。开发出口指向本工程真实源码，分发声明和模块指向 `dist`。

当前交付源码和直接单元证据：四类模型 62 项、生命周期 8 项、JSDOM 真实组件行为 2 项、清单装载与导入边界 2 项，以及专用 strict。JSDOM 只验证 React/DOM 行为，不作视觉、浏览器或真实模型验收。

公开服务批次另增加 10 项直接单元，按新增项分批通过；未重复运行前批 74 项。覆盖完整动作、参数和大小、原始日志、未知结果、消费者与提供者撤销、模型隔离及旧代结果。

未生成 `dist`、未完成 AI/业务基础包独立分发闭环，未做实际外部模型、CLI/SDK 子进程、浏览器、设备或性能验证。SDK 与 HTTP 契约使用真实本地包或明确开发目录，不虚构 registry 发行。清单自动扫描、公共包映射和同址旧页撤销由主代理集成验证。
