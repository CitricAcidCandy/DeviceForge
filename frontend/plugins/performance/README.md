# 性能与调用栈工作区插件

唯一 `manifest.json` 提供身份与版本。公开出口为 `.`、`./model`、`./profile`、`./services`、`./view`。

性能会话模型及 Android 性能归档实现迁入本插件；HTTP 类型仅消费独立公开的 `@deviceforge/contracts/api`，Job、设备与产物使用 SDK。保留分页、修订、来源归属、未知控制状态、原字节摘要、堆栈及画面区间规则。

工作区启用不自动开始采集。视图挂载后读取操作目录；指标采集、Root 录制与截图仍由显式动作控制。画面清理失败保留在当前工作区实例的历史清理记录中，不封锁无关操作，也不冒充当前采集失败。

业务图形继续沿用已有布局，静态样式转换为 Tailwind；图表几何保留动态行内值。火焰图校验错误使用公开内联反馈，不依赖私有全局通知控制器。

## 版本化公开服务

激活时通过公开扩展登记 `<identity.id>.api@1`；默认身份对应 `deviceforge_performance.api@1`，不占用 `host.*`。服务支持八个动作：`start`、`inspect`、`pause`、`resume`、`stop`、`samples`、`list`、`capabilities`。`capabilities` 只接受 `{ action: 'capabilities' }`；其余请求使用 `{ action, input }`，动作字段、会话 UUID、分页、采样间隔与时长沿已迁模型严格校验。请求最多 16KiB，结果最多 4MiB，按 UTF-8 JSON 字节计数，拒绝未知字段、非有限值和循环数据。

服务专属模型在第一次调用时按需创建，与视图挂载创建的模型不共享；激活不请求操作目录、不联网、不自动启动会话。调用信号、插件作用域及释放信号共同取消等待；卸载释放本代模型并撤销登记，旧句柄和晚到响应不能复活新代。成功、HTTP 错误、失败任务和结果限额错误保留本次真实日志；日志为空仍为空，不用历史日志补齐。一次失败不封禁独立新调用，未知控制状态仍遵守模型原有的同会话显式重查约束。

资源边界保持原服务契约：取消等待或卸载不是后端会话停止，不自动重放写入、不扫描并停止会话，也不把本地等待取消冒充真实后端取消。后端采样仍由明确的 `stop` 动作或会话自身终态结束。

2026-10-29（Asia/Shanghai）定点验证：新增服务单元先红 0/7，再通过 7/7；定向 strict 首次发现对象收窄不足，采用公开类型守卫修复后退出 0，并仅复跑受影响的参数拒绝用例 1/1。测试使用内存公开上下文及工作区注册表夹具，不代表真实宿主集成或设备运行结果。

旧 `host.performance@1` 兼容转调、旧 runtime 服务退役与页面适配由集成阶段完成，本插件没有修改这些宿主文件。本目录未生成 `dist`，没有进行浏览器、性能、Root 或真机验收。
