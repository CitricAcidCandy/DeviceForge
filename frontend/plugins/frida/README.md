# Frida 工作区插件

身份和版本由唯一 `manifest.json` 提供，工厂入口消费装载器传入的身份。`package.json` 仅声明独立工程的语言依赖与公开出口。

- `.`：工作区插件工厂。
- `./model`：原 Frida 规则、目录与 Job 消费模型。
- `./services`：只消费公开 SDK 的视图本地装配。
- `./view`：既有业务界面及公开 React 挂载入口。

启用时只登记 `/frida`、视图及布局，不自动查询业务、采集设备或执行脚本。打开视图后显式读取公开操作目录。卸载撤销视图作用域，已接受的后台任务不因本地停止等待而被视为取消。

旧宿主业务适配保留，删除集中装配由集成阶段负责。本目录尚未生成 `dist`，不能据源码已迁入宣称独立分发或浏览器体验验收完成。
