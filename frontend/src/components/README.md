# 公共组件

本目录是整个前端的通用组件入口，不绑定 shadcn/ui，也不绑定任何业务功能。组件可以使用已批准的第三方库，也可以是对其他第三方 UI 的统一封装；依赖安装与组件实现分别遵守项目要求。

| 目录 | 存放内容 | 输入与边界 |
| --- | --- | --- |
| ui/ | 官方基础控件，例如按钮、对话框、选择器 | 展示参数和事件；不导入上层组合 |
| common/ | 项目通用组合，例如标题、空态、表单字段、结果和错误展示 | 普通数据与回调；不识别业务服务或 API DTO |
| integrations/<库或能力>/ | 自封装的其他第三方 UI，例如编辑器、图表、播放器 | 对外使用本项目定义的 Props，集中处理库差异、事件和资源释放 |
| lib/ | 组件内部纯工具，例如类名合并 | 纯函数；不访问业务状态、网络或运行宿主 |

按真实需要建立子目录，不预建空的库封装，也不把全部组件导出到一个巨型入口。基础控件优先按文件导入；组合与封装可有各自局部 index。新增公共封装须写清 Props、受控状态、事件、加载/失败/空态和销毁行为。库私有类型不得泄漏为业务服务契约。

功能专用组件放 features/<功能>/ui，应用外壳和业务适配留 app。组件不得导入 app、features、plugins、plugin-sdk、shared/api 或 shared/jobs；需要业务数据由上层通过属性与回调注入。common 不依赖具体第三方集成，integrations 可以复用 common 和 ui，不能反向污染基础控件。

完整分层和自动门禁见[前端目录与组件约束](../../docs/前端目录与组件约束.md)。
