# 浏览器调试本地用例装配

`index.ts` 只编排当前目标、登记、UI 工具和公开调用；不包含调试界面或网络请求。
`attachment` 管理插件代次、当前语义与资源登记、按会话开启的事件和清理。
`ui` 管理精确挂载根、公开槽位和贡献挂载事实及有界 collector；`ui-parameters` 校验未知参数。
`overview` 只合并公开槽位、注入路由和当前目标贡献目录；`navigation` 管理精确路由回调和有界导航。
`report` 导出已采冻结快照页、清单和续页指示，后端负责持久化产物。
`invocation` 校验命令/服务归属与版本、显式确认及单次运行实例重载。
`validation` 负责有限 JSON、脱敏和有界等待，不执行任意对象路径或脚本。

目标必须由外层显式选择。多个挂载根不默认选首个，未实例化页面不虚构结构。
无活动选择不扫描 DOM、不记录详细事件；主动登记的当前元数据是有界发现信息，不是持续跟踪全部插件。
调用、树和报告默认不复制输入值或凭据；常见字段过滤不能识别自由文本中的所有秘密。

报告包含已采快照实际 JSON 页，不自动采树；每页 500 节点、响应 1MiB、每根十个逻辑快照。超出预算通过清单与明确续页补全；不会把未扫描或字节超限节点当成可分页内容。
导航未注入公开路由目录和回调时明确拒绝；拾取只拦截一次点击并返回明确所有者，其他插件仍需显式选择。
重载可委托共同安装钩子，回执须对应真实新代，范围和构建修订由主代理共同安装入口核实；未注入时只重载原浏览器运行实例，不宣称更新构建。
重载等待不绑定旧目标选择或旧插件作用域，其他旧代 UI 动作仍被取消；试调用缺省只返回元数据和日志 ID，显式请求才读取脱敏数据。
这些限制必须在公共服务、MCP 与中文指南中保留，不能仅因函数存在而标记首期生产可用。
