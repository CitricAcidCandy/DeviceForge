# 有界自动调试执行器

本模块由浏览器调试装配接收 `automation_run` 后调用，逐步消费原本地调试入口，不创建另一任务系统。新面板尚待可编辑设计稿和用户确认，本模块不包含界面。

计划包含一至三十二个唯一步骤，工具限定为检查、数据目录、数据读写、界面树、查询、断言、动作和公开入口调用；禁止嵌套计划、人工拾取和重载。任何变更要求计划确认，原动作确认与未知副作用声明仍保留。全计划最多二十八秒，单步最多十秒，共享原截止点，为三十秒桥命令留出收尾时间。

`bind.target_from_step` 只接受更早且完整的单节点界面查询，投影节点标识、代次和修订，并继承原挂载根；明确指定不同根会拒绝。`bind.revision_from_step` 只接受更早同数据源读取的修订，不访问任意对象路径或执行表达式。插件写入回调仍须原子比较实际修订；宿主预读不能代替插件的最终校验。

每步只执行一次。失败默认停止；允许继续时，也不能越过结果未知或取消。界面派发保留业务未知，写入后的回读只作为数据证据。`verified` 是保守的界面检查点汇总，数据写入和公开入口试调用不会据此宣称整个业务验证通过。

每步最多保留十六KiB证据，总量最多七百六十八KiB；超过限额保留字节数和省略标记。绑定只留小型节点引用和修订，不为绑定缓存完整原始结果。已完成步骤与未执行步骤均返回，凭据字段和已知秘密文本脱敏，普通业务 `value` 字段保留。任意自由文本中的秘密仍须由插件避免登记。
