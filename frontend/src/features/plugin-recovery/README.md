# 插件核对与恢复

该功能通过公开恢复 API 消费宿主状态，不依赖操作目录、设备调用入口或 ProductServices 改造。

- models 管理当前目标、查询、手动核对、取消及晚到结果；切目标撤销旧请求，代际由恢复前的 GET 获取。
- 未选择设备时仍使用插件级目标读取状态，并允许 input 为空对象核对全部投屏台账；不要求先发现设备或成功打开投屏。
- types 仅声明浏览器状态与目标，不重复定义后端 DTO；HTTP 业务类型索引生成契约。
- 正常打开前仅 GET 一次；自动核对由宿主的新会话准入执行，不自动 POST、不重放投屏或输入。
- 手动恢复最多提交一个 POST。取消已提交的 POST 后仅 GET 一次，取消等待不表示服务器回滚。
- 404 显示升级提示并保留原始错误和日志 ID，普通投屏仍沿原入口尝试；辅助 GET 失败不额外封锁普通打开，也不伪装恢复成功。
- 报告必须声明 coverage 为 plugin，以及非负整数 inspected / remaining；recovered 还须 remaining 为零、检查非空且全部 confirmed。报告消息、资源名和检查消息均非空且至多 500 个 Unicode 码点，检查明细至多 64 项，与 SDK 保持一致。
- 恢复报告是插件最近一次报告，契约未携带目标；只有本页 POST 返回的报告可以明确标记为当前目标。
