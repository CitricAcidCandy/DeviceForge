# 市场目录

市场功能读取独立资源服务的 `market.json` 目录，负责筛选、模糊搜索、上传发布和当前浏览器的地址覆盖。市场页只提供上传入口，上传发布在独立 Dialog 中按“选择资源—填写描述—确认发布”三步完成；确认前校验元数据，确认后先把原始文件流式上传到 `/api/v1/resources`，再把摘要和元数据发布到 `/api/v1/catalog`。运行时 `manifest.json` 仍由现有插件安装器管理，市场展示字段不会混入执行协议。

## 页面与目录职责

`services/catalog.ts` 解码目录并标记不完整元数据，`utils/metadata.ts` 校验发布字段，`services/download.ts` 流式计算 SHA-256。卡片、筛选、详情、配置和上传表单位于 `pages/marketplace`；公共 Dialog、Stepper、文件选择和表单组件不依赖市场业务。

目录默认隐藏内部资源。发现页支持类型、分类、适用项目及高级兼容性筛选；已安装页从真实服务器包和浏览器包目录读取，并独立获取市场描述。当前实现连接一个有效市场地址，浏览器覆盖独立保存在当前站点的本地存储中；没有完成多个外部市场的聚合去重。

## 插件安装、更新与配置

自动安装要求完整元数据、有效资源摘要及 `details.plugin_kind`，后者必须明确为 `server` 或 `browser`，不能按主题或界面分类推断。安装前先展示来源、摘要、平台、权限和重启要求；下载完成校验摘要，再交给公开插件安装器验证真实运行清单。缺失市场描述的本地插件仍可显示和卸载。

更新仅对更高语义版本开放。公开 PUT 更新接口暂存并验证新包后替换，失败保留旧目录，不使用先卸载再安装。更新后按运行状态与界面提示到插件页启用，不自动恢复旧实例。

插件配置只有在元数据明确声明以下目标时开放，使用设置服务的版本条件保存，避免覆盖并发修改。插件是否实际消费该配置由其运行协议决定，市场不猜测私有配置文件。

```json
{
  "details": {
    "plugin_kind": "browser",
    "configuration": {
      "scope": "user",
      "owner_id": "demo",
      "section": "options"
    }
  }
}
```

工具、配置和分发条目目前提供详情及校验后下载，尚未实现通用工具安装器、任意配置自动应用或这些类型的已安装清单。

## 下载、上传与取消

条目下载固定使用其来源地址；一次上传与发布也固定使用开始时的地址，避免中途切换市场导致跨来源交付。浏览器暂存上限为 256 MiB，超限或摘要不匹配明确失败；资源服务器自身仍支持大文件和 Range。

中文文件名以 `encodeURIComponent` 编码发送，并携带 `x-resource-filename-encoding: percent`。响应存在该标记才解码，兼容旧 ASCII 文件名与字面百分号。关闭上传对话框或离开市场会撤销等待并忽略晚到结果；已经到达服务器的上传不保证回滚。
