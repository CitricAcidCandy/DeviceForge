# 本机浏览器调试桥

该功能只负责已登记实例、心跳、按明确会话领取命令和一次性结果回执，不执行 DOM 或业务规则。
网络协议消费由 Rust 契约生成的类型，通过公共 API 客户端调用，不另外启动端口或进程。

- `start` 必须由产品装配显式调用，独立运行工厂默认没有调试网络副作用。
- 无活动会话仅发送轻量目录心跳，不长轮询、不扫描 UI。
- 连接中断停止领取，不自动登记新实例，不重试已执行动作或失败回执。
- 每次最多四项在途，命令从服务器剩余预算继续计时，取消只终止宿主等待。
- 关闭会撤销心跳、延迟和等待，断开登记最多等待两秒；实际可信回调的副作用可能尚未停止。

当前属于宿主底座实施批次，悬浮 UI、可导入插件、完整安装恢复与实际浏览器闭环未据此验收。
