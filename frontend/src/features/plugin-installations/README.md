# 功能插件安装

功能插件是用户安装和管理的单位，一个功能可包含服务器及浏览器组件。领域模型使用独立 camelCase 字段，HTTP 服务只能从生成契约映射，不能维护并行 DTO。

安装与更新先取得服务器计划，再提交安装 Job；Job 成功后重新读取安装目录，继续等待独立的服务器启用 Job，重新确认启用状态后再启动浏览器组件。浏览器启用失败保留独立客户端状态、日志与错误，收回本次已启动的其他浏览器组件。更新和卸载先等待旧浏览器组件清理，再等待服务器停用 Job，失败不继续删除或替换。

等待取消不自动撤销服务器任务，也不自动重放请求；失败后以独立生命周期重新读取实际目录。无令牌参数的服务器选择继承 runtime 原有 ApiClient。不可变修订属于浏览器资源地址和请求头，不混入业务 input schema。

`restore` 只恢复目录中已启用且配置完整的浏览器组件，不修改服务器启用意图。目录快照与客户端运行快照分别订阅，快照引用在通知之间保持稳定。

当前纯模型定点测试覆盖安装后独立启用、配置阻断、部分浏览器启动失败清理、旧修订拒绝、卸载顺序、清理失败和取消晚到结果；这不代表 HTTP、产品页面或真实浏览器已经验收。
