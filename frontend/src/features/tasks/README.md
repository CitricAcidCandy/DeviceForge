# 任务基础用例

## 当前目录结构

2026-10-14按用户最新约束采用 Ant Design Pro 风格的功能组织。此前 domain/application/infrastructure/ui 方案已被覆盖，不再作为当前目录约束。根 `index.ts` 保留核心公开API且不加载TSX，目录仅按实际职责创建。

- `models/`：用例、状态、订阅、轮询与会话控制；HTTP工厂在此组合注入的服务。

`models/log-search.ts` 负责完整任务 ID／日志 ID 的只读回查和关键词搜索。完整编号先尝试读取指定任务，未找到时查询服务器保留日志；关键词直接请求服务器的 `q` 查询，不读取近期任务列表。时间顺序通过 `order=desc/asc` 传给服务器，再每批最多四项读取明确关联的任务，不自动执行设备动作。全流程共用五秒等待上限，并继承调用方取消和模块释放。保留被查询的日志 ID 与本次查询请求日志的区别；关键词结果没有单一被查编号，每条日志分别携带自己的编号。缺失历史任务不丢弃已取得日志，旧服务缺少接口或拒绝新查询参数时明确要求升级。
