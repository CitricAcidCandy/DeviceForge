# 产物元数据与 ZIP 目录浏览

本模块提供选择产物、读取元数据、分页预览 ZIP 目录、上传、原字节下载和删除产物的基础用例，不提供具体业务界面。实际列表、配额管理和下载后的文件保存由各自能力负责；本批不新增产物列表或管理接口，不扩展浏览器 SDK。

## 职责与装配

- `types.ts` 定义注入网关、由生成响应组合的只读视图及浏览快照，不手写 HTTP DTO。上传和下载端口可选，缺少时返回受控协议错误。
- `rules.ts` 校验规范产物 UUID、文件名、Blob 响应、分页输入、元数据身份和目录几何关系，复制并冻结结果。
- `state.ts` 管理请求代次、选中产物、元数据、当前页、传输日志、订阅、取消和销毁。
- `index.ts` 编排网关调用；`createHttpArtifactBrowser(client)` 通过共享 API 端点消费真实生成合同。

新增 `shared/api/artifact-queries.ts` 索引生成的 GET 元数据、DELETE 删除、GET 目录响应、路径与查询参数，补对应端点和形状校验；沿现有 `client.call` 的 v2 包装、日志和取消，不修改客户端、现有网关或生成文件。

宿主可使用 `createArtifactBrowser(gateway)` 注入公开查询、删除和可选传输端口，也可使用 `createHttpArtifactBrowser(client)`。`select(id, signal)` 读取元数据；`page(query, signal)` 分页读取当前选择；`upload(filename, Blob, signal)` 保留原 Blob，核对服务器返回的文件名、字节数、媒体类型、UUID 和 SHA-256，并返回带日志 ID 的元数据；`download(id, signal)` 保留服务器返回的原始 Blob 和响应日志，不解析 JSON、不创建本地 URL；`remove(id, signal)` 调用 `DELETE /api/v2/artifacts/{id}`，成功删除当前选择后清空浏览状态并返回已校验的被删元数据。`snapshot` 分别保留 `metadataLogId`、`entriesLogId`、`uploadLogId`、`downloadLogId` 和 `removeLogId`，冲突、未知产物和取消沿 `ApiError` 保留真实日志 ID。`snapshot`、`subscribe`、`clear`、`dispose` 管理本实例消费。所有读取、传输和删除要求显式 `AbortSignal`。

## 真实合同与状态

元数据来自 `/api/v2/artifacts/{id}`。模块将 UUID 转为小写，核对返回 ID，并校验文件名、媒体类型、非负安全整数大小和时间以及 SHA-256 形状。元数据可以属于 ZIP、图片或数据文件；只有 `application/zip` 的当前选择可发目录请求。

目录来自 `/api/v2/artifacts/{id}/entries`，偏移默认 0、页长默认 50，页长范围 1–200。验证偏移不超过总条目数、本页长度为剩余条目与页长的较小值、下一偏移精确符合末尾关系；偏移等于总数时允许空页。目录项大小和压缩大小必须是非负安全整数，目录标识是布尔值。

目录预览保留中央目录原顺序、目录项和重复名称，不强制唯一、不推算文件系统解压结果。它不是提取、逐成员 CRC 校验、签名验证或可安装性验收。HTTP 目录结果没有源 ID 或请求偏移回显；客户端按请求代次与几何关系绑定当前选择，不能凭返回对象独立证明源身份，也不宣称元数据与目录是原子快照。

上传文件名沿服务器公开规则校验为不含路径的非空文件名，最长 180 字节；前端不猜测服务器配额或容器内容资格。下载只验证响应是 `Blob`，大小和摘要核对由需要完整性保证的业务消费者依据已发布元数据执行；该端口不把字节转换为字符串或 JSON。

每次选新产物立即清空旧元数据、目录、错误和日志。每次读新页清空旧页及目录日志，保留当前元数据；删除、上传和下载开始撤销同一浏览实例的旧请求并进入独立代次，成功删除当前选择后清空选择，删除其他产物则保留当前选择。失败或取消保留本次真实错误，旧页不能复活。`metadataLogId`、`entriesLogId`、`uploadLogId`、`downloadLogId` 和 `removeLogId` 分别属于各自请求，互不覆盖。

选择切换、读新页、删除、上传、下载、`clear`、`dispose` 撤销旧等待；即使网关忽略信号，晚到成功或拒绝也不能发布。caller 取消只取消本次读取或传输，不改变服务器产物。`dispose` 清空快照和订阅，后续命令拒绝；允许读取最终空快照。坏订阅不影响有效订阅，订阅重入导致换代时停止旧通知和旧结果交付。

结果建立独立只读副本，冻结快照、元数据、页、条目列表和每条目录项；网关随后修改原对象不能改变已发布观测。查询参数也建立副本，不保留调用者可变引用。未来目录或文件名展示须使用文本，不拼成 HTML。

## 本批验证

`tests/artifact-browser-consumption.test.ts` 覆盖查询回归、上传元数据与原始 Blob、下载字节与响应日志、网关缺失、取消、代次和晚到隔离，以及 HTTP 工厂接线。HTTP 用例使用注入传输夹具，不属于真实服务运行。定向测试、`tsc --noEmit` 和架构检查须由主代理在共享工作区阶段门禁中复核。

本模块未执行生成器、全前端门禁、真实服务、MCP、真实包或浏览器页面验收；主代理在阶段节点分别协调。产物列表、配额、实际解压、另一台局域网主机、视觉与完整重写仍不在本批证据范围内。
