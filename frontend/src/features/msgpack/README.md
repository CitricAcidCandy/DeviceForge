# MessagePack 基础用例

## 当前目录结构

2026-10-14按用户最新约束采用 Ant Design Pro 风格的功能组织。此前 domain/application/infrastructure/ui 方案已被覆盖，不再作为当前目录约束。根 `index.ts` 保留核心公开API且不加载TSX，目录仅按实际职责创建。

- `models/`：用例、状态、订阅、轮询与会话控制；HTTP工厂在此组合注入的服务。
- `utils/`：纯规则、转换、结果验证和计算，不依赖models、services或components。
- `types/`：业务模型与端口类型；保留已有共享契约类型。

## 职责与装配

- `types.ts` 定义转换输入、四类筛选、分页输入与业务结果。
- `rules.ts` 校验并复制输入，将规范 UUID 转为小写，补齐分页默认值。
- `results.ts` 校验宿主包装、来源、产物元数据和分页几何关系。
- `index.ts` 复用共享任务执行器，提供运行、恢复、查询、显式取消和可选原字节下载。

通过 `createMsgpack(jobGateway, jobOptions, artifactReader)` 装配。任务网关可使用现有 `createHttpJobGateway(client)`；下载能力可传入客户端的产物下载适配器。未装配下载能力时，`download` 明确失败。所有异步方法要求 `AbortSignal`，`dispose` 撤销本实例任务等待及在途下载。

## 输入与结果合同

`encode` 和 `decode` 只接受 `{artifact_id}`，分别返回唯一的 `converted.msgpack` 与 `converted.json` 宿主产物。模块核对来源、格式版本、固定文件名、媒体类型及业务大小与产物大小一致，输出不得超过 16 MiB。下载复用共享产物消费器，核对原字节的大小和 SHA-256，并保留下载请求日志 ID。

`page` 的默认偏移为 0、默认页长为 50；偏移范围为 0–100000，页长范围为 1–100。筛选支持 `equals`、`contains`、`greater`、`less`，字段名按 UTF-8 校验 1–100 字节并拒绝控制字符。点号保持单层键文本；包含匹配区分大小写。`equals` 可比较任意受支持 JSON 值，`contains` 仅接受字符串，数值比较仅接受数值。

分页结果允许任意 JSON 记录，验证 `matched ≤ total`、`offset ≤ matched`、页长度及下一偏移严格符合实际服务合同；偏移等于匹配总数时允许末尾空页。记录顺序和筛选由服务器决定，前端不重新筛选或推算匹配总数。

`byId` 复用真实查询：偏移 0、页长 1、字段 `id` 的相等筛选。ID 不要求唯一，返回完整分页结果及 `matched`，调用方可以识别重复匹配；不能将第一页记录视为唯一性证明。

## 精度与恢复边界

共享 HTTP 使用普通 JSON 数值解析。查询筛选值、按 ID 的值及返回记录递归拒绝安全整数范围之外的整数，避免将已舍入数值交付为精确整数；有限非整数浮点按 JavaScript 数值消费。完整 i64/u64 查询仍需保留整数的解析方案，当前基础用例不提供该能力。

编解码和下载保留服务器文件原字节；下载不进行 JSON 解析，因此 JSON 文件中的宽整数文本不会因前端下载而舍入。标准 MessagePack 与 JSON 转换不证明旧 DLL 私有容器兼容。

`resumeEncode`、`resumeDecode`、`resumePage`、`resumeById` 只读取并等待原任务，不重新提交。恢复必须提供原输入；服务器分页结果没有回显筛选，前端可以核对来源、偏移和页长对应关系，但无法证明恢复时提供的筛选就是原任务筛选。`queryJob` 和 `cancel` 仅接受本模块三项操作的票据。

取消等待不自动取消服务器任务；可用失败中保留的任务身份恢复，或显式调用 `cancel`。即使网关忽略取消信号，已取消或已销毁实例也不会交付晚到结果。任务提交日志、后续任务响应日志与下载日志分别保留。

## 本批验证

`tests/msgpack-consumption.test.ts` 先因缺少模块入口失败，再通过 13/13 项定点测试。覆盖编解码、四类筛选、UTF-8 边界、分页几何、重复 ID、输入副本、整数精度、取消恢复、票据限制和原字节下载核验。`tsc --noEmit` 与 `check:architecture` 均退出 0，本次架构检查覆盖 119 个源码文件。

本代理未运行 API 生成器、全前端门禁、构建或真实服务器通信；这些由主代理串行协调。具体界面、视觉、真实设备、性能与旧 DLL 容器兼容不属于本批证据。
