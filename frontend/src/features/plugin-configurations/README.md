# 插件配置

浏览器配置按服务地址和插件标识隔离持久化，修订值采用比较后写入，激活前校验声明版本及 JSON Schema。插件通过公开 `HostContext.configuration` 读取自身配置；需要重载的保存不会提前改变运行中插件的值。

服务器适配只消费公开 API 生成类型；页面视图使用 camelCase 字段。公共 SchemaForm 与配置对话框不读取该 feature，由页面注入配置回调。

敏感字段与只读约束沿本地 `$ref`、组合 schema、数组及字典解析。读取时同时遮蔽值、schema 默认值和根对象默认值；本地记录保留敏感字段的 JSON Pointer 集合，升级删除注解后仍遮蔽已有值，保存原占位继续保留原值。历史记录不保存敏感值副本。

浏览器插件配置重载等待原代清理成功，再激活新代；失败清理在当前运行实例中阻止再次启用、重载与删除，避免重复操作绕过资源收敛。新代激活成功才确认已应用修订，并恢复仍有效的原主题选择。
