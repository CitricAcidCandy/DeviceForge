# 投屏录像业务用例

`createMirroring` 消费 `plugin.mirroring.runtime.status` 与 `plugin.mirroring.record`。`rules.ts` 校验设备、1000–120000 毫秒时长及分辨率/帧率范围；`results.ts` 校验 H264、向上整秒时长、128 MiB 文件上限及真实 `screen.mp4` 元数据；`index.ts` 组合任务、原任务恢复、显式取消和原字节下载。

普通请求只提供业务设备和编码参数，后端固定关闭播放、控制与音频。消费结果明确保留 `live_stream:false`。录像任务结束并发布 MP4 后才可下载，不代表实时直播已实现。下载核对发布大小、SHA-256 和 MP4 文件头；浏览器能否解码完整视频仍需实际媒体验收。

注入公开宿主任务方法与产物下载方法即可接入。取消信号只结束客户端等待，不伪造录像结束或回滚；恢复查询使用原任务 ID，不重新开始录像。当前没有产品页面、播放器或真机直播验收。
