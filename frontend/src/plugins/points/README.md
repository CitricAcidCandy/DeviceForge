# 开放扩展点注册表

本模块复用现有插件作用域的信号与 `track`，不创建另一套插件管理器、清理队列或执行器。扩展点定义、贡献和订阅均归属创建它们的插件及代次；挂载或功能子作用域通过 `scopedPointAccess` 缩短资源寿命。

插件使用 `define` 定义自己的具名、精确版本扩展点，使用 `contribute` 向任意公开扩展点登记贡献。目标不存在时保留为等待，版本不匹配或数据不符合 Schema 时保留诊断；定义恢复后自动重新计算可用性。数据有界并冻结，Schema 复用现有服务校验器。

`list` 返回本地条目，包括组件、函数等 `payload`；渲染方只使用 `active` 条目，追加项依次消费，替换项仅消费 `selected`。`catalog` 是引用稳定的只读 JSON 元数据快照，不含本地 `payload`，可供调试和跨端传输。

选择必须由消费方显式提交，加载顺序不改变当前选择。所选贡献暂时缺失时选择保持，但 `selected` 返回空；贡献恢复后可继续提供视图，注册表本身不挂载视图、不重放业务操作。

注册表只负责目录、数据契约和所有权，不负责 DOM、布局持久化、业务参数或设备控制权限。每个注册表最多 512 个扩展点、2048 个贡献及2048项选择；单份数据不超过64 KiB、32层和8192个节点，避免无限积累。
