# 开放扩展注册表

注册表拥有组件/模块/命令/服务/任务钩子元数据，按插件和运行代次登记、冲突拒绝、取消及撤销。bus 负责事件和插件状态命名空间；invocation 负责公开调用与晚到保护。模块路径和服务版本由公开贡献声明，宿主不接触插件私有状态。

await-active.ts 只管理异步回调的宿主等待：预取消不进入回调；调用者、提供者运行代次、调用者插件或注册表寿命撤销时，即使回调忽略信号且永不返回，也以 HostError(cancelled) 结束等待。成功、拒绝、同步抛错和取消各分支移除监听，取消后的晚到 resolve/reject 被消费，不再改变已结算结果。invocation 将它用于命令/服务；registry 将它用于提交钩子，并在 dispose 标记关闭后先撤销寿命信号，再清除目录。

helper 首次结算后不回退；公开调用在交付前仍校验提供者代次、贡献身份和结果形状。结果通过这些检查并被宿主接受后，调用者随后取消不追溯撤回该结果，也不代表服务器任务被取消。资源是否继续有效由登记身份与生命周期决定。竞速无法强制中断可信回调自身副作用，也不证明插件完成清理；插件仍须登记释放逻辑。

同优先级任务钩子按 ID 排序，失败或撤销中止提交，不跳过失败插件继续写入。状态仅存于内存，卸载清除；插件只能修改自身状态、发布自身事件，可订阅公开宿主与插件事件。可信插件必须登记全局副作用的清理函数。

slots.ts 提供框架无关具名渲染适配器，默认 renderer 与插件 lease 根均受宿主所有权管理；append 保留默认，replace 独占替换位置，撤销恢复默认。mounts.ts 管理组件/模块子生命周期与根节点，不读取私有宿主 DOM。模块路由仅作为元数据，实际导航与页面等待设计稿。

FRONT-CANCEL 的确定性回归源码位于 tests/extension-cancellation.test.ts，覆盖永不返回回调、调用者/提供者/注册表撤销、调用者插件卸载、预取消零回调、晚到成功/拒绝及监听移除；不使用长时间 sleep。当前仅完成源码和静态交接，类型检查、测试及生产浏览器证据由主代理统一执行，不将等待结束扩大为副作用清理完成。
