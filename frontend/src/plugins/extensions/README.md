# 开放扩展注册表

注册表拥有组件/模块/命令/服务/任务钩子元数据，按插件和运行代次登记、冲突拒绝、取消及撤销。bus 负责事件和插件状态命名空间；invocation 负责公开调用与晚到保护。模块路径和服务版本由公开贡献声明，宿主不接触插件私有状态。

同优先级任务钩子按 ID 排序，失败或撤销中止提交，不跳过失败插件继续写入。状态仅存于内存，卸载清除；插件只能修改自身状态、发布自身事件，可订阅公开宿主与插件事件。可信插件必须登记全局副作用的清理函数。

slots.ts 提供框架无关具名渲染适配器，默认 renderer 与插件 lease 根均受宿主所有权管理；append 保留默认，replace 独占替换位置，撤销恢复默认。mounts.ts 管理组件/模块子生命周期与根节点，不读取私有宿主 DOM。模块路由仅作为元数据，实际导航与页面等待设计稿。
