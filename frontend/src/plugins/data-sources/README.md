# 公开数据源目录

本目录只登记数据源身份、读取与变更服务引用、JSON 模式和生效策略。调用经既有公开服务体系执行，不创建第二条任务或通信总线。

`createDataSourceRegistry().access(owner, services, track)` 建立插件访问入口；`owner` 提供插件 ID、代次和信号，`services.call` 保留原调用链及错误语义，`track` 绑定资源释放。子作用域使用 `scopedDataAccess` 撤销登记、订阅和等待资格。

读取服务输入为 `{}`，输出为 `{value, revision}`。变更服务输入为 `{value, expectedRevision}`，成功返回同形新快照。冲突、结果未知及服务错误原样返回，不自动重放；编辑草稿由消费界面保存，重新读取不意味着可以覆盖草稿。

目录不包含处理函数，也不读取闭包内部状态。订阅通知目录变化及本访问通道确认的成功写入；不将其宣称为服务器推送，远端状态需通过提供者公开事件或重新读取取得。插件卸载立即撤销目录；晚到结果被隔离，旧释放不能删除新代登记。
