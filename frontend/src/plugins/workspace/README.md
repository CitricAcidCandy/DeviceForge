# 开放工作区模型

本模块只管理页面、工作区与视图声明、实例身份和 JSON 布局，不创建 DOM，不调用业务挂载或设备操作。渲染宿主继续复用已有插件挂载、取消和清理预算。

## 接入

`createWorkspaceRegistry()` 为每个运行实例创建一份注册表；`access({pluginId,generation,signal},track)` 提供插件所属的 `UiAccess`，`hostAccess()` 提供根控制访问。插件定义 ID 和新实例 ID 必须位于自身命名空间；可信组合方可以显式调整其他实例的目标、可见性和提供者。

- `register({pages,workspaces,views})` 原子校验并登记本地声明，返回可撤销函数；所有权信号撤销也同步移除声明。批量校验失败不发布半份目录。
- `catalog()` 只含展示与来源元数据；挂载函数留在本地。目录和总快照在无变更时保持同一引用，返回的数据递归冻结。
- `open(input,signal?)` 要求显式选择提供者，允许 `null` 表示未选择；同一视图可用不同实例 ID 多次打开。
- `selectProvider()` 不根据注册顺序自动选择，不静默改用同类的其他提供者。
- `setTarget()` 及提供者失效或换代立即撤销旧运行信号，生成新运行代次；`setVisible()` 只发布可见性，不替业务决定停止或清理。
- `resolveView()` 给渲染桥返回本地定义、提供者所有权和实例上下文；上下文撤销后读取快照或继续订阅会明确失败。该方法不会执行 `mount`。
- `resolvePage()` 给渲染桥读取本地页面定义；目录公开接口不包含这类函数。

`scopedWorkspaceAccess()` 不创建注册表，只绑定子作用域。注册与订阅交给传入的 `track`，打开实例同时绑定子信号，真实功能或挂载作用域关闭后不会留下仍可用的实例。

## 布局和恢复

布局支持分栏、页签、浮窗、覆盖层及自定义节点，所有节点只引用稳定实例标识或提供者引用。布局验证限制层级、节点数、重复实例、分栏权重及几何值，不保存函数、信号或运行代次。

提供者撤销时实例与布局保留，状态改为缺失；提供者恢复只更新可渲染资格，不主动调用挂载或重放业务。实例打开方所属作用域被撤销后状态为 `owner_inactive`，新作用域须显式 `open` 重接，旧释放不能删除新代。

`save()` 返回纯 JSON 的稳定身份、目标、可见性与布局。`restore(unknown)` 先验证整份数据，再原子替换；无效内容不影响当前状态。恢复的实例没有旧作用域资格，必须显式重接；省略新目标或可见性时保留保存值。持久存储适配属于宿主，模型自身不访问浏览器存储或网络。

`close()` 是用户明确关闭实例，会移除实例及其布局引用；停用或卸载提供者则不会这样删除布局。根 `dispose()` 同步撤销全部运行上下文及注册，不调用任意插件清理回调。

## 浏览器存储适配

宿主可注入 `createWorkspaceStorage({registry,storage,key,maxBytes?,signal?})` 接入浏览器存储，`key` 必须由调用端明确给出，适配器不读取私有连接配置、不主动获取 `localStorage`。存储接口包含 `getItem/setItem/removeItem`，但适配器不会自动删除来源草稿。默认 UTF-8 大小限制为 1 MiB。

首次先读取未知 JSON 并通过注册表 `restore` 整批验证，再订阅变更。成功恢复不会立即重写来源；后续仅在 `save()` 的纯 JSON 内容发生变化时写入，目录或运行代次变化不会重复写。读取拒绝、损坏或超限只阻止自动持久写，当前工作区及插件仍可继续操作，原始草稿完整保留。

`snapshot()/subscribe()` 提供稳定、无原始内容的诊断。`retryRead()` 表示用户明确选择重新读取持久草稿；`saveCurrent()` 表示用户明确选择保存当前布局，可以覆盖无效源或重试失败写入。两者不自动打开视图、挂载界面或重放业务。写入失败后只接受显式重试，不借新目录通知反复写。取消信号或 `dispose()` 会撤销订阅，已取消的初始信号不会触碰存储。

## 当前证据边界

本模块提供纯模型、SDK 契约及可注入存储适配，不等于工作区渲染、外壳恢复按钮、生产存储接线或全部官方业务插件迁移已经完成。相关证据由集成和设计确认后的实现另行记录。
