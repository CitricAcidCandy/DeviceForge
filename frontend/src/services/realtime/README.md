# 宿主实时通信

本模块负责按需加载、共享 Socket.IO Manager、命名空间租约、有界恢复及关联响应校验。任务和调试业务状态继续由各自业务层持有。完整契约、示例及验证范围见[实时通信与调试确认](../../../docs/implementation/实时通信与调试确认.md)。

## 连接与兼容

每个前端宿主运行实例创建一份客户端，通过一个 Manager 复用底层连接。`/debugger` 和 `/tasks` 分别取得可释放租约，单个消费者退出不影响其他消费者。最后一个消费者退出后撤销所属初始化、定时器和连接。客户端库在首次消费时动态加载，失败不阻塞工作台初始化。

使用 `socket.io-client 4.8.4`，仅启用 WebSocket，协议路径为 `/api/v2/realtime/socket.io`。首次通过 `/api/v2/realtime/capabilities` 核对协议版本、路径及命名空间。`channel.supported` 表示能力兼容，实际就绪由 `subscribe` 的 `ready` 通知确认。

只有能力探测明确返回 `404/405/501` 时，才能将宿主判定为旧协议并交给原 HTTP 调试桥。网络失败、协议不匹配和加载错误不会授予启动第二条调试桥的资格。WebSocket 断线后继续有界恢复，避免两种传输竞争同一调试实例。

正常连接下不发周期性 HTTP 调试心跳；任务消费者完成快照同步后也应停止周期性列表刷新。首次探测、快照及业务变化后的读取仍会使用 HTTP，WebSocket 的 Ping/Pong 保活继续存在。

## 公开入口与预算

| 入口 | 语义 |
| --- | --- |
| `acquire(namespace)` | 取得指定命名空间的消费者租约；调用方最终执行 `release()` |
| `channel.subscribe(listener)` | 观察可用状态；可能同步收到当前状态，返回本监听的释放函数 |
| `channel.on(event, listener)` | 监听业务事件，单个观察者异常局部收敛 |
| `channel.request(event, value, signal)` | 在原调用信号和期限内等待 ACK；超时后仍需核对原操作结果 |
| `subscribeTasks(listener)` | 向宿主任务适配层提供变化与连接提示，返回独立释放函数 |
| `dispose()` | 撤销本实时客户端所有所属资源，由宿主生命周期统一调用 |

两命名空间共享最多 8 条待确认请求、累计 8 MiB 正文预算，单条传输消息最多 1 MiB＋16 KiB；业务正文继续服从原业务限额。这些限制约束待发送或待确认数据，不代表进程实际内存占用。

能力探测、库加载、连接与默认 ACK 等待各有 5 秒期限。重连按 0.5～5 秒退避、20% 抖动，Manager 最多尝试 12 次，单轮恢复窗口最多 60 秒。发送不设置自动重试或离线缓冲；容量不足在发送前拒绝，已经发送后的超时不能证明业务未执行。

## 任务订阅与所有权

业务插件通过公开的 `host.taskHistory.subscribeChanges?` 消费变化，不直接访问本模块。公开契约见[任务历史类型](../../plugin-sdk/task-history.ts)：`ready` 要求读取快照，`changed` 合并触发刷新，`unavailable` 保留内容并按原节奏降级；`reset: true` 要求补查，`revision` 是不透明修订而非任务正文或可排序的跨重启序号。

消费者先订阅再读快照，读取期间的变化标记为待刷新；只有连接可用且读取成功后才停止降级定时器。缺少可选订阅时继续使用原查询能力。业务卸载只释放自身订阅、读取和定时器。

宿主向插件创建作用域时，[任务历史适配](../../plugins/task-history-access.ts) 同样保留可选 `subscribeChanges`，不能只转发查询方法。订阅由作用域的当前代次检查、取消信号及资源登记管理：消费者错误局部收敛，旧引用不能重新登记，兄弟消费者独立；同步初始通知关闭作用域时，晚返回的释放句柄仍立即回收并参与异步排空。

令牌仅由宿主提供器交给连接认证，不进入 URL、插件接口或业务通知。默认免鉴权、可选令牌及任务局域网／调试本机连接的原规则保持。

## 验证边界

前端动作及检查点子任务的 25 项定向测试已通过，包含相关严格类型检查。后续任务作用域漏接修复单独执行 `tests/task-change-scope.test.ts`，9 项通过，两个生产入口和新增测试的定向严格类型检查通过；没有重跑此前四个调试测试文件。具体命令和证据见完整实施文档。

这些结果不扩展为共享连接、Socket bridge 或服务端已验收，其测试由主代理最终汇总。真实 WebSocket、浏览器、设备和性能改善幅度尚无本子任务证据。
