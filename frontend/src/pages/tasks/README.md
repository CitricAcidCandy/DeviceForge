# 任务与日志

现有搜索框输入关键词、完整任务 ID 或日志 ID 后按 Enter（或点击刷新）向服务器回查。关键词匹配服务器保留日志中的公开诊断字段，不再过滤浏览器当前加载的任务列表；近期列表的 200 项上限不限制搜索范围。状态筛选、任务选择、事件、产物与取消操作继续复用原任务用例。

任务列表、任务事件与请求日志默认按时间倒序，不再把旧的运行任务置顶。点击各处时间排序文字可统一切换升序／倒序；查询结果的切换会重新请求服务器，让服务器在匹配与排序之后截取结果，避免只把旧的一百条倒过来。

`LogRecords.tsx` 在原明细区展示保留请求日志和可复制编号，关键词结果可逐条复制日志 ID。HTTP 状态只表示请求响应，不能代替任务执行结果；未找到、只查到部分日志、没有关联任务和历史任务已不存在分别说明。查询中修改输入会取消等待，迟到结果不能覆盖新输入；输入搜索词期间暂停最近列表的自动刷新。服务器仍有扫描预算和单次结果上限，触及上限明确提示，不宣称覆盖所有历史文件。

复制使用公共 `shared/clipboard`，兼容没有 Clipboard API 的局域网 HTTP 环境；失败时保留可手动选择的完整编号。页面不读取服务器文件、不自行解析协议、不重放设备操作，不判断网络错误意味着服务器没有日志。
