# 异步资源代际

`createLatestResource` 保存最新读取快照，刷新时取消上一代；即使旧传输忽略取消，晚到结果也不发布。订阅重入发起新读取或 dispose 时，立即停止旧通知，旧调用不能继续发请求或交付旧成功；前代取消回调重入时同样复核代次。通知只遍历开始时仍登记的订阅，不把通知中新增订阅加入本轮。订阅失败互不影响，dispose 撤销请求和订阅。不承担业务 DTO 映射或 HTTP 解析。

每次 subscribe 有独立登记身份；同一回调重新登记不能继承旧通知或被旧解除函数删除。成功快照在通知开始前接受；此后仅取消调用方等待不会撤回已接受快照或成功交付，通知中发起新读取或销毁资源仍会撤销旧代交付。功能销毁须先关闭自身准入和资源，再触发寿命取消，避免取消回调同步重入。
