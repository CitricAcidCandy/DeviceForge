# 前端基础测试

`npm test` 使用 Node 22.18 以上的内置运行器执行全部 `*.test.ts`。维护测试与夹具均纳入严格 TypeScript 检查，不保留 JavaScript 副本。api 覆盖传输注入、可选鉴权、日志/错误、取消和原字节；features 覆盖晚到选择、管理取消重查和串行；runtime 覆盖 app/SDK 映射；plugin-runtime/extensions 覆盖激活与挂载回滚、独立卸载、资源逆序、跨插件服务、真实任务输入钩子及合法运行代次路径。

既有架构测试拒绝反向依赖、跨功能依赖、网络边界和动态导入绕过；生成类型仅由主代理同步。`dom-fixtures.ts` 使用 JSDOM 创建真正的类型化 DOM 节点，验证所有权和释放；网络为注入传输，外壳做 Svelte 服务端渲染。这些不是真实服务、浏览器视觉、静态包依赖执行或设备验收。
