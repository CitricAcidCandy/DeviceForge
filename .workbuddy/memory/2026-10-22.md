## 经验

- 本项目 Tailwind 工具类会被 `src/app/styles.css` 里的无层全局规则压过（如 `* { border-color }`、`[data-slot='button'] { border-radius: 4px }`）。涉及 border 色、按钮圆角时优先用 `after:` 伪元素或显式 arbitrary 值，而不是假设工具类生效。
- `[data-slot='button']` 会被 Sheet/Dialog trigger 的 asChild 覆盖掉，导致这类触发器丢失 4px 圆角与移动端 44px 最小高度。
