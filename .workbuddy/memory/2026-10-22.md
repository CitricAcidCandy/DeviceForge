## 终端页 v3：左栏撤掉，改会话带（`output/design/terminal-v3.html`）

用户选中左栏（`2:144`）反馈「占空间、会话和档案混着很奇怪」，并问插件是否支持会话恢复。查了应用层与前端模型，结论如下（都是本次新证据）：

- **会话 ID 是 UUID v4**（`session-gateway.ts` 的 `normalizeSessionId` 只收 UUID）。设计稿里写的 `sess_8f3a2c` 是假的，页面现有 `id.slice(0,8)` 显示的是 UUID 前 8 位。
- **会话只活在服务进程内存**：`crates/application/src/interactive/mod.rs` 的 `Sessions.entries` 是 `BTreeMap`，`RECORD_LIMIT = 8`、`ACTIVE_LIMIT = 4`、输出 16 MiB。`交互会话连续输出实施.md` 明确「本批不是持久化会话或跨服务重启恢复」。所以「恢复」= 同一进程内重新接上，刷新页面/换标签页有效，重启后端即全丢。
- **恢复后不能输入（真 bug）**：`open` 把 `inputState` 置 `writable`，`resume` 置 `unknown`，而页面 `writable = inputState === 'writable'` → 接回旧会话后输入框永久禁用。同时 `resume` 会 `selectionReset()` 清空 chunks、游标归 0，页面只剩空态，必须在底部手动点「持续读取」才看得到输出。即：**接回 = 白屏 + 死输入框**。
- 因此「按 ID 恢复会话」这个入口本身站不住：ID 是 UUID，没人手输；列表来自 `session_records`，接回应该自动。

设计决定（v3，静态稿已出）：**删除左侧 248×639 的面板**，会话改成终端上方 32px 标签带（状态点 + 档案标题 + 时间），终端宽度 876→1140；**档案降级成「新会话」按钮里的菜单**（档案只是开哪个插件的参数，不是浏览对象）；带宽右侧显示 `运行 1 · 记录 3/8`，把服务端上限变成可见事实；接回的会话在输入条显式标「可写性未确认」并保持发送可用，不再静默禁用。

静态稿四块：01 运行中、02 未打开、03 档案菜单明细、04 接回旧会话。画布工具本轮不可用，未同步到 Ardot 文件（原 v2 仍在 739122463979201）。

## 设备页画面放大 + 可拖动缩放 + 右栏加宽 + 全站字号上调一档（同日）

- 画面变小的根因不是框宽，而是**高度**：`.media-frame` 写死 `height: min(100%, 640px)`，且读数/胶囊是流内元素又吃掉约 85px。改成「上下两条预留带子（`padding: 28px 20px 52px`）+ 读数与胶囊绝对定位」，中间全部给画面。
- 尺寸不再用 JS 量：`.workbench-stage` 加 `container-type: size`，框高 `calc(min(100cqh, 100cqw * var(--frame-fit-inv)) * var(--frame-zoom))` + `aspect-ratio: var(--frame-ratio)`，`--frame-ratio`/`--frame-fit-inv` 由 `videoSize` 内联给出。竖屏受高限、横屏受宽限，同一公式；`margin: auto` 负责居中且溢出时不裁头。
- 自定义大小：右下角 `.media-zoom-grip`（`role=slider`，拖动 / 方向键 / 双击复位），`--frame-zoom` 0.6–3 存 localStorage。实测 1536×1024：100% → 390×833，150% → 586×1250（舞台 `scrollHeight 1330 > clientHeight 913`，内部滚动而不是撑开整页），60% → 234×500 居中。
- 右栏 `--workbench-rail-width` 296 → 384（+30%），断点 264→344、240→312。1536 下舞台 916、画面 390×833，比原来 300×640 大 30%。
- **右侧空带的真凶是 `.workplane` 的 `scrollbar-gutter: stable`**：设备页不需要滚动，那 15px 槽位就是一条空白。设备路由加 `overflow: hidden; scrollbar-gutter: auto` 后，实测 1536/1366/1920 三档 `scrollWidth === clientWidth`，工作区右缘贴到视口边。
- 字号：写脚本按 `font-size`/`font` 声明与 TSX 的 `text-[Npx]` 一次性上调一档（9→11、10→12、11→12、12→13、13→14、14→15、15→16、16→17、17→18、22→24，≥24 不动），32 个文件；Tailwind `@theme` 里 `--text-xs/sm/base` 同步改成 0.8125/0.9375/1.0625 rem，否则 `text-sm` 会和手写的 15px 打架。
- 顺手把 `check-ui-policy` 的行内白名单放开 `--*` 自定义属性：拖拽尺寸与主题都只能走这条通道，颜色/字号仍禁止行内。
