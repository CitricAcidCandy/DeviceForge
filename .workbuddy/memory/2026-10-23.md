### 追加：拆掉共用白面板，三页换成不同构图（用户第二次说"还是一样"）

- 诊断：上一轮只换内部组件，但三页仍共用「白色圆角面板 + 面板头 + 发丝线」，所以第一眼还是同一个壳。**壳不拆，怎么加组件都一样。**
- 改法（同一个文件）：
  - AI 助手 `2:575` 去壳（`fills/strokes/effects` 全清、`cornerRadius:0`）→ `[fill 留白][白纸 720 通高，圆角 2 + 1px 投影][1px 线][深色柱 300]`；白纸装会话，深柱装"运行旁批"。旁批内 20+ 个文本全部转浅色（标题 `#E9EEF4`、参数值 `#C9D2DE`、参数名 `#8A939D`、分组 `#6B7280`、分隔 `#232833`、关态开关 `#333A46`）。
  - 任务与日志 `2:587` 去壳 → 标题与筛选直接浮在底色上；`splitB` 由 `gap:1/#E6EAF3` 改成 **`gap:8` + 底色缝**，列表卡与明细卡各给 `cornerRadius:8`；明细 `2:425` 整体 `#14161C`，日志窗 `#0B0E13`，提交块 `#0B0E13`，按钮转深色描边（`#1E232C` 底 + `#2C333F` 边），取消按钮文字 `#F08CA0`。
  - 设置 `2:578` 去壳 + 删头部发丝线 → 四个分组各自变成白卡（`#FFFFFF` / 圆角 8 / `#E9EDF5` 描边 / padding 18），直接铺在底色上，右列底部保留深色 JSON 窗。
- 结果：四页深色占比 100% / 55% / 25% / 8%，遮住标题也能分出谁是谁。
- 又一次确认：**给分组容器加 padding 会同时把组标题和行内边距一起推进去**，所以卡内行宽要按 `卡宽 - 2×18` 重新核对，否则 label 与控件会被挤到换行。
