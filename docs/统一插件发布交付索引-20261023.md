## 交付内容与使用边界

市场安装单位为完整功能插件。`release.json` 绑定服务器组件、可选浏览器组件、固定版本工具及各自摘要；用户提交一次安装，服务器准备依赖、生成资源绑定并管理组件生命周期。在线安装和完整离线 ZIP 使用相同用例，HTTP、MCP、前端和 CLI 共享任务与日志关联。

宿主程序和主网页资源随 npm 包分发。用户安装的插件、工具、安装记录和配置固定保存于服务器 `DEVICEFORGE_USER_DIR`，默认 `~/.deviceforge`；业务 `--data-dir` 和 npm 缓存均不改变这些目录。卸载默认保留配置，共享工具受活动发布、上一发布、事务和实际使用保护。

账号、API 密钥、项目目录、签名证书与设备授权仍属于用户输入。发行模板不保存构建机器路径或用户凭据；缺少必要业务输入时显示需要配置。工具供应的本地与远端来源使用通用 `requirements.any_of`，托管模式无需手填安装根。
